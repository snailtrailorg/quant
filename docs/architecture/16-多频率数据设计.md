## 1. 分层心智

```
慢路径（日/周/月）                快路径（分钟/盘口）
  bar_1D 直读（复权权威）            1min 滚动 history（现状不动）
  → 暖机预载 + 日界沿刷新            → on_bar 实时喂（现状）
  → ctx.daily / ctx.resample         → ctx.history / ctx.order_book(Phase 2)
策略信号 = 慢层方向过滤 × 快层触发执行
```

## 2. 数据契约（两个 ctx 对称扩展，向后兼容）

| 字段 | 语义 |
|---|---|
| `ctx.history` | 1min 滚动窗口（现状，不动） |
| `ctx.daily` | 日线 `list[dict]`，**截至当前 bar 的交易日之前**（cutoff 由**当前 bar 的 ts 日期**推导——A-F3：测试平台夜间回放下墙钟"昨日"会把未来日线放进 ctx，`ts < bar_date` 才与回测 ≤D-1 断言同构；暖机期 cutoff=预载 history **最新一根**的日期（K 曲解#1：三种读法钉死此一种，收敛后与日界沿一致），仅当 history 为空才允许墙钟） |
| **NULL adj_factor 降级**（K 补） | 行级因子为 NULL 时**视为 1.0**（未复权原价参与聚合）+ 暖机断言非空率：声明 `1d` 且窗口内非空率 <100% → 限频告警（system warn"复权因子未回填，跨除权日因子失真"）但不拒跑——积分到账回填后自动收敛 |
| `ctx.resample("W"\|"M"\|"Y")` | 从 ctx.daily 重采：**先复权后聚合**（close×adj_factor→ohlc 聚合；volume 不乘因子）+ **头尾残根都丢**（窗口起点桶同样不完整）+ 单 bar 内缓存（键=`(freq, daily 末行 ts)`） |
| `ctx.order_book` | Phase 2：分钟末五档；无则 None |

**缺省语义（A-S6）**：未声明 `1d` → `ctx.daily = None`（注册期禁止 DSL 引用）；声明但无数据 → `[]`（触发新鲜度校验告警）。

**回测 ctx.history 语义声明（A-F4，既有裂缝显式化）**：回测现为**日线回放**（`tasks.py` 写死 1D、无 freq 参数）——`ctx.history` 在回测=日线、实盘=1min。**任何消费分钟语义的因子不可标 backtest_verified**（三级开关第三级校验加此规则）；根治（1min 回放通道）另立任务。

## 3. 需求声明（配置驱动）

```jsonc
// 策略级 params（唯一通道——B-S1：砍任务级 needs，浅合并会整体覆盖丢键）
"needs": {"1min": 100, "1d": 250}    // 缺省 {"1min": 100}，老策略零改动零查询
```
```python
@register_factor("ma20_daily", category="trend", needs_daily=20)   # DSL 因子从注册表聚合
```
- 框架按声明只载所需：未声明 `1d` 连 PG 都不查（零开销）
- **窗口换算**：`1d: 250` 交易日 ≈ 日历 380 天（`timedelta(250)` 只够 ~170 日——A 陷阱）；或直接用交易日历
- **scope**：仅 A 股系三品类（B-S6：crypto 无日线源、日界定义不同；needs 命中无源市场启动即告警拒跑）
- **resample 下限校验**（A-S4 后半，K 补）：注册期按目标频率推窗口下限（W→5n+10、M→22n+5、Y→拒绝或日期对齐）并**报错**而非运行期静默短窗（250 日≈50 周，52 周均线静默降级、`resample("Y")` 恒空都是此洞）
- **合成规则**（K 矛盾#3）：策略级 params.needs 与注册表聚合 needs_daily 合成=**按 freq 取 max**；"未声明"指合成后的有效声明
- factor_def 加 `needs_daily` 列（alembic 迁移 + load/register + Web 表单三处同步）

## 4. 刷新语义（三处同构，一份函数）

```python
def maybe_refresh_daily(bar_ts, state: dict, loader) -> bool
```
- 暖机（启动/重启/暖机补缺）：预载 bar_1D（cutoff=首根 bar 的日期）
- **日界沿 + lazy 校验**：新交易日首根 bar 时重查一次；此后**每 20 根 bar** 比对 `ctx.daily 最末日 >= 上一交易日(对 bar 日期)`，不符重查+限频告警（A-S1：单发沿在 `_guard` 吞异常区一次失败=整天冻结无告警；沿只是提前刷新的优化）
- **隔离与超时（B-S5，K 补）**：重查自裹 try/except——失败**退回旧 daily**+告警，绝不丢当根 bar（信号/bar_shadow 落库在 handler 尾部，不能被日界查询连坐）；direct 模式重查跑在 vnpy **事件线程**内，连接超时 ≤2s（开盘首分钟是 tick 高峰）
- rewarm/gen_jump/`factor:recalc` 触发：**多频刷新**（history + daily 一起，A-S3）
- direct/hub 注入 PG loader，**回测注入内存切片器**（B 简化：预载全区间日线一次，每 bar `ts < bar_date` 切片——零逐 bar PG 往返，与 live 严格同构同一纯函数）

## 5. 数据纪律（写进实现与测试）

1. 日线直读 bar_1D，**永不从 bar_1min 重采**（除权日聚错）
2. 先复权后聚合；volume 不乘因子。**复权口径=逐行乘各自因子（后复权比值链）**——历史值不随窗口移动重述、跨窗天然可比（52 周均线各窗同标尺）、与 B-F1"append-only 因子不漂移"裁定同向；~~窗口末日锚定~~（前复权式归一）会逐窗重述历史，弃用
3. 头尾残根都丢；W 用 W-MON（周标签落交易日）
4. **ts 类型统一** `tz_convert('Asia/Shanghai')` 后取 date（现状 PG aware/vnpy naive/hub ISO 三混——A 陷阱）+ PG timezone=UTC 环境测试；共用日界工具**只许看 date() 禁 HH:MM**（direct 分钟首标注 vs hub 分钟末标注，K 补）；日界沿插在 ts 去重之后（回放重复 bar 白触发，K 补）
5. 复权一致性（K 修订）：逐行因子链下同一历史 bar 重采值恒定（不重述）；除权日**之后**的窗口自然跳变（真除权，非重述）。signal_log 记窗口末日 adj_factor 供审计（A-S5）
6. IPO 短窗：不足声明窗口不报错，sma 类自然降级（契约写明）
