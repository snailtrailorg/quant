# 24 - 多源架构总方案（历史/实时/交易三层，单源激活）

> 状态：方案 v5 整合版（待双盲审）。整合 24 号多数据源 + 25 号限速聚合 + 能力矩阵/供给矩阵/归一化，并把实时/交易纳入统一「单源激活」原则。

## 一、分层模型与统一原则

| 层 | 平台 | 抽象接口 | 注册表 | 单源选择 | 现状 |
|---|---|---|---|---|---|
| **历史数据** | Tushare/聚宽/米筐/腾讯(特例) | `BaseDataAdapter` | `_ADAPTERS` | `sync_config.provider` | 24 号已做核心 |
| **实时行情** | XTP/同花顺/券商 | vnpy `BaseGateway` | vnpy 网关体系 | 行情源配置 | 已抽象（ThinGateway） |
| **交易** | XTP/券商 | `Broker`（broker.py） | `get_broker` 注册表 | `strategy_account.broker_provider` | 已抽象（XTPBroker） |

**统一原则（用户 2026-09-07 裁定）**：
1. 每层「抽象接口 + 多实现注册表 + **单源激活** + 可切换」。
2. **暂不做多源并存**（不做主备降级、不做双源同时写——同一数据/同一账户同一时刻只一个源）。
3. 切换源 = 历史重建（delete+backfill）/ 实时交易重连。

## 二、历史数据多源（本方案主体）

### 2.1 抽象 + 归一化（✅ 已做 + 待补归一化）

`BaseDataAdapter` 已做：`pull_daily`/`pull_minute`/`to_bar_rows`（11 字段唯一出口）+ `pull_daily_batch`/`pull_adj_factor` 能力方法。mapper 三合一已完成（金标准测试兜底）。

**待补：归一化方法（预留多源）**——三平台接口规范对照（Tushare `.SZ`/聚宽 `.XSHE`/米筐 `.XSHE`；`1min` vs `1m`；`qfq` vs `pre`），接口加 3 个带默认实现的方法（Tushare 直通，聚宽/米筐覆写）：

```python
def to_source_symbol(self, symbol) -> str: return symbol   # 内部 ts_code ↔ 源格式
def to_source_freq(self, freq) -> str: return freq         # '1min' ↔ '1m'
def to_source_adj(self, adj) -> str | None: return adj     # 'pre' ↔ 'qfq'
```

### 2.2 限速抽象聚合（25 号，待编码）

`RateLimitPolicy` 策略模式替代「四层覆盖」：
- `FixedIntervalPolicy`（Tushare：间隔秒，类默认 + DB 覆写两级）
- `DailyQuotaPolicy`（聚宽/米筐：每日额度 → 平均间隔）
- `DataSource` 持 policy，`get_rate_limit` 委托；engine/`rate_limit_context` 零改动
- **去掉**：`POINTS_PRESETS` 积分档、`points_tier` 层、`rate_time_overrides` 时段乘数

### 2.3 能力矩阵 + 同步项级 provider + 切换重建（待编码）

- **能力声明**：`data_source_config` 加 `capabilities`（JSON 数组：该平台能提供的 `sync_id` 清单），DB 可改（平台可变/同步项可增）。
- **同步项级 provider**：`sync_config.provider`（24 号已加列），每同步项单选平台。
- **标的集天然分流**：`bar_1D` 被 astock/etf/cb 三任务写，但标的集不重叠（`.SH/.SZ` vs `.OF` vs `123xxx`），唯一键 `(symbol,ts)` 已够，**source 不进唯一键、schema 零改动**。
- **冲突防护=切换重建**：切换某同步项 provider，该同步项标的重建（delete + backfill），否则历史 source 混列 + 唯一键写不进。

## 三、实时接口多源（已抽象，明确化）

- vnpy `BaseGateway` 抽象 + `ThinGateway`（hub 行情）+ `GuardedXtpMdApi`（XTP 实现）。
- 加同花顺 = 实现 BaseGateway 子类 + 行情源配置切源。
- 单源激活：hub 一个行情源（`system_config` 行情源键），切换=重连（不动历史数据）。

## 四、交易接口多源（已抽象，明确化）

- `broker.py` `get_broker(provider)` 注册表 + `XTPBroker`；`adapters.py` `{"xtp": XTPAdapter}`。
- 加券商 = 实现 Broker 子类 + 注册 + `strategy_account.broker_provider` 选源。
- 单源激活：每策略账户一个 broker_provider，切换=该账户重连。

## 五、UI 设计
