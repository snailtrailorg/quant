# A02 · 外部接口与市场维度设计（批189 修订：接口三类）

> 状态：**批55 立法，批189 修订**（2026-11-18）。原「行=账号 / 列=能力 / 页签=能力过滤」已被接口拆分取代；本文件是修订后的现行真源。
> 与 D32 关系：插件/端口/manifest 细节以 D32 为准；本文只保留维度栈与接口实体立法。
> 需求与迁移：`flow/方案/批189-TD-MD接口拆分-现状与需求.md`。

## 一、核心立法（修订后）

1. **行的边界=接口**：行情接口、交易接口、数据源各一表一行；同一券商/交易所的 MD 与 TD 是**两条独立配置**（各自 provider/凭证/参数/启停）。
2. **列的语义=能力**：能力由「接口类型 + provider manifest」派生，页面只读；写侧校验「类型 ⊆ provider 声明」，越域即 400。
3. **页签=接口类型**：集成中心分「行情接口」「交易接口」「数据源」；不再用能力做页签，也不存在“一份配置多处可见”。
4. **身份=code**：三类接口的对外身份是 `code`（`md-*/td-*/ds-*`），系统实例名、Redis 键、API、日志、UI 一律用它。

**为什么拆**：原「一账号一行同时承载 MD+TD」导致 (a) 同一物理账号无法独立启停行情/交易；(b) 行情订阅源按账号过滤，A 股标的灌进加密 hub；(c) TD 取价映射与 MD 生命周期耦合。拆分后三者各自独立、可分别启停、映射显式。

## 二、维度栈（不变）

```
市场 market（A股/加密）
 └─ 交易所 exchange（XSHG/XSHE/BJSE；XBIN/XOKX）
     └─ 板块 board（规则以交易所属性承载）
         └─ 品类 category（stock/etf/convertible/fund/reits/perp）
供应商 provider（tushare/tencent/xtp/emt_emq/binance_perp/okx_perp）
```

- 交易所覆盖用 `exchanges text[]`（NULL=全所）；权限五键经 `MARKET_OP_DECOMP` 无损映射（不动权限键）。

## 三、能力模型（三类域）

| 接口类型 | 域 | 允许能力 | 说明 |
|---|---|---|---|
| 数据源 | `data_source` | hist_quote / ref_data / inst_event | 历史与参考数据拉取 |
| 行情接口 | `market_interface` | rt_quote | 实时行情（订阅/推送） |
| 交易接口 | `trade_interface` | trading | 下单/撤单/持仓/资金 |

- 能力真源=代码（adapter/端口声明）；配置列是启用子集，写侧 `check_capability_subset` + 域集校验。
- 三域集合互斥（同一 token 不得落两域），并有「并集=全部 token」守门（随代码词表）。
- 交易能力是否可启用由**插件载体**决定：无 `execution` 实现的 provider 不得建可启用的交易接口（页面标「待接入」）。
- **注册实体按域**：一个 provider 在每个接口类型各注册一次（XTP = 行情实体 + 交易实体，无数据实体）；`registry.DOMAIN_PORT_CAPS` 在注册时校验实体只声明本域端口。
- **就绪判定只看载体**：建进程/进下发 = 行存在 ∧ provider 在该域有载体；`enabled` 只管干活/空转，`impl` 只是形态标记（I4）。

## 四、分层与守门

- 注册表/词表在 `quant_common`（层 0）；能力校验在 `data_platform`（层 1）；入口层不得内联 SQL。
- 接口表 CRUD 由 `web_api/routes/interfaces_api.py` 三族端点提供（md/td/ds，`code` 身份）；能力/域校验复用 `data_platform/capabilities.py`（`IFACE_CAPS`）。

## 五、边界

- 短信/邮件/LLM 不并入接口表（无市场语义、凭证体系异构）。
- 历史/参考数据仍走「数据源」页签，不并入行情接口（D4）。

## 六、配置存放（不变）

- `.env` 只放加密密钥；其余配置入库，敏感值 Fernet 加密存 `credentials_encrypted`。
- 鸡生蛋例外：DB/Valkey/Celery 连接串留 `.env`。
- 迁移次序：先建库行验证，再清 `.env` 值。
