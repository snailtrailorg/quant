## 五、M2 路由内核

**职责**：RoutingTable 合成+resolve（硬过滤/软排序/**bulkhead 闸门**/审计）+供给消费分叉+热更新。
**边界（不做什么）**：不实现 adapter fetch（只选不拉）；不管流（M5）；不管交易切换（M6）。

**契约**：

```sql
CREATE TABLE routing_policy (
  consumer_tag text PRIMARY KEY,
  weights jsonb NOT NULL,
  bulkhead_defaults jsonb,                    -- per-adapter 并发闸门阈值（Quality 派生初值可覆写）
  trade_switch_confirm_timeout_s int NOT NULL DEFAULT 300,  -- M6 消费（人审信息包时限；读类 failover 不消费此列）

  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  ts timestamptz NOT NULL DEFAULT now(),
  fingerprint text NOT NULL,
  req_summary jsonb NOT NULL,                 -- 四审架构建议：kind+symbols 数+mode——审计可解释
```

```python
class RoutingTable:
    def resolve(self, req: DataRequest) -> CandidateChain: ...
    def epoch(self) -> int: ...
@dataclass(frozen=True)
class Candidate:
    adapter: str; account: ExternalInterfaceRow; is_local: bool
class CandidateChain:
    candidates: tuple[Candidate, ...]; epoch: int
    def fetch(self, skip: set[str] = frozenset()) -> ContractFrame:
        """链式下移（四审架构 P3 立法）：
        ① 依序取候选（跳过 skip 集）；② SourceUnavailable → 下移下一候选；
        ③ bulkhead：候选在途请求超闸门 → skip_busy 审计+下移（防风暴打死备源）；
        ④ 全链尽或 deadline_ms 耗尽 → 抛 SourceUnavailable(timeout)；
        ⑤ DataGap → 尝试覆盖更广的后续候选，全 DataGap 则抛 DataGap。
        '无循环'= 不重入 DataBus.get（on-miss 在链内完成，不回门面）——
        非放弃 failover（28 §6.2 '一切读类'不变）。"""
```

**bulkhead 机制本体（四审架构 P4① 回填）**：per-adapter 并发闸门，计数器住 **Valkey**（跨进程风暴同防：web+celery+hub 同时 failover 场景）；阈值=adapter Quality.rate_profile 派生初值+DB 可调（routing_policy 加列 `bulkhead_defaults jsonb`）；两态审计（skip_busy vs skip_unhealthy——"为什么没用 B"两种答案分开记）。

```sql
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
```
