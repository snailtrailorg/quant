## 状态注记约定

- 每份文档**头部 blockquote 记录重大变更注记**（含日期）；批次类状态（进行中/✅）一律指向 `flow/待办.md`，不在架构文档里重复维护计数。
- 设计文档描述"为什么与是什么"；代码签名以模块契约为准；两者矛盾时**以代码+契约为准并回写本文档**。
- 已废弃/已吸收文档移 `docs/obsolete/`（清单见其 README）；外部参考在 `docs/reference/`（索引见其 README）。
