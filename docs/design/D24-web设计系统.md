### 1.2 语义色（金融语义，最关键的决策）

**默认遵循 A 股习惯：红涨绿跌**（平台主战场为 A股/ETF/可转债，目标用户为中国交易者）：

| `--flat` | `#8A93A6` | 平 |

| `--critical` | `#7F1D1D` | 严重（独立深红，区别于 `--up`，且强制配图标+背景，绝不裸文本） |
| `--success` | `#0E8388` | 成功反馈（青绿系，与跌色 `--down` 色相拉开 ≥30°；仅用于 toast/操作反馈，必配 ✓ 图标） |

暗色变体（盯盘场景核心，初版遗漏）：`--up:#F0565E`、`--down:#3DBE8B`、`--warn:#E8A33D`、`--critical:#FF6B6B`、`--success:#2DD4BF`——全部在 `#151D30` 画布上 ≥4.5:1。

规则：
1. `--up/--down` **只用于价格与盈亏方向**，`--success/--critical` 只用于操作反馈与系统状态——四令牌四色相，互不借用（初版 `--success` 与 `--down` 同值 #0E9F6E 属自撞，已修正）
2. **默认按市场分色**：A股/ETF/转债页=红涨绿跌，crypto 页=绿涨红跌（perp 用户习惯国际色，7×24 高压市场误读代价高）；设置中提供全局覆盖"跟随市场/统一中国/统一国际"。初版"沿用全局"判断被盲审驳回，采纳分色默认
3. 现状代码里 `daily_pnl>=0 ? #67c23a : #f56c6c` 是国际惯例，**必须全局替换**
4. 涨跌信息必须双编码：颜色 ± 符号/箭头（色盲安全），halted/熔断状态用静态红底+图标，**不用闪烁**（光敏）

## 2. 字体

```css
/* 全局 */
font-family: -apple-system, "PingFang SC", "HarmonyOS Sans SC", "MiSans",
             "Microsoft YaHei", "Segoe UI", Roboto, sans-serif;
/* 数据数字（价格/数量/百分比/代码） */
--font-num: "JetBrains Mono Web", ui-monospace, "SFMono-Regular", Consolas, monospace;
font-variant-numeric: tabular-nums; /* 表格列对齐的生命线 */
```

等宽字体**自托管 woff2 子集**（仅数字+符号，~10KB）——大陆网络无 CDN，外链字体必挂，回退漂移会毁掉 tabular 对齐（盲审修正）。

字号阶梯（px，语义化六级——每级绑定角色，大数字是稀缺资源）：
25 KPI 数字（一屏 3~5 个，唯一大数字）｜18 页标题（一页 1 个）｜14 卡片标题｜13 正文/表格/Banner（基线）｜12 表头/Tag/标签/分组名｜11.5 注脚/图例/状态栏。
层级由三维合成而非字号堆叠：字号(6) × 字重(400/500/600) × 灰阶(text1/2/3)。数字列右对齐 + tabular；≥1800px 基线 13→13.5、KPI 25→27。
KPI 数字用 `--font-num` + `font-weight:600`。（原型 v2 收敛：注脚统一 11.5、Banner 并入 13；文档原 16/20/28 按 B 端密集实践下调为 14/18/25）

## 3. 数字与人机惯例（金融产品的地基）

1. **千分位 + 中文单位**：`1000000000 → ¥10.00亿`；表格中 `73.321`、`4996546 → 4,996,546`（股数）或 `499.65万`
2. **精度规则**：价格 2 位（可转债 3 位）、百分比 2 位带符号、份额整数千分位；涨跌幅显示 `+1.24%` 带符号着色
3. **证券代码规范**：**展示与内部同形** `600000.XSHG`（批177 起 canonical=MIC；禁止剥后缀上屏，守门 `server/tests/test_web_symbol_display.py`）
4. **时区**：一律北京时间；时间显示 `08-29 14:54`（同年省略年份），精确到秒仅日志/审计用
5. **空值**：禁止显示 `null/undefined/NaN/缺`（现状 selection 结论里 "winner_rate=缺"）；统一 `—` + tooltip 说明原因

## 4. 布局与组件

1. **侧边栏 220→240px**，支持折叠至 64px 图标模式（记忆状态）；分组标题 11px+降低字重/透明度（中文无大写，初版"全大写"表述对中文无效——盲审修正）
2. **顶栏**：左侧面包屑 + 全局搜索（⌘K，搜策略/标的/因子/任务）；右侧市场开闭市状态灯、通知中心、用户
3. **表格**：表头吸顶、行高 40、斑马纹去掉（用 hover 高亮替代）、右对齐数字列、固定操作列、行点击进详情
4. **KPI 卡**：数字 + 环比箭头 + sparkline（7 日），不再是一个裸数字
5. **危险操作分级（盲审仲裁修正：确认强度对称于代价，而非动作本身）**：
   - 停实盘任务/终止回测=确认弹窗（显示影响面）
   - **风控熔断=轻确认**（一键急停，慢半拍=真实亏损；误触代价=再点一下恢复）
   - **风控恢复=输入确认**（恢复=重新暴露风险，才是强确认该在的地方）
   - 删除数据源/账号/策略=二次确认+红色按钮；删除被引用对象先提示引用清单
6. **图表**：统一 ECharts 主题（与令牌一致）；净值曲线标配：净值+基准双线、回撤面积图（副轴）、区间选择器
7. **图标**：弃用 emoji（🔔）；统一 Element Plus Icons 或 Lucide，一个语义一个图标（现状 ChatDotRound 被 4 个页面混用）

## 5. 令牌落地方式

Element Plus 落地要整组做（初版低估，盲审修正）：
1. 品牌色需覆盖预计算 ramp：`--el-color-primary-light-3/5/7/8/9` 与 `--el-color-primary-dark-2`——只覆盖 `--el-color-primary` 的话 hover/选中/disabled 仍是模板蓝
2. 暗色需引入 `element-plus/theme-chalk/dark/css-vars` + `html.dark`
3. 全部令牌收敛到一个 `tokens.css`；另补基础令牌：间距 4/8/12/16/24/32、圆角 4/8、阴影两档、z-index 三档、focus-visible 样式（键盘可达）
4. 工程上无需换组件库。

## 6. 跨平台字体与布局韧性规范（2026-08-31 增，详见 14 号方案）

**背景**：Windows 默认 150% DPI 下有效 CSS 视口缩水（1920×1200 → 1280×800），叠加微软雅黑度量差异——必须按"有效视口"而非物理分辨率设计。

1. **字号令牌视口驱动**（单一驱动源 --fs-body，其余字号按比例挂靠）：
   `--fs-body: clamp(12.5px, calc(9.5px + 0.234vw), 14px)`（@1280=12.5 / @1707=13.5 / @1920=14）；
   `--fs-kpi: calc(var(--fs-body)*1.92)`、`--fs-page: *1.38`、`--fs-label: *0.92`、`--fs-foot: *0.87`；EP 字号变量桥按**站内消费面实证**挂令牌（通用组 base/small/extra-small/large + 批168 扩面 16 个组件变量——完整清单以 tokens.css EP 变量区为真源；未消费组件不臆造）
1b. **标题级元素统一档（批167 立法/批168 成文）**：标题级元素（内容卡卡头 / 页签标题 / 弹窗标题 / 折叠头 / popover 标题 / alert 标题）**字号=fs-card、字重=600**——层级靠三维合成但标题级例外地同档同重，禁止散落各档（批167 页签 13.99/500 vs 卡头 16.09/600 案即此类违规）

   **注（批170，唯一特例）**：标题栏语言钮拉丁短标（「EN」）用 15px——汉字与拉丁在同一字号下墨迹高度差 3–4px（汉字约 0.93em、拉丁大写约 0.72em），15px 为用户实看选定的光学补偿值。该处内联 px 以 `token-ok` 行标记豁免令牌门，**不得复制到别处**。
2. **断点按有效视口**：≥1707 完整布局｜1280–1706 侧栏自动 64px 图标模式（用户手动展开记忆优先）｜<1280 保底可用（桌面优先立场，小屏场景由 IM 承接）
3. **行高三档令牌**：`--lh-tight:1.3 / --lh-base:1.5 / --lh-loose:1.7`，覆盖 `--el-font-line-height-primary`，body 默认 1.5——中文 UI 必须显式行高（雅黑默认 1.32 会挤压）
4. **字体栈（自托管后）**：`--font-ui: "MiSans Web", -apple-system, "PingFang SC", …, "Microsoft YaHei"(末位回退)`；`--font-num: "JetBrains Mono Web", "MiSans Web", …, monospace`——**等宽栈必须含 CJK 回退位**（¥/亿/万 不回退系统字体，数字列混排才对齐）
5. **布局韧性铁律**：KPI 行用 `flex:1 1 0` 等分（禁用 span 拼满 24 栅格，5 卡即 25/24 超栅格事故）；文本表格列 `min-width`+`show-overflow-tooltip`（禁纯固定 width）；KPI 卡/卡片标题/表头/按钮/Tag 强制 `nowrap+ellipsis`；flex 子项记得 `min-width:0`
6. **新页面验收必含**：1280×800（Windows@150% 等效）视口走查——这是平台的最低支持线

## 7. 交互组件统一律（2026-10-17 增，批 124~126k 裁定链提炼）

> 背景：安全页/筛选组件/图标钮三轮精修（批 124-126k）产出的用户裁定，全部已实施验证。
> 本节是**强制规则**——新组件必须遵守，存量违规按清单收敛。

### 7.1 指示点（dot）
1. **尺寸唯一源 `--dot: 7px`**——全站所有状态/来源/激活点直径一律引用，禁止散落 px 字面量
2. **颜色语义法**：红=故障、绿=无故障（`--critical`/`--success` 只用于系统状态）；**激活/选中态用蓝 `--brand-500`**；筛选激活点用红属违规（批126c 裁定）

### 7.2 图标按钮（IconBtn）
1. 行内动作**必须 IconBtn + tone**，禁 `el-button type="danger"` 上色（批86 立法，构建守门）
2. **间距唯一源 `--icon-gap: 8px`**：header 工具栏 `gap: var(--icon-gap)`；行内相邻钮由 `.icon-btn + .icon-btn` 全局覆写（EP 默认 12px 已收敛）
3. **动作归位原则**：动作属于哪个对象就放在哪——行级动作（测试/删除）在**操作列**，不挂表头（批126d：邮件测试入行）

### 7.3 下拉筛选菜单（RowFilter/ColumnSettings 双标准）
1. **一套组件**：行筛选=RowFilter、列显隐=ColumnSettings——**禁止自制 el-select/el-checkbox 另作一套**（批126d：数据源能力筛选收编）
2. **菜单字体统一**：全菜单一个字号 `fs-label`（含 `:deep` 覆盖 EP checkbox 14px 默认）；**层级只靠字重**：分组标题/清除钮=600，选项=400
3. **菜单色彩**：分组标题与动作钮（清除筛选/恢复默认）= `text-secondary` 灰（黑白对比后灰胜出——批126j 裁定）；选项=默认主文本
4. **顶部动作钮常驻+disabled**：清除筛选/恢复默认放顶部、恒显示、无动作时 disabled 灰置——**禁 v-if 显隐**（popover 高度跳变）；N 计数随行动作词回显「清除筛选（N）」
5. **激活指示**：图标角蓝点（RowFilter=有勾选；ColumnSettings=偏离默认列集——判定纯函数 colDiff.js 单测覆盖）
6. **契约**：RowFilter 空 modelValue=全显；ColumnSettings 空档=全隐藏（有效选择）——**消费页 colOn 判据必须 `includes(数组)`**，对象键判据即 bug（批126k：LLMModels 实证）

### 7.4 工具栏排布
1. **搜索框在左、图标钮在右**（输入在左动作在右惯例）；同页多个工具栏**顺序一致**：搜索→筛选→（列设置）→新建

## 8. 页面结构模式与术语（2026-11-02 立，同日 v2 修订：页签壳退役）

> v1 三层模式（页面→页签壳→…）当日被用户复审推翻：「页签无壳更简洁，标题按钮不受影响」——技术核实成立：
> 内容卡（标题/动作/立体感载体）自包含，与外壳无关；header 槽反而是字体连坐风险的引入面（8.3.4 事故源）。
> v2 收窄为两层：**唯一强制层=工作区内容卡**；页签栏一律裸放（TabsShell 无壳）。

### 8.1 两层结构（每个业务页面）

```
页面（Page，侧栏菜单项；无标题无描述行）
 ├─ 页签栏（TabsShell 裸放——EP 原生样式，无壳无标题层）
 └─ 工作区（Workspace）——当前页签的内容
     └─ 内容卡（Card）× 1..N
         ├─ 卡头：左标题（600 字重）+ 右动作钮（IconBtn 组，--icon-gap）
         └─ 卡体：表格 / 表单 / 监控小组件（card-grid 小卡组）
```

### 8.2 术语表（统一语言）

| 术语 | 定义 | 规则 |
|---|---|---|
| **页面（Page）** | 侧栏一个菜单项对应的路由 | 页面级不写标题、不放描述行——菜单名即语境 |
| **页签栏（Tab Bar）** | TabsShell 裸放（无 el-card 外壳） | **一律无壳**（v2）；页签键走 i18n；query 同步+记忆沿用 TabsShell 契约 |
| **工作区（Workspace）** | 页签栏下方内容区域 | 放 1..N 张内容卡；纵排为主，监控小卡可横排 |
| **内容卡（Card）** | 工作区直属 el-card/ContentCard | 默认阴影（直属卡；card-grid 内嵌小卡豁免见 8.3.2）；卡头=左「××列表/明细」标题+右动作钮——**标题与动作只在这层出现** |
| **卡头（Card Header）** | 内容卡 #header 槽 | ContentCard 的 title prop+actions 槽；无动作可只显标题 |
| **卡体（Card Body）** | 内容卡主体 | TableShell/表单/监控小组件（小组件=card-grid+never 小卡，防阴影叠加） |

~~页签壳（TabShell 卡）~~：v1 术语，v2 退役——页签栏不再包卡。

### 8.3 规则要点（v2）

1. **页面无标题律**（不变）：标题只出现在内容卡卡头。
2. **立体感分层**（不变）：直属内容卡默认阴影禁 never；card-grid 内嵌小卡（metric-card/kpi 类）never 合法。
3. **动作归位**（不变）：页签级动作挂内容卡卡头右侧；行级动作在表格操作列。
4. **页签栏裸放律**（v2 新）：TabsShell 一律不包 el-card 外壳——header 槽模式整体退役（同时消灭 8.3.4 字体连坐红线的事故面：无 header 槽即无连坐）。
5. **单工作区页面**（不变）：无页签的页面内容卡直接作主体。
6. **术语即验收语言**（不变）：「页面→页签栏→工作区→内容卡→卡头/卡体」。

### 8.4 组件与守门（v2 修订）

- **ContentCard**：唯一结构组件——卡头（title+actions）+卡体+默认阴影。新页一律用它。
- **PageShellCard**：随 v1 模式退役（未投入使用即废，留档 git 史）。
- **守门 check-pageshell.mjs** 两规则：
  - R1（改）：**el-card header 槽内出现 TabsShell**（=壳模式）或裸表格 → 报错。v2 后 header 槽模式整体非法，R1 同时抓「壳回归」与「裸表连坐」两类。
  - R2（不变）：shadow=never 基线计数（豁免 card-grid 内嵌），只降不升。
## 9. 组件分级表（2026-11-02 立）——一致性核心=shadow，由 R2 门守；本表=选用速查不新增门（用户裁定）
