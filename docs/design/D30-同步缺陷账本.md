### DEF-01 空帧被记为成功，游标越过未发布日

### DEF-10 停牌日被计入缺失期望

- **观察**：`000002.SZSE` 2010 起本地 3,932 行 / 期望 4,087 交易日，缺 155 日分 12 段，最长段 2016-02-15~06-08。
- **复现**：
```bash
venv/bin/python -c "
import sys; sys.path.insert(0,'.')
from src.data_platform.db import get_conn
with get_conn() as c:
    days=[r[0] for r in c.execute(\"SELECT cal_date FROM trade_cal WHERE is_open=1 AND cal_date>='2010-01-04' AND cal_date<='2026-11-04' ORDER BY cal_date\").fetchall()]
    have={r[0] for r in c.execute(\"SELECT (ts AT TIME ZONE 'Asia/Shanghai')::date FROM bar_1d WHERE symbol='000002.SZSE'\").fetchall()}
    f,l=min(have),max(have)
    miss=[d for d in days if f<=d<=l and d not in have]
    segs=[]
    for d in miss:
        if segs and (d-segs[-1][1]).days<=4: segs[-1][1]=d
        else: segs.append([d,d])
    print('本地=',len(have),'期望=',len([d for d in days if f<=d<=l]),'缺=',len(miss),'段=',len(segs),'最长=',max(segs,key=lambda s:(s[1]-s[0]).days))
"
```
- **实测**：`本地= 3932 期望= 4087 缺= 155 段= 12 最长= [2016-02-15, 2016-06-08]`。
