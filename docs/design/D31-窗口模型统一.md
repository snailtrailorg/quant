> **性质**：模块设计（纯知识，D 系列编号）。批 171 阶段③下一条（2026-11-06 用户裁定立项：171c 腿 2/3 吸收进本设计）。
> **依据**（引用 ≤2）：`docs/design/D30-同步缺陷账本.md`（DEF-04 空窗 success/DEF-16 日历覆盖门）、`docs/design/D29-同步机制事实清单.md` §五（窗口/地板机制）。
> **状态**：v2（双盲审 A 2P0/6P1/4P2 + B 2P0/6P1/5P2 全收编，2026-11-06 晚）。
> **前置（步 0）**：trade_cal 全史回补（1990-12-19 → 今；dev 已落 13,162 行实证、prod 待补）——本设计空洞检查/覆盖感知全以交易日历为坐标。

## 0. 问题与目标（一句话）

窗口语义散落三处（地板=任务级 retention / 增量=游标+overlap / 回补=backfill_from 全段重拉），三者**从未对齐成一个模型**——静默截断、游标与数据分叉、回补无空洞感知、冷启动一次惊险马拉松。本设计统一为「**一个窗口函数，三种参数**」，并把用户五条裁定落为结构。

**用户裁定原文要义**（2026-11-06 午后讨论，全部采纳；标注 A/B 审后澄清项）：
1. 地板可设置、全局、对所有任务类型生效；回补段早于地板的部分不回补（地板优先级最高）。**〔v2 澄清〕有效地板＝`max(全局, 任务 retention, inception, source_earliest)`——retention 只能抬不能降**（审 A-P0-1 裁定：回落链会使 astock_basic 1990/index_daily 2005 逃逸全局，违背「对所有任务生效」；深史任务需求由「地板可设置」承载——临时调全局键）
2. 稀疏事实表（无可回补判据）与稠密族**分别处理**——稀疏族回补＝整窗幂等重放
3. 尾巴＝上次同步到当前的缺口；**同步自身必须保数据-游标一致**（上次失败 ⇒ 下次正常同步自愈补齐）；只查最后数据点，**中间空洞靠显式回补**（每轮全面检查不可接受）
4. 「最后数据点当同步依据、不设单独游标」——按族分轨采纳（稠密=派生/稀疏=外置+成功闸，见 §3）
5. 单轮最大跨度配置（如 1 年）——冷启动分 N 轮平稳跑完（**任务级 max_span_days 列为延伸设计**，对齐 retention 惯例，审 A-P2-3 标注）

## 1. 统一窗口函数（§2~§5 的骨架）

```
窗口 = [max(四地板..., 起点), min(终点, 起点 + 最大跨度)]

起点：增量轮 = 游标+1−overlap；回补轮 = backfill_from
终点：增量轮 = 数据就绪日；回补轮 = 请求终点（默认=数据就绪日）
```

- **适用域**（v2 显性，审 A-P1-3）：**含** tier1 按日族/daily_batch/bar 族/jq/trade_cal 的全部「有日期轴」同步任务（§3 分轨表稠密+稀疏两轨）；crypto 族（连续轴、无日历语义）与 pool 族暂不收编。**豁免态**（不收编、防「禁第二处算式」守门误伤）：①全量重建族 2 任务（`_make_full_rebuild_handler`，DELETE+INSERT、start="full"、无窗口语义——namechange/concept）②pool_data 族（自带游标表 `pool_data_cursor`+timebox+complete 门，独立体系）③静态快照 6 族（§3 第四类——无逐日期望集概念）。豁免清单进守门白名单。
- **叠加规则**：终点收口三套（lag_trade_days/publish_lag/today）维持各族现状；crypto 起点=游标+1 无 overlap（:1280-1281 现状，**有意**——连续轴无需回看），per-symbol 地板叠加（:1419-1433）不变。
- **窗口算式收敛是目标态**：现状七处窗口点（tier1 工厂 :3343-3373/_sync_via_kind :3216-3226/astock_basic :648-656/crypto 工厂 :1393-1395/jq :2831-2842/trade_cal :837-843/pool `_window_of`）——批 A 落地时以**共享 `_clamp_span` 助手**接线（各站点调用，不重写各自起点逻辑），守门测试钉「新增窗口算式必须经助手」。
- **`_local_dates` 现状澄清**（审 A-P2-1）：其 SELECT DISTINCT 无窗过滤，窗口界在 Python 侧差集——效率声明按此口径（非 SQL 窗口扫）。

## 2. 地板全局化（裁定 1）

- **模型**（v2 定稿）：`system_config` 新键 `sync_floor_default`（全局默认日期，**缺省 2014-01-01**——用户裁定）＋ `sync_config.retention`（任务级，**只能抬高有效地板，不能降低**）。
- **取值链**：`有效地板 = max(sync_floor_default, retention, inception, source_earliest)`——`_window_floors` 的 known dict（engine.py:1177-1179 现状三源）**加第四源**即可，任务 retention NULL 时该臂缺席。裁定实例：astock_basic（retention 1990）有效地板仍 1990（其自身 retention 深）；全局 2014 抬住的是 NULL retention 的 25 个任务；「回补 1990 前深史」由调全局键承载。
- **读取点**（v2 钉死，审 B-P1-5）：全局键在 `_get_config`（每轮一次）读出挂 `cfg["floor_default"]`，`_window_floors` 只消费 cfg——**禁在 _window_floors 体内查 system_config**（crypto 循环 per-symbol 调用会 N+1）。
- **值域防呆**（审 B-P1-4）：`sync_floor_default` 写侧日期格式校验（update_system_config 白名单）+ 读侧 fail-open（坏值 ⇒ 忽略+响亮告警，171 留痕纪律）；`sync_max_span_days` 入 `SYSTEM_CONFIG_BOUNDS`（1..36500）。
- **policy_discard 批量登记预告**（审 B-P1-6）：全局回落生效首轮，NULL retention 且源界早于 2014 的族（dev 实查 ~10 族）将批量落 [源界,2014) 排除段+warning——**属预期**（每族一轮一次，幂等），非故障。
- **配置面**（v2.2 用户裁定修正）：全局 `sync_floor_default` 与 `sync_max_span_days` 均为**用户可调旋钮**——设置页可改，**不设策略门禁**（旧「策略列不入 Web 白名单」纪律对全局键不适用——批 108 立法针对任务级 retention，本设计把地板重定位为用户配置后旧纪律不延展）。保留**格式防呆非门禁**：写侧非日期串拒绝（400 语义）+ 读侧 fail-open 告警；`sync_max_span_days` 保留整数下界 1（0/负数是语义错误非策略限制）。任务级 `retention`（深史策略）维持迁移层变更。
- **trade_cal 豁免**（审 B-P1-1）：批 B 迁移同帧给 trade_cal seed `retention='1990-12-19'`（任务级自持深史，防 fresh 环境全局 2014 夹死日历自举）。
- **迁移**：system_config 两行键值（批 B）；无新表。

## 3. 尾巴自愈与游标分轨（裁定 3+4）

**统一纪律**：数据落后于游标＝错误态；每轮增量**必须**自愈尾巴，不依赖显式回补。

- **稠密族**（bar/按日快照——有「应有而未有」判据）：
  - **游标派生化**（v2 契约小节，审 A-P0-2/B-P0-1 合并裁定）：
    - **写侧派生、列作物化缓存**：`last_sync_date` 列保留，`_update_sync_state` 写入值改为「本轮窗口终点与 max(local) 收口的较小者」（见下）；**读点零改动**（sync() :421/:466、handler 起点 :3221/:3356/:1279、前端——全走列，UI 零改）。不做读侧派生（bar_1d 共享表 17.7M 行×七写者，per-族 max 查询是每轮成本炸弹——审 B-P0-1 账）。
    - **派生值域**：`max(local) WHERE <族符号域>`——族谓词按 `security_master.category`（对账 :3077 先例）；**时区锚 per 族**（A 股 Asia/Shanghai :3076 现状、crypto UTC :2687）。
    - **缺口语义改写**（审 A-P1-6/B-P0-2 同撞，v2 按裁定 3 定稿）：派生游标**不越过数据**（数据-游标一致性的结构保证）但**会越过中窗缺口**（max 尾部在缺口后 ⇒ 游标在缺口后）。**尾部缺口**由 max 结构吸收（自动重拉直至愈）；**中窗缺口**处理权显式移交 sync_gap 主张+显式回补——**D1 cursor_cap 的「窗口内自愈」语义按裁定 3 退役**，Valkey cap 键（7d TTL :2016）自然过期无需清理。守门（批 C）：test_batch171a 白名单/excluded/收口断言逐族改写账入批规格。
    - **delete 互斥**（审 B-P0-1 边界）：置 NULL 复位点（:4123/:4161）与派生写的次序——复位 ⇒ 下轮全窗重算，派生自然重建；跨族共表写（jq 回补推高 bar_1d max）被**族谓词**隔离（jq 的族域=stock，不污染 cb_daily 游标）。
    - **迁移期优先序**：族已派生 ⇒ handler 停发 cursor_cap、sync() 收口分支旁路（`_cap=None` 路径现状已支持，:408-424 零改）；未派生族维持 D1 现状——两态并存至批 C 逐族清零。
  - **尾巴检查**＝每轮窗口内日期差集（`_reconcile_dates` 现机制）；差集命中 ⇒ 内联重拉；重拉仍缺 ⇒ 落 sync_gap 主张。
- **稀疏事实表**（0 行/日正常态，max(local) 推不出扫描进度——保留外置游标的结构性必然）：
  - **外置游标保留 + 成功闸**：推进条件＝「窗口内期望日全部成功」（failed_dates 空；空日 API 0 行=成功，171b :3391 现状）。有失败 ⇒ 游标停最后连续成功日（纯游标不推，无 Valkey）。
  - **准入条件**（审 B-P1-2，防 G-S1 重试风暴）：稀疏轨仅限**日频及以上调度**（16:35/18:10 档）；30min 级任务禁入（:451-455 分钟线三态旧警告的推广）。日频下冻结风暴有界（跨度夹 366d×0.3s≈2min/日+告警去重）。
  - 尾巴检查退化为整窗幂等重放（overlap=3 现状）；中间空洞无判据、靠显式重放（§4）。
- **分轨声明表**（v2.1 补全，快核 A 抓漏 6 静态快照族——dev sync_config 35 行全覆盖）：
  - **稀疏轨**：suspend_d_sync / forecast_sync / top_list_sync / block_trade_sync（日频档 ✓）
  - **稠密轨（批 C 派生候选）**：bar 6 族（astock_daily/listed_fund_daily/cb_daily/index_daily/astock_minute×2）+ astock_daily_jq + tier1 按日 5 族（stk_limit/moneyflow/margin_detail/cyq_perf/st_list）
  - **静态快照豁免**（v2.1 第四类）：astock_basic / astock_list / cb_basic / convertible_terms / listed_fund_list / static_symbols——**生命周期主档型**（无逐日期望集概念，全量快照拉取/全量重建切换，不适用增量窗口三态；回补=整表重拉）。批 C/D 不涉及。
  - **豁免态**：全量重建 2（namechange/concept）+ pool 2 + trade_cal（自举特例）+ 加密 8 族（连续轴、无日历语义——派生化另行评估，批 C 范围外）+ 静态快照 6（上行）
- **并发面直答**（审 B-P2-5）：per-sync_id 互斥已存在（SyncLock :370-374，SET NX EX+心跳）；beat+手动双入口同锁；**共享表跨族写**（bar_1d 六写者——astock_daily/jq/cb_daily/listed_fund_daily/binance_perp_daily/okx_perp_daily，各持各锁）由族谓词隔离（上）——无新增竞态面。

## 4. 回补与空洞检查（裁定 2）

- **稠密族**：`backfill_from` 到请求终点的**日期差集**驱动重拉；**幂等口径分族**（审 A-P2-4）：A 股=不覆写（upsert 现状）/ crypto=`save_bars_overwrite` 覆写（:1414 有意立法——手动回补优先级最高）。
- **预算闸**（v2 修正，审 A-P1-1）：`_GAP_ROW_BUDGET` 现唯一消费在 per-symbol 对账（:2711-2719）；per-date 差集（回补主路径）**现状只有 max_repull 次数帽**——本设计为 per-date 差集**新接**行预算闸（阈值同表），超阈告警不硬冲。
- **next_from 语义**（v2 钉死，审 A-P1-4）：`truncated` 时返回 `next_from=连续成功末日+1`（镜像增量三态 G-Q1a :471-474 语义）——**不是实际终点+1**，防链式续跑跳过本轮中窗失败日；回补差集按「完整请求段」计算（续跑轮复访剩余缺口）。
- **稀疏族**：无空洞概念——回补＝`backfill_from` 起整窗逐日重放（suspend 13 年实证形态）。跨度切轮同 §5。
- **地板截断**：请求起点 < 有效地板 ⇒ 执行被夹部分＋§6 显性反馈。
- **retention_days 互斥**（v2 新增，审 A-P1-5）：回补段 ∩ 批 158 滚动裁剪窗 ⇒ **拒绝+告警**（防复活已裁数据与 GC 互搏）；§8 评审点第八条消项。
- **步 0 前空转预告**（审 A-P2-2）：trade_cal 未补齐时历史窗回补=uncertain 落行、不重拉不告警（:2395-2400 现状）——步 0 硬前置的原因，上线后非 bug。

## 5. 单轮最大跨度（裁定 5）

- **配置**：`sync_floor_default` 同 §2；`sync_max_span_days` 全局键（缺省 366）＋ `sync_config` 新列 `max_span_days`（任务级覆盖，NULL=回落全局；**任务级列随批 A 落地**——§0 标注的「延伸设计」指其超出裁定 5 字面（裁定只说全局旋钮），非延后实施，§0/§5/§7 三处口径以此句为准）。
- **夹取**：`终点 = min(请求终点, 起点 + 最大跨度)`——共享 `_clamp_span` 助手（§1），**增量轮/回补轮同 cover**（每站点一次接线）；全量重建族不适用（豁免态）。
- **轮次衔接**：增量轮游标推到实际终点 ⇒ 下轮自然续；回补轮返回 `truncated: true + next_from`（连续成功末日+1，§4）——**服务端无自动链式续跑**（手动/任务重复触发，如实声明）；FE 面提示+续跑按钮（批 A 含前端面）。
- **时限预算对照**（审 A-P2-1 修正）：sync_via_celery 3600s/crypto 5400s——跨度 366 天 ×各族限速均在单轮内；超限族的跨度建议值在批 A 任务文件逐族标注。

## 6. 显性截断反馈

## 8. 评审要点（v2：八条全收口）
