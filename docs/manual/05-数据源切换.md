# 05 · 接口切换操作册（批189 版）

> 适用：换行情接口、换交易接口、换凭证、新增接口、调整 TD→MD 映射。**全程 Web 操作。**
> 状态：批189 起生效（接口三类 + code 身份 + 进程常驻）。旧「外部接口/交易账号」页签已拆为「行情接口」「交易接口」。

## 一、先记住三句话

1. **行情接口、交易接口、数据源是三类独立配置**：同一券商的行情与交易是两行，各自凭证、各自启停。
2. **接口一旦注册，对应进程就常驻**：启用=干活（建连接/订阅/下单），停用=空转（不建任何券商连接）；「停用」不会让进程消失。
3. **交易接口要指定取价行情接口**（可配主备）：清仓/取价按映射读行情；没配映射时清仓会明确报「映射缺失」。

## 二、页签与身份

- 系统管理 → 集成中心：**数据源 / 行情接口 / 交易接口** 三个页签。
- 每个接口有一个**不可改的 code**（如 `md-xtp`、`td-xtp`），监控、日志、任务绑定都按它显示。
- 展示名（name）可随时改；code 改不了（改=换身份）。

## 三、时间约束（不变）

- 换行情/交易配置只能在非交易时段：交易日 15:10 之后至次日 9:15 前，或非交易日全天。
- 盘中改配置会打断行情/会话，实盘任务断粮。

## 四、常见操作

### 4.1 换凭证（测试账号换正式 / 改密码）
1. 行情接口页或交易接口页找到对应行 → 编辑。
2. 凭证留空=保持原值；只填要改的字段。
3. 保存后进程会在约 15–30 秒内检测到变更并重建连接。

### 4.2 换行情通道（XTP 行情 → 东财行情）
1. 行情接口页 → 新建或编辑目标行，改 provider/凭证。
2. 若该行情接口被交易接口引用，映射无需改（code 不变）；换 code 则需改映射。
3. 到「系统监控 → 连接状态」看 `md-...` 卡片转为「运行中·工作中」。

### 4.3 新增接口
1. 行情接口页：新建 → 选 provider → 填凭证。
2. 交易接口页：新建 → 选 provider → 填凭证 → **选择取价行情接口（可多选并排序）**。
3. 保存后进程自动拉起；若 provider 尚无插件载体，会显示「待接入」（不可启用）。

### 4.4 调整 TD→MD 映射
1. 交易接口行 → 编辑 → 映射区选择行情接口，拖动排序（第一=主，其余=备）。
2. 保存后 ≤5 秒生效；清仓会按主→备顺序取价，全部无价时报「映射缺失」。

## 五、状态怎么看

- 「运行中·工作中」= 进程在、已建连接；
- 「运行中·空闲」= 进程在、接口停用（空转，不建连接）；
- 「已停止」= 进程异常（需看运行日志/告警）；
- 「待接入」= provider 没有对应插件能力，暂不可启用。

## 六、常见问题

- **停用后进程为什么还在？** 批189 起进程常驻，停用只让它空转；这是设计，不是故障。
- **服务没起来？** 先看状态：待接入=缺少插件；已停止=看运行日志；空闲=接口被停用。
- **清仓报「映射缺失」？** 去交易接口编辑页补取价行情接口（同市场、有 rt_quote）。
- **改了 code 会怎样？** 现有任务/历史绑定不跟随（code 是身份），不要改；改展示名。
