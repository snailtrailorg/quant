## 接口契约
- **改后签名**：
  ```python
  class MinuteAnalysisEngine:
      def on_bar(self, bar: dict, history: list[dict] | None = None) -> dict:
          # bar: {ts, open, high, low, close, volume}（1min/5min）
          # history: 过去 bar 列表（构建因子上下文，防未来函数；None 时只用当前 bar）
          # 返回 {"action": "BUY"/"SELL"/"HOLD", "score": float, "rating": "BUY"/"HOLD"/"AVOID",
          #       "conclusion": str, "factors": {"ma_dev":..., "momentum":..., "vol_ratio":...}}
  ```
- **因子公式**（复用 DailySelectionEngine._analyze_single 模式，analysis.py:90-143）：
  - `sma_20`：`history` 最近 20 根（含当前 close）收盘均值；`len < 20` 时用当前 close
  - `ma_dev = bar["close"] / sma_20 - 1`
  - `momentum = bar["close"] / history[0]["close"] - 1`（history 空或 len<1 时 0）
  - `vol_ratio = bar["volume"] / (mean(history[-5:]["volume"]) + 1)`（history<5 时 1）
  - `score = ma_dev*2 + momentum*1.5 + vol_ratio*0.5`
  - 评级：`BUY(score>0.3) / AVOID(score<-0.3) / HOLD`
  - action 映射：`BUY->"BUY"` / `AVOID->"SELL"` / `HOLD->"HOLD"`
  - `conclusion`：f-string 汇总因子值（参考 DailySelectionEngine 的 conclusion 格式）
- **不变量**：防未来函数--只读 `history`（过去）+ 当前 `bar`，不读未来

## mock 方式
纯函数测 on_bar，不连 DB/LLM（D2 不调 LLM）：
```python
from src.astock_analysis.analysis import MinuteAnalysisEngine
eng = MinuteAnalysisEngine()

# 1. 涨（history 递增 -> momentum 正 + ma_dev 正 -> BUY）
hist_up = [{"close": 9+i*0.1, "volume": 100} for i in range(20)]
r_up = eng.on_bar({"ts":"2026-08-10T09:31","open":11,"high":11.2,"low":10.9,"close":11.1,"volume":150}, history=hist_up)
assert r_up["rating"] == "BUY" and r_up["action"] == "BUY"
assert "ma_dev" in r_up["factors"]

# 2. 跌（history 递减 -> AVOID/SELL）
hist_dn = [{"close": 11-i*0.1, "volume": 100} for i in range(20)]
r_dn = eng.on_bar({"open":9,"high":9.1,"low":8.8,"close":8.9,"volume":150}, history=hist_dn)
assert r_dn["rating"] == "AVOID" and r_dn["action"] == "SELL"

# 3. 震荡（history 平 -> HOLD）
hist_flat = [{"close": 10, "volume": 100} for _ in range(20)]
r_flat = eng.on_bar({"close":10,"open":10,"high":10,"low":10,"volume":100}, history=hist_flat)
assert r_flat["rating"] == "HOLD" and r_flat["action"] == "HOLD"

# 4. history=None 不崩
r_none = eng.on_bar({"close":10,"open":10,"high":10,"low":10,"volume":100})
assert "score" in r_none and r_none["action"] in ("BUY","SELL","HOLD")
```
