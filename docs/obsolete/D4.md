## 接口契约
- **新加 Pydantic 模型**：
  ```python
  class LogAnalyzeReq(BaseModel):
      logs: list[dict] | None = None     # [{level, module, msg, ts}, ...] 直接传
      task_id: str | None = None          # 或从 task_logs 查（二选一）
  ```
- **新加端点**：
  ```python
  @app.post("/api/log/analyze")
  def log_analyze(req: LogAnalyzeReq, payload=Depends(require_role("viewer","analyst","trader","admin"))):
      # 1. 取日志：req.logs 直接用；或 req.task_id 调 task_manager.get_task(task_id)["logs"]
      #    过滤 ERROR/WARN（INFO/DEBUG 不归因）；无日志返回 {"analysis":"无异常日志"}
      # 2. 调 _analyze_logs_with_llm(logs) -> str
      # 3. 返回 {"analysis": str, "log_count": int, "logs": logs}
  ```
- **新加辅助函数** `_analyze_logs_with_llm(logs: list[dict]) -> str`：
  - 拼日志文本：`"\n".join(f"[{l['level']}] {l.get('module','')}: {l['msg']}" for l in logs)`
  - 调 `gateway.chat(messages=[system+user], role="viewer", caller="log_analyze")`
    - system: "你是运维归因助手，分析异常日志的根因 + 给排查建议，用中文"
    - user: f"以下是异常日志，请分析可能原因并给出排查建议：\n{log_text}"
  - 返回 `resp.content`（LLM 不可用时 "（LLM 暂不可用）"）
- **复用**：`from src.llm_gateway import gateway`（延迟 import）/ `from src.task_manager import get_task`（task_id 模式，延迟 import）
