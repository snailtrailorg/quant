## Phase 1 · 风控黑箱打开 + 指挥中心（最高业务价值）

1. 风控总览重设计（05 §5.3）：总闸红警条、risk_log 决策面板、fail-closed 可见、水位仪表
2. 对账处置台（05 §5.4）：结构化差异表（需后端把 issues 结构化）+ 豁免/清零/场外单登记
3. Dashboard 指挥中心（05 §5.1）：告警条、风控水位、实盘任务、今日事件、权益曲线
4. 通知中心本体重设计（05 §5.0-2）：结构化 body + runbook 链接
5. 实盘任务列补齐：md_mode/lag/bars/frozen + 冻结处置闭环 + 自愈时间线

## Phase 2 · 研究链路闭环（最高频使用路径）

1. 策略列表：验证✓证据链（可点回看）、最近回测战绩、[发起回测]/[保存并回测]
2. 回测中心重设计（05 §5.7）：列表指标摘要+筛选+轮询、报告扩指标+费用摩擦+基准按品类+买卖点、最低验证样本门槛
3. 因子库（05 §5.5）：试算参数放开、DSL 入口+校验、被引用可导航
4. 选股器三合一（05 §5.9）：转债/ETF 核心列、静态因子接入、F-SEL-003、虚拟滚动
5. 策略编辑独立路由 + 快照隔离提示 + 频率差异声明

## Phase 3 · 系统组归并 + 设计系统落地

1. 集成中心六合一（field_schema 动态表单反哺券商/数据源）、数据运维、可观测性（05 §5.10）
2. tokens.css + EP ramp 覆盖 + 等宽字体自托管子集 + 暗色盯盘三页（04）
3. Cron 编辑弹窗、审计/日志检索、帮助移顶栏、⌘K 命令面板（页面+策略/因子名子集）

## Phase 4 · 目标态（依赖外部条件，原型预留位）

- 加密永续操作面（等币安/OKX 开通）｜回测报告 PTrade 全家桶（α/β/基准/每日持仓/导出——模型字段已有、引擎未算）｜策略版本管控/灰度状态机｜动态池/强制绑池｜WS 推送（/ws/pnl、/ws/strategy 需后端先实现）｜AI 会话持久化｜漂移监控（#40 实盘后）
