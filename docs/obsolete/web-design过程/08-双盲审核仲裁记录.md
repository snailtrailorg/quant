## 第二轮盲审（菜单架构 v2，2026-08-29 晚）

三路：导航 IA 专家 / 业务权限专家 / 红队（专职攻击双环模型）。红队结论"**有条件通过**"——骨架（分区=风险隔离、边界=门禁投影）经攻击站立，快照隔离瓦解了最凶的攻击（盘中改因子：改配方不影响在跑任务，摩擦=护栏）。三路意见全部采纳，无一驳回：

1. **去术语**（导航+红队交叉）：研究环/运营环/可观测性不上 UI → 界面组名=研究/实盘交易/风控/系统 + 健康与日志；"信号"双义 → 每日研判
2. **并页**：运行监控并入实盘任务（无独有职责）；数据源并入数据中心（用户心智"数据出问题去哪"）；16 项 5 组
3. **权限收紧**（业务盲审）：对账豁免/清零=admin（执行守护者不能抹平自己的差异）；analyst 创建实盘任务落灰度态、转正式需 admin（证据生产者不能一人走完出证据→上线）；数据中心 trader +"按标的回补"单动作
4. **论证修正**：撤回"时间尺度"分组论证（被 05 回测最高频自证伪），只押风险轴；"研究环失败无代价"改为"无本金代价、共享配额/预算"（资本隔离非资源隔离）
5. **红队五补丁**：顶栏常驻急停+盯盘页头就地熔断；回测报告内嵌同窗实盘净值对照；健康灯抽屉自含诊断（修复 P4 死链）；交易台人工单登记；盘中回测"日线回放"横幅
6. **落地简化**：先 admin/非 admin 两档实现，四角色数据标记；viewer 备脱敏开关；Web/IM 同门槛声明
7. 模式切换式替代方案被红队自己否决（mode error 认知事故源）——双环维持"最不坏"
