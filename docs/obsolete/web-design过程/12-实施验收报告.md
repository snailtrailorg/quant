3. AI 助手**未顶栏化**：仍占 research 组菜单末位，顶栏无 AI 入口——03 v2.1 定案双背离
4. 策略编辑仍是 **720px 弹窗**（方案定独立路由，弃弹窗/抽屉）

## 二、方案新增的功能未实现

**Dashboard**：可用资金/占用 KPI（换成"任务运行 X/Y"）、水位双条仅剩回撤单条、总盈亏无时间基准切换、sparkline 变文字、**今日事件仍是通知标题复用（非除权/强赎/财报事件源）且无逐条路由**、告警统一跳 /monitoring 非精确路由、盘中轮询缺（一次性加载）
**Risk**：市场开关确认无"挂单 N 笔将被撤销"、总闸关闭时开关未禁用、加密市场未做"未开通"占位、杠杆水位条缺
**Reconcile**：四处置缺"重新同步"、行展开无订单流/快照时间证据链/查看持仓跳转、汇总无分类计数与最后对账时间、RESET 输错提示复用 RESUME 文案
**LiveTask**：未验证策略静默过滤（方案=灰项+原因 tooltip）、今日成交/盈亏/运行时长列缺、冻结原因不显示、快照仅 JSON dump 无配方 diff、停止确认无影响面数据
**Trading**：持仓缺名称与**现价列**（市值=成本×量非现价×量）、现价/浮盈行情联动缺、订单缺委托号、行情降级黄横幅缺、盘后汇总缺费用/净盈亏
**Backtest**：列表缺夏普/区间列、失败无重试/诊断、发起弹窗无 remote 标的搜索（纯粘贴）、Run 缺 Calmar/最大连亏、费用摩擦仅一条横幅（滑点 bps 不可配）、标记验证未限定 done、View 缺品类基准/同窗实盘对照/回撤副轴/明细盈亏列/分页、盘中"日线回放"横幅缺
**Strategy**：DSL 编辑器=Monaco plaintext（无因子补全/高亮/实时校验）、验证✓无 hover 证据摘要、列表缺模式/标的列、select 参数无选项编辑器/number 无 min<max 校验
**Factors**：**DSL 新建入口缺（仍仅 Python）**、搜索/分类筛选/分页全缺、试算标的手填非搜索、引用列表不可跳转
**Screener（选股器）**：A股未接静态因子条件、无 F-SEL-003 勾选跳建模、无导出 CSV、无虚拟滚动（el-table 50/页）、市值仍"万"步长 50（方案亿 0.5）、CB 缺纯债溢价/规模/现价列与条件、ETF 缺折溢价列、无涨跌幅列/K线
**DataOps**：完整性页无搜索/分页/缺口行[回填]（**断链仍未打通**）；数据源被挪去集成中心（方案=数据中心四合一）
**Permissions**：仅 API 单维平铺勾选——**三维模型（nav 三态/端点组读写/数据域）与"角色+单用户"主体切换/override/系统策略锁定全部未做**（10 号核心）；/permissions 路由是孤儿双入口（无菜单指向）
**顶栏**：⌘K 缺、通知无 runbook 链接、头像下拉仅 profile/logout（方案五项：个人资料/改密/语言主题/我的权限/退出）
**H2/H10/H12 尾差**：StockDetail 涨跌无 ▲▼ 双编码、Cron 无防抖、Factors 视图仍自带防御 parse（api 层统一未贯彻）

## 三、页面实现差异（结构性）

1. 权限落地走的是"角色×13 权限 key 平铺"（现状 PERMISSIONS 字典 UI 化）而非方案的三维×两级模型——/auth/me 已下发指纹 ✓（好），但消费侧粗糙：ops 组对 analyst 整组可见（方案矩阵要求隐集成中心/设置）
2. 发件箱/通知历史落在**日志页**而非方案的邮件 tab；数据源 tab 归属集成中心（方案数据中心）
3. Factors 弹窗 vs 方案右侧抽屉；集成中心 dialog vs 方案抽屉
4. Dashboard 第 5 KPI 卡 span=4 与前四卡不等宽（视觉破格）
5. LiveTask 状态未中文化、初始资金未万元化；Strategy 状态列把 enabled 译"运行中/已停止"（僭越实盘任务唯一入口的语义——虽未加启停按钮，文案有歧义）
