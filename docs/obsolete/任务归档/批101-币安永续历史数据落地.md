## 落地契约（实测值，与设计稿初版有出入处以本表为准）

### `sync_config` 行
`id='crypto_perp_daily'`、`name='加密永续日线'`、`tushare_api='binance.klines'`、
`pg_table='bar_1D'`、`data_type='crypto'`、`sync_mode='incremental'`、
**`schedule='30 8 * * *'`（北京时区解释 ⇒ 00:30 UTC，正落 UTC 昨日 T+1 文件之后）**、
`enabled=true`、**`trade_day_filter='none'`（crypto=连续轴，无交易日历；枚举闸核过合法）**、
`provider='binance'`、`supports_backfill=true`（handler 真读 `backfill_from`）、
**`start_floor='2019-09-08'`（USDT-M 永续上线日；adapter 真能投递该起点）**、`description`。

### `sync_kind_config` 行
`sync_id='crypto_perp_daily'`、`kind='bar_daily'`、**`sub_kind='perp'`（新子类）**、
`pg_table='bar_1d'`、`pk_cols='{symbol,ts}'`、`float_cols='{open,high,low,close,volume,amount}'`、
`text_cols='{}'`、`rebuild='incremental'`。

### 落库映射（**修正设计稿的 `close_time`**）
- `ts = **open_time**`（bar 起始），**必须 UTC aware**——naive 会被 `db.validate_bars`→`as_utc`
  按 Asia/Shanghai 解释＝**静默错 8h**（`validate_bars` 对 aware 直接 `astimezone(UTC)`）。
- `symbol = f"{src_sym}.BINANCE"`（vt_symbol 形态，`security_master.SMClient._market_of_suffix` 认 → crypto）。
- `freq='1D'`、`source='binance'`、`amount = quote_volume`、`adj_factor=None`（加密无复权）。
- 写入口：增量 `db.save_bars`（冲突跳过）；回补 `db.save_bars_overwrite`（手动回补优先级最高）。

### 数据源契约（实测，2026-10-06 prod）
- 批量站：`https://data.binance.vision/data/futures/um/{daily,monthly}/klines/{SYM}/{interval}/{SYM}-{interval}-{key}.zip`。
- CSV 12 列：`open_time,open,high,low,close,volume,close_time,quote_volume,count,taker_buy_volume,taker_buy_quote_volume,ignore`；
  **旧文件无表头**（探测首格 == `open_time` 决定是否弃首行）。
- **T+1**：UTC 当日 404、前一日 200 ⇒ 窗口上界＝**UTC 昨日**。
- **月包起点＝2020-01**（实测；2019-09/10 → 404）⇒ 更早区间回退日包。
- 符号枚举：S3 `ListObjectsV2`（`s3.ap-northeast-1.amazonaws.com/data.binance.vision`，分页），
  实测 1056 条目 = **1004 永续 + 52 交割合约**（`_YYMMDD` 后缀排除）；含 5 个中文名符号（须 URL 编码）。

## 顺手修掉的两个真缺陷

1. **省流阀静默裁掉 pre-2020 历史**：>90 天区间先探最早**月包**，而无条件 `max(s, 月包起点)`
   会把 `start_floor='2019-09-08'`~2019-12-31 的逐日区间静默丢掉（且 config 声明变谎言）。
   改为「仅当起点 ≥ floor、或探到的月包起点晚于 floor 时才上抬」+ 反证测试。
2. **迁移离线不可渲染**：首版 `op.get_bind().exec_driver_sql(带参)` 在 `alembic upgrade --sql` 下炸
   `MockConnection has no attribute exec_driver_sql`——**用例 N 当场抓到**；改 `op.execute(内联字面量)`。
   （同族写法在 0129/0131 等**已应用**迁移里也有＝既存债，不改已应用迁移，另批处理。）
