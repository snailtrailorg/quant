## 3. 关键设计

- **编辑弹窗**=角色下拉+启停开关两字段（等价原行内三操作），保存走现有 `POST /api/user/{uid}?role=&enabled=`（零新端点）；locked 行（自己/deactivated）禁用同现
- **邀请批量删**：`POST /api/invites/batch-delete`，require_perm(user_mgmt)，ids 数组上限 100，逐条 DELETE + 计数返回；audit_log 记 batch_delete
- **注册头像**：RegisterReq 扩 `avatar`（dataURL base64，≤2MB 校验（与 avatar 端点同限））→ 复用 profile 头像保存函数（从 `/api/user/avatar` 端点下沉公共 `_save_avatar()`）→ users.avatar_url；昵称写入 users.nickname
- **注册用户名**：唯一性已有；补保留字黑名单（admin/root/system 等，防冒充）
- **创建时间到日**：前端 `[:10]` 截断展示，不动后端
- 迁移 0070：`DROP COLUMN users.email_verified`（downgrade 重建列 default false，数据不可逆——邮箱验证流程本就未启用，裁定 ③）
