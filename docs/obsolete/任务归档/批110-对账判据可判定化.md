## 目标

一句话：让母设计 §八.5 的门控判据**可自动判定**，并补齐它赖以成立的前提（inception 单一真源）。

**成功的样子（三条并列，缺一即不算成功）**：
1. `data_gap_reconcile` 每轮在 journal 落结构化摘要（含**轮次 id**、连续命中分布、误报证据计数、
   SM 覆盖率、N），判据可**由该摘要自动判定**；
2. 该机制的成本**由 scope 数决定、不由数据量决定**——「真批量」而非改措辞（见产出 D）；
3. 「哪些 scope 的 inception 真值可读／不可读」是**显式声明**，并被 CI 闸与真实可及性**互证**。

**本批不删冻结**（R0，含结构性理由）；**删冻结**拆为后续批且按族分治。

## 产出

**A. inception 收编（裁定 G① 收尾——判据成立的前提）**

- `security_master.py` 新增**模块级** accessor（与 `get_market_hours()` 同制）：`def sm_inception(vt_symbol: str) -> str | None`
  ——返回 `YYYY-MM-DD` 或 **`None`＝不可得**；**不设回退**（`_get_list_date` 的 `_TUSHARE_MIN_DATE` 回退把
  「未知」伪装成 `2010-01-01`，与本门语义冲突；该函数归挂账 G-3，本批不动）。
- `engine._window_floors`（`:1089`）与 `engine._reconcile_symbols`（`:1835`）改读该 accessor（生产者仍是 accessor 链里的 adapter，**读侧唯一**）。
- **SM 缺两类分开登记**（不得合并、不得沉默降级）：
  - 「SM **有**该 symbol 但 `list_date` 为空」＝**结构性未知** ⇒ `uncertain(inception_unknown)`；
  - 「SM **无该族 symbol**」＝快照不完整 ⇒ **响亮告警（新 alert code，见 V6）**。
- **SM 覆盖率进每轮摘要**：`sm_covered/sm_total`（按 scope）；覆盖率 < 1 ⇒ 该 scope 的**判据不许过门**
  （**v4 落点**：产出 B「门控合取」的 `suppressed`；v3 只有散文）。
  覆盖率**长期** < 1（≥ `_SM_COVER_STALE_ROUNDS` 轮）⇒ **响亮告警**（V7：防「一次刷新网络抖动写 `None` 且未恢复」致缺口被永久静默抑制）。
- **显式声明不可得**：新增并列常量 `_RECONCILE_UNKNOWN_INCEPTION: frozenset[str]`（当前＝4 个 `binance_perp_*` scope）。
- **互证闸（比对键＝结构性 unknown，非「恒 `None`」）**：闸比对「SM **有**该 scope 的 symbol 且 `list_date` **空**」的 scope 集
  vs `_RECONCILE_UNKNOWN_INCEPTION`；**且闸只在 SM 快照新鲜时评估**（stale ⇒ 标 `unverified`，**不判**）——
  避免把「瞬时探不到」（网络抖动 / SM 过期）误判为**结构性未知**（§九.1 风险落进闸自身）。

**B. 判据可判定化（R1/R2/R3）**

- 迁移 `0141`：`sync_gap` 增**两**列（expand-only，`ADD COLUMN IF NOT EXISTS`，接往返用例）：
  `hit_rounds int NOT NULL DEFAULT 0`（**连续**命中轮次）＋ `last_hit_round bigint NOT NULL DEFAULT 0`
  （最后一次命中的轮次 id）。
  > **为什么不是三列（v4 删列，步 4 代码双盲审 P1-2）**：v3 原设计的第三列 `false_rounds`
  > （「误报证据累计」）经双盲审＋主会话一手 `grep` 确认**全仓零写入点**＝死列。根因是 R2 的两类
  > 检测器在本结构的**单分支**语义下**结构不可达**（同一 `(symbol, anchor)` 一轮内只走
  > opened／closed／uncertain **之一**）⇒ 任何写入恒为 `0`。保留「声明不被执行面消费」的列
  > 违反本仓红线 ⇒ **删列**；**当轮**误报证据仍由 `_gap_judge` 计算并进摘要（不落表）。
- **轮次身份（严格单调）**：`round_id` ＝ 任务入口 `business_redis().incr("reconcile:round")`
  （Valkey 自增；`sync:lock` 同源客户端 `src/quant_common/redis_client.business_redis`）。
  **每轮任务入口无条件推进一次**（与 scope 是否写行无关）。
  > 为什么必须是「无条件推进的序号」而非墙钟：① 裸 Unix 秒在 beat 周频下**手动重跑可达同秒** ⇒ 碰撞（双计/误判）；
  > ② NTP 回拨可非单调；③ DB `MAX(last_hit_round)+1` 派生在「该轮所有 scope 均未写行」（全族跳过）时**不推进** ⇒ 断档被当连续。
  > Valkey 失效方向**安全**：丢 ⇒ 计数回退 ⇒ `last_hit_round != round_id-1` ⇒ **复位** ⇒ 只推迟过门，不产生假过门。
  > Valkey 不可用 ⇒ 该轮 `round_id` 不可用 ⇒ **只观测不判定**（判据不过门）＋ 摘要响亮标注。
- **`_sync_gap_sync` 维护语义（含断档复位——本批核心修正）**：
  - 新开/reopen ⇒ `hit_rounds=1`、`last_hit_round=round_id`；
  - **本轮对齐** ⇒ `hit_rounds = (hit_rounds+1) if last_hit_round == round_id-1 else 1`；`last_hit_round = round_id`；
  - `closed` ⇒ **保留** `hit_rounds`/`last_hit_round` 供判据读史。
  > **为什么必须复位**：`hit_rounds>=N 且 last_hit_round==本轮` **只证「最近一次命中＝本轮」，不证「最近 N 轮连续」**。
  > 反例：轮 1–4 命中 → 轮 5 该 scope **整轮跳过**（行不动）→ 轮 6–7 命中 ⇒ `hr=6,lhr=7` 判过门，**实际连续仅 2 轮**。
  > 复位逻辑（`last_hit_round == round_id-1` 才累加）把它归 1 ⇒ 正确不过门。
- **判定式（收敛）**：`hit_rounds >= N`（复位已自证连续；`==本轮` 因复位逻辑而冗余，保留为摘要断言）
  **且本轮未被抑制**（见下「门控合取」）。
- **⭐ 门控合取（v4 补，步 4 代码双盲审 P1-1）**：本方案 §产出 A 与 D 各写了一条「覆盖率 < 1 ⇒
  判据不许过门」「`budget_exceeded` 的 scope 其判据不许过门」——v3 只有散文、**代码未落地**。
  v4 钉死落点：`_gap_judge(..., suppressed: bool)`，`suppressed=True ⇒ hit_ge_n=0 且 judged=False`；
  调用方取值面＝`budget_exceeded or sm_covered < sm_total`（这两路**只有它们**未天然闭合：
  `round_id is None` 由 `round_id is not None` 条件闭合；`stale_source` 因全族转 `uncertain` ⇒
  无 `open` 行可数）。**为什么必须显式归零**：`budget_exceeded` 轮把 `gaps_map` 全置 `None` ⇒
  行**保持 `open` 且保留旧 `hit_rounds`** ⇒ 不归零就会「**拿旧值过门**」＝**假过门**。
- 新增纯函数 `_gap_judge(stats, scope_rows, round_id, *, suppressed=False) -> dict`：算本轮
  **误报证据**（下 R2 两类）＋连续命中分布＋门控合取结果。
- 常量 `_GAP_JUDGE_ROUNDS`（N，R3 定值）。**落点＝代码常量**（§三判据「同类任务共享 ⇒ 代码按 kind 给默认」；
  母设计 §四 DB 承载物清单不含任何判据阈值）——**但必须进可观测摘要**（N7）。

**D. 读取规模契约（P1-γ + 事实 1/14）**

- **真批量（读侧 ＋ 状态同步侧一并）**：`_reconcile_symbols` 按 scope **一次**取本地日期集（`GROUP BY symbol`）、
  **一次**取 live 行、**一次**取 repullable；**`_sync_gap_sync` 亦须批量化**（否则「O(scope)」仍是**假陈述**）。
  成本由 **scope 数**决定（陈述与验收均**不含** O(标的数)）。
  **实现纪律（守迁移 0140 禁 ON CONFLICT 纪律）**：批量**不得**走 naive bulk upsert —— 须「**scope 级读 ＋ 内存集合差 ＋ 逐锚批量语句**」，
  否则会污染 `pull_count/last_seen/hit_rounds` 连续性判据（0140 docstring 明令）。
  实测支撑：dev `bar_1d`（17.5M 行/9088 标的）逐标的 `_local_dates` **4.88 ms/次**（折算 9088 标的 ≈ 44 s，仅此一步）
  vs 批量 `GROUP BY symbol` 一次 **0.47 s** ≈ **94×**。
- **体量上界 + 超阈响亮拒绝**：常量 `_GAP_ROW_BUDGET` ＝ **按 kind/family 的字典**（daily 族与 minute 族量级差巨大，
  单值必致「minute 恒漏报」或「daily 无保护」——参数三层归位：同类共享 ⇒ 代码按 kind 给默认）；
  **语义钉死＝本轮该 scope 的「落表行数」上界**（**不**约束扫描量——扫描量须先读才知，不可预算）。
  超阈 ⇒ **不落该 scope 的缺口主张** ＋ 告警 ＋ 摘要标 `budget_exceeded=1`。
  > **显名取舍**：这是「**用漏报换稳定**」——该 scope 当轮缺口**不报**，以**告警**替代**静默**；
  > 且 `budget_exceeded` 的 scope 其**判据不许过门**（与覆盖率<1 同制）——**v4 落点见产出 B 的「门控合取」**
  > （`_gap_judge(suppressed=True)`；v3 只写了散文，代码未落实，由步 4 盲审 P1-1 抓出）。
  > `astock_minute`/`astock_minute_5min` 一旦启用，`bar_1min` 每标行数远大于日线 ⇒ **「启用前先评估对账体量」列为前置条件**。
- `data_gap_reconcile` **显式声明** `soft_time_limit`/`time_limit`（**消除隐式继承全局 300 的沉默态**）；
  初值 `soft_time_limit=1800, time_limit=1980`（仓内重任务同制），**校准机制**：**触发＝2026-10-11 首轮**；
  **归属＝本批步 8 集成观察**——主会话读实测单轮耗时，若 > 1800s 则本批内改常量并重跑门。
