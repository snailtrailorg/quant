## 目标

冻结入口＝**独立图标**（不复用铃铛），点击目标单值可判定（冻结任务列表），解决「铃铛点击目标按来源二选一、并发无解」的契约不闭合。

## 现状（已实证）

| # | 事实 | 锚点 |
|---|---|---|
| 1 | 铃铛点击目标＝`/observe`（系统监控）；把冻结塞进铃铛 ⇒ 两类告警并发时无法路由 | `flow/任务/批76b-冻结史UI.md` §7.2 |
| 2 | 铃铛权限面＝admin-only；冻结史权限面＝`read`（四角色）→ 两者面不同 | 同上 |
| 3 | `task_blind`（含盲视动态态）≠ 冻结真源；`freeze_event`（F1 未闭合行）才是 | `hub_worker.py:452`（盲视不落 F1） |
| 4 | 前置 P0 已满足（`LiveTask.vue` 展开行有落点） | `202610020100-53e7523` |

## 产出

1. **后端**：`freeze_event.list_events` 加参数 `open_only: bool = False`（**SQL 层过滤** `AND unfrozen_at IS NULL`，**先过滤后 LIMIT**——消「LIMIT 50 先截断漏计未闭合行」）；新增全局端点 `GET /api/freeze-events?open_only=true` 消费它，权限面 `read`。图标角标读它。
2. 新增独立图标（不复用铃铛/`el-badge` 组件实例），权限面挂 `read`。
3. 信号源＝全局 F1 未闭合行（`/api/freeze-events?open_only=true`）。
4. 点击目标＝冻结任务列表/下拉（逐条跳对应 `LiveTask` 展开行），**不是** `/observe`。

## 限定范围

只改图标 + 跳转接线 + 新增全局只读端点。
**不碰**：铃铛监控点击目标 `/observe`；后端 `freeze_event` **写路径**；**「铃铛侧冻结告警信号源单向化」**（`monitor.py:186-190` 的 `task_blind` 冻结告警与 F1 不同源——`task_blind` 含盲视态、盲视不落 F1，「归一到 F1」会丢盲视告警，语义陷阱，**已另挂账不进本批**）。

## 接口契约

- 改：`freeze_event.list_events(task_id: int | None = None, limit: int = 50, *, open_only: bool = False)`（`freeze_event.py:80`）——`open_only=True` 时 SQL 追加 `AND unfrozen_at IS NULL`（**在 `ORDER BY id DESC LIMIT` 之前**过滤，角标计数不被 limit 截断）。
- 新增：`GET /api/freeze-events?open_only=true` → `{"events": [<同 list_events 返回 dict 形状>]}`（`open_only` 透传；默认 `false` 行为＝现 per-task 端点）。
- 既有调用方 `trading.py:287`（per-task 端点）**签名不变**（`open_only` 默认 False，行为零漂移），仅需确认传参不受影响。
