## 关键设计（v2）

- 线程模型账（A 裁定采纳）：daemon 线程不占 anyio 40 token 池（每次点按占 1 token ≤5s，容量宽裕）；**真正无界的是 OS 线程**→Semaphore(8)+cancel_event+看门狗三件套兑现"≤600s"
- **lark 全局 loop 冲突证伪**（A-P2-3）：register_app=纯同步 requests 轮询无 asyncio；web 进程无 lark import，惰性首载无害
- "≤2s 零轮询"改口"**≤2s 目标+5s 兜底回落轮询**"（A-P2-4 措辞）；回落率打点挂账观察
- admin 面响应形态对齐自助 `{ticket, qr_img,...}`（B-P2-7）

## 不做

SSE（批 B——#2 的 ts 字段已留钩子）；拒答场景化文案（批 C）；过期自动刷新（SDK 不支持单换码）；ImBots.vue 向导 UI 改版（后端同链路受益）
