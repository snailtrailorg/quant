# 批 137a · pool/对账重拉的源格式与符号映射（数据正确性）

> 立项 2026-10-22。原「批 137 四子项」经盲审打回后**拆批**：本批只做可立即编码的两项（重拉失效 + 符号映射缺陷），
> 对账覆盖/时间盒见 `批137b`（判据须重写，另立）。

## 问题（盲审实证纠正后的口径）

### ① 分钟级对账重拉恒失败（不是日线）

- `_repull_symbol(adapter, kind, sub_kind, freq, src_sym, gap_start, gap_end)`（`engine.py:2240`）的调用点 `engine.py:2458` 做
  `src_sym = vt_symbol.rsplit(".", 1)[0]` ⇒ **剥成裸码**。
- tushare 侧 `_SUPPLY_PULL`（`base.py:577-599`）**没有** `(bar_minute, None)` 映射 ⇒ 恒 `UnsupportedFeature`（被 catch 计入 errors，静默）。
- **受影响面=A 股分钟**：`astock_daily` 不在 `_RECONCILE_SYMBOL_SCOPE`（`engine.py:1495`），该 scope 只有 `astock_minute`/`5min`；日线缺口走 tier1/`astock_daily_jq` 的 `_reconcile_dates`，不经本路径。
- 「改传 vt」**不够**：tushare `pull_minute(ts_code, freq, start_date, end_date)`（`tushare_adapter.py:246`）参数名与 `_repull_symbol` 传的 `symbol/start/end` 全不匹配，`fetch_supply` 用 inspect 过滤（`base.py:570-571`）⇒ 只剩 freq，必 TypeError。
- 也不能为了统一改走 `fetch`：crypto 侧（binance/okx）**无 `fetch`** 只有 `fetch_supply`，改了即崩。

### ② `vt_to_ts` 与 `to_ts_code` 同源 bug（映射缺 SSE）

- 两函数目前行为等价（都会把 vt 后缀套 `EXCHANGE_TS_MAP`），但该表**缺 `SSE`**（`schema.py:26-30`）⇒ `vt_to_ts("600000.SSE")` 原样返回 `.SSE`。
- `.SSE` 是本仓合法形态（`fees.py:33` / `risk.py:340` / `tasks.py:241` 实证）⇒ 池同步/回测建池把 `.SSE` 发去 tushare 必失败。
- 只合名不补映射 = 把 bug 一起合并。

## 产出

1. **源格式归一（engine.py:2458）**：`src_sym = adapter.to_source_symbol(vt_symbol)`。
   - `BaseDataAdapter.to_source_symbol` 默认直通 ⇒ crypto（binance/okx）零漂移（其 `pull_daily` 自带 `split(".")`）。
   - tushare 走批 131 的覆写（vt→ts_code，含 SSE 别名）。
2. **补 `(bar_minute, None)` 供应映射（base.py:577）**：新增薄壳，把 `symbol/freq/start/end` 适配到 `pull_minute(ts_code, freq, start_date, end_date)`（与 `_SUPPLY_PULL` 其余项同形）。薄壳内不再做形态转换（形态已由 1 归一）。
3. **映射补全（schema.py）**：`EXCHANGE_TS_MAP["SSE"] = "SH"`；`vt_to_ts` 改**薄别名**（`return to_ts_code(s)`），实现唯一、调用点零改动（不做全仓替换——5 处调用点会破限定范围）。

## 限定范围

改：`server/src/data_sync/engine.py`（1 行）、`server/src/data_platform/adapters/base.py`（映射项 + 薄壳）、`server/src/data_platform/schema.py`（映射 + 别名）、`server/tests/`（新增/扩展）。
不碰：`pool_data.py`、对账判据、时间盒（归 137b）。

## 验收标准

1. `to_source_symbol` 接线钉：`_repull_symbol` 收到 vt 时，tushare 的 `pull_minute` 实收 `600000.SH`；拆掉归一即红。
2. crypto 零漂移：`_repull_symbol` 对 binance 适配器仍收到 vt 原值（`to_source_symbol` 直通），断言一次。
3. 供应映射：`fetch_supply(kind='bar_minute')` 能到 `pull_minute` 且参数名对齐（`ts_code/freq/start_date/end_date`），不再 `UnsupportedFeature`、不再 TypeError。
4. 映射矩阵：`vt_to_ts("600000.SSE") == "600000.SH"`、`to_ts_code` 同值；`.SHSE/.SZSE/.BSE` 与已源格式幂等不回归。
5. 全量 pytest 绿。

## mock 方式

适配器替身 + `patch` `tushare_adapter.pull_minute` 断言入参；`_repull_symbol` 直调（不启 worker）。
