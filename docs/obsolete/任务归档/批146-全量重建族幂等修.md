## 产出

1. **engine.py 工厂通用去重**（`_make_full_rebuild_handler` 写入段 :3195 前）：`_pk = [c for c in pk if c in df.columns]`；`if _pk: df = df.drop_duplicates(subset=_pk, keep="last")`——**交集空跳过去重**（subset=[] falsy 会退化全列去重，B-P2a）；pk 缺列容错防上游再改版撞 NameError——namechange 修面。
2. **tushare_adapter.py pull_concept 窄投影**（:652-660）：返回前 `df = df.loc[:, ~df.columns.duplicated()]` 去重名列 + 取表列交集（ts_code/name）——**源特定列面归 adapter**，表不加列零迁移；新版 class1-3/item_size 等真消费者出现时再扩（不过度设计）。
3. **sync_config 复位**（上产后 DB 操作，非迁移）：concept_sync enabled=true + last_status=failed→idle（让下轮 07:00 周一轮自愈）。
4. **C 族新鲜度阈值按 id 分档**（`pool_reconcile.py` :230-231 **两行同改**）：`C_STALE_DAYS: dict[str, int]`——trade_cal=**370**（年度刷新 1 月 1 日，数据到 2026-12-31 齐全、10-05 success，7 天阈值对年度任务误伤 77 天告警），其余五键=7（不变）；判定行 `if age > C_STALE_DAYS.get(sid, 7):` + 文案行 `…（阈值 %d）" % (name, age, C_STALE_DAYS.get(sid, 7))`——**文案 %d 引用必须随判定行同改**（改 dict 后旧 `% C_STALE_DAYS` 整型格式化必 TypeError，盲审 B-P1b）。
5. **回归钉（tests/）**：①namechange 路径——mock fetch_supply 返回含同键两行 df ⇒ 断言 INSERT 行数=去重后（1 行）且 success；②concept 路径——mock 返回 12 列新版（含重名列）⇒ 断言写入仅 ts_code/name 两列、3000→去重后行数；③既有 _TIER1_FULL 注册钉全量回归；④trade_cal ts=200 天前 ⇒ 无告警、astock_list ts=200 天前 ⇒ 有告警（分档钉）。

## 接口契约

- `_make_full_rebuild_handler(kind, sub_kind, table, pk, date_param=None) -> Callable`（签名不变；行为=写入前去重 by pk）。
- `pull_concept(trade_date: str = "", ts_code: str = "") -> pd.DataFrame`（签名不变；返回保证=列集 ⊆ {ts_code, name}、无重复列名；**行去重由工厂 pk 兜**——B-P1a 修正）。
- 回滚：git revert 三文件 + `UPDATE sync_config SET enabled=false, last_status='failed' WHERE id='concept_sync'`（产 3 逆操作）。
- 读写表：namechange/concept（DELETE+INSERT 全量重建，幂等）；security_state（namechange 派生写）；sync_config（状态复位 UPDATE）。
