## 0. 契约（一句话）

`_sync_gap_sync` 增加**显式开关** `window_guard`（默认 `False`＝逐字现状）；仅 per-date 路径（`_sync_gap_sync_one`）传 `True` 时，按本轮窗口 `win_map[sym]=(lo,hi)` 夹取：**窗口外既有行零写入**（不 closed / 不 touch / 不转 uncertain / 不对齐 / 不 pull / 不因新锚而 INSERT 重开）；窗口内语义逐字不变。

**为什么要显式开关**：`_sync_gap_sync` 有 3 个调用点（2150 per-date / 2486 per-symbol stale / 2578 per-symbol 正常）。其中 **2486 是单日窗 + `uncertain_map=stale_source`**，语义是 §5.4「全族抑制一切缺口主张」（必须写全部 live 行）。若按窗口夹取 uncertain，会破坏该门且 `stat["uncertain"]=sm_total`（2490 硬编码）与库内实态不符。故夹取**只对 per-date 生效**，per-symbol 两路代码路径不进夹取逻辑 ⇒ 行为逐字不变。

## 2. 改动规则（`window_guard=True` 时；为 `False` 时走原路径，零变化）

前置：`lo/hi` 必须非空（per-date 必传；为空 ⇒ `ValueError` 显式失败，不静默退化）；`in_win(a) := lo <= a <= hi`（等宽归一串，字典序＝日期序）；`live` 切 `live_in` / `live_out`。
**窗口归属按锚（`gap_start`），重叠判定按区间（`[gap_start, gap_end]`）**。

| # | 分支（对应写段） | 现状 | 改后 |
|---|---|---|---|
| R1 | `unc_u` 2113 / `unc_i` 2119 | 全部 `live` 转 uncertain | 仅 `live_in` 转；`unc_i`（lo/hi 插入）不变 |
| R2 | `touch` 2132 | 全部 `live` 刷 last_seen | 仅 `live_in` |
| R3 | `align` 2097 / `align_nh` 2103 | 全部 `live` | 仅 `live_in`；`live_out` 命中直接跳过 |
| R4 | **`clo` 2107** | 全部 `live` 中 `a ∉ current` ⇒ closed | **仅 `live_in` 且 `in_win(a)` 才 closed**；`live_out` 零写入 |
| R5 | `ins` 2123 / `reopen` 2127 | 按 `by_anchor` 判 | `current` 新锚 `a` 若落在任一 **`live_out` 非终态行**（`_SYNC_GAP_LIVE_STATES`，1561）的 `[gap_start, gap_end]` 内 ⇒ **仅从 `ins/reopen` 候选剔除**（不 INSERT、不 reopen、不写该行任何列）；其余不变 |
| R6 | — | — | **删除**（原「跨窗口对齐 gap_end」与「零写入」矛盾、且无任何验收可证伪；「不新开锚」已由 R5 单独实现） |
| R7 | `pull` 2135 | `pulled_map` 全量计数 | 仅 `in_win(a)` 的锚计数 |

**R1 的 `if live:` 不得改成 `if live_in:`**：`ureason` 分支以 `if live:`（全量 live 行）判定走 `unc_u` 还是 `unc_i`；夹取只把 `unc_u` 的循环体换成 `for r in live_in:`，`if live:` 本身与 `unc_i` 分支逐字不变。若误改成 `if live_in:`，「有窗口外 live 行、窗内无 live 行」时会被误判为「无行」而 INSERT 一条 scope 级 uncertain 行（凭空造行）——验收 5 的「行数不变」即钉此。**per-date 抑制语义随之收窄**：`calendar_uncovered` / `local_unreadable` 在「仅窗外 live 行」时该轮零写入（含倒置窗），「本轮不确定」不再落表；属知情取舍，见 §6。

**R5 剔除集合写死**：`{a ∈ current | ∃ r ∈ live_out, r[2] ∈ _SYNC_GAP_LIVE_STATES, r[0] <= a <= r[1]}`；终态行不参与（防 `server/tests/test_batch109_sync_gap.py:265-271` 的 `unreachable` 隐性漂移）。实现中 `live_out ⊆ live`，终态排除实由 `live` 的 `_SYNC_GAP_LIVE_STATES` 过滤保证，该条件为与设计逐字对齐的**防御性冗余（恒真）**，不得删以免 `live` 口径变更时语义漂移。
**R6 删除后**：窗口外行 `gap_end` 亦不变 ⇒ 生产重拉口 `_repullable_map(prev_map)`（`engine.py:2547`，输入＝`prev_map` 内存行）的区间/计数输入不变（`last_seen/hit_rounds/pull_count` 均不变）⇒ 重拉资格与判据均不污染；`_list_repullable`（2311）是单标的 SQL 版，仅测试作等价 oracle 调用、生产不调。

## 3. 契约细节（自包含）

- **签名**：`_sync_gap_sync(sync_id, *, symbols, win_map, round_id=None, gaps_map=None, uncertain_map=None, pulled_map=None, prev_map=None, window_guard=False) -> dict`。新增 1 个 `bool` 参数，默认 `False`；返回字典键与语义**逐字不变**（`updated` 仍＝「对齐整值行数」，不混入任何新计数）。`window_guard=True` 时 `prev_map` 须由 `_sync_gap_scope_rows` 产出（日期已 `_anchor` 归一）；仅单 symbol 路径传 True ⇒ `out_spans` 规模恒 ≤ 单标的既有行数，无需区间索引。
- **唯一传 `True` 处**：`_sync_gap_sync_one`（2141）内部调 `_sync_gap_sync(... window_guard=True)`；`_reconcile_symbols` 的 2486 / 2578 两处**不改**。
- **不新增表/列/状态词/模块/锁/调度档**；`_gap_judge` 不动（per-date `round_id=None` 不参与判据；per-symbol 走 `window_guard=False`）。
- **影响面**：per-date＝唯一受益路径；per-symbol（含 stale 单日窗）行为逐字不变；单测 `_vsync`（`server/tests/test_batch109_sync_gap.py:79`，win=10-01~10-10）走 `window_guard=True`：多数用例锚 10-02~10-06 在窗内；`t3`（`test_terminal_excluded_not_overwritten_by_gap_claim`，2019 锚）与 `v6`（`test_uncertain_inserts_scope_row_when_empty`，无锚）锚不在窗内，但 t3 既有行是终态 `unreachable`（`live` 为空 ⇒ 零写入、新锚走「只告警不改写」分支）、v6 走 `unc_i`（R1 声明不变）⇒ 二者断言同样不变。故既有断言全部不变。
  **另注**：`server/tests/test_batch110_reconcile_scale.py` 的「批量 ≡ 逐条」等价性断言，批量侧走默认 `False`、逐条侧走 `True`，**仅因该 fixture 是 fresh 库且锚（20261002）落在窗内 `[20261001,20261004]` 才仍成立**；窗外既有行时两路本应不等价（by design），**不是无条件等价契约**——验收 8 的混合 fixture 对照即钉此。

## 5. 验收（可证伪，dev 真库 + 新守门用例）

3. **既有测试零修改全绿**：`server/tests/test_batch109_sync_gap.py`（含 `test_open_then_close` / `test_partial_fill_yields_new_anchor_no_ghost` / `test_closed_reappear_is_new_event`）、`server/tests/test_batch110_reconcile_scale.py`、`server/tests/test_layering.py`（三份均在 `server/tests/` 下）。
4. **跨窗口不造重复行**：fixture 造窗口外行 `(10-10,10-20)`，以 `win=[10-15,10-15]`、`gaps=[(10-15,10-15)]` 调用 ⇒ `sync_gap` 行数不变、原行**所有列**不变、`opened==0`、`updated==0`。

6. **per-symbol stale 分支行为不变**：构造 stale 场景（`win_map` 单日 + `uncertain_map`）经 `window_guard=False` 路径 ⇒ 全族 live 行（含窗口外锚）转 `uncertain`，`stat["uncertain"]==sm_total`。
7. **统计自证**：同一组窗口内 fixture 在 `window_guard=False/True` 下 `stats` 各键相等。

9. **R1/R2 正向路径（步 4 A-P2-3）**：窗内 `open` 行 + `uncertain_reason` ⇒ 该行转 `uncertain`、`stats["uncertain"]==1`；`gaps=None` ⇒ 窗内行 `last_seen` 被刷新（证明夹取没有误伤窗内语义）。
10. **倒置窗知情取舍（步 4 B-P2-5）**：`win_lo > win_hi` + `uncertain_reason="calendar_uncovered"` ⇒ `live_in` 恒空 ⇒ 全族零写入、`sync_gap` 行数不变、`stats["uncertain"]==0`（不插 scope 级 uncertain 行、不 fail-fast）。

## 6. 明确不做（本批边界）

- **不修窗口外的 `open` 行**（只保住、不补数据）——修复出口属阶段③后续条；验收只断言「行仍在、状态与所有列未变」，**不断言数据落库**。
- 不改 `win_map` 定义/窗口值；不动 `retention_days` / 停牌 / 预算；不新增状态词/表/模块/锁/调度档。
- 不改 `_gap_judge` 统计口径（本批对判据零影响，见 §3）。
- **不做 `gap_end` 单向扩展**（R6 已删）；窗口外行区间若需修正，属后续条。
- **不保留 per-date「本轮不确定」落表信号**：`calendar_uncovered` / `local_unreadable` 在「仅窗外 live 行」（含倒置窗 `lo>hi`）时按 R1 收窄为零写入，既不落 scope 级 uncertain 行、也不 fail-fast（后者会把日历覆盖信号变成同步失败）。「日历未覆盖该轮如何留痕」属阶段③后续条（D1 就绪门 / 修复条），本批只钉住该取舍可证伪（验收 10）。
