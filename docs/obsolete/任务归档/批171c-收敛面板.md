## 0. 背景与杠杆（prod 实测 2026-11-06）

面板 partial 3400 中 A 股类 2486 只：**缺口 >100 日的 1591 只（64%）**、中位缺口 139 日。big-gap 抽样全为**历史长停/暂停上市**型（000670 的 886 天空洞＝2020-03→2022-08 暂停上市期，suspend_d 在案实证）。⇒ **面板不收敛的主因是历史停牌窗无净化数据**（171b 只回了 2026-10 后），而非采集缺陷。

## 腿 1：suspend 历史回补（数据腿，试点）

- **迁移 0169**：retention 地板 2026-10-01 → **2014-01-01**（上游最早可回补窗，2013 前 API 0 行——回不了的自然空窗，宁多报）。增量调度安全：last_sync_date 已推至 20261106，地板只影响回补夹取与无游标首跑。
- **回补执行**：`backfill_from=20140101` 分窗跑（限速 0.3s/日，全窗 ~15min）；幂等 upsert，重跑无重复。
- **验收（可证伪）**：①回补后 prod `suspend_calendar` 覆盖 2014→今（日行数与上游抽样一致）；②面板净化自动生效——000670 类标的 expected 骤降（dev 实证：2020 窗 243→50，减 193 暂停上市日）；③面板 partial 数显著下降（前后差记录）；④增量轮不受影响（16:35 调度照常）。
- **边界**：`first=自然日非交易日`（如 1-01）落外推分支不减——真实面板 first 恒为 bar 日不受影响，记录在案。
- **明确不做**：不改 expected_bars 外推分支语义（宁多报）；不删 suspend 数据（downgrade 只回地板值）。
