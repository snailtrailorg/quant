## 0. 契约（自包含）

- **`_clamp_span(start, end, max_days) -> tuple[str, str, bool]`**（engine.py 模块级纯函数）：`(start, effective_end, truncated)`——`effective_end = min(end, start + max_days - 1)`（含两端）；`max_days is None ⇒ 不夹取`（**0/负数不进本函数**——防线在回落链，见下）。日期算术一律经 `_ymd`（:1129）+timedelta，**禁新写 str 解析**。入参出参 YYYYMMDD 串。
- **跨度回落链（唯一防线，每轮一次）**：`_get_config` 读 `max_span_days` 列（`cfg.get`——**缺键容忍**：手搓 cfg 的 8 个既有测试文件不炸，缺键/NULL ⇒ 下一级）→ `system_config.sync_max_span_days`（**非正整数/不可解析 ⇒ 回落 366 + logger.warning**，171 留痕纪律——0 不是「不夹取」是手滑，裁定 5 防的正是它）→ 366。挂 `cfg["_max_span_days"]`；禁 handler 体内直查 system_config。
- **截断轮游标不变式（P0-2 核心）**：`truncated=true ⇒ cursor_upto/last_success_date ≤ effective_end`——tier1 工厂（无键族 cursor_upto=end_date :3451 与 reconcile=False 早退 :3361 两处）与 cb_daily（:2929 核实后同）**必须改写为 effective_end**；daily_batch/crypto(jq) 数据驱动游标天然安全。否则截断余窗永不再拉（增量首跑必触）。
- **clamped/next_from 的三个出具点**（handler 返回体）：
  - `clamped`: `{"floor": str|None, "span": bool}`——**批 A floor 恒 None**（归因接口是批 B 域——`_window_floors` 现只返 max 值无归因，本批不扩）；span=被截断。**仅回补轮出具**（增量轮截断不示——游标自动续，示了会诱导 FE 续跑钮错配 crypto overwrite 路径）。
  - `next_from`: 仅回补轮且 truncated——**单一助手 `_next_from(effective_end, failed_dates, last_success_date=None)`**：有 last_success_date（keyed 族）⇒ 取之；否则有失败日 ⇒ `min(failed)+1`（==连续成功末日+1）；无失败 ⇒ effective_end+1。**禁在站点各写推法**（判定单源纪律）。
  - **tier1 工厂三返回点枚举**（P0-3）：②reconcile=False 早退分支（:3431-3439，**suspend_d 专属出口——验收 2 的族**）必须带两键；①start>end 早退与③正常尾部按条件带。
- **透传链三跳各补键（P0-1，v1「零改」论断作废）**：engine sync() 返回体白名单（:512-515）+ tasks.py hset mapping（:1353-1361，**clamped 须 json.dumps**——hset 值只收标量）+ sync.py AsyncResult 兜底（:248-258）——三跳都加 `clamped`（JSON 串）/`next_from`；读侧 hgetall 原样透出（零改 ✓）+ FE `JSON.parse` 容错。
- **FE**：DataManage 轮询处 clamped 提示＋续跑按钮（复用 `submitBackfill` 通道 :483-494，权限键 data_sync 现状）；文案入 `web/src/locales/index.js` 三语言块（zh :674/en :2078/繁 :3721——N 语言纪律）。
