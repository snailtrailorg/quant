- **DEF-06（`_local_dates_map` 下界）v2 口径（P0 修正）**：原「min(sm_rows floors)」不可行——:2870 在 per-symbol 循环**之前**，floors 未算（list_date min=1990-12-19 顶替则 stock 恒真退化无效）。**修法=家族级地板预读**：循环前 `_window_floors(adapter, kind, cfg, sym=None)` 一次（`sym=None`=家族级：retention+source_earliest 取 max，无 inception——:1373 既有语义），其 floor 作为 `_local_dates_map` 的 `since` 下界。**收益实证**（盲审）：stock 族 1990→**2010**（available_range 顶住）、perp 族→2026 近月；非完美下界（per-symbol inception 更紧）但**读侧集合消费是超集投影**（`local_map.get(sym)` 后与 expected 逐日比对——超集零语义漂移，test_batch110 等价守门仍绿）。**DISTINCT 不加**（dict[str,set] 天然去重）；**fetchall 不改**（下界后量级回窗内）。
- **since 参数契约**：`since: str | None = None`；None=零漂移（SQL 不加条件=逐字现状）。SQL 形态 `AND {date_expr} >= %s`（复用 to_char YYYYMMDD 表达式，8 位定长字典序=日期序，UTC/SH 两形态均无时区坑——盲审 P2 核过）。
- **`_window_floors(sym=None)` 返回 None 时**（三源皆未声明）：since=None 零漂移（现状兜底）。
