## 0. 契约（自包含，v2）

### 件一：halted×平仓方向放行（A-P0-1 判据修正）
- **判据＝`order["action"]=="SELL"`**（非自造 offset 词表——Order dataclass 无 offset 字段、XTP/EMT send_order 硬编码 `Offset.NONE`、A 股现货 SELL 必然减仓，与 market_op 豁免/F-31 日亏/frozen_allows 同判据哲学）。halted 分支：SELL 放行（进第 2 步后链），非 SELL 照拒（HALTED）。**边界注释钉**：本判据是 A 股现货共享分支——crypto 永续接入时 SELL≠平仓（开反向仓），届时须换判据。HALT_UNREADABLE 全拒不变（读不到=保守，A 认可）。
- risk_log reason 注记「熔断·平仓方向放行」（放行可审计）。

### 件二：一键撤单 `POST /api/risk/cancel-all`（perm=**halt**——B-P0-1 修正：market_op 是 role×market 维非 API 维〔require_perm 走 api 键集，"market_op" 不在 API_PERM_KEYS ⇒ 恒 403 含 admin〕；halt 键=admin 独占〔批 77 全站影响半径判据〕，与 :193 halt 端点同键——撤单/全平同属全站急停面）

- **通道（A-P1-2/B-P1-5 合流定稿）＝GETDEL 请求键+结果键**（`_unfreeze_poll` hub_worker :548 与 freeze_event :37 双先例；pub-sub 不可选——worker 全轮询无订阅面 B 实证）。键：请求 `risk:cmd:{tid}`（值=JSON {id, verb, ts}——GETDEL 天然幂等单消费），结果 `risk:cmd:result:{req_id}`（worker 写 TTL 10min；web 短轮询 5s 窗，超时返 202 dispatched）。**消费抽模块级函数** `consume_risk_cmd(r, adapter, tid)`（B-P1-7 批 56b run() 闭包不可测教训）供测试直调。

### 件三：一键全平 `POST /api/risk/close-all`（perm=halt+body `{"confirm":"CONFIRM"}`——B-P2 键名钉，先例 Risk.vue :203 RESUME prompt）
- `trading.py _close_all_positions(adapter, account_id) -> dict`：query_position（事件驱动轮询既有时限）→ 逐标的：
  - **volume=可卖仓截断**（A-P0-3：`volume - frozen`——当日买入冻结仓剔除，T+1 废单防线；策略路径同款截断在 strategy.py :430 的兜底先例）。可卖=0 的标的跳过并记「T+1 冻结不可卖」。
  - **price=最新价/成本价真实值**（A-P0-2：市价 price=0 必被 INVALID_PRICE 拒；用持仓快照 cost_price 或 bar 最新价——先 cost_price〔必然可得〕）。
  - order dict 构造：**不带 strategy_id**（A/B 同点：max_trades_per_day 计数豁免——急停非策略行为）+ action="SELL" + operator=发起人 + account_id。
  - **SELL 方向豁免 MAX_SINGLE_AMOUNT 截断**（A-P1-1②/B-P1-6：reduce-only 被截=残留仓反语义——平仓方向金额上限不适用；risk.py :392 区 SELL 豁免）。
  - 走 check_order 全链（halted 放行〔件一〕；其余照走）→ send_order。
- **无自动重试**（残余=人工面板处置）；结果汇总 `{closed_requested, skipped_t1, rejected, positions_remain}`（**T+1 frozen 份额残余口径声明**——B-P2：available=volume-frozen，当日仓不可平=预期非失败，skipped_t1 列名示）+audit_log+`risk.close-all` 告警。
