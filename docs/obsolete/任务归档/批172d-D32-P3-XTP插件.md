## 目标

XTP 的 MD 与 TD 收进 `providers/xtp/`，通用层零 vnpy；号段改 DB 租约（唯一域 = `(account_id, provider, terminal_id)`）、

`data_license` 订阅门落地；批末删除 XTP legacy 投影与 ACL。

## 产出

1. **迁移 `0179_d32_session_slot.py`（expand）+ `0180_d32_account_key_market_contract.py`（contract）**：
   - 建表 `provider_session_slot(account_id BIGINT, provider TEXT, terminal_id INT, holder TEXT NOT NULL, boot_epoch BIGINT NOT NULL, heartbeat TIMESTAMPTZ NOT NULL DEFAULT now(), PRIMARY KEY(account_id, provider, terminal_id))`。
   - `trading_account.impl TEXT NOT NULL DEFAULT 'legacy' CHECK (impl IN ('legacy','plugin'))`。
   - `account_key` 部分唯一：**先预检** `(market, account_key)` 重复（含 enabled 行）→ 有重复 raise（禁静默）；然后 `DROP INDEX CONCURRENTLY IF EXISTS ix_trading_account_account_key` → `CREATE UNIQUE INDEX CONCURRENTLY uq_trading_account_market_account_key ON trading_account(market, account_key) WHERE account_key IS NOT NULL AND enabled`。
   - downgrade：恢复旧索引（同名 `ix_trading_account_account_key`，重复行预检 → 有重复 raise）→ 删列 → 删表；可重入（IF EXISTS）。
   - **可逆性声明**：租约表是瞬态数据（心跳行），downgrade 不保留其内容即等价（重启后重建）；代码投影/ACL 的删除由整 release rollback 承担。本迁移归类 **expand**（无数据回填、无列删除），不走破坏性迁移门。
   - **回滚管道**：downgrade 的重复行 raise 只拦「数据不满足约束」；A06 rollback 遇本迁移失败**降级为告警并继续**（旧代码容忍新表/新列），不阻塞整版本回滚。需清空租约行时：`DELETE FROM provider_session_slot`（先停相关任务），步骤写入 `deploy/DEPLOY.md` 回滚节。
2. **`strategy_runner/session_slot.py`**：`SessionSlot` + `SessionSlotAllocator.acquire/renew/release`。
   - `acquire` 单语句（§9.5 SQL 原文），`RETURNING (holder = %s) AS acquired`；返回 `acquirer=False` → 抛 `SessionBusy`（入口映射 EX_TEMPFAIL 75）；terminal 越界/耗尽 → `SessionConfigError`（78）；DB 错 → `SessionUnavailable`（75）。
   - **库层不抛 SystemExit**；退出码映射只在入口（main/hub_worker）。
   - `renew(slot)` = `UPDATE ... SET heartbeat=now() WHERE account/provider/terminal/holder = ... AND heartbeat > now()-interval '45 seconds' RETURNING 1`；0 行=被抢，抛 `SessionLost`；异常=DB 错（重试，非被抢）。
   - `release` 必须带 holder 条件（防旧进程删新主）。
   - `terminal_id`：TD=`(tid-1)%98+2`；MD 取账号行预留号（manifest `terminal_id.md_domain`）；域检查按 role。
   - **legacy 账号不写租约**：`impl='legacy'` 走旧进程模型，不调用 allocator；互斥由 `account_key` 部分唯一 + impl 单值保证。切到 `plugin` 需整任务重启（部署窗内），不存在同账号双路径同号争抢。
   - MD 单槽（id 固定）滚动切换 = **先停后起**（hub 由 systemd 单实例管理），不做并存 tie-break。
   - `order_prefix = f"t{tid}:e{boot_epoch}:"`（boot_epoch 来自进程启动时间戳，调用方传入）。
3. **`providers/xtp/`**：`__init__.py`（`from . import plugin` 触发 `registry.register("trading_account","xtp",XtpPlugin())`）、`manifest.py`（port_caps={`execution`,`market_data`,`account`}；terminal_id 域 md=[1,1]/td=[2,99]）、`plugin.py`（`build(account, role, slot)` 返回 role 视图：md 只暴露 MarketDataPort，td 只暴露 ExecutionPort，越权抛 `registry.UnsupportedCapability`）、`translate.py`、`_transport.py`（**唯一 vnpy_xtp import 点，懒导入**）、`md.py`（第一段=端口化包装，连接原语下一段搬入）、`td.py`。

## 接口契约

~~~python
@dataclass(frozen=True)
class SessionSlot:
    account_id: int; provider: str; role: str
    terminal_id: int; order_prefix: str; window_open: bool; tid: int

class SessionBusy(Exception): ...        # 有主 → 入口 75
class SessionConfigError(Exception): ... # 越界/耗尽 → 入口 78
class SessionUnavailable(Exception): ... # DB 不可用 → 入口 75 退避
class SessionLost(Exception): ...        # renew 0 行 → 立即断开退出

class SessionSlotAllocator:
    @classmethod
    def acquire(cls, account_id: int, provider: str, role: str, tid: int,
                boot_epoch: int, window_open: bool) -> SessionSlot: ...
    @classmethod
    def renew(cls, slot: SessionSlot) -> None: ...   # 失败抛 SessionLost/SessionUnavailable
    @classmethod
    def release(cls, slot: SessionSlot) -> None: ...

class XtpPlugin:
    manifest: Manifest
    def build(self, account: AccountDTO, role: str, slot: SessionSlot) -> object: ...
~~~

- `impl='legacy'` 与 `'plugin'` 双轨；同账号不得混跑（唯一索引 + 审计列）。
- S7 金标准：开发期从旧路径**录制** OrderRequest/回报/查询序列到 `tests/fixtures/legacy_xtp/`，新插件回放比对；批末删除旧路径后测试仍可跑（不依赖 live legacy 代码）。
