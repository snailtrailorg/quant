# 批 178 · 筛选派生指标非有限值致 500（可转债方案加载失败）

> 2026-11-14 用户报「可转债的筛选方案加载失败」；两次上产修复（202611142057 / 202611142117）。

## 现象
- GET /api/screen/presets?category=convertible 200；点应用 → POST /api/screen/run **500**；DSL 路径正常。
- journal：json.dumps → **ValueError: Out of range**（Starlette JSONResponse 用 allow_nan=False）。

## 根因（两层）
1. 可转债派生指标 premium_pct/double_low 由 SQL 现算；prod 有 conv_price 极小的行 → 分母下溢 → 结果溢出。
2. **numeric 列取回是 Decimal**：PostgreSQL numeric 支持 Infinity/NaN，Decimal('Infinity') 经 FastAPI
   编码成 float('inf') 后 JSON 序列化失败。第一次只清洗 float，故仍 500。

## 修
1. data_platform/screen.run_query：取数后把 **float 非有限**与 **Decimal 非有限**都降级 None。
2. web_api/routes/stock._f（astock/cb/etf 三处）：Decimal 非有限 → None。
3. 守门 tests/test_batch178_nan_guard.py 3 条：run_query(float)、run_query(Decimal)、cb 端点。

## 验收
- 全量 **3410 passed / 2 skipped**。
- prod：POST /api/screen/run（convertible 预设）**200**、返回 30 行（vt_symbol 已 MIC）。

## 观察（未处理，数据面）
修复后可见部分转债 premium_pct 高达 400~500%（如 123270/113059）——说明这些行
conv_price 极小或正股价格异常，属**数据质量问题**，与本次 500 无直接关系；如需治理另立数据批。
