# 批21 标题栏与圆钮统一

> 立项 2026-09-14（用户五裁定）。全站圆形图标按钮统一尺寸+统一风格；标题栏三个非圆钮（语言/暗色/健康）转圆钮乒乓；卡片 header 工具栏「创建/新增/邀请/同步」文字按钮 icon 化（title 携带原文字）。
> 文案：用户可见 tooltip/title 一律经文案师智能体（`.claude/agents/copywriter.md`）产出，「点击切换为XXX」句式为用户钦定。

## 用户五裁定

1. 圆钮建统一风格，先设 **32px**（后期改尺寸只改一处）。
2. 语言切换 = **单按钮动态显示目标语言**（zh 态显「EN」、en 态显「中」）。
3. 暗色 = **switch → 圆钮乒乓**（亮态 Moon / 暗态 Sunny）。
4. 健康 = **Warning 圆钮**，健康时隐藏、异常才显示，点击转健康页 `/observe?tab=health`。
5. 工具栏按钮**不一刀切**：卡片 header 工具栏位 icon 化；**导航/行内/弹窗 footer/表单内按钮保留文字**。

## 一、目标

全站圆钮视觉统一：统一尺寸 32px、统一渲染走共享组件、乒乓按钮 title 改「点击切换为XXX」句式；标题栏三控件归位圆钮并重排顺序；19 处卡片 header 工具栏文字按钮 icon 化。

## 二、依赖（就绪）

- 无外部依赖。Element Plus `@element-plus/icons-vue ^2.3.0` 已装；`tokens.css` 令牌体系已建；`IconBtn` 无既有实现（本批新增）。
- 前置批 17/18/19/20 已全部上产（prod 202609131943），本批在其干净基线上。

## 三、产出（分三块）

### A. 基建（一次性，后期改一处）

- `web/src/styles/tokens.css`：`:root` 加 `--icon-btn: 32px;`（圆钮尺寸唯一源；`html.dark` 无需变体——尺寸与色彩无关）。
- 新增 `web/src/components/IconBtn.vue`：封装 `el-button circle`，props=`icon/title/type/disabled/loading/ariaLabel`，emit `click`。渲染约定：`circle` + **`:style="{width:'var(--icon-btn)', height:'var(--icon-btn)', padding:0}"`**（不是 `size` 属性——EP `size` 只吃 large/default/small；`padding:0` 保证文字槽位「EN」两字符不撑破 32px 圆）+ 内部 flex 居中；有 icon 渲染 `<el-icon><component :is="icon"/></el-icon>`，无 icon 用 `<slot/>`；`title` 存在时自动 `:aria-label="title"`（无障碍）。默认 `inheritAttrs`（单根透传，ColumnSettings 的 el-popover `#reference` click 触发依赖此透传，**勿设 inheritAttrs:false**）。
- 后期改尺寸 = 改 `--icon-btn` 一处。

### B. 标题栏（`web/src/layouts/MainLayout.vue`）

| 控件 | 改动 |

**顺序重排**（按功能分组，左→右）：`急停(安全) · 健康 铃铛(状态) · AI助手 帮助(工具) · 语言 暗色(偏好) · 用户(身份)`。
- 分组用子容器落地：状态组/工具组/偏好组内 gap 16px、组间 gap 24px（顶栏右侧容器改嵌套 flex）。
- **已知行为**：健康异常才显示，出现时右侧工具/偏好/用户整体右移约 44px——告警态的合理跳位（罕见且本应醒目），如需静态稳定可在视觉验收时改用 `visibility:hidden` 占位，本次不默认占位。

## 五、接口契约

**新组件 IconBtn.vue**（web/src/components/IconBtn.vue）：
```js
props: { icon: Object /* EP 图标组件 */, title: String, type: String /* default|primary|danger|warning */,
         disabled: Boolean, loading: Boolean, ariaLabel: String }
emits: ['click']
// 渲染 <el-button circle :type :title :disabled :loading :aria-label="ariaLabel||title"
//         :style="{width:'var(--icon-btn)',height:'var(--icon-btn)',padding:0}" @click>
//   <el-icon v-if="icon"><component :is="icon"/></el-icon><slot v-else/>
// </el-button>
```
