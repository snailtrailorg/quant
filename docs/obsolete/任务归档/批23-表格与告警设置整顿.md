# 批23 表格与告警设置整顿

> 立项 2026-09-15（用户七项裁定）。表格交互与告警设置的收尾整顿：表头位置规则统一、列筛选/行筛选图标化、通知确认机制退役、AI 归因退役、三表（通知/日志/审计）批量删除、设置页签改名。

## 一、目标（用户七裁定）

1. **表头位置规则统一（用户已确认）**：**卡片 header 左=标题，右=筛选+动作组（筛选/新建/刷新/列设置/导出，行筛选改弹窗后同样放右侧）**，逐页核查归位。
2. **列筛选按钮图标**：ColumnSettings 的 `Filter` → `Operation`。
3. **行筛选下拉 → Filter 弹窗多选**：TaskManager（状态）、Backtest（状态）、Logs（级别，现状有两处重复下拉合一）的行筛选 `el-select` 改为 `Filter` 图标按钮 + popover 复选组（可多选、含"全部"）。
4. **通知确认机制退役**：删「全部确认」按钮与「确认时间」列（ack 后端端点保留不动，最小改动）。
5. **AI 归因分析退役**：Logs 页「AI 分析」按钮+弹窗+`/api/log/analyze` 后端端点整链删除。
6. **三表批量删除**：通知/日志/审计表格加 selection 复选 + 「删除所选」+「全部清除」按钮；后端新增 3 个 DELETE 端点。
7. **设置页签改名**：`alertsTab`「告警」→「告警通道」/「Alert Channels」。

## 二、产出

### A. 后端（双盲审 A+B 合并修订后）

1. `GET /api/log` **补 id 字段**（盲审 B-P0-1：现响应无 id，删除契约不成立）。
2. 两个删除端点（盲审修订：**POST /api/xxx/delete** body `{ids?: [int], all?: bool}`——贴项目 batchDeleteInvites 先例，不用 DELETE+body）：
   - `POST /api/notifications/delete`：**require_perm("user_mgmt")**（提级，非对齐读的 read）+ **可见类别作用域** `AND category = ANY(visible_categories(role))`（对齐 ack-all 写法，防越权删不可见类别）；`all=true` 仅 admin。
   - `POST /api/audit/delete`：require_perm("user_mgmt")；audit 自删尤其留痕。
   - 两端点均写 `audit_log(username, "xxx_delete", "n=…")`（盲审 A-P1-3：删数据必留痕）。
   - **日志不做删除（用户裁定 2026-09-15：候选④）**——task_logs 是实盘任务时间线不动，GET /api/log 也不补 id（B-P0-1 随裁定④消解）。
3. `GET /api/tasks` 支持 `status=ANY(多值)`（盲审 A-P1-5：TaskManager 行筛选多选走后端过滤，防稀疏状态被挤出窗口）。
4. `/api/log/analyze` 端点 + `LogAnalyzeReq`（**被 6 个路由文件 import，同步清**：trading/strategy/backtest/system/sync/auth_routes）+ `_analyze_logs_with_llm` + api.js `logAnalyze` 退役（用户裁定 5，独立于日志删除裁定）。

### B. 前端（双盲审修订后）

1. `ColumnSettings.vue`：图标 `Filter` → `Operation`；title 与 RowFilter 的 `Filter` 钮明确区分（盲审 B-P3）。
2. 新组件 `RowFilter.vue`：`Filter` 图标钮 + popover 复选组；契约（盲审 B-P1-4 补全）：`props {options:[{value,label}], modelValue:[], title}`，**「全部」= 空数组（无过滤）**，勾选态双向同步；放 header 右侧动作区。**动作组统一序：筛选 → 新建 →（页面特有）→ 刷新 → 列设置**（盲审 B-P2）。
3. 三页接入（数据流逐页）：TaskManager=后端 `status=ANY` 重拉；Backtest=本地 `filteredRuns` computed（状态 label 补词条，盲审 B-P2）；Logs=本地 computed（**表格下方死筛选表单整组删除**——filterLogs 未定义属批22 前遗留死控件，盲审 A-P1-4；选项集以后端 task_logs 实际枚举为准，统一两处不一致）。
4. `NotificationTable.vue`：删 ack-all/unacked/acked_at 列；加 selection 列（**row-key=id + reserve-selection**——30s 轮询重赋值不清勾选，盲审 B-P1-6）+ 删除所选/全部清除（**ElMessageBox confirm 数量回显**，盲审 B-P1-1）。
5. `Logs.vue`：AI 分析整链删（按钮/弹窗/doAnalyze/errorLogs/analyzing/analysisResult/showAnalyze/ElMessage 孤儿）；**不加 selection/删除（用户裁定④：日志不做删除）**；行筛选接 RowFilter + 死筛选表单整组删。
6. `Audit.vue`：筛选表单（actor/action）迁 header 右侧 RowFilter 形态或收纳；导出归右侧动作区；表加 selection+删除（confirm）。
7. **Dashboard todayEvents 连带**（盲审 B-P1-2）：确认退役后 active 池只增不减——todayEvents 改拉 `('all', 50)` + 前端过滤今日。
8. `locales`：alertsTab「告警→告警通道/Alerts→Alert Channels」；新增（删除所选/全部清除/筛选）；孤儿点名清单：`notify.ackAll`、`cols.confirmedAt`、`log.analyzeHint/phAnalyze/noResult/analyzeFailed/aiAnalyzeCount/aiTitle/analyze`；api.js `ackAllNotifications` 删。
