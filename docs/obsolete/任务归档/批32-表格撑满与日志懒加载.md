## 二、设计

### 32-1 TableShell `fill`
- prop `fill: Boolean` + `fillReserve: Number = 40`（下预留——**≥30px**：el-main padding-bottom 30px，小于则残留外滚 A-P2-1；页有表下元素时调大）
- 计算：`可用 = el-main 底 − 表格 rect.top − fillReserve`（**锚 el-main rect.bottom 非 viewport**——fixed footer 22px 遮挡巧合非设计 A-P2-2），地板 240px；el-main 引用经 closest('.el-main') 取
- 重算时机：ResizeObserver **观察表格自身**（页签 v-if 激活 0→实高自然触发）+ window resize
- **fill 生效时忽略外部传入的 height/max-height**（B-P2-7 契约；Logs/DataIntegrity 的旧值随删）
- EP 实证：maxHeight 接受动态数字且 watch 响应（A 核实 2.14.3）

### 32-2 TableShell `infinite`
- prop `infinite: Boolean`（隐含 fill）+ emit `load-more`——**用 el-table 公开 `@scroll` 事件**（event.target=滚动 wrap，A-P2-7：免 querySelector 内部 DOM 依赖），距底 ≤60px 触发；父层 loading 守护去抖（Shell 只发信号）；加载后仍距底场景不处理（100 行×~40px >> 视口，A 注记）
- "加载中/没有更多"提示走 **el-table `append` slot**（滚动区内，天然计入高度——A-P2-6 免 fill 扣减）+ expose 给父层喂内容：Shell 新 prop `moreText: String`（空=不渲染）
- 顶部加 EP 内部结构警示注释（B-P2-5，同列宽回放先例）

### 32-3 后端游标+筛选
- `/api/log`（auth_routes.py:990）参数：`before: str|None`（不透明游标）、`limit: int = 100`（钳 1-500）、`level: list[str] = Query(())`、`module: list[str] = Query(())`（**FastAPI 重复参数，零逗号歧义**——B-P2-4：module 自由文本）
- SQL：`WHERE (ts,id) < (%s,%s) [AND level = ANY(%s)] [AND module = ANY(%s)] ORDER BY ts DESC, id DESC LIMIT %s`——**双键排序与谓词严格一致**（A-P1-1/B-P0-0：log_sink 同事务批量≤100 行同 ts，单键必丢/重行）
- **游标序列化独立全精度**（epoch 微秒+id，`f"{ts microseconds}|{id}"`；展示字段保持现状 str[:19]——A-P1-2：截秒游标必漏行）；解析失败→400 CURSOR_INVALID
- 响应：`{logs, next, modules}`——next=尾行游标（行数<limit=null）；**modules 仅首屏（无 before）附带** SELECT DISTINCT module（A-P2-3；含空串前端滤）
- `/api/audit`（risk.py:249）同构：游标+limit 100+`actor`/`action` 两维 ANY（Audit.vue 实况两维——A-P2-5/B-P1-4 定案）；响应 `{logs, next, actors, actions}`（DISTINCT 各 **LIMIT 500** 封顶——audit_log 只插不删全表扫随年头增长，B 量级注记）+ **形状变更 list→dict（破坏性）**：唯一消费方 Audit.vue 同批切换+Ansible 同车发布无错配窗口（B-P1-2/A-P2-4 口径）
- 兼容口径：**limit 缺省=100（首屏语义=最新一页 100）**——原 200 字样删除（A-P1-3/B-P1-1：无参消费方仅两视图同批改，server 内部/脚本零 HTTP 消费）；LiveTask task_id 分支零改动（其对 limit 忽略写明）

### 32-4 前端接线（Logs.vue / Audit.vue）
- 游标分页：首屏（带筛选参数）→ load-more 传 before 追加 → next=null 显"没有更多"
- **请求序号守卫**（A-P1-5）：筛选变更重置 reqId，在途响应 reqId 不匹配即丢弃（防旧页后到覆盖新筛选）
- 筛选后端化：level/module（Logs）、actor/action（Audit）变更=重置游标重拉首屏；下拉数据源=响应 modules/actors/actions
- CSV 导出=已加载行（现状语义，不扩）
- 两表挂 `fill infinite`+moreText；Logs 删 height="500"

### 32-5 四页撑满落地
- Logs/Audit：如上；DataIntegrity：`height="500"` → `fill`；TaskManager：主表挂 `fill`
