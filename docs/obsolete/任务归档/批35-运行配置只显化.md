# 批35 · 运行配置只显化+编辑弹窗（2026-09-17）

## 背景

用户需求（2026-09-17 原话）：设置菜单-运行配置页面，所有配置的值都改成不可修改，列标签也改成当前值，保存按钮改成图标按钮，点击弹出编辑框进行修改。

动机：值列 inline 控件（每行一个输入框/开关）视觉嘈杂且易误触；改为只显+编辑弹窗（批16「操作收编编辑弹窗」同模式在全站的延续）。

## 方案（用户已确认）

- 值列纯文本显示，列头「当前值/Current Value」：int/float/string 显原文；bool 显「开/关」；password 显「已设置/未设置」（不明文）
- 操作列「保存」文字钮 → IconBtn 编辑图标钮（Edit 笔形，size=small，批21 先例）
- 编辑弹窗：配置项名+说明只读 + 新值控件（四型控件原样搬入，**int/float 保留 `:min="0"`**——批28-7 负保留天数防线）+ footer 取消/保存；保存走原 save 链（dynamic 应用提示/apiErr/成功才关窗+重载，失败留窗改了重试）
- 后端零动

## 实现

- `web/src/components/RunConfig.vue` 重写（单文件）：值列 template 三分支显示；`openEdit(row)` 拷贝行+editValue 转型（int/float/bool 与原 load() 同款；**password 空起 `''`**——留空=不改由后端 400 CONFIG_PASSWORD_EMPTY 兜底，前端 apiErr 已有该码词条）；saving 从行级 `_saving` 改弹窗级 ref
- `web/src/locales/index.js`：systemConfig 域 +7 词条（文案师终稿）：

| key | zh | en |
|---|---|---|
| currentValue | 当前值 | Current Value |
| boolOn / boolOff | 开 / 关 | On / Off |
| pwdShown / pwdShownNo | 已设置 / 未设置 | Set / Not set |
| editTitle | 编辑配置 | Edit Configuration |
| newValue | 新值 | New Value |

- 死键退役：`common.configValue`（值/Value）消费方归零顺手删（zh/en 两处）——pwdShown 刻意与 pwdSet（编辑态占位「已配置，留空不改」）错开用词防两状态混淆（文案师裁定）
