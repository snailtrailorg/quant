### 前端(3 文件+词条+守门)

**3. `web/src/utils/pct.js` 新建**(单源换算,两页共用):

```js
// 百分比显示/编辑换算(存储 0~1 不动,显示层 ×100)
// 浮点坑:0.07*100=7.000000000000001——显示/初值都归整
export const toPct = v => (v == null ? null : Number((v * 100).toFixed(2)))  // 编辑模型初值
export const pctShow = v => (v == null ? '' : `${Math.round(v * 100)}%`)     // 纯显示
export const fromPct = v => (v == null ? null : v / 100)                     // 提交回存储
export const camelKey = k => k.replace(/_([a-z])/g, (_, c) => c.toUpperCase())  // 词条键转换(与 riskRule.param 同款,单源防漂移——A-P2-3)
```

**4. `web/src/components/RunConfig.vue`**:

- 值列:percent 键 `pctShow(parseFloat(row.value))`(0.9→90%);int 键原样。**percent 判定一律可选链 `row.bounds?.percent`**(text 键 bounds=null——A-P1-2)。
- 编辑弹窗(percent 键=`editing.bounds?.percent`):
  - openEdit:`editValue = toPct(parseFloat(row.value))`(0.9→90)
  - 控件:`:min="bounds.lo*100" :max="bounds.hi*100" :step="1" :precision="0"`,控件后紧邻 `<span>%</span>`
  - save:`fromPct(editValue)` 提交(91→0.91)
  - **step 三元写死** `percent ? 1 : (value_type === 'float' ? 0.1 : 1)`——防未来 float 键 step=1 坑复发(B-P2-1)
- description 列:`te('systemConfig.desc.' + camelKey(key))` 有词条用词条,无词条回落 DB description(新键无词条仍可用——双缺兜底;`legacy:false` 下 te() 不查 fallback,语义成立——A 员核实)。
