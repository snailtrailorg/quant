## 状态机设计（五态+续时；超时语义写死——A-P1-1）

```
steady ──nominate──▶ nominated ──confirm──▶ confirmed ──execute──▶ done
                       │  ▲                    │
                       │  └── extend(一次)      └─复评不过=停留 confirmed（checklist 更新，可重试）
                       ├─超时(lazy)─▶ expired（+升级告警，旧链维持）
                       └─abort─────▶ aborted；confirmed ──abort──▶ aborted
```

- **超时语义（写死）**：时限=**确认截止**=`coalesce(extended_at, nominated_at) + timeout_s`；仅 nominated 受超时管辖（lazy expire 于 list/get + confirm 时二次校验拒）；**confirmed 无超时**，仅 execute/abort 出边（A04「确认时限」本意）。
- 续时一次：nominated 且 extended_at IS NULL → extended_at=now。
- 复评不过=confirmed 保持+checklist 更新+返回失败明细（人工处理后重试/abort）。
- **切换执行（execute）单事务**：`SELECT ... FOR UPDATE`（会话行+live_task affected 行，lock_timeout 10s——B-P1-3 TOCTOU 收口）→复评四必过→`UPDATE live_task SET account_id=to`（affected 全行）→session→done。任务不自动启停（半自动立法）。

## 范围裁定（六条）

1. **TradeBus 四方法=现状继承+挂账**：place/cancel/query 已在 worker 链（时序纪律/风控/幂等全现成）；**Web 手动下单不做**（Web 进程 XTPAdapter 无 gateway 返 mock- 前缀=实盘事故面，adapters.py:158 实证）；subscribe_orders（SSE 桥）挂账。接口契约.md 补 TradeBus 映射节。
2. **幂等键不迁移**：现键 `t{tid}:e{boot}:c{seq}` 结构性全局唯一，强于 (client_order_id, account) 复合；不动实盘幂等面（0040 索引+对账链）。注记进接口契约。
3. **确认面=Web 五闸等价**（29b 卡绑飞书 ws 不可直连）：时效=超时语义（上节）｜身份=JWT｜权限=require_perm｜dedup=状态机+FOR UPDATE 行锁｜exec=execute 单事务。**飞书=通知通道**（safe_notify：提名/超时升级/完成），非确认通道。A04 §九注记「29b 复用=五闸形态」（61c）。
4. **检查单第四项 running**（勘察真发现）：运行中任务进程内绑旧账号，DB 改行进程不知=分裂——人工先停再切。
5. **紧急双人通道挂账**（A03 §10.3 break-glass admin 双人）：先立主路径，break-glass 预授权剧本另批。**A04 §九验收判据对照**（A-P1-3）：本批覆盖=状态机全路径（超时回旧链/续时/aborted）/检查单拒切实测/提名 L1 预检拒实测；遗留=紧急双人（挂账）+L2 真连预检（挂账）——A04 §九随批注记。
6. **权限键**：nominate/confirm/extend/abort=strategy_control（analyst 可达——发起/确认属操作准备面）；**execute=trade**（B-P1-4：analyst 无 trade 键 perms.py:23-27，改实盘账号绑定的执行动作=admin/trader 专属）。

## 风险面

- **切换原子性**：execute 单事务+FOR UPDATE 双锁（会话行+live_task 行）——TOCTOU 收口；失败全回滚+audit 对冲行
- **在途误报**（保守方向）：已撤单停留 submitted→拒切不错放；人工勾选第二源弥补；根治挂账
- **唯一索引只挡 to 侧**：from 侧链式会话（A→B 与 B→A 交叉）可并存——复评含「from 仍被 live_task 引用」校验（B-P2-5）+执行实时复评兜底，风险面注记不设索引
- **前端倒计时**：纯展示（API 返回 timeout_s 自带），真值=服务端 confirm 二次校验
- **lazy expire 写放大**：单行只转一次（expired 终态幂等），read 门触发可议非缺陷（B-P2-4 注记）
