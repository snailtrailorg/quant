量化交易平台需求规格说明书
一、全局统一术语规范（平台唯一标准，全系统强制执行）
1.1 原始指标 Raw Indicator
数据源直接输出的基础观测数值，无模型运算逻辑，仅用于标的筛选、数据观测、可视化展示，分为两类：
静态原始指标：低频更新（季度 / 半年）财报数据，不随盘中行情变动；例：静态 PE、市净率 PB、营业收入、毛利率、总市值、分红年化回报率。仅适配 A 股、ETF、可转债，加密市场无此类数据。
时序动态原始指标：随实时行情逐 K 线滚动更新，贯穿回测与实盘全流程；
全市场通用：开盘价、收盘价、最高价、最低价、成交量、成交额、涨跌幅、换手率
品类专属：可转债转股溢价率、永续合约资金费率 / 持仓量 / 基差
1.2 衍生因子 Derived Factor
基于原始指标，通过公式运算、时间窗口滚动迭代生成，专门用于模型训练、收益预测、交易信号生成，分为两类：
截面衍生因子（静态因子）：基于单一时间截面数据计算，无滚动时间窗口；
时序衍生因子（动态因子）：核心实盘因子，基于自定义历史时间窗口滚动计算，每更新一根 K 线自动刷新数值；例：20 日动量、ATR 波动率、均线乖离率。
1.3 模型特征 Feature
送入量化预测模型的最终输入项，可选：【原始指标】/【衍生因子】。
1.4 跨市场指标兼容规则（硬性架构规范）
通用行情时序指标：字段定义统一，但交易时间、单位、涨跌停规则、T0/T1 机制跨市场不通用；
财务静态指标：仅证券类标的（A 股 / ETF / 可转债）可用，加密现货 / 永续合约完全不兼容；
时序衍生因子：数学计算公式全局通用，但时间窗口、交易日历必须跟随对应市场自动适配；
各品类专属指标隔离可用，系统自动根据标的品类过滤不可用指标 / 因子。
1.5 数据库统一存储架构（行业标准，最终落地方案）
摒弃「按标的品类分表」「全字段超级宽表」两种错误方案，采用三层分层通用存储架构，全市场通用、可无限扩展、无冗余空值：
通用时序主表（kline_base）：全品类统一存储通用行情时序指标，表结构永久固定，无需迭代变更；
时序扩展表（kline_ext）：通过 JSONB 结构存储各标的品类专属时序指标，新增指标 / 品类无需改表结构；
静态信息表（asset_static_info）：独立存储低频更新的标的静态属性、财务数据，与高频时序数据物理隔离。
二、底层抽象与第三方集成模块
MKT 交易市场抽象管理
MKT-001｜F 多市场统一配置管理
需求描述：后台提供可视化市场配置页面，支持新增、编辑、启用、停用、删除交易市场。统一抽象市场模型，兼容接入：A 股、ETF、可转债、加密现货、币安 / OKX 永续合约等所有交易市场。
输入：市场名称、市场类型、接口接入地址、鉴权密钥、标的类型映射、专属指标清单、交易时段 / 交易日历配置
输出：市场持久化配置记录、前端市场分类树、第三方接口连通性自检结果
优先级：高
关联模块：标的筛选、策略挂载、实盘交易、数据采集存储
MKT-002｜F 只读数据源隔离管理
需求描述：支持录入 Tushare 等纯数据只读接口，标记为「只读市场」；只读市场仅可用于标的筛选、历史数据回测读取，禁止策略实盘挂载交易。
输入：数据源名称、接口地址、字段映射关系、只读标识
输出：市场树独立分组展示、策略挂载页面只读市场置灰不可选
优先级：中
关联模块：标的筛选、历史数据服务
MKT-003｜S 市场密钥加密存储
需求描述：所有第三方交易 / 数据接口密钥禁止明文存储，数据库加密入库；前端页面密钥全程脱敏展示，仅支持重新录入，无法查看原始密钥。
输入：第三方接口原始密钥
输出：加密存储数据、前端脱敏密钥展示
优先级：高
关联模块：市场配置、第三方集成
INT 第三方集成配置模块
INT-001｜F 飞书多账号分级权限配置
需求描述：支持批量配置飞书机器人账号，绑定三级角色权限，实现功能、消息差异化管控：
管理员：全部配置修改、策略启停、日志查看权限；
操作者：仅可启停策略、接收交易信号，无配置修改权限；
审计员：只读日志、监控数据，无任何操作权限。
输入：飞书 webhook 地址、角色类型、消息推送类型勾选（交易信号 / 风险告警 / 系统通知）
输出：权限规则生效、差异化消息分发、前端功能按钮权限拦截
优先级：高
关联模块：消息通知、日志审计、权限管控
INT-002｜F 大模型统一可配置接入
需求描述：搭建全局大模型配置面板，支持自定义录入 API 地址、密钥、模型版本、调用 QPS 阈值、单次 Token 上限。全平台策略分析、信号优化模块统一复用配置，无需单独开发对接。
输入：大模型 API 地址、密钥、模型标识、限流参数
输出：大模型连接状态检测、全局统一调用配置生效
优先级：中
关联模块：策略分析、信号处理
INT-003｜P 第三方接口定时健康探测
需求描述：系统后台定时轮询探测所有交易市场、飞书、大模型接口连通性，异常状态在管理后台高亮告警。
输入：所有已保存的第三方集成配置
输出：接口在线 / 离线状态标签、最后探测时间、异常告警提示
优先级：中
关联模块：全部第三方集成模块
三、指标与因子库管理模块（核心数据规则模块）
FAC 指标因子核心管理
FAC-001｜F 原始指标全生命周期管理
需求描述：搭建标准化原始指标库，严格区分「静态原始指标、时序动态原始指标」；每条指标绑定适配市场、标的品类、数据来源、更新频率；支持启用、禁用、查询详情，预置全行业通用指标。
输入：指标名称、指标类型、数据来源、适配市场 / 品类、更新周期、字段映射规则
输出：标准化指标库列表、筛选 / 建模页面自动加载可用指标
优先级：高
关联模块：标的筛选、策略建模、数据采集存储
FAC-002｜F 自定义衍生因子管理
需求描述：支持用户基于原始指标自主编写计算公式，创建自定义衍生因子；区分静态截面因子、动态时序因子，时序因子强制要求配置滚动时间窗口；新增因子需通过语法校验、市场适配校验后方可启用。
输入：因子名称、计算公式、因子类型、滚动时间窗口（时序因子必填）、适配品类
输出：合规衍生因子入库、策略建模模块可选为模型特征
优先级：高
关联模块：策略建模、回测计算
FAC-003｜F 指标因子跨品类兼容性自动校验
需求描述：用户选定市场、标的品类后，系统自动过滤、校验指标 / 因子可用性；禁止选用当前品类无数据源的指标 / 因子，弹窗提示兼容异常，阻断后续操作。
输入：选定市场品类、用户选中的指标 / 因子集合
输出：自动过滤不可用项、兼容性告警、非法操作拦截
优先级：高
关联模块：标的筛选、策略建模、策略回测
四、标的筛选模块（业务流程第一步：池内初选）
SEL 标的智能筛选
SEL-001｜F 多市场标的筛选主界面
需求描述：筛选界面分区布局：左侧市场分类树、中部原始指标条件配置区、右侧标的结果列表；仅支持使用原始指标设置筛选阈值，禁止直接使用因子筛选标的。
输入：选定市场范围、多条原始指标阈值条件（且 / 或逻辑）
输出：符合条件的标的清单、实时筛选结果
优先级：高
关联模块：市场管理、原始指标库
SEL-002｜F 多指标组合筛选配置
需求描述：支持动态增删多条原始指标筛选条件，自定义数值阈值区间；预置 PE、PB、分红年化、成交量、涨跌幅等常用指标；支持条件逻辑组合筛选。
输入：原始指标、阈值区间、逻辑运算规则
输出：完整可执行筛选条件集
优先级：高
关联模块：原始指标库
SEL-003｜F 筛选结果联动操作
需求描述：结果列表展示标的代码、名称、所属市场、全部原始指标实时数值；支持任意指标排序、批量勾选标的；一键携带选中标的上下文跳转策略建模页面。
输入：勾选标的清单
输出：上下文联动跳转建模页面
优先级：高
关联模块：策略建模
五、策略建模与历史回测模块（业务流程第二步：模型训练验证）
MOD 策略建模与回测
MOD-001｜F 可视化策略建模画布
需求描述：自动带入筛选选中的标的池；支持用户自由选取「原始指标 / 衍生因子」作为模型特征，自主调整各特征权重；配置完成后保存为基础策略方案（无执行规则，不可实盘）。
输入：标的列表、模型特征集合、特征权重、方案名称、备注
输出：未绑定风控规则的基础策略方案
优先级：高
关联模块：标的筛选、指标库、因子库
MOD-002｜F 时序适配型历史回测
需求描述：支持自定义回测时间区间、初始本金、手续费率；系统根据标的市场自动适配交易日历与时序窗口；时序动态因子全程滚动迭代计算，1:1 还原实盘运算逻辑；回测完成自动生成净值曲线、胜率、最大回撤、夏普比率等绩效指标。
输入：基础策略方案、回测参数、市场交易日历规则
输出：回测可视化报告、量化绩效指标、策略有效性判定
优先级：高
关联模块：历史数据服务、时序因子计算引擎
MOD-003｜F 策略方案版本管控
需求描述：所有策略方案修改自动生成新版本，完整记录操作人、修改时间、前后变更内容；支持版本查询、复制新建、历史版本回滚。
输入：方案 ID、版本操作指令
输出：新版本记录、历史版本回滚生效
优先级：高
关联模块：策略存储、日志审计
六、执行规则封装模块（模型→可实盘策略包核心层）
EXE 策略封装与执行规则
EXE-001｜F 独立执行规则配置面板
需求描述：核心分层逻辑：模型仅负责输出预测信号，买卖时机、风控阈值由独立执行规则管控；基础策略方案必须绑定执行规则，方可封装为可运行策略包。支持配置：买卖触发阈值、自定义止损类型、止损阈值、委托参数。
输入：基础策略方案、信号触发阈值、止损风控参数、委托规则
输出：完整策略执行规则配置集
优先级：高
关联模块：策略库、实盘交易、风控系统
EXE-002｜F 可执行策略包生成与市场绑定
需求描述：将「基础策略方案 + 执行规则」封装为标准化策略包；策略包必须绑定指定交易市场，系统自动校验标的与市场兼容性，不匹配直接拦截；实盘运行时，持续刷新动态指标、滚动计算时序因子，实时生成交易信号。
输入：基础策略方案、执行规则、目标交易市场
输出：可挂载实盘的标准化策略包
优先级：高
关联模块：市场管理、策略执行引擎
EXE-003｜S 未验证策略禁止实盘封装
需求描述：无有效历史回测记录、回测不合格的基础策略方案，禁止封装为策略包、禁止挂载实盘交易，从源头控制交易风险。
输入：策略方案回测状态、绩效数据
输出：非法封装操作拦截、风险提示
优先级：高
关联模块：策略回测、实盘交易
七、实盘监控与风险控制模块
MON 实盘监控与实时风控
MON-001｜F 多策略并行实时监控看板
需求描述：区块式布局，单区块对应一套运行策略包；实时展示标的行情曲线，自动标注模型买点、卖点、止损点位；同步展示动态原始指标、时序动态因子实时数值。
输入：已挂载策略包、全量实时行情数据流
输出：可视化行情图表、交易信号标记、动态指标因子实时数据
优先级：高
关联模块：实时数据服务、策略执行引擎
MON-002｜F 策略启停管控
需求描述：支持手动暂停 / 恢复策略包运行；暂停后停止生成交易信号、停止委托下单，但持续接收行情、更新图表、计算风险指标。
输入：策略包 ID、启停操作指令
输出：策略运行状态变更
优先级：中
关联模块：策略执行引擎
MON-003｜F 实时风险预警推送
需求描述：实时监控账户总回撤、单标的仓位占比、行情异常波动；触碰预设阈值后，页面红色弹窗告警，同时向对应权限飞书账号推送分级告警消息。
输入：账户持仓数据、预设风控阈值、实时行情波动数据
输出：页面告警、分级飞书消息推送
优先级：高
关联模块：飞书集成、账户管理、风控系统
MON-004｜P 多策略并行性能保障
需求描述：支持同时运行≥10 套策略包，并行刷新行情、滚动计算时序动态因子，整体界面刷新、数据更新延迟≤2 秒。
输入：多路实时行情数据流、多策略计算任务
输出：低延迟可视化展示、实时因子计算结果
优先级：中
八、账户、日志与审计模块
ACC 账户管理与合规审计
ACC-001｜F 多市场交易账户绑定
需求描述：支持绑定多市场交易账户，每个账户独立配置仓位上限、账户级风控阈值；支持账户与指定策略包一对一 / 多对一关联绑定。
输入：账户接入参数、独立风控阈值、策略关联关系
输出：账户配置列表、策略包账户绑定生效
优先级：高
关联模块：实盘交易、风险监控
ACC-002｜S 全链路不可篡改日志审计
需求描述：系统全操作留痕：指标因子编辑、策略建模、回测、策略封装挂载、实盘交易、策略启停、参数配置变更；日志永久存储、不可删除篡改，审计账号支持查询、导出。
输入：系统所有业务操作行为
输出：结构化审计日志、可导出合规记录
优先级：高
关联模块：全平台模块、权限管控
九、全局非功能性需求
P 性能需求
P-001｜P 行情与计算并发需求
需求描述：支持多标的、多策略并发订阅实时行情，数据无丢失；支持大批量时序动态因子并行滚动计算，适配多市场高频数据更新节奏。
优先级：中
S 安全需求
S-001｜S 全局操作鉴权管控
需求描述：所有后台配置、策略操作、交易相关功能，必须校验用户身份与权限；越权操作自动拦截并记录审计日志。
优先级：高
S-002｜S 全配置变更留痕
需求描述：市场配置、指标因子公式、策略参数、风控规则、第三方集成配置的所有变更，完整记录操作人、变更时间、新旧参数对比。
优先级：中
