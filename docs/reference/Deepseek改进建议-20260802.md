## 二、系统定位与设计原则

### 2.1 系统定位
- 使用场景：个人量化交易系统（可扩展到小团队）
- 数据共享：所有用户共享策略、因子、订单、历史数据、API配置（不按用户隔离）
- 权限控制：用户角色控制操作权限（查看/编辑/删除），非数据隔离

### 2.2 设计原则
1. 用户旅程驱动：按交易员的工作流程组织功能
2. 场景串联：打通"筛选→K线→同步→策略→回测→实盘"全链路
3. 角色分离：业务功能与运维功能清晰分层
4. 数据完整性优先：智能同步，只补缺失数据
5. 混合数据架构：历史数据本地存储 + 实时数据API获取

### 4.2 智能同步算法

核心逻辑：只同步缺失的数据区间，避免重复下载

abcdfeghijklpython
def smart_sync(symbol, sync_type):
    """
    智能同步：判断本地数据完整性，只补缺失部分
    """
    # 1. 获取本地已有数据范围
    local_start, local_end = get_local_range(symbol)
    
    # 2. 获取预期数据范围
    expected_start = get_earliest_date(symbol)  # 上市日期或配置起始日
    expected_end = get_latest_trading_day()     # 昨天（或当前时间前）
    
    # 3. 计算缺失区间
    missing_ranges = []
    if local_start is None:
        # 完全没有数据
        missing_ranges.append((expected_start, expected_end))
    else:
        # 头部缺失
        if local_start > expected_start:
            missing_ranges.append((expected_start, local_start - 1))
        # 尾部缺失
        if local_end < expected_end:
            missing_ranges.append((local_end + 1, expected_end))
        # 中间空洞（如某些日期数据缺失）
        gaps = find_data_gaps(symbol, local_start, local_end)
        missing_ranges.extend(gaps)
    
    # 4. 只同步缺失部分
    for start, end in missing_ranges:
        fetch_and_save(symbol, start, end)
    
    return {
        'missing_ranges': missing_ranges,
        'total_missing_days': sum(days_in_range(r) for r in missing_ranges),
        'integrity': calculate_integrity(symbol, expected_start, expected_end)
    }

def find_data_gaps(symbol, start, end):
    """
    查找数据空洞（如：某些交易日没有数据）
    """
    expected_days = get_trading_days(start, end)
    actual_days = get_local_days(symbol, start, end)
    missing = sorted(set(expected_days) - set(actual_days))
    
    # 将缺失日期合并为连续区间
    gaps = []
    if missing:
        gap_start = missing[0]
        gap_end = missing[0]
        for day in missing[1:]:
            if day - gap_end > 1:
                gaps.append((gap_start, gap_end))
                gap_start = day
            gap_end = day
        gaps.append((gap_start, gap_end))
    
    return gaps

# 每次同步前备份，防止错误覆盖
def sync_with_backup(symbol):
    # 1. 备份当前数据
    backup_id = create_backup(symbol)
    
    try:
        # 2. 执行同步
        new_data = fetch_data(symbol)
        save_data(symbol, new_data)
        
        # 3. 验证数据质量
        if validate_data(new_data):
            mark_backup_success(backup_id)
            # 可保留最近3次备份
            cleanup_old_backups(symbol, keep=3)
        else:
            rollback(backup_id)
    except Exception as e:
        rollback(backup_id)
        raise e
