# 量化交易策略制定与回测平台开发参考文档

## 总述
整套系统为**Python量化策略在线编写+回测引擎+回测结果可视化分析平台**，页面分为两大核心模块：【策略代码编辑页】、【回测结果详情页】，回测结果详情页内部包含多个标签页切换视图。
下面按页面模块逐页面拆解：页面元素、功能、展示内容、可选技术组件参考。

---

## 页面1：策略代码编辑页面
### 顶部区域元素
1. **搜索输入框**
    - 控件：单行文本输入框
    - 功能：搜索策略名称

2. **右上角按钮组**
    - `API文档` 按钮：跳转平台量化API接口说明文档
    - `策略` 按钮：当前激活标签，标识处于策略编辑视图

3. **回测参数筛选栏（黄色背景条）**
    - `2020-01-01` 日期选择框：回测**起始时间**，日期选择器组件
    - `到` 静态文本
    - `2021-01-01` 日期选择框：回测**结束时间**，日期选择器组件
    - `¥ 100000` 金额输入框：回测初始资金，数字输入框，支持货币符号
    - `每天 ▾` 下拉选择框：回测调仓周期，下拉菜单（可选：每分钟/每小时/每天/每周等）
    - `更多 ▾` 下拉按钮：展开更多高级回测参数（手续费、滑点、撮合规则等）
    - `运行回测` 蓝色主按钮：触发后端执行策略回测任务
    - `保存` 按钮：保存当前编辑的策略代码文本到数据库
    - `设置 ▾` 下拉按钮：策略通用设置（运行环境、日志等级、风控参数等）

### 主体区域：代码编辑器面板
#### 代码内容（业务逻辑）
Python语法量化策略，三段式标准结构：
1. `initialize(context)`：策略初始化函数
2. `handle_data(context, data)`：每日/周期触发的主交易逻辑
3. `control_risk(context)`：风控预留函数

#### 编辑器页面元素
- 左侧：代码行号
- 主体：深色主题代码编辑器
  - 语法高亮（Python关键字、字符串、注释区分颜色）
  - 支持代码换行、注释、函数折叠
  - 内置平台量化API：`get_history`、`set_universe`、`order_target`、`get_position`、`log.info`
  - 支持策略逻辑编写，典型案例：15日均线策略（均线金叉买入、均线死叉卖出）

### 技术插件/组件参考
1. 代码编辑器：**Monaco Editor（VSCode内核）** / CodeMirror
2. 日期选择：Element UI / Ant Design DatePicker
3. 下拉菜单：Select下拉组件
4. 按钮：基础Button组件，区分主色/普通按钮
5. 布局：左右/上下弹性布局，顶部工具栏+下方编辑器

### 页面交互能力
- 在线编写、修改Python策略代码
- 保存策略文本
- 配置回测时间区间、初始资金、调仓频率
- 发起回测请求，提交代码+参数至后端回测引擎

## 页面2：回测结果【收益概述】标签页
### 顶部通用导航栏（所有回测结果页面共用）
- 回测参数回显：`设置：2020-01-01 到 2021-01-01，100000，每天`
- `回测完成` 进度条：展示回测任务执行进度
- 右上角按钮：
  - `查看代码`：跳转回到【策略编辑页面】
  - `导出 ▾`：下拉菜单，支持导出回测报告（Excel/PDF）
  - `策略` / `回测` 标签切换：切换编辑页与结果页

### 左侧导航菜单栏（固定侧边标签，所有回测详情页通用）
收益概述（当前激活）、交易详情、每日持仓&amp;收益、日志输出、收益、基准收益、阿尔法、贝塔、夏普比率、索提诺比率、信息率、策略波动率、基准波动率、最大回撤

点击标签，右侧主体区域切换对应数据视图。

### 右侧主体内容
#### 1. 指标概览表头（横向指标行）
展示核心风险收益指标：
策略总收益｜基准收益｜阿尔法｜贝塔｜夏普比率｜索提诺比率｜信息率｜策略波动率｜基准波动率｜最大回撤

示例数值：
53.69%｜27.21%｜0.426｜0.403｜1.574｜2.443｜0.857｜0.328｜0.226｜23.910%

#### 2. 收益率折线图表
- 图表控件：ECharts / Highcharts / Plotly
- 缩放控件：`1星期｜1个月｜6个月｜1年｜全部`，图表区间快速缩放
- X轴：时间轴
- Y轴：累计收益率百分比
- 图例：蓝色线=策略收益率，红色线=基准收益率
- 悬浮tooltip：鼠标悬浮展示当日数据（日期、策略收益率、基准收益率、当日盈利、当日亏损、当日买入、当日卖出）

#### 3. 每日盈亏柱状图
- 垂直柱状图，绿色=当日盈利，紫色=当日亏损
- Y轴：每日盈亏金额

#### 4. 波动率对比柱状图
蓝色柱：策略波动率；橙色柱：基准波动率

#### 5. 最大回撤图表
展示策略历史回撤区间

### 技术组件
- 可视化图表库：Apache ECharts（推荐）
- 侧边标签：Tabs侧边导航组件
- tooltip悬浮弹窗、图例切换、区域缩放

## 页面4：回测结果【每日持仓&amp;收益】标签页
左侧：侧边导航（当前激活：每日持仓&amp;收益）
右侧主体：持仓明细表

### 表格列定义
| 列名 | 说明 |
| ---- | ---- |
| 股票 | 证券代码 / Cash（现金） |
| 收盘价(元) | 标的当日收盘价格，现金无价格 |
| 持仓数量 | 当日收盘持仓股数，Cash无数量 |

3. Cash文本使用绿色标签样式高亮
4. 支持纵向滚动，遍历回测周期内每一天收盘持仓快照

### 业务作用
跟踪每日账户总资产、现金仓位、个股持仓市值变化

## 遗漏自查补充（全页面细节补全）
### 1. 交互隐性功能（截图可见但上文初版未标注）
1. 图表支持鼠标悬浮Tooltip信息弹窗（收益概述页面折线图）
2. 所有表格支持纵向无限滚动加载历史数据
3. `更多`、`设置`、`导出`均为下拉悬浮菜单
4. 日志面板、代码编辑器支持复制文本
5. 回测运行存在**进度条状态**：未完成/回测完成两种状态
6. 图表右上角内置缩放、下载图片、刷新原生工具（ECharts自带）

### 2. 数据类型规范补充
1. 金额统一保留2位小数；收益率百分比/小数两种展示形式
2. 证券代码统一格式 `XXXX.SZ / XXXX.SH`
3. 时间粒度：回测撮合固定15:00收盘成交（日线级别策略）

### 3. 风险提示类信息补充（日志页面）
系统自动预警日志：`WARNING - 当前账户资金不足，调整下单数量`，属于**内置风控撮合引擎自动处理逻辑**，不是策略代码实现。

### 4. 策略代码内置API归属说明
所有 `get_history / order_target / get_position / log.info` 属于平台封装量化SDK，前端编辑器仅负责文本传输，**实际执行在后端Python回测引擎**，前端不运行策略代码。

## 后端配套业务逻辑（开发参考延伸）
1. 前端提交策略文本+回测参数 → http请求发送任务到回测调度服务
2. 调度启动Python沙箱执行策略，撮合历史行情生成交易记录、持仓、日志、指标
3. 回测结果持久化存入数据库
4. 前端各Tab页面通过不同接口拉取对应数据：
    - `/api/backtest/overview` → 收益概述指标+图表数据
    - `/api/backtest/trades` → 交易详情
    - `/api/backtest/positions` → 每日持仓
    - `/api/backtest/logs` → 运行日志
    - `/api/backtest/metrics?type=return/benchmark/alpha...` → 滚动绩效指标
