# PTrade 回测结果设计 · 采纳清单（我们实施参考）

> 评估 PTrade 回测结果页面设计（源自 `screen-shot-description.md`），标注哪些借鉴/不照搬/要扩展，指导待办 #1（回测 API）/ #9（数据看板）/ #10（Dashboard 指标）。
> 核心结论：**策略编辑页（代码框）不照搬，回测结果可视化高度借鉴**。

---

## 一、回测结果多标签页结构（✅ 借鉴）
左侧垂直 Tab 导航 + 右侧主体，标签页：
- 收益概述（默认）
- 交易详情
- 每日持仓&收益
- 日志输出
- 收益 / 基准收益（月度滚动二维表）
- 阿尔法 / 贝塔 / 夏普比率 / 索提诺比率 / 信息率 / 策略波动率 / 基准波动率 / 最大回撤（同模板）

## 二、各标签页设计 + 采纳评估

### 页面2 收益概述（✅ 整体借鉴）
| 元素 | 采纳 | 说明 |
|---|---|---|
| 顶部导航（参数回显/进度条/查看配置/导出/标签切换）| ✅ | "查看代码"改"查看配置" |
| 指标概览表头（总收益/基准/α/β/夏普/索提诺/信息率/波动率/最大回撤）| ✅ | **BacktestResult 要扩展**（现有净值/胜率/回撤/夏普，补 α/β/索提诺/信息率/波动率/基准）|
| 收益率折线图（策略 vs 基准，缩放 1周/1月/6月/1年/全部 + tooltip）| ✅ | ECharts |
| 每日盈亏柱状图（绿盈紫亏）| ✅ | |
| 波动率对比柱状图（策略 vs 基准）| ✅ | |
| 最大回撤图表 | ✅ | |

### 页面3 交易详情（✅ 借鉴）
表格列：时间 / 标的 / 买卖 / 数量 / 成交价 / 成交额 / 手续费
- 标的代码扩展多市场（不只 XXXX.SZ/SH，含可转债 11/12、ETF 51/15/56、加密）
- 支持滚动/排序/导出单行
- 我们 BacktestResult 有 Trade 列表，补手续费字段

### 页面4 每日持仓&收益（✅ 借鉴）
按日期分组表格：标的 / 收盘价 / 持仓数量 / 证券市值 / 收益
- 分组：现金（绿色标签）+ 持仓股票，分组底部"总共：总资产，总共：总收益"
- **我们要补回测每日持仓快照**（当前 BacktestResult 可能只有 Trade，要记录每日 positions）
- 支持纵向滚动遍历每日收盘快照

### 页面5 日志输出（✅ 借鉴）
黑色控制台面板：`[时间] - [等级] - [正文]`
- 等级颜色区分（WARNING 橙黄 / INFO 白色）
- 内容：资金不足调整、生成订单、策略自定义 log、证券代码、委托数量、订单号
- 虚拟滚动日志面板（终端控制台样式）
- **我们要补回测日志**（策略 log.info + 风控预警，如"资金不足调整下单数量"）

### 页面6-8 收益/基准/阿尔法（✅ 借鉴）
月度滚动二维表：行=日期（按月），列=1个月/3个月/6个月/12个月
- 单元格=滚动收益率（小数）；`-`=时间不足无数据
- α/β/夏普/索提诺/信息率/波动率/最大回撤共用此模板，仅指标计算不同
- **我们要补滚动绩效分析**

## 三、全局组件（✅ 借鉴）
1. 顶部策略操作工具栏（搜索/文档/参数选择器/运行回测/保存/设置）
2. 回测通用头部（参数回显/进度条/查看配置/导出/视图切换）
3. 侧边垂直 Tab 导航（常驻，切换分析视图）
4. 全局按钮组件（主按钮/次要/下拉拓展）
5. 弹窗预留（导出/高级参数/API 文档）

## 四、页面跳转链路（✅ 借鉴）
策略配置页 ->【运行回测】-> 后端执行 -> 任务完成跳转 -> 回测结果页（默认收益概述）
回测结果页【查看配置】-> 跳回策略配置页

## 五、交互隐性功能（✅ 借鉴）
- 图表 tooltip 悬浮弹窗 + 缩放 + 下载图片 + 刷新（ECharts 自带）
- 表格纵向无限滚动
- 下拉悬浮菜单（更多/设置/导出）
- 日志/代码编辑器支持复制
- 回测进度条状态（未完成/完成）

## 六、数据类型规范（✅ 借鉴 + 扩展）
- 金额 2 位小数；收益率百分比/小数两种形式
- 证券代码统一格式（扩展多市场：XXXX.SH/SZ + 可转债 11/12 + ETF 51/15/56 + 加密）
- 时间粒度（PTrade 15:00 收盘固定；我们多市场：A 股收盘 + 加密 7×24 + 可转债 T+0）

## 七、后端 API 分层（✅ 强烈借鉴，待办 #1）
```
/api/backtest/overview    -> 收益概述指标+图表数据
/api/backtest/trades      -> 交易详情
/api/backtest/positions   -> 每日持仓
/api/backtest/logs        -> 运行日志
/api/backtest/metrics?type=return|benchmark|alpha|beta|sharpe|sortino|information|volatility|drawdown
                          -> 滚动绩效指标
```

## 八、后端配套（✅ 一致 + 要补）
- 前端提交策略+回测参数 -> 后端回测引擎执行 -> 结果持久化
- **要补 backtest_tasks 缓存表**：参数快照 + 资金曲线 JSON + 绩效 JSON + 状态，避免重复计算
- 前端各 Tab 通过不同接口拉取对应数据

3. **内置量化 SDK API**（get_history/order_target/get_position）-- 自建框架
4. **仅 A 股股票**（XXXX.SZ/SH）-- 多市场（A 股/可转债/ETF/加密）
5. **15:00 收盘固定撮合** -- 多市场时间轴
