## 1. 登录页与首页

**登录页**：全屏紫渐变（`linear-gradient(135deg,#667eea,#764ba2)`，2018 模板色）+ 400px 卡片 + 错位品牌名。无记住我、无安全提示、无 2FA 线索——金融产品零安全感设计。

**首页 Dashboard**：4 个裸数字卡（总资产/今日盈亏/总盈亏/"回测策略 X/Y"）+ 一张 4 列策略状态表（名称/类型/标的/启用）。
- 不承担指挥中心职能：无权益曲线（/api/pnl 有数据）、无实盘任务状态、无风控水位、无数据健康、无告警入口

- KPI 无环比/无 sparkline/无下钻

## 2. 交易执行组（Trading / Monitoring / LiveTask / Reconcile / Risk / RiskRules / StockDetail / Backtest×3）

### 2.1 交易台 `/trading`
4 统计卡 + 三 tab（持仓/订单/盈亏）。
- **持仓表只显示 代码/持仓量/操作 三列**——API 有 direction/frozen/cost_price/pnl 却不展示，看不到成本与浮盈，不具备看盘运维能力
- 订单 6 列无委托号/失败原因；盈亏 tab 有 echarts 曲线
- 手动刷新

### 2.2 监控页 `/monitoring`
每策略一卡（状态/标的/类型/回测验证/权益+200px 小净值曲线）。
- **正确性缺陷：所有策略卡共用同一条账户级曲线与权益值**（代码把单账户 curve/total_value 塞进每张卡）——实盘监控数据失真
- 无自动轮询、无告警阈值

### 2.3 实盘任务 `/live-task`
表格（ID/名称/策略/标的/状态/账户/初始资金/操作）+ 720px 创建弹窗。
- **"停止"无二次确认**（删除反而有）；状态值英文直出
- 无"最近信号/成交/运行时长"列——任务是否真在跑无法判断
- 创建弹窗亮点：只列已验证策略、remote 标的搜索、动态参数表单

### 2.4 对账 `/reconcile`（半成品）
汇总 alert + 三列表（类型/数量/详情）。
- 每条 issue 映射为一行：类型列文案恒定、count 恒 1、detail 为未结构化原始文本
- 无差异时间/标的维度/重新对账动作。实测当前有 15+ 条"持仓账实分离"critical 异常，页面无法承载处置

### 2.5 风控 `/risk`
风控状态卡（熔断 alert + 阈值 descriptions + 熔断/恢复按钮，**有确认** ✓）+ 实盘开关卡（5 市场 el-switch）。
- **市场级实盘启停用裸 switch，一拨即生效**——关市场下单是高影响操作
- 只读展示阈值，无"当前回撤 vs 阈值"水位——看不到离熔断多远，风控页最有决策价值的信息缺失

### 2.6 风控规则 `/risk-rules`
上表格下内联表单。**params 用裸 JSON 文本编辑**，无 schema 表单无即时校验；JSON 长串溢出无 tooltip；编辑/新增切换会静默丢失输入。

### 2.7 个股详情 `/stock/:symbol`（完成度最高）
行情头（价格/涨跌/五档盘口）+ 六 tab（K线/资金流/筹码/事件/财务/AI分析）。
- 30s 轮询+防竞态 ✓；筹码空态解释数据策略 ✓
- K 线无 MA/MACD、无周期多选；AI 结果纯文本一坨；五档无占比条；**无加自选/无下单动作，与交易台断裂**

### 2.8 回测三页
- **列表**：发起弹窗（策略/标的 textarea 自由输入/池/区间/模式/资金/参数/高级 JSON）；"终止"无确认
- **Run 详情**：4 指标卡 + 分组汇总 + 标的结果表 + "标记已验证"（**无确认**，但它喂给三级开关准入门禁）
- **单标的结果**：净值/回撤（前端现算）/交易明细三 tab，**SSE 流式渲染是全站亮点** ✓
- 缺：年化收益、盈亏比、交易次数、回撤持续期、Calmar、基准对比线、买卖点 markPoint；明细无每笔盈亏；佣金硬编码不可配

## 3. 系统运维组（14 页）

### 3.1 做得对的（先说优点，重构时保留）
- **安全基线高于同类自研平台**：密码掩码+"留空=不改"+连接测试三件套齐；错误码文案完备（SMTP_SECURITY_INVALID 等）
- **ImBots 是全站标杆**：按 provider field_schema 动态渲染凭据表单、secret 自动掩码、扫码引导 3s 轮询、凭据留空策略
- DataManage 的同步进度条（2s 轮询+30s 超时告警）、回填缺口提示细致
- SystemConfig 按 value_type 渲染控件（number/switch/password/text）

### 3.2 问题清单

| 页面 | 核心问题 |
|---|---|
| DataManage | **Cron 在表格内裸输入框，onChange 即写库**——无校验/防抖/确认，误删一个字符就改掉生产调度；回填日期用正则 prompt 而非 DatePicker；"管理标的"按钮靠前端硬编码 id 显隐 |
| DataIntegrity | 无搜索/无分页（找一只股票只能 Ctrl+F）；状态英文枚举直出（complete/partial/missing）；**发现缺口后无"去修复"入口**，要切到 DataManage 手动回填 |
| TaskManager | 无自动轮询（运行中任务进度手动刷新）；详情 params JSON.stringify 裸输出 |
| Health | 进页面快照一次，**无刷新按钮无轮询**——"健康页"是静态照片；事件无时间筛选；英文枚举直出 |
| Logs | 无关键字/时间范围/分页；级别单选且纯前端过滤；AI 分析送全文无脱敏提示（亮点：AI 归因异常） |
| Help | **放在运维组，trader/viewer 看不到帮助**——最需要文档的角色被排除；marked 后 innerHTML 无 sanitize；无搜索无目录 |
| SystemConfig | 逐行保存无批量；描述列 i18n 复用错位（risk.label） |
| Brokers | **凭据要求在掩码密码框里盲写 JSON**（340px 宽）；无"保存并测试"动线；删除仅普通确认 |
| Channels | 启用状态是 ✓/✗ tag 无行内 switch，临时停用要进表单提交 |
| ImBots | **default_role 和用户映射可直接授 admin，无二次防护**——IM 侧一句命令提权到平台管理员，全站最锋利的危险配置 |
| LLMModels | 表单缺 context_window/supports_tools/temperature 控件（数据模型里有）；预算表只读无编辑入口；7 日趋势用文本 span 拼接而非图表 |
| Audit | **全站检索最弱**：无时间范围/分页/关键字/导出；"筛选"按钮实际只是重新拉全量（误导） |
| DataSources | 同底部内联表单动线问题；日限额与用量分居两处，看不到"今日已用/限额"比值 |

### 3.3 横切问题
1. **配置页统一"列表+分隔线+页面底部内联表单"**：编辑任何行都要滚到底；编辑中无高亮；"重置"兼任"取消"；与 ImBots 弹窗模式自我不一致
2. **权限危险面防护倒挂**：删数据源普通 confirm，IM 授 admin 零防护
3. 角色取自 /auth/me 后由前端渲染层控制可见性（按钮显隐非真鉴权，需后端对等确认）；viewer 在导航层不隐藏交易/策略组
4. trader 看不到数据健康/日志——但行情断流最先体现在 trader 的下单异常上，MTTR 被人为拉长；analyst 能改 Cron 却无自证渠道（看不到审计）

## 4. 研究工具组（Factors / Strategy / Backtest / Pool / 三个筛选器 / Analysis / AIChat）

### 4.1 因子库 `/factors`
表格（名称/分类/类型/静动态/被引用/描述/参数 JSON.stringify 裸输出/操作）+ 720px 编辑弹窗（分类/描述/默认参数 JSON textarea/历史窗口/Python 代码+校验+试算抽屉）。
- **无自定义因子时操作列整体消失**（线上当前即是）——新用户不知道这里能建因子；且新建弹窗只有 Python 入口，没有 DSL 因子的表达式编辑入口（dsl 预设因子的 __doc__ 明说支持 Web 端受限表达式）
- **试算硬编码 600000.SHSE / 1D / 60 根 bar，不可更换**——因子在不同标的/频率/窗口的行为完全验证不到
- "被引用"只是个数字，点不动，看不到是哪些策略

### 4.2 策略 `/strategy`
列表（名称/类型/状态/操作[编辑+✓已验证小tag]）+ 720px 超长单栏编辑弹窗（DSL/Python 双模式 radio 切换、因子+权重行、聚合阈值、参数定义卡片、执行规则、账户绑定）。
- **无删除、无复制、无"发起回测"**；（注：无启停开关是批次 3 的刻意设计——策略是配方，运行入口唯一=实盘任务；`symbol:""` 为契约行为，见 06 差距审计更正）
- **DSL 表达式是裸 textarea**——无高亮、无因子名补全、无校验按钮；Python 反而有专用编辑器+校验
- 参数定义编辑脆：select 无选项编辑器、number 默认值是文本框、min/max 不校验
- 双重编码回填契约不一致：策略页直取对象 vs 因子页防御性 parse 并存——字符串一旦泄漏，Python 策略显示成 DSL 模式、阈值 NaN

### 4.3 回测中心 `/backtest`
列表（ID/裸 strategy_id/状态/模式/标的数/时间/操作[详情|终止无确认]）+ 640px 发起弹窗。
- **无策略/状态/日期筛选、无轮询**（running 手动刷新）；**接口 500 时只有 toast+空表**，无重试无诊断
- 标的 textarea 自由输入（LiveTask 已有 remote 搜索组件却不用）；佣金硬编码 5e-4 不可配
- 亮点：ParameterForm 按 parameter_defs 动态生成（全站唯一正确实现）；单标的 View 页 SSE 流式渲染

### 4.4 股票池 `/pool`
列表（行可展开：分钟数据明细+行内加标的）+ 520px 弹窗（textarea 换行分隔整体覆盖语义，无搜索选择器）。
- "分钟同步进度"行是**永不渲染的死代码**（状态对象从未赋值）

### 4.5 筛选器三页
- **A股**：4 个条件（PE/PB/市值[元,步长百万无单位标注]/换手）+ 5 列可排序 + 行点弹 K 线——三页中唯一可用的；但不自动查询、无方案保存、无导出、无分页（500 行直渲）
- **可转债**：条件只剩"数量限制"；**无双低/转股溢价率/纯债溢价率/剩余规模/现价等核心列**（因子库明明有 double_low 因子）——退化成列表查看器
- **ETF**：同样只有数量限制；无价格/涨跌幅/规模/费率列

### 4.6 分析 `/analysis`
评分/评级/支撑/压力/结论（长文本撑高行）/加池。
- 加池走 `symbolsStr` 契约正确（盲审二实测生效、分钟起点 COALESCE 保留）；**真正的数据丢失 bug 在 Pool 页自身**——见 P0#5
- conclusion 是拼接文本（`winner_rate=缺`），未结构化

### 4.7 AI 对话 `/chat`
WS 流式 + REST 回退；3 个快捷提问。
- **textContent 纯文本渲染**——无 Markdown/代码高亮/表格，量化回复必含代码与表格，基本不可读
- **Enter 和 Shift+Enter 都直接发送**，无法输入多行；生成中输入框禁用且无"停止生成"；无会话列表、切路由丢全部上下文

### 4.8 三级开关黑箱化（横切研究链路）
①代码校验（Python 有按钮，DSL 无）→ ②回测证据（Run 页手动"标记已验证"，不判断 run 状态）→ ③verified 门禁实盘（实盘任务下拉**静默过滤**未验证策略）。
逻辑闭环存在，但视觉上互不可见：✓tag 挤在操作列不可点、无证据回链（哪次回测/什么成绩）、被拦用户只能靠后端错误码文案反推"差哪一级"。

## 5. 问题分级汇总（终版）

### P0 正确性/安全（立即修）
1. 监控页所有策略共用同一条账户级曲线——实盘监控数据失真
2. 危险操作确认缺失：实盘"停止"、回测"终止"、市场实盘 el-switch、"标记已验证"一键生效；反向地，**IM 机器人可直接授 admin 角色零防护**、Cron 表内 onChange 即写库
3. 红绿涨跌语义三处打架（K线红涨绿跌 vs 盈亏绿涨红跌 vs 分时量柱又一种）
4. 回测列表接口 500（当日复测仍在）+ 前端仅 toast，无重试/诊断入口
5. **Pool 页保存即清空池标的（数据丢失级）**：编辑弹窗发送 `symbols` 数组，而后端契约仅接受 `symbolsStr`（按 \n split）——字段被忽略、实测 count:0；分析页传 symbolsStr 才是正确的（盲审二实测反转了初判）
6. 通知路由错误映射（email→/logs、system→/logs）
7. 双重编码回填契约不一致（策略页直取对象 vs 因子页防御 parse）——字符串泄漏即静默错乱

### P1 业务能力缺失（影响核心决策）
8. 首页无指挥中心职能；交易台持仓缺成本/浮盈/冻结（API 有数据不展示）
9. 策略⇄回测双向断链：无一键回测、策略行无回测战绩、回测列表只显裸 id——研究迭代主循环每圈跨 3 页人肉串参数，**研究效率最大出血点**
10. 三级开关黑箱化：✓不可点、无证据回链、实盘下拉静默过滤无解释
11. 回测报告指标过薄（无年化/盈亏比/交易次数/回撤持续期/基准/买卖点）
12. 风控无阈值水位；对账页半成品（差异不可处置）
13. 转债/ETF 筛选器无核心指标列——选债选基的核心动作平台内完成不了
14. 因子试算硬编码标的/频率/窗口；因子⇄策略引用关系不可导航
15. 帮助页放运维组——trader/viewer 看不到帮助；trader 看不到数据健康/日志
16. AIChat 纯文本渲染 + 无法多行输入 + 切页丢上下文

### P2 体验与规范（系统化还债）
17. 品牌错位（"人工智能开发学习"）、模板视觉、无设计令牌、无中文字体栈
18. 数字/空值/英文枚举格式化不成体系（¥1000000000 上屏、winner_rate=缺、SELL/running 直出）
19. 无分页、实盘链路无自动轮询、无全局搜索
20. 配置页"列表+底部内联表单"统一动线差；券商凭据掩码框盲写 JSON（对照 ImBots 动态 schema 是同平台代差）
21. 审计/日志检索能力缺失（无时间范围/关键字/分页/导出）
22. 筛选器重复摩擦（不自动查询、无方案保存、无导出、市值单位为元步长百万）
23. 策略无删除/复制；编辑弹窗超长单栏无锚点

### 值得保留的优点（重构时不丢）
- 回测单标的 View 页 SSE 流式渲染 + 防竞态请求序号
- 实盘创建弹窗：只列已验证策略 + remote 标的搜索 + 动态参数表单
- ImBots 的 field_schema 动态凭据表单 + 扫码引导（全站标杆，应反哺券商/数据源页）
- 风控熔断/恢复有确认弹窗
- 安全基线：密码掩码+留空不改+连接测试三件套、错误码文案完备
- 个股页 30s 轮询+卸载清理、筹码空态解释数据来源
- DataManage 同步进度条（2s 轮询+30s 超时告警）、回填缺口提示
- 帮助内容本身按"首页/因子/策略/回测/实盘"组织是对的（错在入口位置）
