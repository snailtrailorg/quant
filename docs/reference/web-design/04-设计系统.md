# 04 · 设计系统规范

> 现状：无设计令牌（全局 CSS 仅 3.5KB）、body 字体栈不含中文、Element Plus 默认蓝 + vue-element-admin 深灰侧边栏、emoji 当图标。以下为替换方案。

## 1. 色彩体系

### 1.1 品牌与中性色

| 令牌 | 值（浅色） | 用途 |
|---|---|---|
| `--brand-600` | `#1F4FD8` | 主操作、选中态、链接（替换 #409EFF 模板蓝，更深更稳） |
| `--brand-500` | `#2E6BF0` | hover、次级强调 |
| `--bg-canvas` | `#F5F7FA` | 页面底色 |
| `--bg-surface` | `#FFFFFF` | 卡片/表格 |
| `--bg-sidebar` | `#101B2E` | 侧边栏（替换 #304156，更深、蓝调更纯，配白字对比度 ≥7:1） |
| `--text-primary` | `#1A2233` | 主文本 |
| `--text-secondary` | `#5A6478` | 次要文本 |
| `--border-weak` | `#E4E8F0` | 分隔线 |

暗色主题（盯盘场景，推荐作为交易监控类页面的默认或全局可切换）：画布 `#0D1321`、表面 `#151D30`、文本 `#E6EAF2`，品牌色提亮至 `#5B8CFF`；涨跌/警告/严重/成功色必须使用上方暗色变体（初版遗漏，盲审指出红 #D93843 在暗画布仅 3.7:1 不可读）。落地策略（盲审采纳）：暗色先行只做盯盘三页（交易台/运行监控/个股详情），全站暗色后置。

### 1.2 语义色（金融语义，最关键的决策）

**默认遵循 A 股习惯：红涨绿跌**（平台主战场为 A股/ETF/可转债，目标用户为中国交易者）：

| 令牌 | 值 | 说明 |
|---|---|---|
| `--up`（涨/盈利） | `#C8102E` | 红（加深档，白底对比度 ≥4.6:1） |
| `--down`（跌/亏损） | `#0A7A54` | 深绿（白底 ≥4.8:1，与成功色拉开） |
| `--flat` | `#8A93A6` | 平 |
| `--warn` | `#B25E09` | 警告（文本档；大面积填充可用亮档 #E6A23C） |
| `--critical` | `#7F1D1D` | 严重（独立深红，区别于 `--up`，且强制配图标+背景，绝不裸文本） |
| `--success` | `#0E8388` | 成功反馈（青绿系，与跌色 `--down` 色相拉开 ≥30°；仅用于 toast/操作反馈，必配 ✓ 图标） |

暗色变体（盯盘场景核心，初版遗漏）：`--up:#F0565E`、`--down:#3DBE8B`、`--warn:#E8A33D`、`--critical:#FF6B6B`、`--success:#2DD4BF`——全部在 `#151D30` 画布上 ≥4.5:1。

规则：
1. `--up/--down` **只用于价格与盈亏方向**，`--success/--critical` 只用于操作反馈与系统状态——四令牌四色相，互不借用（初版 `--success` 与 `--down` 同值 #0E9F6E 属自撞，已修正）
2. **默认按市场分色**：A股/ETF/转债页=红涨绿跌，crypto 页=绿涨红跌（perp 用户习惯国际色，7×24 高压市场误读代价高）；设置中提供全局覆盖"跟随市场/统一中国/统一国际"。初版"沿用全局"判断被盲审驳回，采纳分色默认
3. 现状代码里 `daily_pnl>=0 ? #67c23a : #f56c6c` 是国际惯例，**必须全局替换**
4. 涨跌信息必须双编码：颜色 ± 符号/箭头（色盲安全），halted/熔断状态用静态红底+图标，**不用闪烁**（光敏）

### 1.3 市场与状态色

| 市场 | 标识色 | 用于 |
|---|---|---|
| A股 | `#C8102E` | 市场徽标 |
| ETF | `#2E6BF0` | 市场徽标 |

## 2. 字体

```css
/* 全局 */
font-family: -apple-system, "PingFang SC", "HarmonyOS Sans SC", "MiSans",
             "Microsoft YaHei", "Segoe UI", Roboto, sans-serif;
/* 数据数字（价格/数量/百分比/代码） */
--font-num: "JetBrains Mono Web", ui-monospace, "SFMono-Regular", Consolas, monospace;
font-variant-numeric: tabular-nums; /* 表格列对齐的生命线 */
```

等宽字体**自托管 woff2 子集**（仅数字+符号，~10KB）——大陆网络无 CDN，外链字体必挂，回退漂移会毁掉 tabular 对齐（盲审修正）。

字号阶梯（px，语义化六级——每级绑定角色，大数字是稀缺资源）：
25 KPI 数字（一屏 3~5 个，唯一大数字）｜18 页标题（一页 1 个）｜14 卡片标题｜13 正文/表格/Banner（基线）｜12 表头/Tag/标签/分组名｜11.5 注脚/图例/状态栏。
层级由三维合成而非字号堆叠：字号(6) × 字重(400/500/600) × 灰阶(text1/2/3)。数字列右对齐 + tabular；≥1800px 基线 13→13.5、KPI 25→27。
KPI 数字用 `--font-num` + `font-weight:600`。（原型 v2 收敛：注脚统一 11.5、Banner 并入 13；文档原 16/20/28 按 B 端密集实践下调为 14/18/25）

## 3. 数字与人机惯例（金融产品的地基）

1. **千分位 + 中文单位**：`1000000000 → ¥10.00亿`；表格中 `73.321`、`4996546 → 4,996,546`（股数）或 `499.65万`
2. **精度规则**：价格 2 位（可转债 3 位）、百分比 2 位带符号、份额整数千分位；涨跌幅显示 `+1.24%` 带符号着色
3. **证券代码规范**：展示 `600000` + 交易所徽标（SH/SZ/BJ），内部 `600000.SHSE` 不裸露给用户（现状 vt_symbol 直接上屏）
4. **时区**：一律北京时间；时间显示 `08-29 14:54`（同年省略年份），精确到秒仅日志/审计用
5. **空值**：禁止显示 `null/undefined/NaN/缺`（现状 selection 结论里 "winner_rate=缺"）；统一 `—` + tooltip 说明原因

## 4. 布局与组件

1. **侧边栏 220→240px**，支持折叠至 64px 图标模式（记忆状态）；分组标题 11px+降低字重/透明度（中文无大写，初版"全大写"表述对中文无效——盲审修正）
2. **顶栏**：左侧面包屑 + 全局搜索（⌘K，搜策略/标的/因子/任务）；右侧市场开闭市状态灯、通知中心、用户
3. **表格**：表头吸顶、行高 40、斑马纹去掉（用 hover 高亮替代）、右对齐数字列、固定操作列、行点击进详情
4. **KPI 卡**：数字 + 环比箭头 + sparkline（7 日），不再是一个裸数字
5. **危险操作分级（盲审仲裁修正：确认强度对称于代价，而非动作本身）**：
   - 停实盘任务/终止回测=确认弹窗（显示影响面）
   - **风控熔断=轻确认**（一键急停，慢半拍=真实亏损；误触代价=再点一下恢复）
   - **风控恢复=输入确认**（恢复=重新暴露风险，才是强确认该在的地方）
   - 删除数据源/账号/策略=二次确认+红色按钮；删除被引用对象先提示引用清单
6. **图表**：统一 ECharts 主题（与令牌一致）；净值曲线标配：净值+基准双线、回撤面积图（副轴）、区间选择器
7. **图标**：弃用 emoji（🔔）；统一 Element Plus Icons 或 Lucide，一个语义一个图标（现状 ChatDotRound 被 4 个页面混用）

## 5. 令牌落地方式

Element Plus 落地要整组做（初版低估，盲审修正）：
1. 品牌色需覆盖预计算 ramp：`--el-color-primary-light-3/5/7/8/9` 与 `--el-color-primary-dark-2`——只覆盖 `--el-color-primary` 的话 hover/选中/disabled 仍是模板蓝
2. 暗色需引入 `element-plus/theme-chalk/dark/css-vars` + `html.dark`
3. 全部令牌收敛到一个 `tokens.css`；另补基础令牌：间距 4/8/12/16/24/32、圆角 4/8、阴影两档、z-index 三档、focus-visible 样式（键盘可达）
4. 工程上无需换组件库。

## 6. 跨平台字体与布局韧性规范（2026-08-31 增，详见 14 号方案）

**背景**：Windows 默认 150% DPI 下有效 CSS 视口缩水（1920×1200 → 1280×800），叠加微软雅黑度量差异——必须按"有效视口"而非物理分辨率设计。

1. **字号令牌视口驱动**（单一驱动源 --fs-body，其余字号按比例挂靠）：
   `--fs-body: clamp(12.5px, calc(9.5px + 0.234vw), 14px)`（@1280=12.5 / @1707=13.5 / @1920=14）；
   `--fs-kpi: calc(var(--fs-body)*1.92)`、`--fs-page: *1.38`、`--fs-label: *0.92`、`--fs-foot: *0.87`；EP 字号变量组（base/small/extra-small/large）全部挂令牌
2. **断点按有效视口**：≥1707 完整布局｜1280–1706 侧栏自动 64px 图标模式（用户手动展开记忆优先）｜<1280 保底可用（桌面优先立场，小屏场景由 IM 承接）
3. **行高三档令牌**：`--lh-tight:1.3 / --lh-base:1.5 / --lh-loose:1.7`，覆盖 `--el-font-line-height-primary`，body 默认 1.5——中文 UI 必须显式行高（雅黑默认 1.32 会挤压）
4. **字体栈（自托管后）**：`--font-ui: "MiSans Web", -apple-system, "PingFang SC", …, "Microsoft YaHei"(末位回退)`；`--font-num: "JetBrains Mono Web", "MiSans Web", …, monospace`——**等宽栈必须含 CJK 回退位**（¥/亿/万 不回退系统字体，数字列混排才对齐）
5. **布局韧性铁律**：KPI 行用 `flex:1 1 0` 等分（禁用 span 拼满 24 栅格，5 卡即 25/24 超栅格事故）；文本表格列 `min-width`+`show-overflow-tooltip`（禁纯固定 width）；KPI 卡/卡片标题/表头/按钮/Tag 强制 `nowrap+ellipsis`；flex 子项记得 `min-width:0`
6. **新页面验收必含**：1280×800（Windows@150% 等效）视口走查——这是平台的最低支持线
