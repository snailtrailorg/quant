## 1. 研究链路（因子→策略→回测→选股→详情页）

### 文档设计的功能全集（用户可见层）
- **因子**：新建（名称不可改/类别/params schema/needs_history）｜Monaco+AST 校验（禁 import/禁用名）｜试算=折线+统计+**图上断点标记**｜DSL 受限表达式（mean/std/ema/rsi/slope 等 8 函数）｜静态/动态二分（静态可选股）｜被引用计数+FACTOR_IN_USE 删除保护
- **策略**：DSL 模式（因子行+权重 0~2+params 展开子表单+阈值聚合+可选表达式）｜Python on_bar(ctx)｜执行规则三档（SHARES/PERCENT/ALL_IN 方向感知）｜保存自动品类兼容校验｜parameter_defs→任务动态表单
- **回测**：发起（**佣金率可配**/single·serial·parallel/per-symbol 参数）｜**自动双预检**（数据完整性+防未来函数，失败原因在 result）｜四指标卡+组汇总+排名｜单标的 SSE 视图｜标记验证（仅 done run 算证据）
- **回测报告（PTrade 采纳清单）**：多标签页（收益概述/交易详情/**每日持仓&收益**/日志/**收益&基准**/α/β/夏普/索提诺/信息率/双波动率/回撤）｜策略 vs 基准折线+缩放｜每日盈亏柱状｜**月度滚动二维表**（1/3/6/12 月）｜交易详情含手续费｜每日持仓快照（现金绿标+分组合计）｜日志控制台｜**导出 Excel/PDF**｜进度条+参数回显
- **选股**：横截面多因子打分（SELECTION_FACTORS+ST/退市 SQL 过滤）｜rating 分位制（BUY≥q85/AVOID≤q15）｜支撑压力｜conclusion+LLM 研判｜分钟级研判 D2+WS 推送｜**可转债条款解读**（强赎/下修/回售，/api/convertible/terms 已实现）｜转债因子 double_low/premium_rate｜Web 配置分析模型

### 宝藏细节（易被 Web 忽略）
1. **证据门语义**：验证=存在 done run，全败不算证据（R-S5）——✓ 做成可点证据链
2. **频率差异声明**："回测验证的是策略结构，不是分钟阈值"——上实盘前必须告知，否则三级开关给的是假信心
3. **SELL 保底哲学**（R-AV2）：冻结/盲视期 BUY 拒、SELL 放——"跌了能卖不能买"是风控安全感核心，应在风控/任务页明示
4. **策略快照隔离**：live_task 固化快照，改策略不影响已跑任务——编辑页应提示影响面（"N 个运行中任务仍用旧配方"）
5. **三档数据生命周期**：按需 TTL、出池停更/入池回补、非池标的"看过即订阅"（hub 临时订阅 30min TTL+上限 100）
6. **降级显式标识**：hub→腾讯→null 降级链遇部分降级应显式标识而非空白
7. **静/动态因子二分**：静态扫全市场便宜可选股、动态仅策略——筛选器与因子库应露出
8. **执行规则方向感知**：ALL_IN 的 BUY=全部资金/SELL=清仓持仓，非对称——文案勿写对称的"满仓"
9. **两个反直觉事实勿误修**：策略页无启停是设计（批次 3 决策"旧启停移除，LiveTask 唯一入口"；初版引"#22"编号查无出处，已删）；策略保存发 symbol:"" 与"配方不绑标的"契约一致

- **IM 深度**：飞书=Web 平级入口且权限更宽——自然语言查持仓/盈亏/研判；操作类（熔断/启停）走确认卡片：验签 fail-closed+event_id 去重+60s 时效+角色门槛+全程审计；Web chat 永远只读，操作只走按钮（这是设计原则，原型遵循）
- **快照机制**：live_task 创建即冻结 strategy_snapshot——Web 无"查看任务所用版本"入口，与版本管控缺失叠加成黑箱
- 通知 category×role 可见矩阵；加密市场开关是三级开关分项而非独立机制（Web 做成孤立 switch 丢了语境）
