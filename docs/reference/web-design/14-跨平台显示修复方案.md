# 14 · 跨平台显示修复方案（Windows 150% DPI）

> v1.1 · 2026-08-31 校准（据 15 号复审：EP 字号漏变量补四处；列宽改造按归并容器分批——旧视图经 tab 内嵌仍活着，按旧路由指路会误导；验收降级为人工双机清单；字体路径改预生成产物提交 public/fonts，不动构建链） · 针对 prod 202608302138-1d4af49 实测 · 症状：Linux@100% 适中，Windows@150%（1920×1200，**有效 CSS 视口 1280×800**）字体/元素偏大、布局变形、非预期换行、占比不均。
> 定位方法自检：Windows Chrome 按 `Ctrl+-` 缩至 67% 若布局恢复 → 证实 DPI 视口主因（`Ctrl+0` 复原）。

### 1.1 主因：DPI 视口缩水 × 全站零响应式

| 2 | 全站 **0 处 `@media`**——没有任何断点体系 | src + index.html 全文检索 |

## 2. 修复规范

### P0 视口/DPI 自适应（对症主因，先做）

**2.1 字号令牌视口驱动**——令牌值本身用 clamp，所有引用 var 处自动获益，**无需全站 rem 化**：

```css
/* tokens.css 替换字号段 */
--fs-body:  clamp(12.5px, calc(9.5px + 0.234vw), 14px); /* @1280=12.5 | @1707=13.5 | @1920=14 */
--fs-kpi:   calc(var(--fs-body) * 1.92);  /* ≈25px@1920 */
--fs-page:  calc(var(--fs-body) * 1.38);  /* ≈18px */
--fs-card:  var(--fs-body);               /* 14px */
--fs-label: calc(var(--fs-body) * 0.92);  /* ≈12px */
--fs-foot:  calc(var(--fs-body) * 0.87);  /* ≈11.5px */
/* EP 字号变量组补全挂令牌 */
--el-font-size-base: var(--fs-body);
--el-font-size-small: var(--fs-label);
--el-font-size-extra-small: var(--fs-foot);
--el-font-size-large: var(--fs-page);
--el-form-label-font-size: var(--fs-label);   /* 15号复审补：漏列变量 */
--el-dialog-title-font-size: var(--fs-card);  /* 15号复审补 */
.el-tag { font-size: var(--fs-label); }        /* EP 硬编码 12px 覆写 */
.el-pagination { --el-pagination-font-size: var(--fs-body); } /* EP 硬编码 14px 覆写 */
```

**2.2 断点体系从 0 建起**（按有效视口设计，写进全局样式）：

```css
/* ≥1707 (2K@150%/1080p@100%): 完整布局 */
@media (max-width: 1706px) { /* 1280–1706: 侧栏自动 64px 图标模式, hover 浮出 overlay */
  /* 用户手动展开的记忆优先于自动折叠 */ }
@media (max-width: 1279px) { /* <1280: 保底可用——栅格降列、卡片堆叠；桌面优先立场，不深度适配 */ }
```
侧栏折叠逻辑挂 `window.matchMedia('(max-width: 1706px)')` 监听，与现有 localStorage 记忆合并（记忆 > 自动）。

**2.3 KPI 栅格 bug 修复**（现独立 bug，必修）：5 张 KPI 卡弃用 el-row/span，改 `display:flex` + 每卡 `flex: 1 1 0; min-width: 0`，卡内标签/数字 `overflow:hidden; text-overflow:ellipsis; white-space:nowrap`——1280 下不换行不挤压。

**2.4 其余栅格降列**：Dashboard 第二排 15+9、底排 4×6 加 `:md`/`:xs` 响应式 props（参照 StockDetail.vue 已有写法）。

### P1 字体归一（用户已选定做，根治度量差异）

**2.5 中文 UI 字体自托管**：**MiSans**（OFL 许可，度量接近 PingFang），用 `cn-font-split` 智能分包为 woff2（按需加载 ~几十 KB/页）：
```css
@font-face { font-family: "MiSans Web"; src: url(...woff2) format("woff2"); font-display: swap; }
--font-ui: "MiSans Web", -apple-system, "PingFang SC", "HarmonyOS Sans SC", "MiSans",
           "Microsoft YaHei", "Segoe UI", Roboto, sans-serif; /* 雅黑降为末位回退 */
```

**2.6 等宽字体落地（此前规范未执行）+ CJK 回退补位**：
```css
@font-face { font-family: "JetBrains Mono Web"; src: url(...subset.woff2) format("woff2"); font-display: swap; }
--font-num: "JetBrains Mono Web", "MiSans Web", ui-monospace, "SFMono-Regular", Consolas, monospace;
/* ¥/亿/万 由 MiSans 承接——数字列混排宽度全部可控 */
```

**2.7 行高令牌三档**（防雅黑 1.32 挤压，全站统一）：
```css
--lh-tight: 1.3;  --lh-base: 1.5;  --lh-loose: 1.7;
--el-font-line-height-primary: calc(var(--fs-body) * 1.5);
body { line-height: var(--lh-base); }
```

### P2 布局韧性（配合 P0 消灭变形残留）

**2.8 279 处固定列宽三分类改造**（优先重灾区：DataManage 19 / Account 17 / Trading 16 / Health 16 / DataSources 16）：
- 数字/代码/时间/操作列：保留固定 width（等宽字体下宽度可预期）
- **文本列（名称/描述/详情类）：改 `min-width` + `show-overflow-tooltip`**——列宽交给表格弹性分配
- 操作列保留 `fixed="right"`（现有 5 处不变）

**2.9 nowrap/ellipsis 白名单补齐**：KPI 卡、卡片标题（el-card header）、表头、按钮文字、Tag——统一 `white-space:nowrap; overflow:hidden; text-overflow:ellipsis`。
