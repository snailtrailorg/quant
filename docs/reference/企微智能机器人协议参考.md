# 企微智能机器人长连接协议参考（自实现唯一依据）

> 2026-09-10 从官方 `@wecom/aibot-node-sdk@1.0.7`（WecomTeam/aibot-node-sdk）dist 源码逐项核出。
> 本项目 Python 自实现（批13）以此为准，勿凭记忆/第三方转述写协议。

## 1. 连接与生命周期

- **端点**：`wss://openws.work.weixin.qq.com`（公共默认；私有部署企业在管理端查专用地址）
- **认证**：连接 open 后立即发认证帧；认证响应 `{headers:{req_id=订阅帧的 req_id}, errcode, errmsg}`。**errcode≠0=凭证错（botId/secret），重试不可恢复——fail-fast 退出子进程**（重连循环外）
- **心跳**：间隔 **30s**（`heartbeatInterval=30000`），帧 `{"cmd":"ping","headers":{"req_id":…}}`；**连续 2 次未收 ack（missedPongCount≥2）判连接异常**→断开重连
- **重连**：指数退避 1s 起 ×2，**封顶 30s**；认证成功后重置计数器

## 2. 命令全表（WsCmd）

| cmd | 方向 | 用途 |
|---|---|---|
| `aibot_subscribe` | 发 | 认证订阅。body=`{bot_id, secret}` |
| `ping` | 发 | 心跳 |
| `aibot_respond_msg` | 发 | 会话内回复（响应收帧的 req_id） |
| `aibot_respond_welcome_msg` | 发 | 回复欢迎语（enter_chat 事件后） |
| `aibot_respond_update_msg` | 发 | 更新模板卡片 |
| `aibot_send_msg` | 发 | 主动推送（body 含 `chatid`，无需收帧） |
| `aibot_upload_media_init` / `_chunk` / … | 发 | 分片上传临时素材（512KB/片，≤100 片） |
| `aibot_msg_callback` | 收 | 消息推送 |
| `aibot_event_callback` | 收 | 事件推送（enter_chat/卡片按钮/用户反馈） |

帧骨架：`{cmd, headers:{req_id}, body}`；req_id 由 `generateReqId(cmd)` 生成（前缀区分类型）；认证/心跳/回复的响应通过 `{headers:{req_id}, errcode, errmsg}` 回执，**同一 req_id 前缀区分类型**。

## 3. 收帧解析（aibot_msg_callback）

```json
{"cmd":"aibot_msg_callback","headers":{"req_id":"…"},
 "body":{
   "msgid":"…",
   "msgtype":"text | image | mixed | voice | file | video",
   "chattype":"single | group",
   "chatid":"…",
   "from":{"userid":"…"},          // 身份键=userid
   "text":{"content":"…"},          // text 型
   "image":{"url":"…(5min有效,加密)","aeskey":"…"},
   "voice":{"content":"…(语音转文本)"},
   "mixed":{"msg_item":[{"msgtype":"text|image","text":{"content":"…"}}]},
   "quote":{…}
 }}
```

事件帧：`body.msgtype="event"`，`body.event={…}`。

## 4. 会话内回复（关键：无纯文本帧，统一流式）

```json
{"cmd":"aibot_respond_msg",
 "headers":{"req_id":"<收到的 msg_callback 帧 req_id——原样透传>"},
 "body":{"msgtype":"stream",
         "stream":{"id":"<自生成 streamId>","finish":true,"content":"<Markdown 文本>"}}}
```

- `content` 支持 Markdown；`finish:true` 单帧即完成回复（流式打字机=多帧 finish:false→…→finish:true）
- `stream.id` 一次回复会话内保持一致；`msg_item`（图文混排）仅 finish=true 可带；`feedback` 仅首帧可带
- 欢迎语走 `aibot_respond_welcome_msg`，body 可为 `{"msgtype":"text","text":{"content":"…"}}`（唯一 text 型场景）
- 模板卡片：`{"msgtype":"template_card", …}`
- **串行回复队列**：同一 req_id 的回复帧官方 SDK 串行发送并等回执——自实现也应对齐（防乱序）

## 5. 主动推送（aibot_send_msg，MVP 范围外，协议备查）

`body={"chatid":…, msgtype:…, …}`——向指定会话主动发 Markdown/卡片/媒体，不依赖收帧。

## 6. 身份/会话判定

- 身份键：`body.from.userid`（写入 im_bot_users.im_user_id）
- 单聊判据：`body.chattype == "single"`（p2p 语义唯一真源）
- 错误语义：认证连续失败（官方 maxAuthFailureAttempts 用尽）=WS_AUTH_FAILURE_EXHAUSTED——对应我们的 fail-fast
