# 第2章 全局统一术语规范
## 2.1 原始指标 Raw Indicator
数据源直接输出，无自定义运算，用于筛选与查看，分为两类：
1. 静态原始指标：季度/半年更新财报数据（PE、PB、营收、毛利率、总市值、分红年化）；仅适配A股、ETF、可转债；加密、期货无此类数据。
2. 时序动态原始指标：逐K线更新。
通用项：开盘、收盘、最高、最低、成交量、成交额、涨跌幅、换手率。
品类专属：可转债转股溢价率；加密永续资金费率、持仓量、基差。

## 2.2 衍生因子 Derived Factor
基于原始指标公式计算，用于建模与信号生成。
1. 截面衍生因子：单时间截面计算，无滚动窗口；
2. 时序衍生因子：必须配置滚动时间窗口，每一根新K线全窗口重算，代表指标：ATR、均线乖离、N日动量。

## 2.3 模型特征 Feature
送入量化模型的输入项，可任选原始指标、衍生因子。

## 2.4 跨市场指标兼容规则
1. 通用行情字段统一；交易时段、涨跌停、T+0/T+1各市场不同；
2. 财务指标仅限A股/ETF/可转债可用；
3. 时序计算公式通用，交易日历、滚动周期自动适配市场；
4. 系统自动屏蔽当前品类不可用指标、因子。

## 2.5 三层数据库强制存储架构
1. kline_base（通用时序主表）：全市场统一存放开高低收、量额，表结构永久固定；
2. kline_ext（时序扩展表）：JSONB存储各品类专属指标，新增指标不用改库表；
3. asset_static_info（静态信息表）：存储标的基础资料、财报低频数据，高低频数据物理隔离。

# 第3章 MKT 交易市场抽象管理模块
模块概述：统一全市场接入、只读隔离、接口密钥安全管控，是多品类接入底层底座。

F-MKT-001｜F 多市场统一配置管理
需求描述：后台可视化页面支持新增、编辑、启用、停用、删除交易市场，兼容A股、ETF、可转债、国内期货、加密现货、加密永续。可配置标的映射、专属指标清单、交易日历、交易时段。
输入：市场名称、市场类型、接口地址、鉴权密钥、标的映射、专属指标、交易日历、时段参数
输出：配置持久化存储；前端生成标准化市场分类树；接口连通自检结果；启停状态生效
优先级：高
关联模块：标的筛选、策略挂载、实盘交易、数据采集存储

F-MKT-002｜F 只读数据源隔离管理
需求描述：Tushare等纯数据接口标记为只读市场，只读市场仅允许用于回测、标的查询，禁止绑定策略做真实交易，实盘挂载入口置灰锁定。
输入：数据源名称、接口地址、字段映射、只读标识
输出：市场分组隔离；实盘挂载按钮置灰；只读权限逻辑生效
优先级：中
关联模块：标的筛选、历史数据服务

S-MKT-003｜S 市场密钥加密存储
需求描述：全部第三方接口密钥禁止明文入库，数据库加密存储；前端密钥全程脱敏，仅支持重新录入，无法查看原始密钥。
输入：第三方接口原始密钥字符串
输出：加密入库；页面脱敏展示；密钥防泄露防护生效
优先级：高
关联模块：市场配置、第三方集成、系统安全管控

# 第4章 INT 第三方集成配置模块
模块概述：管控飞书消息、大模型对接、全第三方接口健康巡检，实现外部服务统一管理。

F-INT-001｜F 飞书多账号分级权限配置
需求描述：可配置多条飞书Webhook，绑定三类角色权限：管理员全操作权限；操作者仅启停策略、接收消息；审计员仅可读日志。消息支持按角色分级推送：交易信号、风险告警、系统通知。
输入：飞书Webhook地址、角色绑定关系、消息类型勾选清单
输出：功能按钮权限拦截；消息分层精准推送；权限校验逻辑生效
优先级：高
关联模块：消息通知、日志审计、权限管控、风险监控

F-INT-002｜F 大模型统一可配置接入
需求描述：全局配置面板录入大模型API地址、密钥、版本、QPS上限、单次Token上限；策略分析、信号优化统一复用该配置，不用单独对接。
输入：API地址、密钥、模型标识、限流参数、Token上限
输出：接口连通检测；全局调用配置生效；限流规则落地
优先级：中
关联模块：策略分析、信号处理、策略优化

P-INT-003｜P 第三方接口定时健康探测
需求描述：系统定时轮询所有市场接口、飞书、大模型接口，检测连通性；异常在后台标红告警。
输入：全量第三方配置、定时探测周期
输出：在线/离线状态标签；探测时间记录；异常高亮告警；巡检日志
优先级：中
关联模块：全部第三方模块、系统告警

# 第5章 FAC 指标与因子库管理模块
模块概述：管控所有原始指标、自定义因子，解决品类不兼容、未来函数等量化核心风险。

F-FAC-001｜F 原始指标全生命周期管理
需求描述：搭建标准化原始指标库，严格区分静态/时序指标；每条指标绑定适配市场、品类、更新频率；支持启用、禁用、详情查看，预置行业通用指标。
输入：指标名称、指标类型、数据源、适配范围、更新周期、数据库字段映射
输出：标准化指标库；筛选、建模页面自动展示可用指标
优先级：高
关联模块：标的筛选、策略建模、数据采集存储

F-FAC-002｜F 自定义衍生因子管理
需求描述：用户基于原始指标编写公式创建因子；区分截面、时序因子，时序因子必须填写滚动时间窗口；新增因子必须通过语法、兼容性双重校验才可启用。
输入：因子名称、计算公式、因子类型、滚动窗口（时序必填）、适配品类
输出：合规因子入库；建模可选；非法公式拦截并提示原因
优先级：高
关联模块：策略建模、回测计算

F-FAC-003｜F 指标因子跨品类兼容性自动校验
需求描述：选定市场、标的品类后，系统自动过滤不兼容指标、因子，弹窗提示异常，阻断下一步操作。
输入：选定品类、勾选的指标与因子集合
输出：无效项过滤；兼容性告警；非法操作拦截
优先级：高
关联模块：标的筛选、策略建模、策略回测、实盘信号

F-FAC-004｜F 时序因子防未来函数校验引擎（商用核心）
需求描述：新增/修改因子时自动检测是否引用未来时间、未来K线数据；回测严格复刻历史当日可获取数据，禁止用未来数据拟合行情；违规公式禁止保存、禁止回测实盘；页面支持一键风险检测。
输入：因子公式、窗口参数、市场交易日历规则
输出：风险检测报告；违规拦截；合规放行；风险点位可视化标注
优先级：极高
关联模块：因子库管理、策略回测、实盘信号生成

# 第7章 POOL 自定义标的池管理模块
模块概述：锁定策略交易边界，分为静态、动态池子，杜绝全市场无差别跑策略。

F-POOL-001｜F 多组别标的池创建与管理
需求描述：支持创建多套独立标的池（A股稳健池、可转债套利池、加密永续池等）；支持手动新增、批量导入、批量删除标的；页面展示池子明细、适配市场、绑定策略数量。
输入：标的池名称、品类范围、标的清单、备注
输出：标的池持久化；策略可绑定池子；统计数据可视化
优先级：极高
关联模块：标的筛选、策略建模、回测、实盘执行

F-POOL-002｜F 动态标的池自动更新机制
需求描述：标的池分为静态、动态。动态池绑定筛选规则，按日盘后/每周自动重筛更新标的；静态仅手动修改。
输入：筛选规则、更新周期、标的池ID
输出：动态池子定时更新；标的保持合规；更新日志留存
优先级：高
关联模块：标的筛选、定时任务、数据同步

F-POOL-003｜F 策略与标的池强制绑定约束
需求描述：所有策略方案、可执行策略包必须绑定标的池；回测、实盘仅在池子内运行，禁止跨品类、全市场执行；支持解绑重绑。
输入：策略ID、标的池ID、绑定/解绑指令
输出：运行范围锁定；跨范围执行拦截；绑定关系更新
优先级：极高
关联模块：策略建模、回测、实盘执行

# 第8章 MOD 策略建模与历史回测模块
模块概述：完成策略搭建、历史回测验证、版本管控，上线前数据校验关口。

F-MOD-001｜F 可视化策略建模画布
需求描述：建模页自动带入选中标的池；用户选择原始指标/因子作为特征，配置特征权重；保存为基础策略方案，无风控执行规则，不能直接实盘。
输入：标的列表、特征清单、特征权重、方案名称、备注
输出：基础策略方案存储；仅用于后续封装
优先级：高
关联模块：标的筛选、指标库、因子库

F-MOD-002｜F 时序适配型历史回测
需求描述：自定义回测起止时间、初始本金、手续费；系统按市场日历适配时序，时序因子滚动逻辑1:1复刻实盘；回测输出净值曲线、胜率、最大回撤、夏普比率。
输入：基础策略、回测参数、交易日历规则
输出：可视化回测报告、全套绩效指标
优先级：高
关联模块：时序因子引擎、历史数据

F-MOD-003｜F 策略方案版本管控
需求描述：策略每次修改自动生成新版本，记录操作人、时间、前后参数；支持版本查询、复制、历史回滚。
输入：策略ID、版本操作指令
输出：新版本生成；历史记录留存；回滚配置生效
优先级：高
关联模块：日志审计、策略存储

F-MOD-004｜F 回测数据完整性预检机制
需求描述：点击启动回测，系统校验标的数据完整性、指标覆盖度、时序窗口充足度、品类兼容性；异常禁止回测，弹窗提示，支持一键跳转到数据补采页面。
输入：策略、标的池、回测时间区间
输出：预检报告；异常拦截回测；补采入口跳转
优先级：极高
关联模块：历史补采、因子计算、回测

优先级：高
关联模块：回测、实盘、风险管控

F-EXE-004｜F 策略包灰度发布与上下架运维
需求描述：策略分为测试中、灰度运行、正式上线、下架停用；支持灰度小范围试运行、手动上下架、版本回滚；运行异常可自动下架保护；记录运行时长、报错次数。
输入：策略包ID、状态变更指令、灰度参数

# 第10章 MON 实盘监控与风险控制模块
模块概述：实盘可视化监控、风险告警、性能保障、数据一致性校验、故障自愈。

F-MON-001｜F 多策略并行实时监控看板
需求描述：看板分区块，一个区块对应一套策略；实时K线展示，标注买点、卖点、止损点位；同步展示原始指标、时序因子实时数值。
输入：运行策略包、实时行情流、实时因子数据
输出：可视化K线图表；交易信号标记；指标实时展示
优先级：高
关联模块：实时数据流、策略引擎、因子计算

F-MON-002｜F 策略启停管控
需求描述：支持手动暂停/恢复策略。暂停后停止发信号、停止下单；持续接收行情、刷新图表、计算风控指标。
输入：策略包ID、启停操作指令
输出：运行状态变更；信号启停；行情正常接收
优先级：中
关联模块：策略执行引擎

F-MON-003｜F 实时风险预警推送
需求描述：监控账户总回撤、单标的仓位占比、行情大幅异动；触碰阈值页面红色弹窗，按角色飞书分级告警。
输入：持仓数据、风控阈值、行情波动、账号权限
输出：页面告警、飞书分级推送、风险日志
优先级：高
关联模块：飞书集成、账户管理、风控

P-MON-004｜P 多策略并行性能保障
需求描述：支持同时运行≥10套策略，行情刷新、因子并行计算流畅，页面整体延迟≤2秒。
输入：多路实时行情、多策略计算任务
输出：低延迟页面渲染；因子实时刷新；多任务无卡顿
优先级：中
关联模块：实盘运算、前端可视化、时序因子

F-MON-005｜F 实盘-回测数据漂移监控校验
需求描述：每日自动比对同一标的、时间、公式下，实盘因子值和回测复刻因子值的偏差；偏差超限弹窗+飞书告警，可暂停策略，保证回测与实盘逻辑一致。
输入：实盘因子、回测复刻因子、自定义偏差阈值
输出：漂移检测报告；风险告警；策略风险标记与保护
优先级：极高
关联模块：因子计算、回测、实盘执行

P-MON-006｜P 数据断连自愈与断点补采机制
需求描述：自动识别接口断线、K线缺失、计算中断；自动重连、补全断点K线、重算缺失因子；全程无需人工干预，消除数据空洞。
输入：接口连接状态、数据完整性检测结果
输出：链路自愈；缺失数据补齐；因子完整；自愈日志
优先级：高
关联模块：数据采集、实盘监控、因子计算

## 16.1 全链路业务闭环总结
完整业务链路：
数据源接入→多源管控→数据清洗治理→指标因子规则校验→标的筛选+标的池锁定范围→策略可视化建模→回测前置校验→策略规则封装→灰度发布上线→实盘可视化监控+实时风控→故障自愈→交易三层对账+全链路审计。
全链路无断点，量化行业高频风险（未来函数、回测实盘不一致、脏数据、错跑品类、未验证策略上线）全部做硬性拦截。

## 16.2 海量数据治理总结
依靠订阅白名单、差异化分时同步、增量优先、冷热分层、分周期数据过期清理、限流分片、脏数据自动清洗，彻底解决时序数据无限膨胀、资源浪费问题，适配多年长期实盘运维。

## 16.3 多市场兼容总结
一套平台统一承载A股、ETF、可转债、国内期货、加密现货/永续；依靠品类自动适配日历、指标可用性，无需多套系统分开维护。
