# P2-双轨差异修复批（2026-08-28 午休窗立项,八步法压缩走）

> 目标:修复双轨 diff 四分类中三项可修缺陷,当日部署,下午盘验证;修后残余差异=仿真不一致基线(门禁口径决策的输入)。
> 证据链见 `flow/踩坑记录.md` 当日"双轨差异四分类"条。

## 目标
hub(`bar_hub`) 与 direct/shadow(`bar_shadow`) 三项确定性差异修复:
1. **盘前伪 bar**:hub 把盘前快照(09:26~09:30)聚合成分钟 bar——改为盘前 tick 不进聚合器
2. **收盘半熟根**:15:00:05 `flush_all` 把只含一笔的 [15:00] 桶(不含收盘竞价量)finalize 落库(V=0),其后到达的含竞价快照进孤立桶永不产出——改为分窗 finalize
3. **shadow 首根 V=0**:vnpy `BarGenerator` 进程首笔 tick 无 `last_tick` 基线,首根 bar V=0/OHLC 平——worker 落 shadow 跳过进程首根

## 接口契约
- 新:`_in_bar_session(t: datetime) -> bool`——`hm=t.hour*100+t.minute; return (930<=hm<1130) or (1300<=hm<1501)`(09:30 起、11:30 前止、13:00 起、**15:00 含**——收盘竞价快照 15:00:xx 必须喂)
- 新:`flush_minute(minute_slot: int) -> list[dict]`——finalize 所有 `b["minute"]` 时分数==minute_slot 的桶(11:29→slot=689,14:59→899,15:00→900);复用 `_finalize`
- 改:`main.py _flush()`——`hm` 查表得目标 slot,`5<=second<10` 窗内 `agg.flush_minute(slot)` 逐根 `_publish`
- 改:worker `_shadow_first={"seen":False}` 闭包 flag;首根(`not seen`)skip INSERT+`logger.info("shadow 首根跳过(基线根)")`+置 seen

## 设计要点与已知边界(评审必读)
- **冷启动基线变化(有意)**:hub 原首见=盘前 09:26 tick(基线含集合竞价量);修后首喂=09:30:0x,基线=该笔累计——与 vnpy"首笔建基线"语义**一致化**,此即修复意图
- **worker 首根跳过 ⇒ bar_shadow 当日首根缺**:anti-join 呈 hub_only(每日 09:31 一根;**本批盘中部署日=worker 重启,再加 13:01 一根**)——`flow/待办.md` 三查手册 anti-join 节补豁免注记
- 15:01 新窗边界:收盘快照若 >15:01:10 到达仍进孤立桶(已知边界,接受;原行为更糟——半熟 V=0 落库)
- **修后判读**:15:01 根 V>0=hub 修复生效;若仍 V=0=hub 侧收不到竞价量=**仿真不一致实锤**(口径决策输入)
- 中途盘中部署语义:hub/worker 波次重启后基线重建(新进程冷启动),当日后续分钟量正确;重连不触发订阅重放问题已由 `_md_edge` 沿处理(不碰)
