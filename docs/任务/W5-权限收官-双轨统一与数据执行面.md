# W5 权限收官:双轨统一+数据执行面+nav 守卫+虚拟滚动(2026-09-01;完美系统战役第五批)

> 承 W4(双轨缺口半修/数据执行面归本批/readonly 守卫归本批)。D 阶段中**账户域多人归属**显式缓做(见"不做的")。

## 产出 1:require_role → require_perm 统一迁移(100 处)

- **映射表**(机械迁移,语义对齐 PERMISSIONS 字典):
  - `require_role("viewer","analyst","trader","admin")`(68 处)→ `require_perm("read")`(deny read=可吊销登录态最低权限——设计能力,10 号语义)
  - `require_role("admin")`(23 处)→ 按域:**mgmt 数据源/通道/券商 CRUD→system_config;llm 模型/预算→llm_config;im_bots→im_bots_config;用户管理→user_mgmt(锁键,effective 地板保 admin);SMTP→system_config;chat admin 端点→user_mgmt**
  - `require_role("analyst","trader","admin")`(6 处)→ `require_perm("strategy_control")`
  - `require_role("trader","admin")`(3 处)→ 逐点判(halt 急停类→halt;交易类→trade)
- **鉴权语义变化声明**:迁移后 admin 专属端点经 permission 表(锁键地板保 admin 恒有);require_role 保留给 /auth/me·login 等身份类(查表无意义的)
- 回归面:全部端点鉴权测试(mock 表)——先加映射基线测再迁移

## 产出 2:data 维执行面脱敏

- **文件**:`src/web_api/routes/risk.py`(risk_log)+`trading.py`(position/orders)
- 新 helper `data_sensitivity(username)`(auth.py):user deny>user allow>role(同 effective;data 维)→ 'detail'|'aggregated'|'count'(缺省 detail=现行为零变化)
- `/api/risk/log`:sensitivity=count → 返回 {count, first_ts, last_ts} 不返明细;aggregated → 按 action 聚合计数
- `/api/position`+`/api/orders`:count → 仅条数;aggregated → 隐 symbol 级明细聚合成总市值/总盈亏
- 前端:持仓/风控日志页对 count/aggregated 形态渲染(空态文案"权限受限,显示计数")

## 产出 3:nav 维消费(readonly 守卫)

- `/auth/me` 增 `nav`:本用户 nav 三态映射(user deny>role)
- 前端路由守卫(router.beforeEach):nav[route]=='hidden'→拒(redirect 首页+提示);'readonly'→放行但页面写操作按钮 disable(经 provide/inject 注入 readonly 标志,重点页:Strategy/LiveTask/Pool 写按钮接)
- readwrite/无配置→现行为

## 产出 4:el-table-v2 虚拟滚动(#2b)

- **对象**:Logs.vue(日志列表)+Audit.vue(审计列表)——两页最长(上限 500/全量)
- el-table-v2(EP 内置零新依赖)替换 el-table,列定义迁移;其余页数据量<200 不动(原裁定维持,这两个是例外因无分页上限)

## 不做的
- **账户域多人归属**(D 阶段原案):当前系统单操作者+admin,多账户归属无消费场景——数据模型(account.owner)+执行面全链 speculative;触发条件=出现第二个交易员账号。显式缓做记录 decisions
- 虚拟滚动铺全站(其余页有分页/上限,原"数据量<1000 不紧迫"裁定对其余页维持)
