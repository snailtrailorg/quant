# 多账号源 D4 · 金融面交易可靠性（详细设计）

> 上级：`docs/architecture/31-多账号源架构设计.md` §六。状态：详细设计（待双盲审）。

## 一、目标

金融面只做「把账算对」三样：**费率对账 / 资金隔离 / 账户级敞口（含同标跨账户反向拦截）**。不做监管合规（举牌/减持/税务/报备/反洗钱——已砍，见 31 号 §七）。

## 二、现状（已核实）

- 回测费用摩擦已有 `BacktestAdapter.set_fees`（佣金可配 + 印花税卖出 0.05% + 过户费 0.001% + 涨跌停一字板不可成交）。
- 资金/持仓现为单账户全局（`account_snapshot` 单行、`position_snapshot` 无 venue 维度）——资金隔离/账户级敞口 per-venue 待 D2 落地后接入。
- 加密资金费 + maker/taker + USDT→CNY 未接入实盘对账。

## 三、设计决策

- **D4-1 同标跨账户反向拦截**：识别「同一用户两个 venue 对同标的反向持仓」（自己跟自己成交=对敲/双份佣金）。**推荐：默认告警（fail-soft），可配置拦截**——个人跨账号可能有合法对冲需求，硬拦截会误伤；但至少要告警让用户知道在自成交。
- **D4-2 加密 leverage 必须下发交易所网关**：现 `place_order` order dict 无 leverage 键、`risk.py:375 order.get("leverage",1)` 恒为 1、`adapters.py:308 _leverage=1`——venue 级 leverage 若不实配到网关（set_leverage/逐仓）仍是空配置。D2-2 的 leverage→venue 级配置须在 D5 下单链路实配下发。

## 四、契约

- **资金隔离**：每 Venue 独立记账（依赖 D2 的 account_snapshot per-venue）。
- **账户级敞口**：同 Venue 同标的同向合并，读写方 per-venue；跨 venue 反向持仓识别（告警/可配置拦截）。**同 venue 反向（加密 hedge long+short 并存）口径=净敞口**（净敞口 + 跨 venue 反向两维都要，非只同向合并）。
- **费率对账**：印花税（A股卖出 0.05%）+ 过户费（A股 0.001%）+ 佣金；**可转债/场内基金免印花且免过户费**；加密资金费 + maker/taker + USDT→CNY（**汇率来源/快照时点需钉死**）。回测/实盘同口径。

> **编码实施补充（2026-09-24，AB 双盲审后）**
> - **费率对账 → 资金对账**：vnpy TradeData 无 commission + 项目 XTP SDK 版本无费用字段 →「券商逐笔费用对账」走不通。改为**资金对账（现金口径余额核对）**：本地推导现金（baseline available_cash + Σ成交净现金流 − Σ理论费用）vs 券商查询 available_cash，差异=漏记+费用误差+出入金（间接覆盖费用）。券商逐笔费用对账挂账 D6。
> - **direction 资源 id 化**：position_snapshot.direction 落库从 vnpy gettext 翻译文本（随 locale 飘）改为资源 id `direction_long/direction_short/direction_net`（`direction_` 前缀防全局冲突），显示层多语言另做。迁移 0103 存量归一化 + SET DEFAULT。
> - **资金对账用现金口径**（available_cash）非总资产——总资产含持仓市值，浮盈浮亏会误报（双盲审 A-1 抓）。
> - **symbol_market 单源下沉**：`quant_common.fees.symbol_market`（层0），risk._market_of 委托之；兼容裸代码（trade_log.symbol 是裸代码，否则 A股印花税/过户费漏算——双盲审 A-2/B-2 抓）。

## 五、限定范围

只做：三样金融面的 per-venue 口径 + 反向拦截识别 + 加密资金费对账。
不碰：D1（权限）、D2（快照 schema）、D3（流）、D5（网关）、D6（hub 部署）。

## 六、验收标准（编码阶段定，行为级）

- 双 venue 资金/持仓互不串账（A venue 成交不改变 B venue 可用资金）。
- 同标跨 venue 反向持仓被识别并告警（或按配置拦截）。
- 费率对账：可转债/ETF 免印花、A股卖出含印花+过户、加密含资金费+maker/taker。
