## 2. 关键设计（v2 增补点加粗）

- join 键=组名字符串，`require_perm`/`load_effective_permissions`/`_load_dim` 零改动；`load_role_permissions` 天然支持（表行直算；**无行=零权限，自定义组永不落 PERMISSIONS 字典兜底**——已双盲验证）
- **身份与权限分层**（P0-1 修）：身份类端点=已认证+账号有效（require_authenticated）；功能端点=require_perm 权限——新组用户"能登录能用身份功能，业务功能按权限逐项放行"
- **builtin 锁**：四名不可改不可删、可改描述；`guard_self_deactivate` 引用的 'admin' 字面量因锁名恒有效（末位防线前提，验收项）
- **锁键防线不变式（验收项）**：任意非 admin 组保存含 user_mgmt/resume/account_keys → 落库恒不含（地板逻辑逐字保留的钉子测试）
- rename 级联单事务+尾断言+invalidate_perm_cache；删组级联清 permission+软删用户归位 viewer+invalidate
- 新组零权限起步=真零（零 read 亦然——身份功能不依赖 read）
