# 批16 · 列表 UX 整顿（范围清单 + 逐页确认表）

> 2026-09-12 立项（用户四诉求）：①列宽按内容自适应 ②"可显示 vs 已显示"差异逐页勾选
> ③操作列=常用按钮 +「编辑」兜底弹窗 ④个人中心弹窗化。
> 本文件=范围单一真相源；逐页确认结果回填"状态"列。
> 勘察方法：全站 views 扫描 + 对照 server/src/web_api/routes/ 端点返回字段与操作。

## 通用方案框架（逐页套用）

### 列宽三机制
| 机制 | 适用 | 做法 |
|---|---|---|
| M1 权重分配 | v1 表默认 | 列去 `width` 改 `min-width`（按内容预估权重），长文本列配 `show-overflow-tooltip`；窗口伸缩自动重排 |
| M2 按内容测量 | 列少内容差异大的 v1 表 | 自研 `v-autofit` 指令（~40 行）：mounted/数据变更后测 `.cell` scrollWidth 取表头+前 N 行最大值设列宽，末列 flex 吸收，resize 重算 |
| M3 估宽函数 | v2 虚拟表（3 张：Risk 日志/Reconcile 差异/SymbolManage） | `width = max(label, 采样行内容) + padding + 排序图标`，末列弹性 |

### 操作列模式
```
常用操作（≤2-3 个）→ 行内直接按钮
其余全部 → 「编辑」（或更贴切名）按钮 → 弹窗内展示完整选项（含低频/危险操作）
```
每页确认：哪些进按钮、哪些进弹窗、弹窗叫什么。

### 已知方案边界
- v2 表（3 张）不适用 M1/M2，只能 M3
- Dashboard 为卡片列表范本，默认跳过（单列口径）

## 后端有端点、前端全站无按钮的操作（集中决策）
| 操作 | 端点 | 建议 |
|---|---|---|
| 删除回测 | DELETE /api/backtest/{id} | 回测列表加（进编辑弹窗候选） |
| LLM 预算编辑 | POST /api/llm-budget/{bid} | 预算表加编辑 |
| 策略启停 | POST /api/strategy/{sid}/start\|stop | 设计裁定不做（启停唯一入口=LiveTask）——维持 |
| 池分钟同步/复权因子回补 | sync.py 三端点 | 池页确认时定 |
| 策略参数预校验 | POST /api/strategy/validate-params | 编辑器内接（属编辑弹窗内选项） |
