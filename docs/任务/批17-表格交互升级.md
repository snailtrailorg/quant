## 17A 列宽拖拽全站+持久化（核心工程）

### v1 表（el-table ×49）——TableShell 包装组件
- `components/TableShell.vue`：透传 attrs/slots 包 el-table，恒 `border`；
  监听 `header-dragend(newWidth, oldWidth, column)` → 存 `localStorage['colw.'+tableKey][colKey]=newWidth`
- **colKey = column.property || column.label**（prop 为主；无 prop 的操作/模板列回退 label）
- 挂载后回放：`nextTick` 遍历 `tableRef.store.states.columns`，命中存档则设 `width/realWidth` + `doLayout()`
  （EP 内部 API——锁定 EP 版本行为，升级 EP 时回归本批测试）
- 迁移 = `<el-table` → `<TableShell`（49 处机械替换，列声明零改动）；tableKey 优先显式 `storage-key`，缺省 `route.path#序号`
- 特例：selection/expand 列不记忆（type 列跳过）

### v2 表（el-table-v2 ×3：Risk 日志/Reconcile 差异/SymbolManage）
- EP v2 无原生拖拽 → `utils/v2colwidth.js` composable：columns computed 外叠 `widthOverrides` ref（初始=estColWidth 结果），
  表头 cellRenderer 注入拖拽手柄 span（mousedown→mousemove 改 overrides→mouseup 持久化同 storageKey 命名空间）
- 三表接入（columns 定义改走 composable 的 `withWidths(cols)`）

### 存储
- `localStorage`（与列显隐同介质同理由——个人查看偏好，不建服务端表；换设备从档位默认重新起步）
- 键：`colw.<tableKey>` = `{colKey: px}`；列下线自动失效（读时按现存列过滤）

## 17B 列显隐扩表（按内容圈定）

原则（用户「根据表格的内容」）：**列 ≥7 或含低频排查列**才配；列少的表配了=空壳噪音。
圈定 16 张（52 表中内容够厚的；清单可增删）：

| 表 | 建议默认隐藏（低频） |
|---|---|
| 选股器 A股/转债/ETF 三表 | 上市日期/换手率类 |
| LiveTask 任务表 | bars/md_mode/账户 |
| Trading 委托表 | 创建时间类 |
| Backtest 列表 | 创建时间 |
| BacktestRun 标的表 | 样本天数/低频指标 |
| UserManagement 用户表 | ID/创建时间 |

| LLMModels 模型表 | 接口地址/优先级 |

（数据中心两表已有——共 18 张 ≈ 35%；其余列数 ≤6 不配）
