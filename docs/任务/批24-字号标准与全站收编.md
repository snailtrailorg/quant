# 批24 · 字号标准立法与全站收编

> 2026-09-15 立项。起因：用户发现"页签字号 < 页签内表格标题字号"——排查证实该 16px 是**继承意外**（el-card__header 与 body 均未设 font-size，落浏览器默认、恒定不缩放），全站另有 94 处 font-size 硬编码旁路六级令牌。
>
> **用户三裁定（本批立法原则）**：①令牌在够用前提下尽可能少——六级数量不变；②令牌明显断档该补就补——**fs-card ×1.0→×1.15 解开与 body 同值冗余**（不新增令牌名）；③旁路不一刀切，度的把握=专业性——快照价保锚点用 kpi 派生，其余归零。
>
> **层级裁定（专业判断，2026-09-15）**：页签(14) < 卡片标题(16.1) **保留为设计特性**——Ant Design/EP/Arco/TDesign 业界通行（导航层小、内容标题大）。本批修的是"继承来的、不缩放的、无标准的 16px"，改为显式令牌声明。

## 一、目标

字号唯一真相源 = `web/src/styles/tokens.css` 六级令牌。四件事：
1. **补档**：`--fs-card: ×1.0 → ×1.15`（16.1@1920）——解开与 `--fs-body` 同值冗余，填补 14→19.3 断档（"卡片/小节标题"档）。**波及面**：监控页 group-title×3（14→16.1，组标题本该更大）+ 弹窗标题（EP 默认本 16px，此前映射 14 属隐性回退，本批归位）。
2. **根修**：`body { font-size: var(--fs-body) }`——继承链兜底基准，无显式字号的裸文本不再落浏览器 16px。
3. **显式化卡片标题**：tokens.css EP 覆写区加 `.el-card__header { font-size: var(--fs-card); }`——16→16.1 视觉无感，但从此显式声明+随窗缩放（页签<卡片标题=业界常态，保留为设计特性）。
4. **收编+守门**：94 处硬编码（13 个值、32 个文件）全部映射到六级令牌；`scripts/check-tokens.sh` 加 FS 维，基线=0。

## 二、字号标准（六级，本批仅改 fs-card 比例）

单一驱动源 `--fs-body: clamp(12.5px, 9.5+0.234vw, 14px)`；@1280=12.5 / @1707=13.5 / @1920=14。

| 令牌 | 比例 | @1920 | 语义（选用依据） |
|---|---|---|---|
| `--fs-kpi` | ×1.92 | 26.9 | 数据大数字（KPI 卡值/统计值）；页面唯一锚点数字用派生 `calc(×1.25)`≈33.7 |
| `--fs-page` | ×1.38 | 19.3 | 页面级标题/横幅/品牌名/次档大数字 |
| `--fs-card` | **×1.15** | **16.1** | 卡片标题/小节标题（el-card__header/弹窗标题/h3 系；配 600-700 字重） |
| `--fs-body` | 基准 | 14 | 正文基准（body 继承根/表格/页签/按钮/markdown h3） |
| `--fs-label` | ×0.92 | 12.9 | 次级正文/链接/meta/深度表 |
| `--fs-foot` | ×0.87 | 12.2 | hint/脚注/徽标/时间线/次要数据 |

**层级靠字重不靠加档**：同级内区分用 500/600/700。**派生有先例**（Profile 庆祝 emoji kpi×1.4/×1.6）：视觉锚点保位用 calc 派生，不新增令牌名。

## 四、守门（防旁路回流）

`scripts/check-tokens.sh` 增第三维：
```bash
count_fs() { grep -rEo "font-size: ?[0-9.]+(px|em|rem|%)" web/src/views/ web/src/components/ web/src/layouts/ web/src/App.vue --include="*.vue" 2>/dev/null | wc -l; }
```
- 正则含 em/rem/%（盲审 A-P2-8：相对单位同属排版旁路，今日全站为零，扩展零成本）。
- 扫描范围只含 views/components/layouts/App.vue——`styles/tokens.css`（令牌定义地）天然不在内，零白名单。
- **集成三步骤（盲审 A-P1-4/B-P1-4 共指，缺一即 `set -u` 下 unbound variable 崩、prebuild 恒红）**：①脚本 :13/:15 两处 echo 同步加 `BASE_FS=$FS`；②收编完成后跑一次 `bash scripts/check-tokens.sh --update` 重采三键（PX/HEX 顺带刷新）；③`web/scripts/.token-baseline` 入第五节"只改"清单。
- 成功输出样例：`✓ 令牌门: PX=44≤44 HEX=24≤24 FS=0≤0`。
- **回流监测备忘（代码双盲审）**：`font:` 简写、`:style` 驼峰对象（fontSize）、`font-size : 13px`（冒号前空格/tab）三个理论绕过向量当前全站零命中——后续若出现属违规，正则按需收紧。

## 五、限定范围

- **只改**：`web/src/App.vue`（1 行）+ `tokens.css`（fs-card 比例 1 行+el-card__header 1 行）+ 第三节映射表 32 文件 94 处的 font-size 声明与少量补字重 + `scripts/check-tokens.sh` + `web/scripts/.token-baseline`（--update 重采）。
- **不碰**：其余令牌定义（kpi/page/body/label/foot 比例零变化）、EP 映射区其余行、line-height/间距/颜色、后端。
- **驼峰 fontSize 豁免声明（盲审 B-P2-7）**：CodeEditor/DslEditor/PythonEditor 的 monaco `fontSize:13`、SystemMetricsCards:81 的 echarts `fontSize:10`、Avatar 几何字号——编辑器/图表/头像 **API 参数非 CSS 排版**，不收编不守门（正则 font-size 小写连字符天然不匹配驼峰）。

## 六、验收标准（cwd=仓库根，除注明外）

1. `grep -rE "font-size: ?[0-9]" web/src/views/ web/src/components/ web/src/layouts/ web/src/App.vue --include="*.vue"` → **0 命中**。
2. `cd web && npm run build` 绿（prebuild 钉子随跑）。
3. `bash scripts/check-tokens.sh` → `✓ 令牌门: … FS=0≤0`。
4. 后端零触碰 → pytest 不跑（令牌门+build 即本批门）。
5. **影响面披露**：body 根修后所有无显式字号的裸文本（含 DataIntegrity 统计卡 label 等各页 div/span）从恒 16px 变为 14@1920、**12.5@1280（缩约 22%）**且随窗连续缩放——这是全站性变化非四页局部。
6. 用户视觉验收重点六页：任务管理（卡片标题 16→16.1 无感+缩放生效）/ Profile（h3 16→16.1+600；扫码向导 13→12.9）/ StockDetail（快照价 34→33.7 无感）/ Register（banner 17→19.3；条款正文 16→14）/ **Help（改动密度最高：h1 22→19.3、h2 18→16.1、h3 15→14）/ BacktestRun+DataIntegrity（统计值 24→26.9 放大）**；任意弹窗（标题 14→16.1 归位 EP 默认——本批唯一视觉变大项）；窗口拉窄到 1280 抽查缩放一致性。
