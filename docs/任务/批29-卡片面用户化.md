## 四、风险与权衡（已裁定项）

- **五轮直通权衡的操作面（用户已裁定）**：未绑定者与自有 bot 私聊/点卡，身份解析为 owner → 可触发操作工具（emergency_halt / strategy_stop / strategy_start / risk_resume；聊天/IM 面无下单工具，FORBIDDEN_TOOLS 常驻过滤）。与五轮"发消息 resolve owner 直通"同权衡、同面（消息面今天已如此）。时效 60s + 五闸收窄执行窗；"卡片仅私聊发"是发送面约束，点击面同直通面（转发卡 60s 内他人可点=点者亦解析为 owner，与私聊直通同权衡，非新增暴露面）。
- **HTTP 面单路径化**：遗留 app 配了卡片回调 URL 得桩 ACK，无害。未来 webhook 模式 bot 按 per-app 路由重设计（不在本批）。
- **真机排查链**：私聊发急停 → LLM 调 emergency_halt → 2.0 卡 → 点确认 → 五闸 → 执行+"已执行"回执（29-2b 修后回执走本 bot 凭证）。卡收到但点确认无反应 → 查开放平台"卡片回调=长连接模式"。
