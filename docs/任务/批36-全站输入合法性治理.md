- 后端模型层 20 模型零 Field 范围；P0=risk_rules params 连 JSON 都不查：①非 dict→`_merged_rules` TypeError **不在 try（仅 `__init__`:73，热加载 :92 在 try）=新进程崩**②坏 JSON→静默回落 DEFAULT（整表）③合法 dict+字符串值（`{"max_drawdown":"0.2"}`）→ check_order 内 `float>=str` TypeError **又一条崩溃路径（A-P0-1 补）**④巨值/负值=护栏静默失效（`max_drawdown=1e9` 永不触发）或该 strategy_id 全拒单。
- **执法断层（A-P1-2/B-P0-1）**：`risk_rule.load_rules_from_db` 全仓零调用=registry 三类（max_position/max_single_order/daily_loss_limit）从未执行；执法三类无编辑 UI（Risk.vue 只读展示，update_rules 内存态无落库）。写侧 type 零白名单（A-P1-1=P0 现实入口）。
- 回测真口子=**负佣金**（slippage 引擎已钳零 `backtest.py:109`；`set_commission` :81 无钳）+**custom 佣金单位 bug**（Backtest.vue:117 万 N 语义 vs step 0.0001=输 0.0003 实际 3e-8 变相零费）+**保留键覆盖**（`:286 ...params` 在 capital/commission 后展开可覆盖）。
- validate_params_against_defs 已存在（strategy.py:121-137）已接 strategy/live-task 写端点，**回测写端点未接**（routes/backtest.py:250）；validate_parameter_defs 不要求 min/max。
- 命名冲突陷阱：`daily_loss_limit` global=比例(0,1] vs registry=max_loss 绝对额——查表必须 **(type,key) 复合键**。
- Trading 人工单：price/action 是死字段（端点只收 symbol/volume）+权限错配（端点 user_mgmt 门 vs 页面无门=Trader 403 静默）。

## 36a · 资金面+P0（本批先做）

### 36a-1 风控规则双侧治理（用户裁定=活参数入 UI）

**后端写侧**（routes/risk.py:211-229）：
- type 白名单=六类（global/etf_conv/crypto + registry 三类）——未知 type 400
- params 校验三层（批28-7/mgmt.py:163 模板）：JSON 合法（坏→400 RISK_PARAM_INVALID）→ dict 形状 → 逐键按 **(type,key) 复合查表**（见下表）范围校验，未知键 400（无消费点三键 strict_stop_loss/margin_mode/pin_protection 容纳存量：入表标 optional）
- **schema 单源下发**：`risk_rule.py` `_REGISTRY` 每类+dict 三类统一暴露参数 schema 元数据（key/label/type/lo/hi/default/step/precision/enum/optional），GET `/api/risk-rules/types` 扩展下发（响应形状变更，前端同批切换）

**消费侧钳位**（risk_control/risk.py 载入路径，A-P0-1 三层语义）：
- 落点=`_load_rules_from_db`/`_merged_rules`（`__init__` 先于一切——init+热加载+存量脏行三面全兜）
- ①非 dict/坏 JSON→该 type 整体回落 DEFAULT+warning（**逐 type 回落**非整表——B-P1-7 对齐按键合并语义）②键值非数值/bool 非法→该键回落缺省+warning ③数值超界→钳边界+warning（**warning 按值指纹去抖每进程一次，仅日志不入 notify**——B-P1-2 防刷屏）

**schema 查表（(type,key) 复合，A-P1-3 全量）**：
- global: max_drawdown(0,1] / daily_loss_limit(0,1]（比例）
- etf_conv: single_position_pct(0,1] / max_trades_per_day int≥0（**0=不限制语义保留**） / max_single_amount>0 / strict_stop_loss bool(optional)
- crypto: leverage_max≥1 / margin_mode enum(optional) / pin_protection bool(optional) / max_single_amount>0 / daily_loss_limit(0,1]
- registry: max_pct(0,1] / max_amount>0 / max_loss>0

**前端 RiskRules.vue**：type 下拉六类（registry 三类标注「未生效——仅存储」）；params 纯文本→**schema 驱动动态表单**（el-input-number 按 lo/hi/step/precision 渲染/bool switch/enum select；optional 键可空）；死代码 registry 接线=另批裁定（本批只标注不激活——激活需 risk_control 消费链扩展，范围控制）。
