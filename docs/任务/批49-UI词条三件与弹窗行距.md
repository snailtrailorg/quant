# 批49:UI 词条三件+弹窗行距立法(反馈池 #10/#11/#13)

> 2026-09-18 用户验收反馈。#13 两条用户亲定措辞;#11 实锤根因=NAV id 与词条键不同名;#10 全局行距立法。

## 一、问题(勘察实锤)

1. **#13a** 系统监控「审计日志」页签/页名→「操作日志」(用户亲定;两词条 `tabs.audit`(Observe 页签真源)+`audit.title`(零消费死键随批退役))。
2. **#13b** 表格图标钮 title:「筛选」→「行筛选」(`common.filter`,消费=RowFilter 触发钮 title 4 处专属——Logs/Audit/TaskManager/Backtest 全传此键,改值零误伤);「列设置」→「列筛选」(`cols.settings`,消费=ColumnSettings 触发钮专属)。
3. **#11** 菜单权限表名称/显示名英文残留:labelOf 兜底链 `nav.<camel(id)>` 词条缺失回落 id 原文——**NAV_ITEMS_BASE 18 id 中 3 个与 nav 词条键不同名**:`live-task`(词条是 `liveTasks` 复数)/`trading`(词条是 `tradingDesk`)/`users`(词条是 `userMgmt`)。其余 15 个 camel 对齐(dashboard/screener/pool/factors/strategy/backtest/analysis/risk/reconcile/riskRules/dataops/integrations/observe/permResources/settings)。
4. **#10** 弹窗行间距偏大且各弹窗不统一:EP `.el-form-item` 默认 margin-bottom 18px;弹窗 label 规格(label-width 80/90/100/110/120px 五档+position top 混用)观感不一——行距全局立法一条;label 规格统一是大改,本批注记挂账。

## 二、方案(4 文件+1 CSS)

1. **locales/index.js**(zh/en 两侧):
   - `sysmon.audit`:'审计日志'→'操作日志';`audit.title` 同改(en: 'Audit Log'→'Operation Log')。
   - `common.filter`:'筛选'→'行筛选'(en 'Filter'→'Row Filter');`cols.settings`:'列设置'→'列筛选'(en 'Columns'→'Column Filter')。
   - `nav` 域补 3 键:`liveTask: '实盘任务'`/`trading: '交易台'`/`users: '用户管理'`(值=侧栏同词条复用,en 侧对应;**键=id camel 形态**——补齐兜底链,不改 NAV id=权限锚)。
2. **tokens.css** 加一行(批46 表格字重同模式全局立法):
   ```css
   .el-dialog .el-form-item { margin-bottom: 14px; }   /* 批49:弹窗行距立法(EP 默认 18px 偏大;全局统一) */
   ```
3. **挂账注记**:弹窗 label 规格统一(label-width 五档+position 混用)——大改另批(#10 残余)。

## 三、验收

- 系统监控页签/页名「操作日志」;表格行筛选钮悬浮「行筛选」、列设置钮「列筛选」(中英环境)。
- 菜单权限表:live-task/trading/users 三行显示中文(实盘任务/交易台/用户管理)。
- 弹窗行距全站收紧一致。
