# 批 60 方案集 · M5 流协议（v13 —— 砍 surrendered 键 + exit 码独立 + guarded 归切换目标）

> v13 缘起：v12 两轮终审（opus 正确性 + 一致性）抓出 4 P0 + 4 P1。根子：①反切对称性砍丢（guarded Lua 只给 B，反切 A 无原语 SET active_instance）；②exit(3) 双语义 + 30s 重拉打穿 StartLimit；③boot 放行后 dispatch 分叉未指定；④surrendered 键与 parts.py 现有 `hub:surrender` 撞名。v13 修：砍 surrendered 键（intent 闸已兜崩溃竞速）、exit 码独立（6=闸拦截进 Prevent）、guarded Lua 归「切换目标」通用、boot 单判定显式 dispatch 分叉。

## 一、设计总纲（一句话）

**「人配好 B 源 + 连通测试 → 盘后 confirm（setsid 绝缘）→ SET intent{snapshot,target} → A 让位（DEL lease exit 0）→ 启动 B（guarded Lua 接管 → SET active_instance）→ worker 次日 gen_jump 重暖机」。全 Valkey 四键，零新表，无待命态。**

## 二、人机分工（同 v12）

| 职责 | 谁 | 动作 |
|---|---|---|
| 配置 B 源 | 人 | `external_interface` 加 B 行 + B 单元 drop-in 写 `HUB_INTERFACE_ROW` + `HUB_UUID` |
| 验证 B 连通 | 人 | 独立连通测试（不起 hub、不碰键） |

| 口径兜底 | 系统 | 盘后腾讯回补 + B 首日口径 diff（`switch.py diff`） |

## 三、Valkey 键（四键，全部状态，零 DB）

```
hub:gen                       世代计数器（14 号已有）——INCR 单调；推进=guarded 首接 / 冷重启 normal
hub:lease                     写权租约（14 号已有）——SET NX + Lua CAS，防双活
hub:switch:intent            切换意图——Lua SET={snapshot:G, target:目标实例名}，EX 300s
hub:active_instance          现任实例名（quant/quant2，无 TTL）——重启仲裁
```

> **砍 `hub:switch:surrendered:{uuid}`**：原作用「先 surrendered 后 DEL lease」防 A 崩溃竞速，但 boot 单判定（intent.target≠自己→exit 6）已兜住崩溃重启，且与 parts.py 现有 `hub:surrender`（真让位）撞名。砍掉后 A 让位=见 intent → DEL lease → exit(0)，T2c 只轮询 lease 空。

## 四、A/B 实例模型

- **A（现任）**：`quant-md-hub@quant`，无 env，现行行为。
- **B（继任）**：`quant-md-hub@quant2`，drop-in 注入 `HUB_INTERFACE_ROW=<B行id>`（账号选择）+ `HUB_UUID=<switch.py 生成的 uuid>`（抢 lease 用此 uuid，switch.py 由此知道 holder）。
- **实例名来源**：base unit 加 `Environment=INSTANCE_NAME=%i`（A/B 同模板一次覆盖）。main.py 读 INSTANCE_NAME 供 boot 单判定比对。
- **uuid 来源**：main.py 优先读 `HUB_UUID` env（B 由 switch.py 注入），无则 `secrets.token_hex(8)`（A 冷启）——**改 parts.py:213 硬生成 → env 优先**。
- **boot 单判定 + dispatch 分叉**（读 intent + active_instance + INSTANCE_NAME，**必须插在 `_lease_boot`（main.py:84）之前**——load-bearing，放后则 A 复活先 INCR 污染 gen）：

```
intent 存在:
    intent.target == INSTANCE_NAME → 放行，走 _lease_acquire_guarded（切换目标接管）
    intent.target != INSTANCE_NAME → exit(6)（被切走者拦截，不 INCR 不抢 lease）
intent 不存在:
    active_instance 存在 且 active_instance != INSTANCE_NAME → exit(6)（非现任不抢回）
    否则 → 放行，走 _lease_acquire（非切换冷启）
```

- **exit 码**（systemd `RestartPreventExitStatus=0 3 6 78`，让位/拦截码都不重拉，避免 30s 重拉打穿 StartLimitBurst=5 进 failed 黑洞）：
  - `exit(0)`：优雅让位（A 见 intent 主动让位）
  - `exit(3)`：真让位（lease 被他人持有，14 号保留）
  - `exit(6)`：boot 闸拦截（intent.target≠自己 / active_instance≠自己）
  - `exit(78)`：EX_CONFIG（保留）

## 五、切换时序（confirm setsid 绝缘、幂等可重跑）

```
T0 稳态：A 持 hub:lease + hub:gen=G + active_instance=quant，写主流。
T1 准备（人）：配 B 行 + B 单元 drop-in（HUB_INTERFACE_ROW + HUB_UUID）+ 连通测试。
T2 confirm（switch.py，setsid 绝缘，阻塞到出结果，幂等可重跑）：
    (a) 切前闸：live_task running 拒切（退出码 2）
    (b) 校验 target ∈ {quant, quant2}（非法 → 退出码 5 fail-fast，防错填让现任下台）
    (c) 单 Lua：G_cur = GET hub:gen；SET hub:switch:intent = {snapshot: G_cur, target: target} EX 300（只 SET 不 INCR）
    (d) 等 A 让位：轮询 hub:lease 为空（A 让位 DEL 或 A 崩 30s TTL 过期；≤40s 超时→告警退出码 3）
    (e) 启动 B：经 quant-svc wrapper start quant-md-hub@quant2
    (f) 等 B 接管：hub:gen > G_cur 且 lease 非空 且 lease 持有者 uuid == HUB_UUID（≤30s 超时→告警退出码 4）
    (g) 数据流证据：读 quant:hb:md-hub 心跳 gen 字段 == G_cur+1（B 真在写，非假接管）
    (h) 收尾：校验 hub:active_instance == target（guarded Lua 接管时已 SET）；DEL intent；审计 audit_log
    (i) 返回：成功打印「切到 target，gen G→G+1」（退出码 0）
T3 A 让位（T2d 窗口）：A 轮询见 intent 存在且 target≠自己 → DEL lease → 退订 → os._exit(0)
T4 次日开盘：B 首根 bar → worker gen_jump → 重暖机（bar 延迟非丢失）
```

## 六、切换目标接管原子 Lua `_lease_acquire_guarded`（正切 B / 反切 A 共用）

guarded Lua 归「切换目标实例」所有（不是「B」），读 intent 得 expected_gen=snapshot+1、target：

```lua
-- KEYS[1]=hub:gen  KEYS[2]=hub:lease  KEYS[3]=hub:active_instance  ARGV[1]=uuid  ARGV[2]=expected_gen  ARGV[3]=target
local g = tonumber(redis.call('GET', KEYS[1]) or '0')
if g == ARGV[2] then
    -- 重启场景：gen 已是 snapshot+1（上次 INCR 过），只抢 lease 不 INCR
    local ok = redis.call('SET', KEYS[2], ARGV[1], 'NX', 'EX', 30)
    if not ok then return -2 end
    redis.call('SET', KEYS[3], ARGV[3])   -- 现任=target（接管即现任，原子绑定）
    return ARGV[2]
elseif g == ARGV[2] - 1 then
    -- 首接场景：gen 还是 snapshot，INCR + 抢 lease + SET 现任（原子绑定）
    local ok = redis.call('SET', KEYS[2], ARGV[1], 'NX', 'EX', 30)
    if not ok then return -2 end
    redis.call('INCR', KEYS[1])
    redis.call('SET', KEYS[3], ARGV[3])
    return ARGV[2]
else
    return -1   -- gen 既非 snapshot 也非 snapshot+1（被污染）→ 拒接管，零污染
end
```

**关键**：校验在 INCR 前，失败零污染；gen 推进+抢 lease+SET 现任三者原子。guarded Lua 只用于「intent.target==自己」的切换目标（正切 B/反切 A 对称）；**非切换窗冷启**（intent 不存在）走 normal `_lease_acquire`（无条件 INCR）。

**反切**：confirm SET intent={target:"quant"} → B 让位 exit(0) → A boot 读 target==自己 → guarded Lua（expected_gen=snapshot+1，SET active_instance=quant）→ 收尾校验 active_instance==quant。与正切完全对称。

## 七、关键不变式（v13 铁律）

1. **gen 单调**：推进 = guarded 首接 INCR / 冷重启 normal INCR。无 DECR。B 重启（intent 存在时）走 guarded「只抢 lease」分支不 INCR；**intent 过期后冷启走 normal INCR=冗余代，worker 重暖机兜（无害）**。
2. **切换意图 = {快照 G, 目标实例}**；guarded 的 expected_gen = intent.snapshot + 1。**target 建模切换方向**，boot 闸据此放行目标/拦截被切走者。
3. **切换目标接管校验在 INCR 前**（guarded Lua g==ARGV[2]-1 分支），失败零污染。
4. **A 让位靠 intent 存在且 target≠自己**（T2 不 INCR）；让位 = DEL lease → exit(0)。
5. **active_instance 重启仲裁**：现任唯一标记，boot 读它 ≠ 自己 exit(6)。**guarded Lua 接管即 SET active_instance=target（原子绑定，不依赖 switch.py 收尾）**；反切同理 SET 回 quant。
6. **boot 单判定插在 `_lease_boot` 之前**（load-bearing）；dispatch：target==自己→guarded，无 intent→normal。
7. **exit 码**：0 优雅让位 / 3 真让位 / 6 闸拦截 / 78 EX_CONFIG，全进 RestartPreventExitStatus。
8. **worker fencing 基于消息**（stale_gen + (symbol,ts) 去重）；warmup 无 gen 过滤。
9. **单租约防双活** + 收尾校验 lease 持有者 uuid == HUB_UUID（正切）/ 反切用 active_instance==target 校验。
10. **confirm setsid 绝缘 + 幂等可重跑 + target 校验 fail-fast**。
11. **类型契约**：gen/intent.snapshot/心跳 gen 比较两侧强制 int()。

## 八、崩溃恢复判定表（gen 单点推进，intent=快照 G）

> 表按**正切方向**（现任=quant，继任=quant2，intent.target=quant2）列写；**反切镜像**（A/B 互换，target=quant）对称适用。「目标」=intent.target 实例。

| active_instance | intent | hub:gen | hub:lease | 判定 → 动作 |
|---|---|---|---|---|
| quant | 无 | G | A 持有 | 稳态 |
| quant | 无 | G | 无主 | A 崩溃 → 冷重启（normal，INCR G+1） |
| quant | 无 | G+1 | 无主 | A 冷重启后崩 → 再冷重启（normal，INCR G+2，worker 重暖机兜） |
| quant | 有=G | G | A 持有 | confirm 已发、A 未让位 → 等 A 让位（T2d，40s 超时） |
| quant | 有=G | G | 无主 | A 已让位 → 启动 B（T2e） |
| quant | 有=G | G+1 | 目标持有 | 目标已接管 → 收尾（T2h：校验 active_instance=target） |
| quant | 有=G | G+1 | 非目标 | 复活 A 抢回 → 收尾校验告警 + 人工介入 |
| quant | 有=G | G+2 | 目标持有 | 目标重启后（intent 残留、gen 被污染到 G+2）→ guarded 走 else 拒，intent TTL 过期后走 normal 收敛 |
| quant2 | 无 | G+1 | 目标持有 | 收尾完成 → 稳态（目标新写者） |
| quant2 | 无 | G+1 | 无主 | 目标崩溃 → 冷重启目标（normal，INCR G+2，worker 重暖机兜） |

> 「有=G|G+2|*」的收敛：intent EX 300s 过期后，切换目标走 normal（无条件 INCR 继续推进），worker 重暖机 + 盘后回补兜，不要求判定表逐格覆盖 G+2。

## 十、验收判据

1. 原子切：confirm 后 A 让位 + B 接管，不双活。
2. fencing 负例：切后 A 旧 gen 消息被拒（stale_gen）。
3. 原子 Lua 三态：首接（INCR+抢 lease）/重启（只抢 lease）/污染（拒，零污染）——单测注入三态。
4. 重启仲裁：SET active_instance 后服务器重启，A 单元不抢回（active_instance 闸 exit 6）。
5. **反切镜像**：正切→反切→正切往返，active_instance 每次正确翻转（guarded 通用化验证）。
6. 盘中 hub 崩溃重启后运行中 worker history 连续。
7. confirm 返回契约（五退出码 + stdout 四态）+ setsid 绝缘 + 幂等重跑 + target 非法 fail-fast。
8. systemd 单元 diff（INSTANCE_NAME=%i + RestartPreventExitStatus）+ 重暖机 bar 延迟非丢失。
9. 口径 diff：switch.py diff 全量比对 + 超阈值告警。
10. 全量 pytest 绿。

> **行为级验收边界**：判据 1/2/3/4/5/6 依赖 B 账号到位，到位前 mock 绿不可作收官依据。切换次日 9:16 首根 bar 告警列为 B 到位后首个运维项。
