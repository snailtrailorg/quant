# 回测实时可视化设计

## 1. 背景
回测跑时**动态展示过程**（K线追加 + 买卖标记 + 仓位/盈亏曲线 + log + 进度），回测完**结果同布局静态复看**。前端组件复用（实时 SSE 流 / 结果静态 JSON 同渲染逻辑）。

## 2. 架构
- **执行**：Celery 任务（异步，不阻塞 web-api）跑 BacktestEngine
- **推送**：BacktestEngine 每bar回调 -> Celery publish Valkey `backtest:{task_id}` -> web-api SSE `GET /api/backtest/{task_id}/stream` -> 前端 EventSource 订阅
- **缓存**：回测完存 `backtest_tasks` 表（参数快照 + bars + trades + positions + equity + 绩效 JSON）
- **复看**：`GET /api/backtest/{id}` 返回完整数据 -> 同布局静态渲染

## 3. 数据流
1. 前端配参数（策略/标的/日期/资金/周期）-> `POST /api/backtest` -> Celery 任务 + 返回 task_id
2. 前端 `EventSource('/api/backtest/{task_id}/stream')` 订阅 SSE
3. Celery 跑 BacktestEngine，每 bar：
   - 算因子 -> on_bar -> 信号 -> 撮合
   - 回调 `publish` Valkey `{progress, bar, trade, position, equity, log}`
4. web-api SSE 端点 `subscribe` Valkey pub/sub，收到推前端
5. 回测完推最终结果（绩效 + 完整曲线 JSON）+ 存 backtest_tasks
6. 前端动态更新图表 + log，完显示完整报告

## 4. 推送数据格式（每 bar 一帧 SSE）
```json
{
  "progress": {"current": 1234, "total": 3950, "pct": 31.2},
  "bar": {"ts": "2024-03-15", "o": 3.0, "h": 3.05, "l": 2.98, "c": 3.02, "v": 100000},
  "trade": {"action": "BUY", "price": 3.0, "vol": 100},
  "position": {"symbol": "510050", "vol": 100, "avg": 3.0},
  "equity": {"ts": "2024-03-15", "value": 100300, "pnl": 300},
  "log": {"level": "INFO", "msg": "MA5>MA10 金叉买入 @3.0 x100"}
}
```
trade 为 null 表示该 bar 无交易。

## 5. 前端布局（实时 + 结果同组件）
```
┌─ 回测配置 ──────────────────────────────────────────────┐
│ 策略[▾] 标的[510050.SSE] 起[2024-01-01] 止[2024-12-30] │
│ 资金[¥100000] 周期[日线▾]            [开始回测]        │
├─ 进度：[========    ] 80% (3160/3950)  耗时 12s  运行 ─┤
│ [主图] K线 + ▲买/▼卖标记 + MA/BOLL 指标               │
│ [副图1] 仓位数量曲线                                   │
│ [副图2] 净值曲线 + 基准对比 + 回撤区间                 │
├─ 绩效指标 ─────────────────────────────────────────────┤
│ 总收益+53.69% | 夏普1.574 | 最大回撤23.91% | 胜率62%  │
│ α0.426 | β0.403 | 索提诺2.443 | 信息率0.857 | 波动0.328│
├─ 日志窗口 ─────────────────────────────────────────────┤
│ 2024-03-15 INFO MA5>MA10 金叉买入 @3.0 x100            │
│ 2024-03-20 WARN 资金不足，调整数量 100->80            │
└────────────────────────────────────────────────────────┘
```
- **主图**：KLineCharts（`applyNewData` 静态完整 / 逐 bar 追加实时）+ 买卖标记 overlay
- **副图1/2**：ECharts（`setOption` 追加数据点实时 / 完整数据结果）
- **绩效表**：实时动态更新（累计重算）/ 结果最终值
- **日志**：实时追加滚动 / 结果完整加载
- **进度条**：el-progress（实时）

## 6. BacktestEngine 改造
- 加 `on_bar_callback(hook)` 参数，每 bar 调 `hook(progress, bar, trade, position, equity, log)`
- Celery 任务传 `hook=publish_valkey`
- 引擎纯逻辑不变，回调推送是外部 hook

## 7. backtest_tasks 表（migration 0010）
| 字段 | 说明 |
|---|---|
| id | PK |
| strategy_config_id | 策略 |
| params_json | 参数快照（标的/日期/资金/周期/因子配置）|
| bars_json | K 线序列 |
| trades_json | 成交记录 |
| positions_json | 每日持仓快照 |
| equity_json | 净值曲线 + 基准 |
| metrics_json | 绩效指标（总收益/夏普/回撤/胜率/α/β/索提诺/信息率/波动率）|
| logs_json | 回测日志 |
| status | running/done/error |
| created_at | |

结果缓存，历史复看不重跑。

## 8. 端点
| 端点 | 说明 |
|---|---|
| `POST /api/backtest` | 启动回测（body: 策略/标的/日期/资金/周期）-> `{task_id}` |
| `GET /api/backtest/{task_id}/stream` | SSE 实时推送（EventSource 订阅）|
| `GET /api/backtest/{id}` | 结果完整 JSON（历史复看）|
| `GET /api/backtest` | 列历史回测 |

## 9. 两种数据模式（同组件）
| 模式 | 数据来源 | 触发 |
|---|---|---|
| 实时（跑时）| SSE 推流（每 bar 帧）| 点"开始回测" -> EventSource |
| 结果（完/历史）| `GET /api/backtest/{id}` 完整 JSON | 回测完自动切 / 点历史 |

前端 `BacktestView.vue` 接收"数据帧"（实时追加 or 静态批量），同一渲染逻辑。

## 10. 绩效指标（BacktestResult 扩展）
现有：净值/胜率/回撤/夏普。补：α/β/索提诺/信息率/波动率/基准收益（参考 PTrade 采纳清单 + strategy-framework-architecture 记忆）。
