# 因子到实盘 · 操作指导书（索引）

> 面向使用者的操作手册：定义因子 → 编写策略 → 回测 → 测试 → 实盘 五环节。
> 技术文档在 `docs/architecture/`；本册只讲"怎么操作"。
> 面向 Web 内置帮助页同步提供（`/help`）。

## 链条总览

```
① 定义因子 ──→ ② 编写策略 ──→ ③ 回测 ──→ ④ 测试 ──→ ⑤ 实盘
 Factors 页      Strategy 页     Backtest 页   校验/试算    LiveTask 页
 (Monaco+试算)   (DSL/Python)   (组模式)      (预检)      (三级开关)
      ↑                ↑            │                        │
      └── 被引用计数 ←──┘            └── backtest_verified ───┘ (三级开关第三级)
```

## 快速开始（10 分钟走通）

1. **建因子**：管理 → 因子 → 新建 → 写 `compute(ctx)` → 「校验代码」→ 「试算」看曲线 → 保存
2. **建策略**：管理 → 策略 → 新建 → 选模式（DSL 或 Python）→ DSL 则选因子+权重+参数+阈值 → 保存
3. **回测**：回测 → 新建 → 选策略+标的+日期 → 运行 → 看详情四卡/净值 → 「标记回测验证」
4. **实盘**：实盘任务 → 新建（只列已验证策略）→ 选标的（搜索）+账户 → start
5. **监控**：管理 → 健康检查（组件矩阵+事件流）；Risk 页看三级开关

## 全链错误码速查

| CODE | 含义 | 处置 |
|---|---|---|
| FACTOR_INCOMPATIBLE | 因子与策略品类不兼容 | 换品类兼容因子或改策略 type |
| FACTOR_NOT_FOUND | 因子不存在或非自定义 | 检查拼写；预置因子不可删改 |
| FACTOR_IN_USE | 因子被策略引用 | 先在策略中移除再删 |
| STRATEGY_NOT_VERIFIED | 未通过回测验证 | 先走回测+标记验证 |
| STRATEGY_NO_SYMBOL | 策略未绑定标的 | 编辑页设 symbol |
| NO_DONE_BACKTEST | 无已完成回测 | 至少一次 done 回测 |
| LIVE_TASK_RUNNING | 任务运行中 | 先 stop |
| MISSING_FIELDS | 必填缺失 | 补全表单 |
