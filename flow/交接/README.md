# flow/交接 · 跨会话 / 跨 agent 交接件

> **性质**：**重写制**（非追加制）——每次交接**重写**。与 `flow/进展/`（**追加制**历史流）职责不同：
> 前者是「当前快照」，后者是「历史流水」。两类生命周期混在一处会互污，故分目录。
> **职责**：给「没有上一轮对话记忆」的 agent / 人一份**一页纸冷启动**：当前进行中批次在哪、下一步做什么、命令、坑、真源索引。
> **🔴 铁律**：只写**指针 + 增量**，**不复述状态**——状态真源仍是 `flow/待办.md` / `flow/任务/` / `flow/进展.md`。
> **本件与真源冲突时，真源胜**。违反此条 ⇒ 制造第二真源（必然漂移）。
> **淘汰**：所涉批次上产（步 7）后删除，或移 `docs/obsolete/`。
