## 接口契约

**迁移 0135 DDL**（expand-only）：

```sql
CREATE TABLE proxy_config (
    name       TEXT PRIMARY KEY,        -- 人类可读标识，如 'aws-tokyo'
    url        TEXT NOT NULL,           -- DSN：{socks5h|socks5|http|https}://[user:pass@]host:port
    notes      TEXT,
    enabled    BOOLEAN NOT NULL DEFAULT true,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE TABLE proxy_binding (
    consumer          TEXT PRIMARY KEY,   -- provider 名（'binance'/'okx'/'tushare'…）或通道名（'binance_perp'/'okx_perp'…）
    proxy_enabled     BOOLEAN NOT NULL DEFAULT false,
    proxy_name        TEXT REFERENCES proxy_config(name),
    endpoint_override TEXT,                -- NULL＝用代码缺省
    updated_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT ck_proxy_binding_name CHECK (NOT proxy_enabled OR proxy_name IS NOT NULL)
);
```

**接线（三层分工——本批的关键形状，**解析不在 adapter 里**）**：

```python
# ① 层 2（engine）：解析一次 + 注入。理由见设计 §3.4
def _apply_exit_config(adapter):
    if not getattr(adapter, "supports_exit_config", False):
        return adapter                      # SDK 型不触库（test_engine_provider 零 DB 的保证）
    try:
        adapter.configure_exit(proxy=proxy_store.resolve_proxy(adapter.provider),
                               endpoint=proxy_store.resolve_endpoint(adapter.provider))
    except Exception as e:                  # 配置读不到 ⇒ 回落直连 + WARNING（口径同 _routing_pilot_on）
        logger.warning("provider=%s 出口配置解析失败，本次回落直连（代理不生效）: %s: %s",
                       adapter.provider, type(e).__name__, e)
    return adapter

# 两处工厂出口统一 `return _apply_exit_config(adapter)`（_get_kline_adapter / _get_supply_adapter）

# ② 基类（base.py）：能力位 + 注入接口。**不触库**
class BaseDataAdapter:
    supports_exit_config: bool = False      # 只有自己发 HTTP 的 adapter 置 True
    def configure_exit(self, proxy=None, endpoint=None) -> None:
        if proxy and not self.supports_exit_config:
            raise UnsupportedFeature(...)   # 响亮拒绝，不静默绕过
        self._proxy, self._endpoint = proxy, endpoint
    def exit_config(self) -> tuple[str | None, str | None]:   # 只读注入结果
        return (getattr(self, "_proxy", None), getattr(self, "_endpoint", None))

# ③ adapter：`_exit()` → (proxy, endpoint or 代码缺省基址)
#    BinanceAdapter.supports_exit_config = True；`_get` 由 urllib → requests.get(proxies=_proxies(proxy))
```
