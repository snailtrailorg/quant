## 目标

一句话：给同步链路加一个**可运维的代理出口**——DB 里管一张全局代理池 + 一条按消费方的绑定，

## 接口契约

**迁移 0135 DDL**（expand-only）：

```sql
CREATE TABLE proxy_config (
    name       TEXT PRIMARY KEY,        -- 人类可读标识，如 'aws-tokyo'
    url        TEXT NOT NULL,           -- DSN：{socks5h|socks5|http|https}://[user:pass@]host:port
    notes      TEXT,
    enabled    BOOLEAN NOT NULL DEFAULT true,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE TABLE proxy_binding (
    consumer          TEXT PRIMARY KEY,   -- provider 名（'binance'/'okx'/'tushare'…）或通道名（'binance_perp'/'okx_perp'…）
    proxy_enabled     BOOLEAN NOT NULL DEFAULT false,
    proxy_name        TEXT REFERENCES proxy_config(name),
    endpoint_override TEXT,                -- NULL＝用代码缺省
    updated_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT ck_proxy_binding_name CHECK (NOT proxy_enabled OR proxy_name IS NOT NULL)
);
```
