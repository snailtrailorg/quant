**闸门反向自证（必做，防「闸门恒真」）**——把 `.lock` 里的 `pysocks==` 行抽掉后，闸门必须报缺：

```bash
cd server && venv/bin/python -c "
import sys; sys.path.insert(0,'.')
from tests.test_requirements_lock_consistency import missing_from_lock, REQ_TXT, REQ_LOCK
lock = REQ_LOCK.read_text()
broken = '\n'.join(l for l in lock.splitlines() if not l.startswith('pysocks=='))
print(sorted(missing_from_lock(REQ_TXT.read_text(), broken)))"
# → ['pysocks']（非空 = 闸门有效；若恒空 = 闸门写歪）
```

实测（2026-10-06）：① 未破坏 → `[]`；② 抽掉 pysocks pin → `['pysocks']`；
③ `.txt` 新增 `some-new-dep` 而 lock 未动 → `['some-new-dep']`。
