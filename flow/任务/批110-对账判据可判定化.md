## 目标

一句话：让母设计 §八.5 的门控判据**可自动判定**，并补齐它赖以成立的前提（inception 单一真源）。

**成功的样子（三条并列，缺一即不算成功）**：
1. `data_gap_reconcile` 每轮在 journal 落结构化摘要（含**轮次 id**、连续命中分布、误报证据计数、
   SM 覆盖率、N），判据可**由该摘要自动判定**；
2. 该机制的成本**由 scope 数决定、不由数据量决定**——「真批量」而非改措辞（见产出 D）；
3. 「哪些 scope 的 inception 真值可读／不可读」是**显式声明**，并被 CI 闸与真实可及性**互证**。

**本批不删冻结**（R0，含结构性理由）；**删冻结**拆为后续批且按族分治。

## 产出

**A. inception 收编（裁定 G① 收尾——判据成立的前提）**

- `security_master.py` 新增**模块级** accessor（与 `get_market_hours()` 同制）：`def sm_inception(vt_symbol: str) -> str | None`
  ——返回 `YYYY-MM-DD` 或 **`None`＝显式未知**；**不设回退**（`_get_list_date` 的 `_TUSHARE_MIN_DATE` 回退把
  「未知」伪装成 `2010-01-01`，与本门语义冲突；该函数归挂账 G-3，本批不动）。
- `engine._window_floors`（`:1089`）与 `engine._reconcile_symbols`（`:1835`）改为读该 accessor。
- **SM 缺失两类必须分开登记**（不得合并、不得沉默降级）：
  - 「SM **有**该 symbol 但 `list_date` 为空」＝显式未知 ⇒ `uncertain(inception_unknown)`；
  - 「SM **无**该 symbol」＝**快照不完整** ⇒ **响亮告警**（新 alert code 入 RUNBOOK）＋ 该轮摘要计数。
- **SM 覆盖率进每轮摘要**：`sm_covered/sm_total`（按 scope）；覆盖率 < 1 时该 scope 的**判据不许过门**。
- **显式声明不可得**：新增并列常量 `_RECONCILE_UNKNOWN_INCEPTION: frozenset[str]`（当前＝4 个
  `binance_perp_*` scope）——**声明面显式化**；并把「该 scope 的覆盖只能靠冻结」变成**可断言事实**（CI 闸）。
- **互证闸**：`_RECONCILE_UNKNOWN_INCEPTION` 的成员必须**恰好**等于「按 `sm_inception` 实测恒 `None`」的 scope 集
  （比对对象＝`sm_inception`，**不是** adapter）。

**B. 判据可判定化（R1/R2/R3）**

- 迁移 `0141`：`sync_gap` 增三列（expand-only，`ADD COLUMN IF NOT EXISTS`，接往返用例）：
  `hit_rounds int NOT NULL DEFAULT 0`（连续命中轮次）＋ `false_rounds int NOT NULL DEFAULT 0`（误报证据累计）
  ＋ `last_hit_round bigint NOT NULL DEFAULT 0`（**最后一次命中的轮次 id**）。
- **轮次身份**：每轮生成单调 `round_id`（＝本轮开始时刻的 Unix 秒；单调、无需额外持久状态）。
  `_sync_gap_sync` / `_gap_judge` 均接收本轮 `round_id`。
  > **为什么必须有它（E2）**：若某轮该 scope **未跑**（skip／error／引擎异常早退），旧行 `hit_rounds`
  > **既不增也不归零** ⇒ 判据会把**中断的观测**当作**连续命中**，「连续 N 轮」退化为「累计 N 轮」。
- `_sync_gap_sync` 维护语义：新开/reopen ⇒ `hit_rounds=1` 且 `last_hit_round=round_id`；本轮对齐 ⇒
  `hit_rounds += 1` 且 `last_hit_round=round_id`；`closed` ⇒ **保留** `hit_rounds`/`last_hit_round` 供判据读史。
- **判定式**：`hit_rounds >= N` **且** `last_hit_round == 本轮 round_id`。
- 新增纯函数 `_gap_judge(stats, scope_rows, round_id) -> dict`：算本轮**误报证据**（下 R2 两类）＋连续命中分布。
- 常量 `_GAP_JUDGE_ROUNDS`（N，R3 定值）。**落点＝代码常量**（§三判据「同类任务共享 ⇒ 代码按 kind 给默认」；
  母设计 §四 DB 承载物清单不含任何判据阈值）——**但必须进可观测摘要**（N7）。

**C. 可观测面**

- `_reconcile_symbols` 每 scope 落**一行** `logger.info` 结构化摘要：
  `sync_id round_id= symbols= uncertain= hit_ge_N= opened= closed= repulled= errors= false_= unknown_inception= sm_covered=/sm_total= budget_exceeded= N=`
- 每轮末尾一行**总计**（同样进 celery result/journal）。
- 取数配方写进 RUNBOOK `sync.gap`（`quant-journal -u quant-celery-worker@quant --since … | grep gap_reconcile`）。

**D. 读取规模契约（P1-γ + 事实 1/14）**

- **真批量**：`_reconcile_symbols` 的**读侧探针与状态同步侧一并按 scope 批量**——
  按 scope **一次**取本地日期集（`GROUP BY symbol`）、**一次**取 live 行、**一次**取 repullable。
  **成本由 scope 数决定**（陈述与验收均**不含** O(标的数)；`_sync_gap_sync` 的**状态同步**亦须批量化，
  否则「O(scope)」仍为假陈述）。实测支撑：dev `bar_1d`（17.5M 行/9088 标的）逐标的 `_local_dates` **4.88 ms/次**
  （折算 9088 标的 ≈ 44 s，仅此一步）vs 批量 `GROUP BY symbol` 一次 **0.47 s** ≈ **94×**。
- **体量上界 + 超阈响亮拒绝**（N6）：新增常量 `_GAP_ROW_BUDGET`（单轮某 scope 的扫描/落表行数上界）；
  超阈 ⇒ **不落该 scope 的缺口主张** ＋ 告警 ＋ 摘要标 `budget_exceeded=1`（**禁**静默截断）。
  `astock_minute`/`astock_minute_5min` 一旦启用，`bar_1min` 每标行数远大于日线 ⇒ **「启用前先评估对账体量」
  列为前置条件**（否则启用当日即触发不可控长轮＋落表膨胀）。
- `data_gap_reconcile` **显式声明** `soft_time_limit`/`time_limit`（**消除隐式继承全局 300 的沉默态**）；
  初值取仓内重任务同制 `soft_time_limit=1800, time_limit=1980`，**集成首轮实测后校准**（值挂实测，R7）。
- per-symbol `except` **收窄**：`SoftTimeLimitExceeded` **直抛**（不再被记为某标的的 error）。
- **超时语义入契约**（N8）：软时限直抛 ⇒ **中止整轮**（**失去** per-symbol 隔离）；契约＝「**整轮放弃、幂等、下轮续**」——
  防后人误以为单标的隔离仍在。

**E. 单测**：`tests/test_batch110_gap_judge.py`（判据/计数/误报 P-1/P-3/inception 收编/未知声明闸/SM 缺两类分开）；
`tests/test_batch110_reconcile_scale.py`（批量读取等价性 + 往返次数上界 ＋ 软时限直抛 ＋ 体量超阈拒绝）。
