## 产出

`ConnectionCards.vue:24-32` task 卡片加「历史」入口（`el-link`，点击 → 跳转该任务 `LiveTask` 展开行冻结史落点）。跨页跳转契约（已写死）：

- **入口**：task 卡片 `goHistory(tid)` → `router.push({ name: 'live-task', query: { freeze: tid } })`（`tid`＝`snap.tasks` 对象键，字符串）。
- **落点**：`LiveTask.vue` `onMounted` 读 `route.query.freeze` → `load()` 后 `nextTick` → `tasks.find(x => String(x.id) === String(freeze))` → 受控展开 `expanded.value = [row.id]`，且 `row._freeze === undefined` 时 `loadFreeze(row.id)`。
- **受控展开**（Pool.vue 同款）：`TableShell` 加 `:row-key="r => r.id"` + `:expand-row-keys="expanded"`；`onExpand` 回写 `expanded`（数组重载 `map(r => r.id)`／boolean 重载 `[row.id]`）。
- **数据**：复用 `getFreezeEvents`（`GET /api/live-task/{tid}/freeze-events`），零新增端点。
- **词条**：`sysmon.history`（zh「历史」/ en「History」）。
