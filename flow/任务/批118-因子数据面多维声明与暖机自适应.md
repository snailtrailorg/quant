## 产出

1. **needs 数据结构（词表单源）**：`needs: dict[str, int]`，键**必须 ∈ `DATA_KINDS`**（`contract.py` 唯一词表——禁 `bar_1d`（表名）/`static`（自造词））；L2 键（`depth`/`stream_tick`）语法合法但运行时占位拒启。`needs_history: int` 糖＝`needs={"bar_minute": N}`，**装饰器与 DB load 双侧统一**（load 时 int 列自动升格 dict）。
2. **持久化闭环**：迁移 `factor_def` 加 `needs` JSONB 列（nullable；NULL≡旧 int 糖映射）；`register_factor`/`upsert_factor`（`:241`）/`load_factors_from_db`（`:195`）三处读写闭环；Web 因子声明面（`routes/strategy.py:244`）接受并回显 needs——**消「重启静默降级单频」**。
3. **暖机自适应**：4 处常量收单一真源模块常量 `WARMUP_BASELINE=100`/`WARMUP_CAP`（裁定：cap 提至 5000，`bar_minute` 声明 >cap ⇒ EX_CONFIG 拒启且报上限——不静默截）；`_warmup_history(n)` 由 needs 聚合（`max(100, needs["bar_minute"])`）传入。
4. **判定语义三分支（钉死）**：
   - kind ∉ `DATA_KINDS` 或 ∈ L2 占位集 ⇒ **EX_CONFIG 拒启**（拼错键同此——消静默不供给）；
   - kind 合法但供给不足 ⇒ `security_master.list_date` 判界：**上市 ≥ 声明窗而数据缺 ⇒ degraded + 告警**（瞬态，同步层追）；**上市 < 声明窗（标的太新）⇒ 拒启**（真不可满足）；**list_date 无档 ⇒ 归分支② degraded**（SM 未回填≠标的太新——对齐「判定层不依赖数据模块生命周期」立法）；
   - **rewarm 后窗口缩至 < 声明窗 ⇒ 视同分支②**（degraded 瞬态——流回放窗有限是常态，不升级为拒启）；
   - 暖机读库失败 ⇒ 维持 fail-open + 告警（现状 #7，D27 边界不动）。

**明确不做（批 119）**：`BarContext` 扩展（`daily_history`/`static`/`degraded` 字段）、`bar_daily`/静态暖机新管道、回测一致钉（回测只喂日线的口径限制下 minute 钉不可执行）。

## 接口契约

- 改：`register_factor(name, *, needs: dict[str, int] | None = None, needs_history: int = 0, ...)`——两参并存，装饰器内合并（显式 needs 优先）。
