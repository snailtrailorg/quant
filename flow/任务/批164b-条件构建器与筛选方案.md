> 方案真源：`flow/方案/标的筛选多因子化方案.md` v3（含本批设计八项补审处置）。本文件=实施规格。
> 前置：164a 已提交（注册表六元组+缓存表+周期谱系）——本批消费其 FIELDS 与 ASSET_CATEGORIES。

## 实施步骤
1. **迁移 0166 screen_preset**：`id BIGSERIAL PK/name TEXT/category TEXT CHECK(category IN ASSET_CATEGORIES)/source TEXT CHECK(source IN ('builder','dsl','builtin'))/definition JSONB NOT NULL/created_by INT REFERENCES users(id)/updated_at`；索引 (category, name) 唯一。builtin 预置种子 3 条（A股 双低蓝筹/红利/动量 三模板——definition 仅 builder 式）
2. **后端 preset CRUD**（`web_api/routes/screen.py` 新文件）：
   - GET `/api/screen/presets?category=stock`（read 键）——列表含 builtin；definition 读侧宽容解析（死字段行跳过+响应 `skipped_fields` 标注——方案 v3 P1-2）
   - POST/PATCH/DELETE（**写面专键 `screen_preset`**——alerts_config 先例：组层单锁；admin 地板含全部；**builtin 一律 403 SCREEN_PRESET_BUILTIN**；非 admin 仅本人 created_by）
   - 错误码：SCREEN_PRESET_BUILTIN/SCREEN_PRESET_NOT_YOURS/SCREEN_PRESET_DUP
3. **条件编译器**（`data_platform/screen.py` 扩——注册表同文件，编译逻辑 `compile_conditions(category, definition) -> (sql_where, params, nulls_excluded)`）：
   - definition={v:1, match:'all'|'any', rows:[{field,op,value}]}（**无行内 logic**——P0-1）
   - op 白名单映射 SQL：`=`/`!=`/`>`/`>=`/`<`/`<=`（数值）；`percentile_top`/`percentile_bottom`（`value∈[0,100]`——用窗口函数 percentile_cont 或预计算分位）；错配 400 SCREEN_FIELD_TYPE_MISMATCH
   - **op×类型矩阵**（P0-2）：num=全部比较 op；bool=仅 `=`（true/false）；错配 400。value 契约：数值收 float（`in` op 期2 不做——降复杂度）；非法 422
   - **NULL 立法**：比较 op 加 `AND <expr> IS NOT NULL`（NULL 行剔除）；响应附 `nulls_excluded` 计数
   - 全程参数化（值绑定）；field/op 走注册表白名单（F5 集合）——注入面=零拼接
   - 端点：POST `/api/screen/run`（body: {category, definition, limit}——读键）替代三端点硬编码参数（旧三 GET 端点保留兼容一发布周期）
4. **前端**（AScreen/CBScreen/ListedFundScreen 三屏同构改造）：
   - 左卡上部=**双页签骨架**（普通条件/高级 DSL——高级页签 164b 只放「敬请期待」占位，164c 填充）
   - 条件行组件（`components/ScreenConditionRow.vue` 新）：字段下拉（按注册表分组 optgroup——`GET /api/screen/fields?category=`新只读端点）+op 下拉（按字段类型出）+数值输入+行删除钮；「+ 添加条件」钮；match 切换（满足全部/满足任一 radio）
   - 下部=**方案列表**（ContentCard）：列表（名称/来源 tag/更新时间）+加载/删除；「另存为」弹窗（名称输入）——builtin 行无删钮
   - nullable=true 且库全 NULL 的字段在下拉中**置灰**（`GET fields` 响应含 `dead:true` 标注——后端查 NULL 率? 期2 简化：注册表静态 nullable+fund 屏标注数据链未通）
