# 批 171a · D2 窗口化状态迁移（阶段③-1 迷你设计 / 任务规格）

> **依据**（引用 ≤2）：`docs/design/D29-同步机制事实清单.md` §五、`docs/design/D30-同步缺陷账本.md` DEF-02。
> **性质**：阶段③逐条迷你设计第 1 条（先 D2「不遗忘」→ 后 D1「不越界」）。**只改 1 个文件、1 个函数**；默认行为不变；独立评审、独立上产。
> **基线**：`68980ad`。淘汰：本批上产后归档 `docs/obsolete/任务归档/`。

## 0. 契约（一句话）

`_sync_gap_sync` 的状态迁移全部按**本轮窗口** `win_map[sym]=(lo,hi)` 夹取：**窗口外的既有行一律不改写**（不 closed / 不 touch / 不转 uncertain / 不对齐），窗口内语义逐字不变；窗口内新锚若落在窗口外既有行区间内，则不新开锚、改为扩展该行 `gap_end`。

## 1. 现状（指针，不复述事实）

- `_sync_gap_sync`（`engine.py:1955`）已接收 `win_map`，并已算好 `lo/hi`（2019-2021，`_anchor` 归一）——**但 `lo/hi` 只被 `unc_i`（uncertain 插入）消费**；closed（2062/2072-2073）、align（2066-2071）、touch（2052-2059）、uncertain_u（2025-2045）均不看窗口。
- 后果（DEF-02）：per-date 对账窗口＝本轮同步窗口（如 10-15 单日），10-14 的 `open` 锚落在窗口外 ⇒ 被无条件 `closed`。
- `prev_map` 行结构（`_sync_gap_scope_rows` 1909-1912）：`r[0]=gap_start, r[1]=gap_end, r[2]=state`，日期已归一。

## 2. 改动规则（单函数，表格即全部逻辑）

前置：`in_win(a) := (not lo) or (lo <= a <= hi)`（`lo/hi` 已是归一形态）；`live` 切 `live_in` / `live_out`。

| # | 分支 | 现行为 | 改后 |
|---|---|---|---|
| R1 | `ureason` 非空 | 全部 `live` 转 uncertain | 仅 `live_in` 转；`live_out` 不动；`unc_i`（lo/hi 插入）不变 |
| R2 | `gaps_map=None` / `sym` 不在 / `gm=None` | 全部 `live` touch | 仅 `live_in` touch |
| R3 | align（`a ∈ current`） | 全部 `live` | 仅 `live_in`；`live_out` 命中改走 R6 |
| R4 | **closed（`a ∉ current`）** | 全部 `live` | **仅 `live_in` 且 `in_win(a)` 才 closed**；`live_out` **零写入** |
| R5 | ins / reopen（`current` 新锚） | 按 `by_anchor` 判 | 先剔除落在 `live_out` 行 `[gap_start, gap_end]` 内的锚 → 改走 R6；其余不变 |
| R6 | 跨窗口重叠（新增） | 无 | `align_cross` 批次：`UPDATE SET gap_end=GREATEST(gap_end, 现算 end) WHERE gap_start=窗口外行锚`；**不刷** `last_seen/hit_rounds/pull_count`（保重拉资格、不污染判据） |
| R7 | `pull` 计数 | 不变 | 不变 |

**为什么 R6 不刷 `last_seen`**：`_list_repullable`（2311-2320）要求 `last_seen >= 1 天`；窗口外行若每轮被刷新会永远选不中重拉。本批只「保住不遗忘」，不破坏既有重拉资格。

## 3. 契约细节（自包含）

- **签名零变化**：`_sync_gap_sync(sync_id, *, symbols, win_map, round_id=None, gaps_map=None, uncertain_map=None, pulled_map=None, prev_map=None) -> dict`；返回统计字典键不变（`opened/reopened/updated/closed/uncertain/new/closed_anchors/uncertain_anchors`）。
- **不新增参数、不新增表/列/状态词、不改任何调用方**。
- `align_cross` 用现有 `cur.executemany` 批次风格，夹在 `align` 之后、`clo` 之前；统计计入 `updated`（`closed_anchors` 不记）。
- **影响面**：
  - per-date（`_sync_gap_sync_one` 2141，win=本轮同步窗口）＝**唯一受益路径**；
  - per-symbol（`_reconcile_symbols` 2390，win=`[floor, end]` 全史）⇒ 所有锚均 `in_win` ⇒ **行为逐字不变**；
  - 单测封装 `_vsync`（`tests/test_batch109_sync_gap.py:80`，win=10-01~10-10，锚 10-02~10-06）⇒ 全在窗口内 ⇒ **既有断言不变**。

## 5. 验收（可证伪，dev 真库）

1. **主判据（10-14 不再被遗忘）**：造 `listed_fund_daily` 在 2026-10-14 的 `open` 行 → 以 `win_lo=win_hi=2026-10-15`、`gaps=[]` 调 `_sync_gap_sync_one` ⇒ 该行仍 `open`、`last_seen` 未变、`stats["closed"]==0`、`closed_anchors==[]`。
2. **窗口内语义不变**：同上行改 `win_lo=2026-10-14`、`win_hi=2026-10-15`、`gaps=[]` ⇒ 行 `closed`（证明不是「一律不关」）。
3. **既有测试零修改全绿**：`tests/test_batch109_sync_gap.py`（含 `test_open_then_close` / `test_partial_fill_yields_new_anchor_no_ghost` / `test_closed_reappear_is_new_event`）、`tests/test_batch110_reconcile_scale.py`、`tests/test_layering.py`。
4. **跨窗口不造重复行**：造窗口外行 `(10-10, 10-20)`，以 win=`[10-15,10-15]`、`gaps=[(10-15,10-15)]` 调用 ⇒ `sync_gap` 行数不变、原行 `gap_end` 保持 10-20、`opened==0`。
5. **uncertain / touch 同样夹取**：造窗口外 `open` 行 + `uncertain_reason` ⇒ 窗口外行状态不变；`gaps_map=None` ⇒ 窗口外行 `last_seen` 不变。
6. **统计自证**：新逻辑前后，对同一组窗口内 fixture 的 `stats` 各键相等（除 `closed` 在「窗口外失配」用例由 1→0）。

## 6. 明确不做（本批边界）

- **不修窗口外的 `open` 行**（只保住、不补数据）——修复出口属后续条（全史回补任务），本批验收只断言「行仍在、状态未变」，**不断言数据落库**。
- 不改 `win_map` 的定义或窗口值；不动 `retention_days` / 停牌 / 预算。
- 不改 `_gap_judge` 统计口径（per-date `round_id=None` 不参与判据；per-symbol 窗口为全史 ⇒ 本批对判据零影响）。
- 不引入新的状态词、表、模块、锁、调度档。
