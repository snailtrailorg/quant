## 0. 契约（一句话）

新增**停牌登记表 `suspend_calendar`**（tushare `suspend_d` 每交易日增量落库，`(ts_code, trade_date)` 幂等 upsert，**kind=`suspend`〔DataKind 词表既有词，非 `suspend_d`〕**）＋**净化口 `suspended_on(day, vt_symbols) -> set`**（**仅 `suspend_type='S' AND full_day`** 的全日停牌行，`to_vt_symbol` 归一后返回）：integrity 面板按标的减停牌日/截退市日；per-symbol 对账差集过滤；**per-date 族与 suspend_d_sync 自身对账豁免**（稀疏事件表不做日期级差集——零停牌日会产假缺口）。

**v1→v2 关键裁定**：① 稀疏事件表 ≠ 按日快照表——suspend_d_sync **跳过 per-date 对账**（工厂加 `reconcile=False` 开关），不入 `_CAP_EMIT_IDS`（与 forecast/top_list 同判别：事件驱动稀疏）；② R（复牌）行当日**实有 bar**（dev 实证 002860/002813 各 1 根）——净化只认 S 行；③ adapter 层触面入清单（分派/能力/限速四处注册，v1 漏列）；④ 首跑 retention 显式 seed（否则 floor=2010-01-01 自动全史 ~4000 次调用）。

## 1. 现状（指针，不复述事实）

- **DEF-10**：期望集＝trade_cal 全市场交易日无停牌减项——000002 误记缺 155 日 12 段。
- **词表**：DataKind 有 `suspend`（contract.py:35、KIND_TEMPORALITY:67）——`suspend_d` 不是合法 kind，import 期 `validate_capability_decls` 即炸。

- **迁移 seed 模板**：0142（CREATE TABLE+sync_config+sync_kind_config INSERT ON CONFLICT DO NOTHING+对称 downgrade）；`retention` seed 先例＝`astock_basic`（1990-12-19，迁移 0139）。

- **per-symbol 对账现实**：现产 scope 全 crypto（无停牌概念）+ A 股分钟（禁用）——**净化当下收益面＝integrity 面板**；per-symbol 过滤代码挂上为未来 A 股日线 scope 扩容预置（死码风险如实声明，验收用 mock）。

## 2. 改动规则

### A. 表 `suspend_calendar`（迁移 0168）

```sql
CREATE TABLE suspend_calendar (
    ts_code     TEXT NOT NULL,
    trade_date  DATE NOT NULL,
    suspend_type TEXT NOT NULL,            -- S=停牌 R=复牌（源语义原样；净化只认 S）
    full_day    BOOLEAN NOT NULL DEFAULT true,
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    PRIMARY KEY (ts_code, trade_date)
);
```
- 幂等 upsert；**updated_at 刷新走 DO UPDATE 尾部**——工厂通用 updates 子句只含 `all_cols−pk`（engine.py:3283），v1 验收 2 原样不可达。修法：**transform 后把 updated_at 排除在 text_cols 外，upsert SQL 由工厂加 `updated_at=now()`**不可行（侵入通用路径）——**采纳 B 建议：表默认 `updated_at=now()` 且验收 2 放宽为「行数不变、值幂等」**（updated_at 只在真值变化时无刷新手段，如实降级为信息列）。
- 注册 `schema_expectations.txt` 一行。

### B. 同步任务 `suspend_d_sync`（kind=`suspend`）

- **adapter 层四处注册**（v1 漏列，P0-1）：① `tushare_adapter.pull_suspend_d(trade_date)`（范式 `pull_stk_limit`:563-566）；② `base._SUPPLY_PULL[("suspend", None)]="pull_suspend_d"`；③ `base.capabilities` 加 `"suspend_d_sync"`；④ `capability_decls` 加 `CapabilityDecl("suspend","historical",ASTOCK_ALL)`；⑤ `markets.SYNC_ID_CAP_MAP["suspend_d_sync"]="inst_event"`；⑥ `data_source.DEFAULT_RATE_LIMITS["suspend_calendar"]=0.3`。
- **工厂消费**：`_make_tier1_handler(kind="suspend", sub_kind=None, table="suspend_calendar", pk_cols=["ts_code","trade_date"], text_cols=["suspend_type","full_day"], date_param="trade_date", transform=lambda df: df.assign(full_day=df["suspend_timing"].isna())[[ "ts_code","trade_date","suspend_type","full_day"]])`。
  - `full_day` 走 text_cols（`str(True)→'True'::boolean` PG 合法——实测）；transform 选取列序＝insert_cols。
  - **transform 泛化边界**：仅做「源列→落库列」的形状适配（布尔派生/列选取），禁业务逻辑；默认 None 零漂移。
- **`reconcile=False` 工厂开关**（P0-1/P1-4 核心）：handler 尾部跳过 `_reconcile_dates`（返回体无 reconcile/gap_dates/cursor_cap 键）——稀疏事件表零行日＝正常态，日期级差集会产 symbol='' 假 open。开关默认 True（既有 9 键逐字现状），suspend_d_sync 唯一传 False。
- **注册路径**：显式 `_HANDLERS["suspend_d_sync"] = ...`（不走 `_TIER1_BATCH` 字典——但**同步改 test_batch100:44 的 len 断言 10→11**，并核 :47 的 `_SUPPLY_PULL_NON_FACTORY` 不需动（我们的键来自工厂项，非 bar_minute 型旁路））。
- **seed（迁移 0168 数据段，0142 模板）**：`sync_config`：id=suspend_d_sync、kind 归置、**retention='2026-10-01'**（P1-3：无 retention 则 floor=2010 全史失控；起步窗一个月，历史回补按 §6 另立）；`sync_kind_config`：`(suspend, None) → suspend_calendar`；enabled=true。
- **调度**：交易日 16:35（`_data_ready_end_date(0)` 上界；上游发布时刻未核实——**依赖 overlap=3 下轮重拉兜底**（批 92 同型机制），§6 声明；不稳可后移 18:10（st_list 先例）——本批先 16:35，观察窗后可调）。

- **消费点 1（integrity 面板，risk.py）**：聚合处一次 `suspend_days_bulk(first_min, last_max, 全部股票前缀标的)` ＋ 一次 SM 批量 `SELECT vt_symbol, delist_date`（v1 漏列的 N+1 修复）；symbol 循环内：`expected_bars(..., suspend_days=per_sym.get(sym))`、`last=min(last, delist) if delist else last`。**减项公式**：`expected -= len([d for d in suspend_days if first<=d<=last]) * bars_per_day(freq)`（v1 漏 ×bpd——1min/5min 须 ×240/48）；**crypto 显式跳过**（is_crypto 不查不减）；外推分支（日历越界段）不减（停牌数据新窗才有，老窗如实多报）。
- **消费点 2（per-symbol 对账）**：`_reconcile_symbols` 差集后过滤 `suspended_on`——**日期形态契约**（P2-4）：expected 是 'YYYYMMDD' 紧凑串、suspend_calendar 是 DATE——过滤口内部统一转 `date.isoformat()` 比对；验收补真库形态断言（mock 测不出）。
- **消费点 3（退市截断）**：`_sm_universe` **不**改 4 元组（A-P1-3：engine.py:2641 解包+两 mock 均 3 元组，改了必炸）——改在调用方 `_reconcile_symbols` 内联二次批量 SELECT delist（一次往返，与 sm_rows 同窗）；risk.py 面板同款独立批量。
- **`data_continuity_check`（tasks.py:554，每小时 :17）**：DEF-10 的**活体受害点**（停牌股近 7 天误报+无效补采）——纳入消费点 4：其 `count(*)<expected` 判定前调 `suspended_on` 过滤当日（文件面 +1，见 §4）。

### D. 净化边界（同 v1，两处收紧）

- 只减期望不删历史；既有误报 open 行下轮对账自然消解。
- 覆盖窗内查不到 ≠ 不停牌——宁多报不漏报，回补后自然净化。
- **R 行永不净化**（当日实有 bar）；**suspend_d 源覆盖**：样本全股票，转债/基金是否有全日停牌行未核实（§6）——若有，净化自动生效（同表同口径），无需改码。

## 5. 验收（可证伪）

1. **落库**：dev 触发 suspend_d_sync 单日 ⇒ 当日行数=API 实测（10-14=13 行，含 2 行 R）；`full_day` 全 true；R/S 型别原样。
2. **幂等（v2 放宽）**：同日连跑 2 次 ⇒ 行数不变、`(ts_code,trade_date,suspend_type,full_day)` 四列值幂等（updated_at 无刷新手段——表默认 now() 信息列，如实降级）。
3. **净化口**：`suspended_on(2026-10-14, {'000016.SZSE','002860.SZSE',...})` ⇒ 含 000016（S）、**不含 002860/002813（R 行永不净化）**；非停牌日 ⇒ 空集；**真库形态断言**（P2-4）：expected 紧凑串与 DATE 的转换在口内闭环。
4. **integrity 减项**：`expected_bars(freq,sym,first,last,open_days, suspend_days=[...])` 直调——1D 减 len(窗内停牌日)、1min 减 ×240；crypto 传 suspend_days 断言不减。
5. **退市截断（v2 换样本）**：`expected_bars` 对 110076.SHSE（20 根/末根 2026-10-27/delist 2026-11-02）传 delist ⇒ last 截 11-02（本例无变化——末根早于 delist）；对面板聚合用 dev 全量跑：**退市转债 missing 数下降**（819 只零窗外 bar 样本被截后转 complete/不进 rows 口径）——以面板 summary 前后差证伪。
6. **per-symbol 净化**：mock `suspended_on` 返回集 ⇒ `_reconcile_symbols` 差集剔除该日（单测）；**真库集成**：dev 对 stock scope 造一停牌日缺行（fixture）⇒ 净化前 gap 含该日、净化后不含。
7. **工厂开关**：suspend_d_sync 返回体**无** reconcile/gap_dates/cursor_cap 键（reconcile=False 生效）；既有 9 个 tier1 键返回体不变（reconcile=True 默认逐字现状）。
8. **回补**：`backfill_from=20261001` dev 真调 ⇒ 10 月窗逐日落库（supports_backfill=true——0142 先例 + TestBackfillCapabilityTruth 钉）。
9. **守门涟漪**：test_batch100 len 断言改 11 后绿；capabilities/kinds/cap_map 三守门绿；**suspend_d_sync 不在 `_CAP_EMIT_IDS`**（test_batch171a:392-397 白名单漂移守门不红即证）。
10. **既有测试零修改（除 §4 声明的 test_batch100 一行）全绿** + 全量 pytest。

## 6. 明确不做（本批边界）

- **不做全史回补**（retention=2026-10-01 起步；历史窗回补另立运维动作）；**不清既有 sync_gap 误报行**；**不动 per-date 族对账**。
- **不做半日停牌**（timing 全 NULL；真出现时 transform 的 full_day 派生自动 false，语义预留已足）。
- **不做 crypto 停牌**（无概念）。
- **suspend_d 源覆盖未核实转债/基金**——若有全日停牌行净化自动生效；若无，转债停牌净化缺席属源覆盖边界（如实声明，非本批缺陷）。
- **上游发布时刻未核实**——16:35 首轮若空拉靠 overlap=3 兜底（批 92 机制）；观察窗确认后可调 18:10。
- **updated_at 无刷新机制**——幂等重跑不刷时间戳（工厂通用路径限制，如实降级为信息列）。
