## 0. 契约（自包含）

- **`_clamp_span(start, end, max_days) -> tuple[str, str, bool]`**（engine.py 新增模块级纯函数）：`(start, effective_end, truncated)`——`effective_end = min(end, start + max_days - 1)`（按日含两端）；`max_days<=0/None ⇒ 不夹取`。入参出参均 YYYYMMDD 串。
- **跨度来源**（每轮一次，挂 cfg）：`_get_config` 读 `max_span_days` 列；NULL ⇒ 读 `system_config.sync_max_span_days`（int，缺省 366）；仍无 ⇒ 366。挂 `cfg["_max_span_days"]`——**禁在 handler 体内直查 system_config**（N+1 面）。
- **clamped 反馈**：handler 返回体新增 `"clamped": {"floor": "YYYYMMDD"|None, "span": true|false}`——floor=有效地板四源中胜出者（仅当**实际夹取了请求起点**时非 None）；span=本轮被跨度截断。透传链（tasks :1353-1361 白名单 int 化 → Valkey progress → sync.py :227-263）零改（字符串/对象透传现状支持）；sync_log note 追加 `clamped=span@20261106` 式短语。
- **next_from**：`truncated=true` 时返回体带 `"next_from": "连续成功末日+1"`（镜像增量三态 G-Q1a :471-474——**非实际终点+1**，防跳中窗失败日；连续成功末日从 failed_dates 推）。
- **FE**：DataManage 触发轮询处展示 clamped 提示（「窗口被跨度截断，下次从 YYYYMMDD」）＋续跑按钮（触发 `backfill_from=next_from`）；不新增页面/路由。
