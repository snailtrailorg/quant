## 0. 契约（自包含）

- **全局键**：`system_config.sync_floor_default`（缺省 **2014-01-01**，用户裁定）——迁移 0171 seed。**用户旋钮**：设置页可改（system_config 既有读写口），格式防呆非门禁（写侧非日期串 400 + 读侧 fail-open 忽略+响亮告警，171d-A `_span_of` 同构纪律）。
- **四源取 max**：`_window_floors` 的 known dict 加第四源 `("floor_default", cfg.get("_floor_default"))`——任务 retention NULL ⇒ 该臂缺席⇒全局顶住；非空 ⇒ 取 max（retention 只抬不降：astock_basic 1990 仍 1990）。**读取点每轮一次挂 cfg**：`_get_config` 加 `cfg["_floor_default"]`（`_span_of` 同位），禁 `_window_floors` 体内查 system_config（crypto per-symbol N+1 面）。
- **policy_discard 预告**（D31 §2）：全局回落生效首轮，NULL retention 且源界<2014 的族批量落 `[源界, 2014)` 排除段+warning——**预期行为**（每族一轮一次幂等），非故障；守门不按失败计。
- **trade_cal 豁免 seed**：0171 同帧 `UPDATE sync_config SET retention='1990-12-19' WHERE id='trade_cal' AND retention IS NULL`——fresh 环境防全局 2014 夹死日历自举（D31 审 B-P1-1）。
- **retention_days × 回补互斥**（DEF-11）：`sync()` 回补分支（`backfill_from` 非空）前置校验——cfg 的 `retention_days` 非 NULL 且 `backfill_from < today - retention_days` ⇒ **拒绝**（`ApiError(400, "SYNC_BACKFILL_RETENTION_CONFLICT", ...)`——回补段落在滚动裁剪窗内，复活已裁数据与 GC 互斥）；NULL=无裁剪不拦。
- **clamped.floor 归因**（171d-A 预留接口兑现）：全局键参与夹取时 `clamped.floor = 实际胜出地板日`（四源 max 值；仅回补轮、仅起点被夹时出具——171d-A 同条件）。实现：六站点已带 `clamped={"floor": None,...}` 占位——改为从 cfg `_floor_effective`（`_window_floors` 已算的 max 值挂 cfg 传递或站点自算）取真值。**最小面**：tier1/via_kind/astock_basic 三站点（有族地板概念）补真值；jq/trade_cal/cb_daily 的 floor 夹取已由 `_family_start` 内联——同源可取。

## 1. 实施步骤

1. 迁移 0171：`system_config` 键行 `sync_floor_default`='2014-01-01' + trade_cal 豁免 seed（条件 UPDATE）。
2. engine `_get_config`：加 `_floor_default` 挂 cfg（`_floor_of(task_ret)`——任务 retention 非空⇒None〔取 max 在 _window_floors 做〕/空⇒全局键 fail-open）。
3. `_window_floors`：known dict 加第四源（`cfg.get("_floor_default")`）——per-symbol 与家族级两条路径同享（`_family_start` 调它，一处改）。
4. `sync()` 回补分支前置 retention_days 互斥校验（DEF-11）。
5. clamped.floor 真值：tier1/via_kind/astock_basic 三站点把占位 None 换 `_floor_eff`（来自 `_family_start`/`_window_floors` 返回的 floor——检查现签名：floor 已返回，站点接线时顺带传）。
6. `SYSTEM_CONFIG_BOUNDS`：`sync_floor_default`（无 int 域——日期串校验走 update 白名单格式检查；BOUNDS 不加条目）。
7. FE 设置页：运行配置 tab 自动渲染新键（system_config 键驱动，零改——核实键 value_type='date' 或 'string' 的展示形态即可）。

## 3. 验收（可证伪）

1. 四源取 max 单测：NULL 任务 retention+全局 2014+源 2010 ⇒ floor=2014；astock_basic（retention 1990）⇒ 1990 不降。
2. dev 真跑：NULL retention 族（如 listed_fund_daily）回补 `backfill_from=20100101` ⇒ 窗口被夹 2014 起+`clamped.floor="20140102"`+policy_discard `[源界,2014)` 登记一条。
