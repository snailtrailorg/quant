## 1. 实施步骤

1. `_DERIVED_CURSOR_IDS` 常量 + `_local_max(sync_id, table, category)` 助手（族谓词 max；tier1 专属表直查；时区锚 Asia/Shanghai）。
2. `_update_sync_state` 写入前：派生族 ⇒ `last_date = min(last_date, _local_max(...))`（None 安全——查询失败 ⇒ 原值+warning 留痕）。
3. `_CAP_EMIT_IDS` 清空（frozenset()——保留变量与消费链，白名单门自然旁路）。
4. sync() 三态消费核：keyed 族 `_raw` 与派生收口的 min 关系（:467 区——`_raw` 已含 cursor_upto 尊重链 171d-A 修，派生 min 再收一层——**只紧不松**，语义自洽声明）。
5. crypto 跨度接入（D31 §1 遗留项顺手——crypto 工厂站点 `_clamp_span` 接线；next_from 不适用〔连续轴〕⇒ 截断只出 clamped.span 无 next_from）。
6. test_batch171a **全文件语义改写**：白名单断言 excluded 集 → `_CAP_EMIT_IDS == frozenset()` + `_DERIVED_CURSOR_IDS == 12 族`双断言；cap 出具/痊愈 DEL/逃逸闸用例 → 改钉「恒 None/零触碰」（反向守门防复活）。
7. 新测试：派生收口行为级（mock _local_max 验 min 收口/查询失败留痕原值/越窗数据不推游标）。

## 3. 验收（可证伪）

1. **派生收口直证**：dev 删 bar_1d 某族末端 3 日 ⇒ 增量轮后 `last_sync_date`＝max(local)（数据末日非 today）⇒ 下轮窗从数据末+1 起（自愈）。
2. **中窗缺口越过后不丢**：dev 造中窗缺 2 日（数据在前后）⇒ 游标在缺口后（max 结构）⇒ sync_gap 落 open 段（批 D 对账主张）⇒ 显式回补差集只拉 2 日。
3. **D1 零触碰**：12 族各跑一轮 ⇒ Valkey `sync:cap_freeze:*` 零新键（journal/caplog 反向钉）。
4. **查询失败留痕**：mock _local_max 抛错 ⇒ 游标原值+warning（fail-open 不阻同步）。
5. **crypto 跨度**：crypto 回补窗>366 ⇒ clamped.span=true（无 next_from——连续轴声明）。
6. 全量 pytest + test_batch171a 改写后绿。

## 4. 评审要点
