## 1. 实施步骤

1. `_DERIVED_CURSOR_IDS` 常量 + `_local_max(sync_id, table, category)` 助手（族谓词 max；tier1 专属表直查；时区锚 Asia/Shanghai）。
2. `_update_sync_state` 写入前：派生族 ⇒ `last_date = min(last_date, _local_max(...))`（None 安全——查询失败 ⇒ 原值+warning 留痕）。
3. `_CAP_EMIT_IDS` 清空（frozenset()）——**涟漪账（B-P0-1，必改消费点）**：tier1 尾部 `_sparse_end` 分轨判据（:3762）`_sid_key in _CAP_EMIT_IDS` 清空后恒 False ⇒ **tier1 稠密 5 族误落稀疏成功闸**（游标停首失败日前＝D1 借尸还魂）。改法：判据改 `_sid_key in _DERIVED_CURSOR_IDS`（派生族走 end_date 推进+写侧 min 结构收口）；守门加行为级断言「tier1 族失败轮 cursor_upto==end_date 不变」。
4. `_update_sync_state` 收口护栏三条（B-P1 全收）：①空域 max=None（bar_5min 现实 0 行）⇒ **不收口原值**+warning（与查询失败同处理，防 None 传染游标写 NULL 全窗循环）；②查询带 `SET LOCAL statement_timeout=5000`（超时归入 fail-open 原值——statement_timeout=0 无护栏）；③min 实际生效（max<原值）⇒ logger.warning 留痕两值（删数据回退自愈型但禁静默）。**收口只改 last_date，count/status 单源不改写**（P1-4：收口+failed 共现词仍 failed——cyq_perf dev 现状 max=1104/游标=1106 是上线首轮**预期回退**活样本）。
5. sync() 三态消费核：keyed 族 `_raw` 与派生收口的 min 关系（:467 区——`_raw` 已含 cursor_upto 尊重链 171d-A 修，派生 min 再收一层——**只紧不松**，语义自洽声明）。同域多写者（jq×astock_daily 同 stock 域）max=并集末日：各自收口主导无互锁，一写者删数据由另一写者撑 max ⇒ 缺口靠 sync_gap 主张不靠游标回退（P2-1 声明句）。
6. crypto 跨度接入（B-P2-2 三钉）：span 按 **family 起点**（`_crypto_base_start` 的 start）算非 per-symbol `_start_of`；接线位 `_crypto_end`/`base_start` 之后 `start>end` 早退之前（date↔串进出镜像 jq :3041 形态）；无 next_from ⇒ 操作员手动续跑 from=span_end+1（FE 无期待声明）。
7. test_batch171a **全文件语义改写**（B-P2-3 账单：必删 b5/d2；必改 d1 双断言；**保留 a1/a5/a6/a7/a8/c1-c3/c5-c8**——收口链代码保留故 mock cap 键行为可测且须锁死〔恰是防 D1 复活的反向守门〕）：白名单断言 excluded 集 → `_CAP_EMIT_IDS == frozenset()` + `_DERIVED_CURSOR_IDS == 12 族`双断言；cap 出具/痊愈 DEL/逃逸闸用例 → 改钉「恒 None/零触碰」（反向守门防复活）。
8. 新测试：派生收口行为级（mock _local_max 验 min 收口/**空域 None 不收口**/查询失败留痕原值/timeout 归入失败/越窗数据不推游标/收口+failed 词不变/:3762 tier1 失败轮 end_date 不变）。

## 3. 验收（可证伪）

1. **派生收口直证（两轮完整链）**：dev 删 bar_1d 某族末端 3 日 ⇒ 第一轮写侧 min 即收口 `last_sync_date=max(local)`（窗口空窗无拉取无 gap 主张）⇒ **第二轮窗口起点=数据末+1 且重拉恰 3 日**——两轮都断（防半证）。
