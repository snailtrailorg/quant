## 0. 契约（自包含）

### 件一：污染检测（data_pollution_scan——日频轻扫）
- **检测什么**（dev 实测底数）：`bar_1d` tushare 源 NULL adj_factor **3.27M/17.77M（18.4%）**，且**新鲜写入持续产 NULL**（11-06 当日 5432/8078=67% NULL；品类构成 stock 2925/listed_fund 2191/convertible 313）。**口径区分**：①stock NULL=真污染（adj_factor 接口有值未填——DEF-14 主体）②fund NULL=**预期形态**（因子在 fund_adj 接口，未接入——非污染，是「因子覆盖面缺口」）③convertible NULL=**预期**（转债无复权因子）④binance 源 100% NULL=**预期**（crypto 无因子语义）。⇒ 检测器**只对 stock 品类报 NULL 污染**，其余品类单独报「因子覆盖面」信息态（不告警）。
- **形态**：tasks.py 新任务 `data_pollution_scan`（beat 每日 16:50——16:35 波次后一轮即抓当日新鲜 NULL）；SQL 聚合：近 N=3 日窗 per-category NULL 计数（stock NULL>0 ⇒ warn 告警〔告警码 `data.pollution`〕+指标；fund/cb ⇒ info 计数进返回体不告警）。复用 `_lock("reconcile:continuity")`？否——独立键 `scan:pollution`（SyncLock 同款）。
- **新鲜写入治本联动**：污染检测只报不改。写入侧根因（per-date 拉取不带因子）不在本批（adj 接口=独立 API 按日全市场拉，与 per-date daily 接口不同——塞进增量轮=每天多一次全市场调用，成本裁定留给「修复映射」后续批）。本件职责=**让污染可见**（DEF-14 的检测半），修数走件二。

### 件二：全历史慢扫修数（adj_factor_backfill_task 复用调度化）
- **既有资产**：`backfill_adj_factor`（engine :1141，A/B-F1 成熟件：只扫股票行/范围谓词 18x/rowcount 真值/降级容错）+ 手动任务 `adj_factor_backfill_task`（tasks.py :674）。**不重写**——本件只做：①首次全史执行（手动触发一次，2026 窗先行——近年 NULL 密度高、回测价值大）②beat 不挂（全史收敛后仅污染检测触发增量补——`adj_factor_backfill_task(start_date=近3日)` 由污染检测告警联动人工触发，不自动〔防积分误耗〕）。
- **执行计划**：prod 首跑 `start_date=20240101`（3 年窗，~730 交易日×0.2s+限速≈30min）；完成后按年回溯至 2010（价值递减，分批裁定）。dev 先验一轮（2026-11 窗）。

### 件三：收敛面板（integrity 口径升级——pct→收敛度）
- **现状口径**：`data_integrity_api`（risk.py :331）pct=cnt/expected，status complete≥99/partial/missing。171b 后 expected 已扣停牌/退市——但**历史长停窗已扣的事实不可见**（用户看 87% 不知道分母已净化）。
- **升级**：items 增两列——`suspended_days`（窗内已扣停牌日数，integrity 侧 expected_bars 的 suspend_days 入参透出）+ `convergence`（收敛度=`cnt/(expected)` 同 pct 但语义分母=**净化后期望**，与 pct 并存过渡一轮〔前端 DataIntegrity.vue 增列渲染〕）。summary 增 `avg_convergence`（市场加权）。**不删 pct**（兼容消费方）。
- **面板范围**：DataIntegrity.vue 表格加「已扣停牌」列+汇总行显示 avg；不加新页签（D24 结构纪律——工作区内容卡内加列，不动页签壳）。
