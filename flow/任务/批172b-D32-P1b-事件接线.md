## 限定范围

只改 `strategy_runner/trading.py`、`strategy_runner/main.py`、`strategy_runner/hub_worker.py`、`md_hub/main.py` 四个消费面 + 新增 `providers/xtp/translate.py`。
**不碰**：`strategy_framework/adapters.py`（P3 才迁）、任何注册点、任何迁移、风控与定价逻辑。

> 说明：本批超「≤3 文件」模板上限，理由＝事件接线是**一条链的不可分割改动**（拆开则中间态两套事件并存、双写 trade_log）。按文件分组做 4 个 commit，逐组跑等价测试。

## 接口契约

```python
# providers/xtp/translate.py
def to_domain_order(d: Any) -> tuple[str, OrderStatus, Side]: ...
    # 入参 vnpy OrderData；返回 (vt_orderid, 领域状态, 方向)
def to_domain_trade(d: Any) -> dict: ...
    # {vt_tradeid, orderid, symbol, direction, price, volume, datetime}
def status_of(d: Any) -> OrderStatus: ...
```

```python
# 消费面签名不变，只换对象类型
trading.write_trade_log(d: Trade, task_id: int) -> None          # 原 Any
trading.reconcile_orders(od: OrderState, ...) -> None
trading.halt_edge_cancel(port: ExecutionPort, od: OrderState) -> None
```
