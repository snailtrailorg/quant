# 批 172b · D32 P1b — 事件端口接线（行为等价）

> 立项 2026-11-11（D32 分批）。前置＝批172a ✅。
> 关联：批172a（骨架）· `docs/design/D32-接入插件架构.md` §六/§9.3/§十二
> **P1b 前置基线（2026-11-11 已存档）**：`flow/稳定性检查/批172b-P1b-金标准基线.md`——171s 16 条 + 交易/回报/撤单三链 107 条实测绿，作为「行为等价」唯一对照坐标。
> **方案 v2（2026-11-11 用户裁定 A）**：P1b 加 `LegacyExecutionPort` 反腐蚀层，事件消费改走端口；`EVENT_LOG` 保留 vnpy；`md_hub` 生命周期面归 P3；`OrderState/Trade` 增 `client_id`（查询→撤销闭环）。

## 目标

把 worker 交易链、任务入口的事件消费从 vnpy 对象/EventEngine 切到 `ports.ExecutionPort` 的领域对象与推送回调；**判定语义零变更**，每处配「旧 vs 新」等价测试。P1b 只切**事件推送**边界；查询/撤单仍走 `ExecutionAdapter`（P3 由插件端口替换），但 `trading.py` 内部统一读 domain。

## 接口契约

### A. 领域字段（形状类，零转换）

```python
@dataclass(frozen=True)
class OrderState:
    orderid: str
    vt_orderid: str
    client_id: str = ""      # 平台侧稳定身份；query_orders 必填
    symbol: str = ""
    direction: Direction = Direction.LONG
    status: OrderStatus = OrderStatus.NOT_TRADED
    volume: float = 0
    traded: float = 0
    price: float = 0
    datetime: datetime | None = None

@dataclass(frozen=True)
class Trade:
    tradeid: str             # 存 vt_tradeid（trade_ref 唯一键）
    orderid: str             # 存 vt_orderid
    client_id: str = ""      # 由 _vt2cid 反填；trade_log 认领
    symbol: str = ""
    direction: Direction = Direction.LONG
    price: float = 0
    volume: float = 0
    datetime: datetime | None = None
```

### B. `providers/xtp/translate.py`

```python
def status_of(d: Any) -> OrderStatus: ...
# SUBMITTING→SUBMITTED；NOTTRADED/UNKNOWN→NOT_TRADED；PARTTRADED→PARTIAL；
# ALLTRADED→ALL_TRADED；CANCELLED→CANCELLED；REJECTED→REJECTED

def to_domain_order(d: Any, client_id: str = "") -> OrderState: ...
# orderid=d.orderid；vt_orderid=d.vt_orderid；status=status_of(d)；direction 映射 LONG/SHORT/NET

def to_domain_trade(d: Any, client_id: str = "") -> Trade: ...
# tradeid=d.vt_tradeid or d.tradeid；orderid=d.vt_orderid or d.orderid

def to_domain_position(p: Any) -> Position: ...
def to_domain_account(a: Any) -> AccountState | None: ...
```

### C. `strategy_runner/legacy_exec_port.py`

```python
class LegacyExecutionPort:
    def __init__(self, event_engine, adapter_getter: Callable[[], Any]): ...
    # subscribe_order/subscribe_trade：ee.register(EVENT_ORDER/TRADE) → translate → cb(domain)
    # send(order: domain.Order) -> OrderReceipt  # 转 legacy adapters.Order；空 cid=accepted False
    # cancel(client_order_id)：vt = adapter.get_vt_orderid(cid) or cid；adapter.cancel_order(vt)
    # query_orders/query_trades：adapter.query_* → translate（client_id 从 _vt2cid 反填）
    # query_positions/query_account/resolve_vt_order_id/connected/connect/close：委托或翻译
```

`adapter_getter` 惰性绑定：`main.py` 在 `build_td_runtime` **之前**构造端口并注册订阅（保住 EMT RESTART 重放接住），adapter 在 build 返回后才可取。

### D. 消费面（签名不变，只换读取类型）

```python
trading.write_order_status(d: OrderState, adapter, sid: str, symbol: str) -> None
trading.write_trade_log(d: Trade, adapter, sid: str, symbol: str) -> None
trading.reconcile_orders(adapter, sid, symbol=None) -> None       # 查询边界 translate
trading.halt_edge_cancel(adapter, halt_state: dict, sid) -> None  # 签名不变
trading._cancel_working_orders(adapter) -> dict                   # 查询边界 translate
```

- `write_order_status`：`d.status` 直接取 `OrderStatus`；仅 PARTIAL/ALL_TRADED/CANCELLED/REJECTED 回写；`client_id=d.client_id or adapter._vt2cid.get(d.vt_orderid)`。
- `write_trade_log`：`action = "BUY" if d.direction == Direction.LONG else "SELL"`；先 `d.client_id`（空则 `_vt2cid` 反查）再 `d.orderid` 反查；`trade_ref=d.tradeid`；`ON CONFLICT DO NOTHING` 不变。
- `_cancel_working_orders`：`query_orders()` 逐条 translate；工作态集合 = `{SUBMITTED, NOT_TRADED, PARTIAL}`；撤单仍 `adapter.cancel_order(od.vt_orderid)`（P3 换 `port.cancel(client_id)`）。
