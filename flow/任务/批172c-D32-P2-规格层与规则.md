### 规则引擎（rules.py + 接线）

- `RuleSet`：`validate(intent, tick, mode)`、`reference_price`、`sellable`、`pre_trade_checks`、`close_policy`、`has_limit_band`、`round_price`、`max_close_qty`；`rules_for(account_id, symbol, provider)` 版本化工厂；`state ∈ fresh/stale/missing`。
- 失败语义三分：开仓 missing/invalid → 拒（`RULE_MISSING` 等码）；平仓 missing → 四级兜底；停牌开仓拒、减仓放行并留痕。
- 四级兜底 `close_fallback_price`：跌停线 → 对手价×aggression → 最新价钳涨跌停带 → None 转人工。
- 动态规则注册表（`register_dynamic_rule`，`convertible` 必注册），启动完整性断言。
- `adapters.py` 规则面全部委托 RuleSet：`close_policy/opponent_price/has_limit_band/close_reference_price/max_close_order_qty/round_close_price(px,tick,sym)`；**send/cancel/query/连接段一行未动**。
- `trading._close_all_positions`：定价切 adapter 薄委托 + 四级兜底；新增 `validate(mode="reduce")` 挂点。
- `strategy.place_order`：WAL 后、send 前 `validate(mode="open")`；拒绝/规则不可用 → 同一 order_log 行标 `rejected`，不发单。
- `risk.check_order`：新增资金/保证金硬门（只拦开仓；`CASH_UNKNOWN`/`CASH_INSUFFICIENT`/`MARGIN_INSUFFICIENT`；快照缺失或 >120s 拒；perp 用 equity−margin_used）。
- `hub_worker`：`cfg-version` 2s 钩子（变化清规格缓存）+ 启动规则完整性预检（告警码 `rules.missing`/`rules.preflight`，已入 runbook）。
