把「市场/品种/账户」三维规格落成**既有表 + 缺列迁移**的映射层，规则消费统一走 `RuleSet`；旧规则源按 §7.5 退役；改一行数据行为随之变，且 ≤2s 全进程一致。

   - `security_master` 加 `sellable_rule TEXT DEFAULT 'volume_minus_frozen'`、`order_types JSONB DEFAULT '[]'`、`position_side TEXT DEFAULT 'long_only'`、`venue_flags JSONB DEFAULT '{}'`、`order_range_override JSONB`

   - 回填：`close_policy.*` 中 `opponent_depth/aggression/max_order_qty` → `trading_account.params`；`has_limit_band/price_tick` 直接删键；删 `system_config` 五键

3. `server/src/data_platform/rules.py`：`RuleSet` + `register_dynamic_rule` + 失败语义三分 + 平仓兜底链

## 限定范围

只改上述迁移 + 两个新模块 + `mgmt.py` 规格段 + worker 启动预检调用点。
**不碰**：`strategy_framework/adapters.py`（P3）、`trading.py` 的定价逻辑（本批只让它调 `RuleSet`）、端口签名。
