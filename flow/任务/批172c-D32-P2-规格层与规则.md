## 接口契约

### A. Specs（P2a）

~~~python
@dataclass(frozen=True)
class MarketSpec:
    market: str; tz: str; calendar: str; anchor: str
    sessions: list[dict]; channels: list[str]
    @classmethod
    def of(cls, market: str, phase: str | None = None) -> "MarketSpec": ...

@dataclass(frozen=True)
class InstrumentSpec:
    symbol: str; exchange: str; category: str; board: str | None
    tick_size: Decimal; multiplier: Decimal; lot_size: int
    t_plus: int; price_band: dict; sellable_rule: str
    order_types: list[str]; position_side: str
    order_range: dict | None; venue_flags: dict
    @classmethod
    def of(cls, symbol: str) -> "InstrumentSpec": ...

@dataclass(frozen=True)
class AccountPermSpec:       # 可缓存，键 (account_id, cfg:version)
    account_id: int; market: str
    allowed_categories: set[str]; allowed_exchanges: set[str]; allowed_boards: set[str]
    st_allowed: bool; convertible_allowed: bool; data_license: str
    @classmethod
    def of(cls, account_id: int) -> "AccountPermSpec": ...

@dataclass(frozen=True)
class AccountSnapshot:       # 每单现读，带 ts，禁进配置缓存
    account_id: int; ts: datetime | None
    available_cash: float; total_value: float
    margin_used: float; equity: float
    @classmethod
    def of(cls, account_id: int) -> "AccountSnapshot": ...
~~~

- 现金门：need = price>0 ? price*volume : (bar_close 或 order_range 上界)*volume；price/ref 皆缺 → CASH_UNKNOWN 拒（开仓）。
- 现金门只 BUY/开仓；平仓/reduce 不查现金；perp 用 equity/margin_used，现货用 available_cash。
- snapshot ts 超 120s 或无行 → 开仓拒 CASH_UNKNOWN + 告警；平仓不受限。
- 市场/品种缓存键含 cfg:version，TTL 2s 兜底；AccountSnapshot 不缓存。
- 停牌：pre_trade_checks 调 integrity.suspended_on(day, {symbol})；bar ts 新鲜度超阈值仅告警不拒单。
- perp 无 band_rules 行：代码缺省 price_band={normal:0,st:0}（无涨跌停）、t_plus=0、position_side='both'、lot_size=1；tick 取 security_master 行。
- data_license 字段只定义，不接 hub 订阅（P3）。

### B. RuleSet（P2b）

~~~python
class RuleSet:
    state: str   # fresh|stale|missing
    def validate(self, intent: Order, tick: Tick | None, mode: str) -> None: ...
    def reference_price(self, intent, tick) -> Decimal: ...
    def sellable(self, pos: Position) -> float: ...
    def pre_trade_checks(self, intent, tick) -> None: ...

def register_dynamic_rule(category, fn): ...
def close_fallback_price(tick, rules, cfg) -> Decimal | None: ...
def rules_for(account_id: int, symbol: str) -> RuleSet: ...
~~~

- 执行序列：check_order（halt 单源 + 现金门）→ WAL（order_log 同一行）→ validate（拒绝标同一行 rejected）→ 定价 → send。
- 失败三分：开仓 missing/stale→拒；平仓 missing→四级兜底；invalid→开拒/平兜底+告警。
- 四级兜底：跌停线 → 对手价×aggression → 最新价钳带内（不乘让价；有市价档优先）→ None 转人工。
- RuleState stale 来自上次成功快照；validate 按 mode 分流。
- 动态规则完整性：启动断言 convertible 等必需 category 已注册（词表按根包判），缺失告警/拒启动。
