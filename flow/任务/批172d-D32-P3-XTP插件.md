## 接口契约

```python
# strategy_runner/session_slot.py
@dataclass(frozen=True)
class SessionSlot:
    terminal_id: int; order_prefix: str; window_open: bool; tid: int

class SessionSlotAllocator:
    @classmethod
    def acquire(cls, account_id: int, provider: str, role: str, tid: int) -> SessionSlot: ...
        # 单语句 INSERT ... ON CONFLICT DO UPDATE ... WHERE heartbeat < now()-45s RETURNING
        # 无返回行 -> EX_TEMPFAIL(75)；越界/耗尽 -> EX_CONFIG(78)；DB 不可用 -> 75 退避
    @classmethod
    def renew(cls, slot: SessionSlot) -> bool: ...      # False = 被抢，调用方立即断开退出
    @classmethod
    def release(cls, slot: SessionSlot) -> None: ...

# providers/xtp/plugin.py
class XtpPlugin:
    manifest: Manifest
    def build(self, account: AccountDTO, role: Literal["md","td"], slot: SessionSlot) -> Runtime: ...
```

## 验收标准

- `cd server && pytest tests/test_d32_s7_golden_master.py -q` → 全绿
  - 同一 fixture 驱动旧路径与新插件，断言：`connect` 实参、`OrderRequest` 全字段、`client_id` 序列、回报映射、撤单退化、查询稳定窗（时钟注入含 `boot_epoch`）
  - **legacy-compat 模式**下号段保持 `(tid-1)%98+2`（仅用于等价证明）
- `pytest tests/test_d32_s8_role_isolation.py -q` → hub 无 ExecutionPort、worker 无 MarketDataPort
- 号段独占：同账号两任务并发启动，两终端号不同、均成功；第三实例抢同一号 → 75 退避
- 急停全平：staging 用 XTP 测试账号跑一次 `cancel-all + close-all`，持仓归零
- `pytest tests/ -q` → 全绿；`grep -rn "vnpy" server/src --include=*.py | grep -v providers/` → 只余基线文件（P5 后为 0）
