## 接口契约

~~~python
@dataclass(frozen=True)
class SessionSlot:
    account_id: int; provider: str; role: str
    terminal_id: int; order_prefix: str; tid: int

class SessionSlotAllocator:
    @classmethod
    def acquire(cls, account_id: int, provider: str, role: str, tid: int) -> SessionSlot: ...
        # INSERT ... ON CONFLICT (account_id,provider,role) DO UPDATE
        #   SET tid=EXCLUDED.tid, heartbeat_at=now(), terminal_id=..., order_prefix=...
        #   WHERE provider_session_slot.heartbeat_at < now() - interval '45 seconds'
        #   RETURNING *
        # 无返回行 → SystemExit(75)；terminal 越界(2..99) 或耗尽 → SystemExit(78)
    @classmethod
    def renew(cls, slot: SessionSlot) -> bool: ...     # False=被抢 → 调用方断开退出
    @classmethod
    def release(cls, slot: SessionSlot) -> None: ...

class XtpPlugin:
    manifest: Manifest       # dataclass: provider="xtp", port_caps={"execution","market_data","account"}
    def build(self, account: AccountDTO, role: str, slot: SessionSlot) -> object: ...
~~~

- `impl='legacy'` 账号走旧路径（`td_registry`/`XtpMdGateway` 保留到 P5 删除）；`impl='plugin'` 走插件。双轨由账号行决定，**同账号不得混跑**。
- legacy-compat 模式号段保持 `(tid-1)%98+2`（仅等价证明用；插件默认也用同式，避免批次内切换号段）。
