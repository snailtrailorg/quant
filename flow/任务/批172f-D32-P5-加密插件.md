# 批 172f · D32 P5 — 加密插件内化

> 立项 2026-11-11（D32 分批）。前置＝批172d ✅。
> 关联：批172a/172d · `docs/design/D32-接入插件架构.md` §9.2/§十三/§十二
> **口径（批177 起）**：crypto 后缀为自定义 venue 码 `XBIN`（币安）/`XOKX`（欧易），非 `.BINANCE/.OKX`；插件出参带该后缀，`security_master.exchange/mic_code` 同值。

## 目标

币安/OKX 永续收进 `providers/binance_perp/`、`providers/okx_perp/`；`paper` 显式登记为内置插件；加密实盘 gate 开启前完成实现 + 单测，不阻塞 gate 决策。

## 现状（已实证）

| # | 事实 | 锚点 |
|---|---|---|
| 1 | `CryptoPerpAdapter` 在适配器层，含 stub 分支 | `adapters.py` 加密段 |
| 2 | `paper_mode` 是类级横切标记，`main.py` 注入 | `adapters.py:57-61`、`main.py:401-403` |
| 3 | paper 虚拟账户靠「未注册 builder → stub」 | `td_registry.py:39-40`、`0127_paper_trade_log.py:55-56` |
| 4 | 数据源与交易通道是两把键（`binance` vs `binance_perp`） | `markets.py:129-140` 注释 |
| 5 | 加密实盘 gate 未开；`_gated_send` 两道 BUY-only 门 | `main.py:513` |

```python
# manifest 关键值

class PaperPlugin:
    manifest: Manifest       # port_caps=["execution"], markets=["*"], transport="none"
```
