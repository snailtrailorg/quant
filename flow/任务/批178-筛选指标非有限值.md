# 批 178 · 筛选派生指标 inf/nan 致 500（可转债方案加载失败）

> 2026-11-14 用户报「可转债的筛选方案加载失败」。定位＝builder 路径 POST /api/screen/run 500。

## 现象
- GET /api/screen/presets?category=convertible 返回 200；点应用 → POST /api/screen/run **500**；DSL 路径正常。
- journal：json.dumps ... ValueError: Out of range（Starlette allow_nan=False）。

## 根因
可转债派生指标 premium_pct/double_low 由 SQL 现算：(close - 100*conv/stk_close)/(100*conv/stk_close)*100。
prod 存在 conv_price 极小的行 → 分母下溢 → 结果溢出为 inf，JSON 序列化直接 500。
DSL 路径未命中该行，故看起来「只有方案加载失败」。

## 修
1. data_platform/screen.run_query：取数后把非有限 float 降级 None（展示层安全值）。
2. web_api/routes/stock._f（astock/cb/etf 三处共用）：非有限 → None。
3. 守门 tests/test_batch178_nan_guard.py：run_query + cb 端点各一条，喂 inf/nan 断言返回 None。

## 限定范围
不改 SQL 口径、不改字段注册表、不碰前端；只做响应边界清洗。

## 验收
- 上述两条守门绿；全量绿。
- prod：POST /api/screen/run 应用 convertible 方案返回 200 且有行。
