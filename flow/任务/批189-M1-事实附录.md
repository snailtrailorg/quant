## 2. 列集（逐表实测）

**trading_account**：`id bigserial PK, name, provider, market, exchanges text[], account_key, credentials_encrypted, params jsonb, capabilities text[] NOT NULL, position int NOT NULL DEFAULT 0, enabled bool DEFAULT true, created_at, updated_at`；0179 加 `impl text NOT NULL DEFAULT legacy`；0127 加 `is_virtual bool`；0191 加 `quote_account_id int`。

**data_source**：`id bigserial PK, name, provider, market, credentials_encrypted, params jsonb, capabilities text[] NOT NULL, position, enabled, created_at, updated_at`；索引 `ix_data_source_provider` / `ix_data_source_position` / `ix_data_source_capabilities`(gin)。

**provider_session_slot**：`account_id bigint, provider text, terminal_id int, holder text, boot_epoch bigint, heartbeat timestamptz`；`PK(account_id, provider, terminal_id)`。

**account_permission**：`account_id bigint`（0104 由 venue_id 改名）、`allowed_categories text[] NOT NULL`, `allowed_exchanges text[] NOT NULL`, `allowed_boards text[] NOT NULL`, `is_st_allowed bool NOT NULL`, `convertible_allowed bool NOT NULL`, `created_at`, `updated_at`；FK `account_permission_account_id_fkey ON DELETE CASCADE`。

**freeze_event**：含 `account_id bigint`（0123，无 FK）。

**data_source_usage**：`interface_id bigint NULL`（0090 加列，按 `provider` JOIN 回填，非精确 id 映射）。

## 4. 存量数据形态

- `trading_account` 列表 API 返回 **4 行**（1 xtp / 3 emt_emq / 4 binance_perp / 5 okx_perp）；`account_key` **全 NULL**；`capabilities` 全 `[rt_quote,trading]`；凭证 2 有 2 无。
- **虚拟账户行**（provider=`paper`）：`capabilities = ARRAY[]::text[]`、`is_virtual=true`、`market=astock`（0127）；**`enabled` 已被 0128 置 false**（DML 迁移——⓪ 必须解析 UPDATE 类迁移）。**API 列表过滤 `is_virtual=false`，故 API 不可见**。
- 虚拟账户配套 `account_permission` 行：三个 `allowed_*` 数组均 NOT NULL（stock/etf/convertible/fund/reits；SHSE/SZSE/BSE；main/star/chinext/bse）。
- `quote_account_id`：0191 对**全表无条件**写 `= id`（含仅 trading 行与虚拟行）。
- 迁移相关 11 张表 dump = 516 KB；全库 9.5 GB；`backup_db` = 998 MB / 4.5 min。
