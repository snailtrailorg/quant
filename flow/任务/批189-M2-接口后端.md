# 批189-M2 接口后端（实施规格）

> 输入：需求(D1–D16) · `批189-M0-契约.md` v2（C1/C2/C5）· `批189-总体实施架构.md` · `批189-M1-事实附录.md` §8（改接面）。
> 依赖：M1（三表已建）。**与 M1/M3/M5 同一 release**。

## 0. 范围

**做**：三实体 API（含 enable、mappings）、code 校验与冲突码、删除事务、**全量旧消费者改接**（附录§8 的 13 + 5 个文件）、入参/出参 code 化。
**不做**：UI（M6a）、进程起停（M3）、订阅/取价（M4/M5）、老 `trading_account` 表（M1 已删）。

## 1. 端点（契约见 M0 §5，不复制）

| 端点 | 方法 | 语义 |
|---|---|---|
| `/api/md-interfaces`、`/api/td-interfaces`、`/api/data-sources` | GET/POST/PATCH/DELETE | 列表/新建/更新/物理删；列表支持 `?enabled=&market=` |
| `/api/{md,td}-interfaces/{code}/enable` `{enabled:bool}` | POST | **唯一启用校验点**（M0 §3 矩阵） |
| `/api/{md,td}-interfaces/{code}/mappings` | GET/POST/DELETE | td 侧=主备增删改；**md 侧=只读反查**（哪些 td 引用我） |
| `/api/interfaces/providers?kind=` | GET | 选型目录（沿用现有 providers 端点，按 kind 过滤） |

**权限**：全部 `require_perm("system_config")`（D6）；路由必须 `Depends()` 包裹（`test_route_auth_gate`）。

## 2. 数据层（新模块 `server/src/data_platform/interfaces.py`，层 1）

| 函数 | 职责 | 关键约束 |
|---|---|---|
| `list_interfaces(kind, filters)` | 三表统一读 | 只读；返回 code 为身份 |
| `create_interface(kind, payload)` | 建行 | code 过 C1；重复 → `CODE_CONFLICT`；`enabled=true` 时先跑 `validate_enable` |
| `update_interface(kind, code, patch)` | 改行 | code 不可改；`enabled=true` 且改后不完整 → 400 |
| `delete_interface(kind, code)` | 物理删 | **顺序**：①有 `live_task` / `is_virtual` 引用 → `IFACE_BUSY`；②**事务外** `systemctl stop`（polkit，附录§5 实测）并复核 `is-active`，未退 → `IFACE_IDLE` 且不删；③事务内清 `td_md_map`/派生快照/（按 login_key+role 且无其他 td 共用时）slot → 删行 |
| `validate_payload(kind, payload)` | **建/改前校验**（行未存在） | 与下方共用同一判定函数；失败码同 |
| `validate_enable(kind, code)` | 启用校验（行已存在） | 无载体 → `PROVIDER_UNSUPPORTED`；缺凭证 → `CREDENTIALS_INCOMPLETE`；td 无映射且需取价 → `MAPPING_MISSING` |
| `set_mappings(td_code, [(md_code, priority)])` | 映射全量替换 | md 必须存在、同市场；重复 priority → 400 |

**分层**：路由零 SQL；本模块只依赖 `quant_common`/`data_platform.db`。
**载体探针**：层 1 不得 import 层 2 的 `md_gateway` → 由 web 组装时注入 `carrier_probe(kind, provider) -> bool`（默认实现= registry ∪ legacy 名单常量）；测试注入 stub。

## 4. 验收（可执行）

```bash
# 建/查/冲突
curl -s -XPOST $API/api/md-interfaces -H "Authorization: Bearer $T" -d '{"name":"x","provider":"xtp","market":"astock"}'
curl -s $API/api/md-interfaces -H "Authorization: Bearer $T" | jq '.items[].code'
# 同 code 再建 → CODE_CONFLICT(P0 断言)
# 旧 int 入参 → 400 ACCOUNT_ID_DEPRECATED
curl -s "$API/api/position?account=1" -H "Authorization: Bearer $T" -o /dev/null -w "%{http_code}"
# 删除：有 running 任务 → IFACE_BUSY
```

**grep 门（两段）**：①`server/src` 的 SQL 形态必须为 0（附录§8 的 13 文件）；②`server/scripts`、`scripts` 的 6 处（附录§8 补列）须改读三表或显式豁免。
**运行期门**：`config_store` 的 `_tbl(kind)` 动态表名 grep 扫不到 → 必须由 `test_batch189_m2.py` 覆盖 list/get/update/delete/test 五条实链路。
