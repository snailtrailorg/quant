## 0. 范围与身份分工
做：unit 名=code；期望集=有载体接口（不看 enabled）；常驻+空转；心跳换族与读侧全量改接；告警 code 化；波次两段切换；**13 文件 + ≥24 测试读路径切换**。
不做：订阅模型（M4）、取价（M5）、UI（M6a）。

**身份分工（P0-11）**：`code` = **进程/心跳/unit 身份**；`bigint id` = **数据面身份**（`hub:bars:{id}`、bar payload 的 account_id、`td:cmd:{id}`）。进程入口解析 code→id 后**同时持有两者**；**不把数据面的 id 直接换成 code**（否则 worker 与命令面全断）。M4/M5 再决定是否把数据面也切 code。

## 1. 单元与实例名（P0-2）
| 项 | 现状（附录§9） | 目标 |
|---|---|---|
| md/td unit | `@...@<id>`，env `ACCOUNT_ID=%i`（非数字即 exit 78） | `@...@<code>`；env 增 `INTERFACE_CODE=%i` **且** `LEGACY_ACCOUNT_ID=<解析出的 id>` |
| 入口解析 | 只认数字 id | **先读 INTERFACE_CODE**（code→查表解析 id）→ 无则回落 `LEGACY_ACCOUNT_ID`（数字，仅迁移窗）→ 两者皆无 exit 78 |
| 旧/回滚代码 | 按 ACCOUNT_ID 数字跑 | 兼容期 unit **仍带数字 `ACCOUNT_ID`**（由 LEGACY_ACCOUNT_ID 同源写入），回滚代码可起；M8 删除该 env |

> 关键：unit 名换 code 后 `ACCOUNT_ID=%i` 变成非数字字符串——**必须显式注入数字值**，不能依赖 `%i`。回滚目标=旧代码 + 同 unit 名，靠这个数字 env 才能起。

## 3. 常驻 / 空转 / 懒加载（P0-3）
| 状态 | 行为 |
|---|---|
| enabled=true | acquire slot、订阅、执行；心跳 working=true |
| enabled=false | **不建券商连接、不 acquire slot、不加载 SDK**；心跳 working=false |
| 无载体 | 不进期望集→无进程 |

- `get_interface_row` 返回**含 enabled、code、id**（现状不含 enabled，P0-3）；td_exec 见 `enabled=false` **不 raise**，改为「只维持心跳、不建会话」；md_hub 同款。
- 配置/凭证变更：`_poll_iface_switch` 比对 provider + credentials 摘要 + updated_at → exit 9 重建。
- 空闲释放 slot：停用 release，启用重新 acquire。
