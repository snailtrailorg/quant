## 目标
在 M1–M5 同一原子发布体内，把 TD 执行面整条身份流从 `int account_id` 切成 `td_code`（平台层唯一身份）；券商 API／租约／订单号所需的物理账号由 plugin 内部经 `login_key` 解析，不下沉为平台身份。禁止「下发 code、消费 int」或「进程用 code、order_log 写 int」的半切换。

## 现状（已实证 2026-11-20）
1. **数据面已切**：0192 已 `DROP TABLE trading_account`，业务表 `account_id` 列全删；`provider_session_slot` PK 改 `(login_key,provider,role,terminal_id)`（无 `account_id` 列）。
2. **进程面未切**：`td_exec/main.py:382-388` 读 `ACCOUNT_ID` 且 `acc.isdigit()` 否则 exit 78；两个 unit 模板 `Environment=ACCOUNT_ID=%i`，实例名已由 M3 改成 `@<code>` → code 实例一启即 78。
3. **runtime 未切**：`session_slot.py` SQL 仍读写 `provider_session_slot.account_id`（列已不存在）；`broker.py build_xtp_setting(row_id=int)` / `get_broker(...,row_id)` 仍按 `trading_account.id` 取数（表已删）；`td_registry._build_xtp_runtime:68` `SELECT impl FROM trading_account WHERE id=%s`。
4. **下游未切**：`td:cmd:{int}` 生产者 `strategy.py:565-566`（策略单）、`td_exec/main.py:313`（消费）、`td:exec:{int}` 心跳 `main.py:38/237/351`；`order_log/trade_log` 写者 `strategy.py`/`adapters.py`/`trading.py`；5 处 `enabled_exec_accounts()`（`risk.py:323/697`、`scheduler.py:160/2087`、`collector.py:232`）。

## 产出（按身份流分组 · 组内可独立 commit · 全组同一 release）

### G1 入口（unit + main · 含防复活守门 P0）
- unit 模板：`ACCOUNT_ID=%i` → `TD_CODE=%i` / `MD_CODE=%i`（实例名=code）。
- `td_exec/main.py`：`main()` 读 `TD_CODE`，校验 `^td-[a-z0-9-]+$`（md 侧 `^md-[a-z0-9-]+$`），`TdExec(td_code: str)`。**防复活铁律**：legacy concrete unit（`ACCOUNT_ID=quant`、无 `TD_CODE`）必 exit 78 Prevent——release.yml:643 靠 `@quant` 非法退码永不复活，code 正则不得让 `quant` 通过（它无 `td-`/`md-` 前缀，自然拒绝）。保留 exit 78 语义不变。

### G2 身份解析（新函数，平台层只认 code）

- `broker.py`：`build_xtp_setting(td_code: str, client_id=None)`；`get_broker(provider, td_code=None)`——**零参调用保留**（`broker.py:269`、`scheduler/tasks.py:1895` 告警探针）：零参=`trade_interface ORDER BY position LIMIT 1`（**不是已删的 trading_account**，`broker.py:98-104` 现读 traded 表须同改）。按 code 取 `trade_interface` + 解密；物理账号解析留函数内部。`row_id` 旧 int 入参 → `PARAM_DEPRECATED`。
- `broker.py get_interface_row(row_id)`：现读已删的 `trading_account`（`broker.py:236`），改读 `trade_interface`（按 code 或 position），去 `enabled=true` 谓词；缺行/解密失败 raise（fail-fast 不变）。

### G3 下发方（策略单 P0 + 5 处 + 队列键）

### G4 消费方 + 心跳 + 取价（td_exec 内部全链）

## 接口契约（写全）
```python
# data_platform/iface_store.py
def get_td_identity(td_code: str) -> dict | None: ...
#   -> {code, provider, login_key, credentials_encrypted, params, impl, is_virtual}

# strategy_framework/broker.py
def build_xtp_setting(client_id: int | None = None, td_code: str | None = None) -> dict: ...
def get_broker(provider: str, td_code: str | None = None) -> Broker | None: ...
#   td_code=None -> 零参语义（position 首行 + .env fallback，dev/test 路径保留——形状跟代码）；
#   td_code 给定但缺行/缺凭证 -> fail-fast。旧 int row_id 入参不收（atomic release 内调用点全改）
#   物理账号解析留函数内部

# strategy_runner/session_slot.py
def acquire(login_key: str, provider: str, role: str, tid: int,
            boot_epoch: int, window_open: bool = False,
            terminal_id: int | None = None, holder: str | None = None) -> SessionSlot: ...
#   SessionSlot(login_key, provider, role, terminal_id, order_prefix, window_open, tid, holder, boot_epoch)

# strategy_runner/td_registry.py
def build_td_runtime(provider, ee, tid, td_code: str, boot_epoch,
                     *, client_id=None, order_prefix=None) -> dict | None: ...
def code_terminal(td_code: str, all_codes: list[str]) -> int: ...
```
**零容忍（验收 grep 门）**：①`server/src` 中 `(FROM|JOIN|INTO|UPDATE)\s+trading_account` = 0；②`provider_session_slot` SQL 含 `account_id` 列 = 0；③`td:cmd:{int}` 生产/消费 = 0（含 `strategy.py`）；④`td:exec:{int}` 心跳读写 = 0。
