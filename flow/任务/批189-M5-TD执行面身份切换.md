## 目标
在 M1–M5 同一原子发布体内，把 TD 执行面整条身份流从 `int account_id` 切成 `td_code`（平台层唯一身份）；券商 API／租约／订单号所需的物理账号由 plugin 内部经 `login_key` 解析，不下沉为平台身份。禁止「下发 code、消费 int」或「进程用 code、order_log 写 int」的半切换。

## 现状（已实证 2026-11-20）
1. **数据面已切**：0192 已 `DROP TABLE trading_account`，业务表 `account_id` 列全删；`provider_session_slot` PK 改 `(login_key,provider,role,terminal_id)`（无 `account_id` 列）。
2. **进程面未切**：`td_exec/main.py:382-388` 读 `ACCOUNT_ID` 且 `acc.isdigit()` 否则 exit 78；两个 unit 模板 `Environment=ACCOUNT_ID=%i`，实例名已由 M3 改成 `@<code>` → code 实例一启即 78。
3. **runtime 未切**：`session_slot.py` SQL 仍读写 `provider_session_slot.account_id`（列已不存在）；`broker.py build_xtp_setting(row_id=int)` / `get_broker(...,row_id)` 仍按 `trading_account.id` 取数（表已删）；`td_registry._build_xtp_runtime:68` `SELECT impl FROM trading_account WHERE id=%s`。
4. **下游未切**：`td:cmd:{int}` 生产者 `strategy.py:565-566`（策略单）、`td_exec/main.py:313`（消费）、`td:exec:{int}` 心跳 `main.py:38/237/351`；`order_log/trade_log` 写者 `strategy.py`/`adapters.py`/`trading.py`；5 处 `enabled_exec_accounts()`（`risk.py:323/697`、`scheduler.py:160/2087`、`collector.py:232`）。

## 产出（按身份流分组 · 组内可独立 commit · 全组同一 release）

### G1 入口（unit + main · 含防复活守门 P0）
- unit 模板：`ACCOUNT_ID=%i` → `TD_CODE=%i` / `MD_CODE=%i`（实例名=code）。
- `td_exec/main.py`：`main()` 读 `TD_CODE`，校验 `^td-[a-z0-9-]+$`（md 侧 `^md-[a-z0-9-]+$`），`TdExec(td_code: str)`。**防复活铁律**：legacy concrete unit（`ACCOUNT_ID=quant`、无 `TD_CODE`）必 exit 78 Prevent——release.yml:643 靠 `@quant` 非法退码永不复活，code 正则不得让 `quant` 通过（它无 `td-`/`md-` 前缀，自然拒绝）。保留 exit 78 语义不变。

### G2 身份解析（新函数，平台层只认 code）
- `data_platform/iface_store.py` 增 `get_td_identity(td_code) -> dict`：`SELECT code,provider,login_key,credentials_encrypted,params,impl,is_virtual FROM trade_interface WHERE code=%s`；缺行 None → 调用方 fail-fast exit 78。
- `broker.py`：`build_xtp_setting(td_code: str, client_id=None)`；`get_broker(provider, td_code=None)`——**零参调用保留**（`broker.py:269`、`scheduler/tasks.py:1895` 告警探针）：零参=`trade_interface ORDER BY position LIMIT 1`（**不是已删的 trading_account**，`broker.py:98-104` 现读 traded 表须同改）。按 code 取 `trade_interface` + 解密；物理账号解析留函数内部。`row_id` 旧 int 入参 → `PARAM_DEPRECATED`。
- `broker.py get_interface_row(row_id)`：现读已删的 `trading_account`（`broker.py:236`），改读 `trade_interface`（按 code 或 position），去 `enabled=true` 谓词；缺行/解密失败 raise（fail-fast 不变）。

### G3 下发方（策略单 P0 + 5 处 + 队列键）
- `strategy_framework/strategy.py:565-566`：策略单 `td:cmd:{int(aid)}` → `td:cmd:{td_code}`（`self` 增 `td_code` 上下文；缺则 fail-closed 不投）。
- `config_store.py`：`enabled_exec_accounts()` → `exec_interface_codes()`（真源=`trade_interface` ∩ registry exec 载体，**不看 enabled**——D9）；调用方 `risk.py:323/697`、`scheduler.py:160/2087`、`collector.py:232` 全改 code；`risk.py:319` 去 `int(a)`。

### G4 消费方 + 心跳 + 取价（td_exec 内部全链）
- `self.account_id` → `self.td_code`；`build_td_runtime(provider, ee, tid, self.td_code, boot_epoch, client_id=<code派生>, order_prefix=f"a{self.td_code}:e{...}:")`。
- **心跳键 C4 化**：`ALIVE_KEY="td:exec:{account}"`（退役键）→ `iface:hb:td:{td_code}`，字段集对齐 C4 白名单（去 `td:exec:{int}` 读写，`main.py:38/237/351`）。命令键 `td:cmd:{td_code}`。
- 取价：quote_account_id → `td_md_map` 按 priority 主→备降级（复用 `iface_store.py:210` 有序 reader）；全无价 `NO_QUOTE`、无映射 `MAPPING_MISSING`（E1 两码不混）。
- `tid` 用 code 字典序稳定派生（见 G5 `code_terminal`）；`order_log/trade_log` 写 `account_code`。

### G5 租约 / 数据面
- `session_slot.py`：`acquire/renew/release` 入参 `account_id:int` → `login_key:str`（**login_key 是 trade_interface 的平台字段，非物理资金账号**，不违 D-M0-7；解析链 `td_code → get_td_identity()['login_key']` 由 td_registry 构建入口调用方完成——即 `td_registry.py:93`，**不是 plugin 内部**）；SQL 列 `account_id` → `login_key`；`SessionSlot.login_key`。
- 恢复 `window_open` 参数；`terminal_id` 保持位置参（修 `td_registry.py:93` 的 `acquire` 调用：首参改 `login_key`、第 6 位置参 `_td_open` 仍对应 `window_open`，避免 TypeError）。
- 新增 `code_terminal(td_code, all_codes) -> int`：按 code 字典序稳定分配 2..99，冲突 → `IFACE_BUSY`（D-M0-6）。
- `td_registry._build_xtp_runtime:68` 改 `get_td_identity(td_code)['impl']`；`:86` 改 `build_xtp_setting(td_code=...)`。

### G6 业务写表 / API 入参
- `strategy.py`/`adapters.py`/`trading.py` 的 order/trade 写入统一 `account_code` 列。
- `web_api/routes/{trading,risk,strategy,chat,mgmt}.py`：入参/出参 account→code；旧 int → 400 `PARAM_DEPRECATED`（M0 §5；M2 §4 旧名 `ACCOUNT_ID_DEPRECATED` 以 M0 为准）。

### G7 期望集 / 读侧（与 M3 同 release，归属 M5 验收）

- **`web_api/routes/risk.py:449/454`（NEW P0）**：前端「执行进程离线」读退役键 `td:exec:{acct_id}` → 改读 `iface:hb:td:<code>`（`r.exists`）；否则 G4 切键后前端恒显离线。该读点在 G4/G6 之外，归 G7 读者面。

## 接口契约（写全）
```python
# data_platform/iface_store.py
def get_td_identity(td_code: str) -> dict | None: ...
#   -> {code, provider, login_key, credentials_encrypted, params, impl, is_virtual}

# strategy_framework/broker.py
def build_xtp_setting(td_code: str, client_id: int | None = None) -> dict: ...
def get_broker(provider: str, td_code: str | None = None) -> Broker | None: ...
#   td_code=None -> 既有零参语义（position 首行）；物理账号解析留函数内部

# strategy_runner/session_slot.py
def acquire(login_key: str, provider: str, role: str, tid: int,
            boot_epoch: int, window_open: bool = False,
            terminal_id: int | None = None, holder: str | None = None) -> SessionSlot: ...
#   SessionSlot(login_key, provider, role, terminal_id, order_prefix, window_open, tid, holder, boot_epoch)

# strategy_runner/td_registry.py
def build_td_runtime(provider, ee, tid, td_code: str, boot_epoch,
                     *, client_id=None, order_prefix=None) -> dict | None: ...
def code_terminal(td_code: str, all_codes: list[str]) -> int: ...
```
**零容忍（验收 grep 门）**：①`server/src` 中 `(FROM|JOIN|INTO|UPDATE)\s+trading_account` = 0；②`provider_session_slot` SQL 含 `account_id` 列 = 0；③`td:cmd:{int}` 生产/消费 = 0（含 `strategy.py`）；④`td:exec:{int}` 心跳读写 = 0。

## 验收标准（可执行证据，缺一不许提交）
```bash
# 数据契约（迁移后）
psql -c "\d provider_session_slot"   # 无 account_id，PK=(login_key,provider,role,terminal_id)
psql -c "SELECT to_regclass('trading_account')"   # NULL
# 进程入口（code 实例能起、非法/legacy 仍 78）
systemctl is-active quant-td-exec@td-xtp
systemctl show -p Result quant-td-exec@td-xtp   # success（非 exit-code=78）
systemctl start quant-td-exec@quant ; systemctl show -p Result quant-td-exec@quant   # exit-code（防复活）
# 心跳/队列键（code 化）
redis-cli hgetall iface:hb:td:td-xtp   # 字段集 == C4 白名单
redis-cli llen td:cmd:td-xtp ; redis-cli --scan --pattern 'td:exec:*'   # 后者空
# 三路下单 + 急停（E1/E5）：策略单/定时/手工都进 td:cmd:td-xtp；order_log.account_code=td-xtp 非空；
#   主 MD 无价降级备 MD；空行情 NO_QUOTE、空映射 MAPPING_MISSING
# grep 门
grep -rnE '(FROM|JOIN|INTO|UPDATE)\s+trading_account\b' server/src   # = 0
grep -rnE 'td:cmd:\{?int|td:cmd:"?\s*\+?\s*str\(int|td:exec:' server/src   # = 0
```
单测：行为断言优先，覆盖失败路径（缺行→78、缺凭证→fail-fast、旧 int→400、租约 CAS 败→SessionLost、策略无 td_code→不投、legacy @quant→78）；相关测试面 ≥24 文件（M2 §3 22 + session_slot + td_exec）。
