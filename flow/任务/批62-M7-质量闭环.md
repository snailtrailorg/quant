## 一、62a · 血缘贯穿（迁移 0109+写侧+帧级）

- **迁移 0109**：signal_log 加 `(source TEXT, fetched_at Timestamptz, dataset_version TEXT)`；backtest_runs 加同三列。dataset_version **TEXT 命名空间编码（A-P2-1/B-P2-1 裁定）**：实盘=`hub:{account_id}:{gen}`（流世代——per-account 纪元跨账号不可比，编码自描述）；回测=`store:{kind}:{version}`（version=**SELECT max(dataset_version) 该 kind bar 表**——不依赖未 seed 的 system_config 键〔B-P2-2/A-P2-2 版本真源挂账绕开〕）。列注释立法双语义。存量 NULL=历史。
- **实盘写点**（strategy.py `_log_signal_order`，66c 指纹同事务）：
  - source=**cfg.adapter**（B 核实：与 iface provider 恒等，免开新通道）
  - fetched_at=**pub_ts**（A-P1-5 裁定：到端时刻——bar ts 已由 bar_fingerprint 承载，fetched_at 专责「决策时数据多旧」；hub_worker handle_msg 与 last_gen 同点注入 Strategy 实例属性 `_pub_ts/_hub_gen`）
  - dataset_version=f"hub:{account_id}:{gen}"（account_id=Strategy 实例属性已有）
- **回测写点**（B-P1-1 裁定：per-symbol 任务 UPDATE 合并——backtest_runs 唯一 INSERT 在建 run 时 bar 未读）：每个 backtest_symbol_task 在 DataBus.get_bars 取 frame 后 `UPDATE backtest_runs SET source=去重合并(frame.source), fetched_at=GREATEST(frame.fetched_at), dataset_version=COALESCE 保持首值` （行锁天然串行；fetched_at=max=最晚读取）。帧级 source 聚合规则（B-P2-6）：行级 distinct 单值直通/多值逗号 join；test_databus 既有断言随批改。
- **帧级补强**（databus local_pg to_contract）：source=行级 BAR_COLUMNS distinct 聚合替换字面量；fetched_at 维持读取时刻（债注记：真实摄取=sync 水位另批；报表侧命名「读取时刻」防审计误读——A-P2-3）。
- **审计链端点**（B-P2-8）：`GET /api/quality/lineage/{signal_id}`（perm system_config）——signal→order_log.bar_fingerprint→source/fetched_at/version 一条链 JSON。

## 二、62b · shadow 引擎+口径白名单+报表（迁移 0110+quality.py）

- **迁移 0110**：`shadow_policy(kind PK, backup_source TEXT, sample_n INT, tolerance JSONB, budget_calls_month INT, enabled BOOL, note TEXT)`——**预算单位=API 调用次数/月**（A-P1-6：Tushare 积分是档位非钱包）；种子：bar_daily（sample_n=5/tolerance 见下/enabled=true）+bar_minute（enabled=false 空档注记）。`shadow_diff(id, kind, symbol, trade_date, field, main_val NUMERIC, backup_val NUMERIC, whitelist_hit TEXT NULL, created_at)`——field 支持 `__missing__`/`__extra__` 伪字段（整行缺失/多余——A-P2-5）；索引 (kind, trade_date)/(whitelist_hit)/(created_at)。routing_policy **不加列**（A-P1-4 尾裁定：金标准源全局事实放 per-consumer 表语义别扭）——`system_config` 键 `sm_golden_static_list`（缺省 'tushare'）。
- **口径白名单** `server/src/data_platform/whitelist_semantic.json`（B-P1-4：**机器可执行 schema**）：条目 `{id, match:{exchange?, board?, field}, rule:{type: "tolerance_pct"|"tolerance_abs"|"skip_field", value}, 适用机会: "daily-expected"|"event-driven", 差异模式, 验证义务, 上次验证, 生效}`。**初始条目（A-P1-1 裁定——已废的 SHSE 收盘竞价例句不入册，A03 §15.1 例句修订提请随批）**：①adj_factor 降级回填（PG NULL=因子接口降级写入 vs 现拉有值——tolerance 类）；②停牌窗缺行（__missing__ 合法缺失——skip）；③盘后定价量口径（量差容差类）。**冷切换条目（B-P1-6 裁定②）**：whitelist_coldswitch.json 迁移并入但 `生效=false`+注记「缺根/时间窗豁免模式引擎未实现——挂账另批」；其验证义务「批 62 接管」承诺**显式降级**（decisions 记录：bars 计数核对随缺根模式另批，不静默吞）。
- **引擎** `server/src/data_platform/quality.py`：
  - `run_shadow_check(kind)`：shadow_policy→采样标的（bar_1D distinct symbol×SM join 品类——**bar_daily 三类分派 sub_kind**）→主源=PG（get_bars）→**备源=逐交易日全市场批拉→过滤采样标的**（B-P1-2 裁定：fetch(bar_daily) 是按日全市场批无 per-symbol——采样窗=**T-1 及以前**〔A-P2-5：Tushare 日线时点不稳，当日半出=每天狼来了〕，拉 N 日）→白名单归一（match 域匹配→rule 应用）→diff（tolerance 默认：价 abs 0.01+rel 1e-4/量额 rel 1e-3/adj_factor rel 1e-4）→落 shadow_diff。
  - **每次 fetch 包 rate_limit_context+record_usage**（B-P1-3：D1 立法限速在 engine 侧——64b 裸调收编先例；**预算=SUM(data_source_usage.calls) 当月**聚合——闸门输入有源）。
  - **预算闸门（A-P1-6 终版）**：超 budget 比例→降采样；**sample 地板≥3**——破地板=跳过执行+升级告警（不静默缩量砍零）。
  - **超容差告警（A-P1-2）**：本轮真 diff（非白名单命中）行数>阈值（缺省 10）→notify critical（文案师）；diff 表 30 天清理=beat cleanup 任务（B-P2-3）。
  - **验证义务治理（A-P1-7 终版）**：履行记录=system_config 键 `whitelist_verify:{id}`（值=日期+结果）——报表「上次人工验证」列读它+回填端点；beat 检查「超 90 天未验证→告警」；命中率分母钉死=**条目命中数/该 kind 当期 diff 行数**；`适用机会=event-driven` 条目（冷切换类）不进比率分母（无机会≠死条目）——双向监控（≥99% 静音器防线+0 命中死条目提示）。
- **beat**：`quality_shadow_check` 每交易日 16:05（**is_trading_day 守卫+data 队列**——B-P2-4）+`quality_cleanup` 每日+手动触发端点（require_perm system_config）。
- **报表**：/dataops 第四 tab「对账」——KPI（**同源自洽标注词条**+diff 计数+命中率）+diff 表（过滤 kind/date/whitelist_hit）+白名单统计（命中率双向+上次验证）；后端 `/api/quality/shadow-diff`+`/api/quality/whitelist-stats`（60s 聚合缓存先例 risk.py:327）。文案走文案师。

## 三、62c · SM 对账差集

- `sm_reconcile()`（A-P1-4/B-P1-5 终版）：**范围钉死** SM `category='stock'` vs static_symbols `list_status='L'`——键归一 ts_code→vt_symbol（复用 schema.to_vt_symbol/_EXCH_CASE 先例）；ETF/转债=「范围外不计」报告注记；退市漂移=static delisted 单列（不混入主差集）。**双向差集**：SM 有 static 无（漏同步）/static 有 SM 无（SM 缺行）。
