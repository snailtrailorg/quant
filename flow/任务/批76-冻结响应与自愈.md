## F1 · freeze_event 事实表（设计草案）

迁移 0123 建 `freeze_event`（PG——介质立法，事实进库）：

| 列 | 说明 |
|---|---|
| id | BIGSERIAL |
| task_id / account_id / symbol | 谁（tid 唯一对应 worker 进程） |
| freeze_type | `ts_gap` / `seq_gap` / `untrusted`（CHECK 锁枚举，对齐三冻结点） |
| frozen_at / frozen_ts_watermark | 冻结时刻 / 冻结时水位（max_ts epoch）+ gap 目标 ts |
| detail | jsonb（告警文案要点/gap 大小等） |
| unfrozen_at / unfreeze_method / operator | 解冻时刻 / `restart`·`auto_reconnect`·`manual_web`·`manual_im` / 操作者 |

写点：①三 sticky 冻结处 INSERT（guard 内 fail-soft——事实表写失败不阻断冻结本身）；②worker 启动时对 tid 的 open 事件补记 `unfreeze_method=restart`（重启解的闭环记账）；③人工/自动解冻处 UPDATE。查询面=Web 任务管理页 + 监控页（读取挂本批或 UI 尾批，方案内定）。
