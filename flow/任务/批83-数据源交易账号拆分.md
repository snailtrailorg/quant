# 阶段一 · 83a 拆表（重构，行为不变）

## 现状（揉合问题）

`external_interface` 单表（12 字段）用能力集 5 token 强行统一两类账号：

| 维度 | 数据源账号 | 交易账号 |
|---|---|---|
| 凭证 | token | 账号密码/API key |
| 能力 | hist_quote/ref_data/inst_event | rt_quote/trading |
| 处理 | 同步引擎 pull | hub/TD 长连接 |
| 插件 | DataSource | Broker/TD |
| params | rate_limits | 连接参数 |
| account_key | 无意义 | 资金账号 |

## 表结构

- **data_source**：`id, name, provider, market, credentials_encrypted, params(rate_limits/熔断), capabilities(hist_quote/ref_data/inst_event), position, enabled, created_at, updated_at`。`exchanges` 可删（routing 对 NULL 兼容全所）、`account_key` 删。
- **trading_account**：`id, name, provider, market, exchanges, account_key, credentials_encrypted, params(连接参数), capabilities(rt_quote/trading), position, enabled, created_at, updated_at`。

## 读表点分叉（真实 SQL 读点 9 文件）

- **数据源**（读 data_source）：`data_source.py:187`、`routing.py:204`、`rate_limit.py:123`（熔断参数经 ds.get_param 内存态，实为传递点）、`data_sync/engine.py`（经 data_source.py）。
- **交易**（读 trading_account）：`broker.py:97/101/216`、`md_gateway.py:81`（凭证经 broker 传入）、`md_hub/main.py:238`（SQL 在 broker）、`risk.py:30`、`trading.py:31/37/127/239`、`monitor.py:107`、`scheduler/tasks.py:249/1451`。
- **管理面**：`interfaces/base.py`（InterfaceProvider 基类保留，`_PROVIDER_MODULES` 注册表拆数据源/交易）、`mgmt.py:149/203/228/234/565`（CRUD 拆两套端点族 + put_account_permission）、`chat.py:70/81`（account_snapshot JOIN → trading_account）。

## 盲审结论（agent a9dd9e50，已采纳）

- **P0-1 迁移重指向 9 个 FK + 交易行保留原 id**：8 表 FK（live_task/position_snapshot/position_refresh/account_snapshot/order_log/trade_log/account_permission/trade_switch_session）挂 external_interface.id。迁移设计：①交易行**保留原 id** 迁入 trading_account（8 表 account_id 零重映射 + data_source_usage.interface_id 零迁移）②FK 重指向 trading_account.id ③`account_key UNIQUE(provider,account_key)` 重建 ④显式 drop FK 再 drop 表（不能裸 DROP，CASCADE 静默删 FK），走 allow_contract。
- **P1-1 data_source 保留 market**：tushare=astock，routing._row_covers/权限过滤依赖。
- **P1-2 tencent 退役**：唯一能力 rt_quote（0096 退役后），功能硬编码不读表，僵尸行直接删。
- **P1-3 读点补全**：trading.py:31/37、mgmt.py:565、verify_integration.py:121；trading 保词 src 9 处 + scripts 1 处（markets.py:8 注释改）。
