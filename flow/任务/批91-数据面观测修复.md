# 批 91 · 数据面观测接口可用性修复

> 立项 2026-10-04（威廉姆「干吧」授权）。来源＝数据同步验证 L5 界面走查（`flow/方案/数据同步验证L5-界面走查表-20261004.md`）。
> 关联：批 90（数据同步验证）· 批 92（游标语义，本批**不做**）

## 目标

一句话：让「数据管理 → 完整性体检」与「管理标的」两个只读接口在 **prod 数据量**下可用；失败时**可见**（不再静默返回空）。附带修「概念板块」残留红。

## 现状（已实证）

| # | 事实 | 锚点 |
|---|---|---|
| 1 | `/api/data-integrity?freq=1D` 在 prod **200 OK 但返回空 items** ⇒ 界面「0 只标的 / 暂无数据」 | quant-web-api journal：Oct 04 20:56 / 21:11 / 21:29 三次 200，**无 traceback** |
| 2 | 该接口 `except Exception` **静默吞错**，返回 `{items:[],summary:{...}}`——与「真没数据」**逐字相同** ⇒ 前端 `loadFailed` 错误条永不亮 | `server/src/web_api/routes/risk.py:355-356` |
| 3 | `/api/sync/symbols/astock_daily?q=&page=1&size=9999` 在 prod **500**，栈底 `psycopg.errors.QueryCanceled: canceling statement due to statement timeout` | journal Oct 04 21:14:00 + traceback |

## 产出

0. `server/src/data_platform/db.py`
   - 新增 `get_conn_for_heavy_read(stmt_timeout_ms=None)`：只读重查询专用连接，事务内
     `set_config('statement_timeout', …, true)`（=`SET LOCAL` 语义，**退出自动复位、不污染池**）。
     超时逻辑必须落在层 1（路由文件加 SQL 会撞 `test_no_sql_in_new_routes` 基线闸）。
1. `server/src/web_api/routes/risk.py::data_integrity_api`
   - **SQL 时区外提**：`min(ts AT TIME ZONE 'Asia/Shanghai')` → `(min(ts) AT TIME ZONE 'Asia/Shanghai')`（min/max 两处）
   - 重查询改用 `get_conn_for_heavy_read()`
   - `except` → `logger.exception(...)` + 返回体加 `"error"` 字段
2. `server/src/data_sync/engine.py::list_symbols`
   - bar 聚合改用 `get_conn_for_heavy_read()`
   - 聚合 `except` 由 `UndefinedTable` 扩为 `Exception`（log + `local={}` 降级）→ 返回体加 `"count_error"`
3. `web/src/views/DataIntegrity.vue`
   - `r.error` 有值 → 置 `loadFailed`（既有错误条 + 重试按钮生效）
4. `web/src/views/SymbolManage.vue`（「管理标的」是独立页 `/data-manage/:sid`，非弹窗）
   - `count_error` 有值 → 顶部警告条（不假装「本地 0 条」）
5. `web/src/views/DataManage.vue` + `web/src/utils/status.js` + `web/src/locales/index.js`
   - 配置表状态列：`enabled === false` → 显示「已停用」（不显示残留 `last_status`）；
     新增 `status.disabled`（zh/en 对称）+ `symbol.countDegraded`（zh/en 对称）

## 接口契约

- `data_integrity_api(freq: str = "1D", payload: dict = Depends(require_perm("read"))) -> dict`
  成功：`{items:[{symbol,local_count,first,last,expected,pct,status}], summary:{total,complete,partial,missing}}`（**不变**）
  失败：同一结构 + 新增键 `error: str`（前端据它亮错误条）
- `list_symbols(sync_id: str, q: str = "", page: int = 1, size: int = 9999) -> dict`
  成功：`{items:[{ts_code,name,list_date,local_count,local_first,local_last}], total}`（**不变**）
  降级：同一结构 + 新增键 `count_error: str`（本地计数聚合失败时；`local_count` 全为 0，前端须显著提示）
