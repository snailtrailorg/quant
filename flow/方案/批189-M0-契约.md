## 0. 使用规则

1. 本文件每条契约都有可执行断言（§9）；改契约不同步改断言 = `pytest tests/test_docs_b189.py` 红。
2. 事实断言只引用 `附录§x` 或 `file:line`；**本文件不重复描述现状**（现状只在附录）。
3. 术语：**接口**=行情/交易/数据源三类实体；**载体**=能提供该角色能力的实现（§6）。

## 1. C1 身份（code）

- 类型：`varchar(32) COLLATE "C"`；正则 `^[a-z][a-z0-9-]{1,30}$`。
- 前缀与表绑定：`market_interface` → `md-%`、`trade_interface` → `td-%`、`data_source` → `ds-%`（表级 CHECK）。
- **不可修改**；改名=换身份。展示名走 `name`。
- 生成默认 `<role>-<provider>`，**provider 规范化**：小写 + `_`→`-`（`emt_emq` → `md-emt-emq`，附录§6）；规范化后不过正则即拒绝。同 provider 多行由用户加语义后缀；**冲突提示改名，不自动编号**。
- **`login_key`（物理登录身份）**：`<provider>|<account_key>`，唯一拼接函数；禁含凭证。例外：`is_virtual` → `<provider>|virtual`；公开行情（无凭证）→ `<provider>|public`；其余 `account_key IS NULL` → **拒绝启用/拒绝迁移**。

### 2.5 删除语义

- 先停进程确认退出 → **物理删行**；有 `live_task` 引用 → 拒删 `IFACE_BUSY`。
- 同事务清理：`td_md_map` 两侧、派生快照、slot 租约；`order_log/trade_log` 靠 `SET NULL` 保留流水；`freeze_event` 保留文本。
- **不留 tombstone**，code 可重建（重建走 `CODE_CONFLICT`）。

### 2.6 唯一约束与索引

- `UNIQUE (market, account_key) WHERE account_key IS NOT NULL AND enabled`：**仅 md/td 两表**（`data_source` 无 `account_key`）。
- 迁移内一律普通 `CREATE INDEX`；0180 的 `CONCURRENTLY` 形态不沿用（附录§3）。

## 3. C3 运行（两轴 + 启用校验）

| 轴 | 取值 | 判定 |
|---|---|---|
| 运行 | `运行` / `停止` | 心跳在场 ∧ unit active；`working` 仅副标 |
| 配置 | `完整` / `未完成(缺载体\|缺凭证\|缺映射)` | 启用校验结果，不占状态位 |

**启用校验矩阵**（唯一校验点；失败不改 `enabled`）：无载体 → `PROVIDER_UNSUPPORTED`；凭证缺失/解密失败 → `CREDENTIALS_INCOMPLETE`；交易接口需取价但无映射 → `MAPPING_MISSING`。

- 不变式：`enabled=true ⇒ 配置完整`；已启用行改成不完整 → 保存即 400。
- 创建允许不完整（`enabled=false`）；有载体的行进程常驻，`enabled` 只决定干活/空转；无载体的行不建进程（UI 显示「—（无进程）」）。

## 6. C6 载体

- 载体 = `registry` 插件声明该角色（market→`market_data`、trade→`execution`）**∪**（M8 前）legacy `create_md_gateway`（`_LegacyMdShim`，现网 emt/binance/okx 行情）。
- 无载体 → 不可启用（`PROVIDER_UNSUPPORTED`）、不建进程；可建草稿行。
- 能力（rt_quote/trading）由接口类型 + 载体派生，页面只读。
- M8：只认 registry，legacy 注册点为零。
