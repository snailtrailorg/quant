## 0. 使用规则

1. 本文件每条契约都有对应的可执行断言（§9）。改契约不同步改断言 = `pytest tests/test_docs_b189.py` 红。
2. 契约里的 `必决` 项在 M0 结束时必须有结论并写入正文；未决项不得进 M1。
3. 术语：**接口** = 行情接口（`md-*`）/ 交易接口（`td-*`）/ 数据源（`ds-*`）；**载体** = 能提供该角色能力的实现（§6）。

## 1. C1 身份（code）

- 类型：`varchar(32) COLLATE "C"`；正则 `^[a-z][a-z0-9-]{1,30}$`（≤31 字符，systemd/Redis 合法）。
- 前缀与表绑定：`market_interface.code LIKE 'md-%'`、`trade_interface.code LIKE 'td-%'`、`data_source.code LIKE 'ds-%'`（表级 CHECK）。
- **不可修改**：改名 = 换身份（unit/键/历史绑定全变）；展示名走 `name`。
- 全局唯一由「前缀互斥 + 各表 UNIQUE」保证，不建 registry 表。
- 生成默认值（用户可改）：`md-<provider>` / `td-<provider>` / `ds-<provider>`；同 provider 多接口由用户加语义后缀（`md-xtp-test`）；**冲突提示改名，不自动编号**。
- 删除后是否允许同 code 重建：见 §8 待决 D-M0-2。

- `td_md_map(td_code TEXT → trade_interface(code), md_code TEXT → market_interface(code), priority INT, PRIMARY KEY (td_code, md_code))`；**priority 唯一决定主备**，无 `is_primary`。

## 3. C3 运行（两轴）

| 轴 | 取值 | 判定 |
|---|---|---|
| 运行 | `运行` / `停止` | 心跳在场 ∧ unit active = 运行；否则停止（停止=异常或人工停，需告警）。`working` 仅作副标（工作中/空转），**不是状态** |
| 配置 | `完整` / `未完成(缺载体\|缺凭证\|缺映射)` | 启用校验结果；不占状态位 |

**启用校验矩阵**（唯一校验点；失败不改 `enabled`）：

| 缺失 | 返回码 |
|---|---|
| 无该角色载体 | `PROVIDER_UNSUPPORTED` |
| 凭证必填项缺失/解密失败 | `CREDENTIALS_INCOMPLETE` |
| 交易接口无映射且本次操作需要取价 | `MAPPING_MISSING` |

- 不变式：`enabled=true ⇒ 配置完整`；已启用行被改成不完整 → **保存即 400**。
- 创建允许不完整（`enabled=false` 草稿）；有载体的行进程常驻，`enabled` 只决定干活/空转；无载体的行**不建进程**（UI 显示见 §8 待决 D-M0-1）。
- 配置/凭证变更检测 ≤5s → 进程 exit 9 重建；删除 = 先停进程确认退出 → 物理删（§2.3）。

## 4. C4 键族（唯一白名单）

| 键 | 形状 | 写者 | 读者 |
|---|---|---|---|
| unit | `quant-md-hub@<md_code>` / `quant-td-exec@<td_code>` | systemd | — |
| 心跳 | `iface:hb:<md|td>:<code>`（hash：`enabled/working/subs/bars/reset_cnt/ts/seq`） | 该接口进程 | collector / readyz / 前端 |
| bars | `hub:bars:<md_code>:<sym>` | 行情 hub | hub_worker / databus |
| tick | `hub:latest_tick:<md_code>:<sym>`（TTL 65s） | 行情 hub | hub_quote（exec 取价） |
| 公共快照 | `hub:latest_tick:pub:<sym>`（**不带 code**，跨接口共享） | 行情 hub | stock_detail |
| 水位 | `hub:worker:max_ts:<md_code>:<sym>` | hub_worker | hub_worker |
| 命令 | `td:cmd:<td_code>` | strategy / scheduler / risk 路由（IM 经 API） | 该交易接口 exec |
| 回执 | `risk:cmd:result:<req_id>[:final]` | 该交易接口 exec | strategy（2s 轮询）/ risk 路由 |

**退役**：`quant:hb:md-hub:*`、`td:exec:*`、`hub:bars:{int}:*`、`hub:latest_tick:{int}:*`、`td:cmd:{int}`、`hub:worker:max_ts:{int}:*` —— M1 起不写不读；`td:exec` 的在场判据并入 `iface:hb:td:<code>`。

## 5. C5 API

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/md-interfaces`、`/api/td-interfaces`、`/api/data-sources` | GET/POST/PATCH/DELETE | 三实体 CRUD（复用 `system_config` 权限键，D6） |
| `/api/{md,td}-interfaces/{code}/mappings` | GET/POST/DELETE | 主备映射（M6b 之前走 curl） |
| `/api/{md,td}-interfaces/{code}/enable` | POST | **启用校验唯一入口**（§3） |

**业务码**（7）：`MAPPING_MISSING` / `NO_QUOTE` / `PROVIDER_UNSUPPORTED` / `CREDENTIALS_INCOMPLETE` / `IFACE_IDLE` / `CODE_CONFLICT` / `IFACE_BUSY`。
HTTP 映射：参数/配置类 = 400；冲突类（`CODE_CONFLICT`/`IFACE_BUSY`）= 409；`NO_QUOTE` 取价场景 = 409；基础设施（`valkey_down`/`bad_json`/DB 不可用）= **503 + detail，不占业务码**。
入参/出参的 account 一律 code；收到旧 int → 400（`detail` 指明用 code）。

## 6. C6 载体（能力从哪来）

- 载体 = `registry` 插件声明该角色（`market`→`market_data`，`trade`→`execution`）**∪**（M8 前）legacy `create_md_gateway` 注册（`md_hub._LegacyMdShim` 通路，现网 emt/binance/okx 行情）。
- 无载体 = 该类型接口不可启用（`PROVIDER_UNSUPPORTED`）、不建进程；可建行（草稿）。
- 能力（`rt_quote`/`trading`）由「接口类型 + 载体声明」派生，页面只读；写侧校验 ⊆ 声明。
- **M8 收口**：只认 registry；legacy 注册点为零（P7 销账后）。

## 7. C7 部署

- 波次对象 = **在跑实例枚举**（`systemctl list-units`），实例名 = code；不按 DB 数字 id 拼接。
- `quant-dbro` / `quant-hbcheck`：按 marker 二选一（新表 / 旧表），未知态 rc=1 响亮失败；**先装位后发布**。
- marker：`alembic_version >= 0192` 或 `schema_expectations` 命中；**M1 必须是单文件迁移 `0192`**（现 head=0191）。
- 发布参数：`-e allow_contract=true -e contract_reason=...`；`auto_rollback_disabled` 由 playbook 在豁免生效时自动置位（不传）。
- 破坏性门：本批不可逆，无自动回滚；回滚=快照恢复（演练前置、窗外完成）。
