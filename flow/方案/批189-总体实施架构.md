## 1. 系统不变式（I1–I7）

> 每条必须能被一条测试或一条巡检命令证伪；不可证伪的不写。

| # | 不变式 | 违反判据（可观测） | 落地 |
|---|---|---|---|
| I1 | **对外身份=code**：unit / Redis 键 / API 入出参 / 日志 / UI 一律 code；DB 内接口表 PK 与业务表 FK 亦为 code。**唯一例外**：`account_permission` 锚 `login_key`（物理账号权限，不随 TD 行） | 出参/键/unit 出现数字接口 id；或 `account_permission` 被改成 account_code | M1/M2 |
| I2 | **单一写入口**：接口三表与映射只经 `/api/{md,td}-interfaces`、`/api/data-sources` 写；进程只读（心跳/租约除外） | 进程内出现接口表 INSERT/UPDATE（心跳/租约键除外） | M2/M3 |
| I3 | **键族白名单=C4**：`hub:latest_tick:<md_code>:<sym>`、`hub:latest_tick:pub:<sym>`（公共快照，跨接口共享故不带 code）、`hub:bars:<md_code>:<sym>`、`td:cmd:<td_code>`、`risk:cmd:result:<req_id>[:final]`、`iface:hb:<md|td>:<code>`；**`td:exec:*` 退役**（在场判据统一用 `iface:hb:td:<code>`）。旧形状（`quant:hb:md-hub:*`、`hub:bars:{int}`、`td:cmd:{int}`、`hub:latest_tick:{int}:*`、`td:exec:{int}`）自 M1 起不再写、不再读 | 迁移后旧形状仍被写/被读；或出现 C4 之外的接口级键 | M1/M3/M7 |
| I4 | **进程 ⇔ 行**：进程存在 ⇔ 行存在 ∧ provider 声明该角色载体；`enabled` 不参与起停 | enabled 改动导致 unit 起停；行存在且有载体却无进程 | M3 |
| I5 | **空转不占资源**：`enabled=false` 不建券商连接、不占 terminal、不订阅、不初始化 SDK | 停用接口仍有 `ss` 到券商端口 / slot 行 / 订阅 | M3 |
| I6 | **取价单源**：TD 取价只经 `td_md_map`（主→备降级）。MD 订阅候选 = 映射反查 ∪ 显式 transient/shadow（按 md_code 直取，不属取价路径） | 出现 `quote_account_id` 读取、`hub:latest_tick` SCAN、按 market 猜源 | M4/M5 |
| I7 | **失败响亮**：无载体 / 无映射 / 无行情 / 向空闲接口下发 → 各自明确错误码，不得 200 空成功或静默零结果 | 接口 200 但零命令；或四类失败共用同一码互相掩盖 | M2/M3/M5 |

## 2. 模块边界与依赖方向

```
层0 quant_common
层1 ports / registry / data_platform
层2 providers / strategy_framework / risk_control / task_manager / alert_notify / llm_gateway / email_service / astock_analysis / strategies
层3 strategy_runner / md_hub / data_sync / scheduler / health_monitor / im_bot
层4 web_api / feishu_bot          组合根，只编排
```

- 真源=`server/tests/test_layering.py::LAYER`；**`td_exec` 当前不在表内 ⇒ 零分层约束**——M3 必须登记为层 3（本批必做项，不是可选）。
- **禁止反向 import**；跨模块只走三种通道：HTTP API / DB 表 / Redis 键。禁止直接调对方内部函数。
- **入口层零 SQL**（`test_no_sql_in_new_routes.py`）。

## 3. 上线原子单元与发布序列

**原子单元（一次 release，不可拆）**：

`M1` + `M2`（含**全部旧消费者改接**）+ `M3` + `M4` + `M5` + **wrapper 装位** + **心跳读侧全量改接**（`collector`/`readyz`/`hub_worker`/`run_hub_postverify`，并删 `legacy_transition` 豁免）+ **期望集 code 化（去 enabled）** + **`get_interface_row` 去 `enabled=true` 谓词**（否则停用即 exit 78 重启环，E4 不可达）+ **health_monitor 两条既有规则 code 化（fail-loud）** + **M6a 最小两页签 + 映射只读**（否则上产后无运维入口，只能 psql/curl）。

可后续分批：M6b 映射编辑表单、M7 新增告警、M8 收口（删旧键读、wrapper code-only、文档收口）。

**M6b 缺位期的映射变更**：走 **M2 已交付的映射 API**（`POST/DELETE /api/td-interfaces/{code}/mappings`，admin token），curl 示例写进 runbook——`quant-dbro` 固定 SQL 内封、不收外部 SQL，故**不走 SQL**；进程 ≤5s 轮询生效。

**发布序列**（与 `deploy/playbooks/release.yml` 实际阶段对齐）：

0. **备份就绪检查（前置）**：确认本次 `backup_db` 产物存在、大小/时间戳正确（~998 MB）。恢复路径已演练过，不再单独演练。
1. **wrapper 先装位**：`quant-dbro`/`quant-hbcheck` 加 `TRANSITION-0189` 块（root/bootstrap），并把 `test_deploy_blast_radius` 的哨兵常量改为**列表**（当前硬编码仅 `TRANSITION-0115`，否则 0189 块无守门）。
2. 停 web / celery / hub / exec；确认无 running `live_task`。**M1 只允许盘后窗（15:05 后）；午休窗（64 min）不承接本批**——预算含备份/迁移/冒烟/观察共 ~70 min，超过午休上限。
3. **全库备份** + 校验（大小/可恢复性），保留至冒烟通过。实测：`backup_db` 产出 ~998 MB `.sql.gz`、耗时 ~4.5 min（2026-11-19）。
4. **单次发布**：`ansible-playbook release.yml -e allow_contract=true -e contract_reason="批189 接口三表拆表"`。
   - 阶段 4 破坏性 DDL 门命中 → 豁免留痕；**`auto_rollback_disabled` 由 playbook 在「豁免生效」时自动置位，操作者不传**（绑事实不绑意图，2026-10-08 定）。
   - 阶段 5 自动跑 `quant-alembic-wrapper upgrade head`——**不手工迁移**（手工会绕过门与留痕）。
5. 冒烟：§4 全链路（E1–E9）+ `/healthz` `/readyz`。
6. 观察窗 **10 min**：窗内 ≥2 个 SA4 对账周期（300s×2）+ ≥10 轮快照（60s）——**不是相加，是包含关系**；逐条验 I3/I4/I5。
7. 收窗，保留快照至下一交易日。

**回滚**：schema 不可逆，**无自动 rollback**；唯一路径 = 恢复迁移前快照 + 部署旧版代码（人工）。**该路径已演练成功（用户确认 2026-11-19），窗口内如需恢复由用户手动执行**，不再单列演练步骤。

## 5. 失败判据与决策点

| 情形 | 判据（2026-11-18 用户确认；数值唯一真源=本节） | 处置 | 决策人 |
|---|---|---|---|
| 迁移超窗 | > 10 min 未到「迁移完成」（实测：业务表千级，原 40 min 估值作废） | 中止 → 恢复快照 → 复盘 | 用户 |
| 校验失败 | 行数/FK/触发器计数不符，15 min 内不可修 | 恢复快照 | 用户 |
| 冒烟失败（可修） | E1–E9 中 ≤1 条失败且根因定位，15 min 内可修 | 窗内修复重跑，不二次迁移 | 助手 + 用户确认 |
| 冒烟失败（不可修） | 根因在 schema 设计 | 恢复快照 + 回退本批设计评审 | 用户 |
| **基线重置** | 历史无保留价值 且 备份已验证 | 见下清单 | 用户（授权兜底，非默认） |
| **观察窗** | 上产后 10 min（含 ≥2 SA4 周期 + ≥10 轮快照） | 未过 I3/I4/I5 → 按冒烟失败处置 | 助手 + 用户 |

**基线重置副作用清单（缺一不可）**：① TRUNCATE **业务表**（含 `hub_transient_subs`、`hub_shadow_symbols`）；**三张接口表保留**（重建成本高、凭证需重录），必要时 reseed 而非重建；② 仅重录失效凭证；③ 清 Redis 键族（C4 全部 + 旧形状，含 `td:exec:*`）；④ 重建 `provider_session_slot`；⑤ 停残留 unit 并确认无 running `live_task`；⑥ **时点**：窗内跑 E3/E4/E6/E7/E8，E1/E2/E5 需实时行情或交易时段 → 下一交易日开盘 30 min 内补跑并留痕；未过按冒烟失败处置。

**红线**：未备份不得迁移；备份产物须校验（`quant_*.sql.gz` 存在且 ≥900 MB、时间戳为本次）；恢复路径已演练（用户确认），恢复由用户手动执行。
