# 批189 手动交易页 UI 优化方案（待确认）

> 现状：功能可用，但结构/表单/状态展示未遵守 D24 页面规范；本文只出方案，确认后改。

## 1. 现状违规（逐条对照 D24）

| # | 现状 | 规范 | 影响 |
|---|---|---|---|
| 1 | 裸 `el-card` + 自定义 header（页面名 + hint） | D24 §8.4：唯一结构组件 = `ContentCard`（卡头=标题+actions）；§8.3.1 页面无标题 | 与其他页结构不一致；hint 混进卡头 |
| 2 | 自定义 `.mt-label` + el-row 拼表单 | `el-form`（label/必填/校验/错误位） | 无统一校验态；窄屏断行不齐 |
| 3 | 行情/盘口手写 flex 行，无表头/列对齐 | 数字列右对齐、`--font-num`、min-width+ellipsis（§4.3/§6.5） | 档位/价格/量对不齐 |
| 4 | `el-empty :image-size="50"` | 统一 `EmptyState` 组件 | 空态样式分裂 |
| 5 | 回执用裸 span + 三元 `:type` el-tag | §9.3 状态走 `StatusTag`；禁止行内三元上色 | 状态色漂移、不可本地化 |
| 6 | 提交/重置按钮直接并排；hint 常驻 | 工具栏排布 §7.4；动作归位 §8.3.3 | 操作区不统一 |
| 7 | 图表固定 340 高、17/7 栅格 | 1280×800 最低视口走查 §6.6 | 1280 下盘口过窄 |
| 8 | 价格固定 3 位小数 | 按标的最小价位（tick_size）格式化 | 不同品种显示不一致 |

## 2. 目标结构（D24 两层）

```
页面（菜单「手动交易」，无标题）
└─ ContentCard title=t('manualTrade.cardTitle')   actions: [刷新 IconBtn]
   ├─ 卡体
   │  ├─ el-form（label-position=top，5 项：接口/标的/方向/数量/价格）
   │  ├─ 行情区（card-grid 内嵌，shadow=never 合法）
   │  │   ├─ 左：日K/分时切换（el-radio-group size=small + v-chart）
   │  │   └─ 右：L1 五档盘口（table：档位/价格/量；整行可点/键盘可达）
   │  ├─ 操作区：[下单 primary] [重置]   （窄屏主按钮整行）
   │  └─ 回执：StatusTag + el-descriptions（请求号/委托号/数量/价格/原因）
```

## 3. 具体改法

1. **结构**：`el-card` → `ContentCard`；卡头 hint 移除，改为标的输入下的 `form-item` 帮助文案或 tooltip；页面不再出现"手动交易"标题（菜单即语境）。
2. **表单**：改 `el-form` + `rules`（必填/数量 100 整数倍/价格>0）；错误就地显示，不再只靠 ElMessage。数量后缀用 `append` 显示基本单位。
3. **盘口表**：改为 `<table>` + 表头（档位/价格/量），价格列 `font-family: var(--font-num)` 右对齐；整行 `role="button"` + tabindex + Enter 触发，保留鼠标点击。
4. **状态**：回执改 `StatusTag`（状态→语义色映射集中）；补充 `part_cancelled` 等新状态的文案与颜色。
5. **空态/加载**：`EmptyState`；图表加载态用统一 `v-loading` 容器（高度令牌类）。
6. **响应式**：≥1707 左 16/右 8；1280–1706 左 18/右 6 或上下堆叠；<1280 行情与盘口上下排；主按钮窄屏整行。
7. **数字格式**：价格用 `tick_size` 精度；量/额用现有 `fmt*` 工具；全部数字列右对齐。
8. **令牌/守门**：零新增内联 px/hex/font-size；不新增 `<el-tag :type="…?">`；pageshell R1/R2、tokens、i18n 三语、孤儿词条门全过。

## 4. 需你拍板的 3 点

1. **卡头标题**：A「手动下单」/ B「委托下单」/ C「下单」。
2. **行情与盘口**：A 同卡内左右并排（推荐）/ B 两张独立小卡 / C 上下排。
3. **下单按钮**：A 与重置并排（推荐）/ B 主按钮整行常驻（更防误触）。

### 单行宽度预算（px，含 label+间距）
| 元素 | 宽度 | 说明 |
|---|---:|---|
| 接口 | 144 | label 28 + 4 + select 112 |
| 标的 | 200 | label 28 + 4 + select 168 |
| 方向 | 136 | label 28 + 4 + radio 104（两个 52） |
| 数量 | 152 | label 28 + 4 + input 120（内嵌单位「股」） |
| 价格 | 152 | label 28 + 4 + input 120 |
| 下单+重置 | 128 | 64 × 2 |
| 组间距 | 48 | 6 × 8 |
| **合计** | **960** | |

- 1920：可用 ≈1608，余量 648；
- 1280（侧栏 64）：可用 ≈1144，余量 184；
- 因此 ≥1280 强制单行（`flex-wrap: nowrap`）；仅在 <1280 才允许换行。
- 「刷新」放卡头 actions，不占工具条宽度。
- 盘口固定 240px（1280 收 200px），行情 `flex:1; min-width:0`。
- 按钮与表单同排右对齐；下方只留状态行（StatusTag + req/vt/量价/原因）。

## 7. 验收

- 1280×800 与 1920 两档走查：无横向滚动、盘口三列对齐、主按钮可达；
- build 全门绿；
- 下单成功/失败/拒单回执在 StatusTag+descriptions 正确显示；
- 不改后端与提交语义，仅展示层。
