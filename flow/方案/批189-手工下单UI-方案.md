## 2. 后端契约（已实现，UI 严格遵守）

`POST /api/manual-order`（`require_perm("trade")`）：
```json
{
  "account_id": "td-xtp",          // 动态下拉选 td-* code（非 int）
  "symbol": "603118.XSHG",         // 手输归一为 .XSHG/.XSHE（SM 主档键；不可用 .SZSE）
  "action": "BUY" | "SELL",
  "volume": 100,                   // 基本单位：A股=股、可转债=张、场内基金=份、加密=币/张
  "price": 13.01,                  // 限价
  "confirm": "CONFIRM",            // 二次确认，服务端钉死
  "client_order_id": "可选"         // 幂等键
}
```
返回 `{status: accepted|rejected|dispatched, req_id, account_id, vt_orderid, volume, price}`（同步最多等 5s 受理回执，超时 dispatched）。
`GET /api/manual-order/{req_id}`：查回执（dispatched 时前端 1s 轮询最多 5s）。

## 3. 手动交易页布局（内嵌，用户确认）

单页两栏布局（左：下单+行情；右：L1 盘口，与主流股票软件一致）：

```
┌─ 手动交易 ────────────────────────────────────────────────┐
│ [接口] td-xtp ▼(动态)  [标的] 603118 ▼(手输+代码提示)      │
│ ┌─ 行情区（同一空间，按钮切换 日K/分时）─────┐ ┌─ L1 盘口 ─┐ │
│ │ [日K] [分时]                                │ │ 卖5..卖1  │ │
│ │ (K线: getKline / 分时: stockIntraday)       │ │ ——现价——  │ │
│ │ 分时横轴: 固定 09:30-11:30 + 13:00-15:00     │ │ 买1..买5  │ │
│ │ 两段拼接共 4h；仅显示 1 天                   │ │ (全部可点)│ │
│ └─────────────────────────────────────────────┘ └───────────┘ │
│ [方向] 买入● 卖出○  [数量] ___ (基本单位)  [价格] ___ (可点盘口自动填入) │
│ [下单] [重置]                                                  │
│ ── 最近回执 ── status/req_id/vt_orderid/成交价/错误码          │
└────────────────────────────────────────────────────────────────┘
```

**交互要点**
- 接口：`GET /td-interfaces` 动态下拉，只列 enabled + execution 行，默认 td-xtp。
- 标的：手输 + 代码提示（复用 `stock/search`），归一 `.XSHG/.XSHE`；输入后触发行情加载。
- **行情区**：`klineMode` 切换（复用 StockDetail.vue 现成样例：`getKline` 日K / `stockIntraday` 分时）；**分时横轴固定 4 小时两段拼接**（09:30-11:30、13:00-15:00），仅 1 天——在 intradayOption 上把 `p.t` 重映射到固定时段轴（现成样例是数据时间直接映射，此处按用户要求改）。
- **L1 盘口**：复用 `stockDetail` 的 `quote.bid/ask`（五档），**每行价格全部可点击 → 自动填入价格输入框**（click → `price = 档位价`）。
- 数量：**基本单位**（A股=股、可转债=张、场内基金=份、加密=币/张），提交时不做 ×100 换算。
- 下单：二次确认弹窗复述全部字段 → 带 `confirm:"CONFIRM"` 提交；`dispatched` 轮询回执；失败 reason 上屏；订单表/事件时间线联动刷新。
