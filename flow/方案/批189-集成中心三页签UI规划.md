# 批189 集成中心三页签 UI 规划（数据源 / 行情接口 / 交易接口）

> 状态：**待用户确认**。输入：旧 `InterfacesCard`（83a 终态 UI）、批189 需求 §M6a、A02 外部接口模型（行=接口/能力派生/身份=code）、M2 API 契约、M6b 两轴状态。
> 原则：**不重造，恢复旧 UI 的成熟件**（RowFilter/ColumnSettings/IconBtn/类型化表单/列显隐），只按新实体模型换列与动作。

## 1. 三页签共同骨架

- **行 = 接口**，主键/展示身份一律 `code`（`ds-*/md-*/td-*`）；`name` 仅人类可读别名。
- 工具栏：`RowFilter`（能力 + 状态 + 市场）→ `ColumnSettings` → `IconBtn(Refresh)` → `IconBtn(Plus)`；筛选/显隐按 kind 各存一份 storage-key。
- 表格：`TableShell`（列显隐/分页/空态），列宽 `min-width`+溢出 tooltip；操作列统一 `IconBtn small`（测试/编辑/删除）。
- 状态两轴：**运行轴**（进程/工作/连接/心跳，来自 `/api/interfaces/status`）与**配置轴**（载体/凭证/映射，`config_ok/config_missing`）分列展示，不合并成一个模糊「状态」。
- 表单：provider 先选（新建时页签选择）→ 按 manifest `FIELD_SCHEMA` 生成凭证/参数字段；**禁止裸 JSON textarea**；密钥只写不回显（留空=不改）；code 创建后不可改。

## 2. 各页签内容

### 2.1 数据源（ds）

| 列 | 内容 |
|---|---|
| code / 名称 / provider / 市场 | 身份与归属 |
| 能力 | manifest 派生，只读 tag（hist_quote/ref_data/inst_event…） |
| 凭证 | 有/无（不显示明文） |
| 启用 | 开关（写权限） |
| 更新时间 | `YYYY-MM-DD HH:mm` |

动作：测试连通、编辑、删除。无进程/心跳轴（数据源是任务拉取，不是常驻行）；页面底部保留既有**限速面板**（DataSources.vue 原特有件，不能丢）。

### 2.2 行情接口（md）

| 列 | 内容 |
|---|---|
| code / 名称 / provider / 市场 | 身份与归属 |
| 能力 | manifest 派生只读（rt_quote/hist_quote…） |
| 载体 | 有插件/待接入（取自 provider ready，不再用裸文本「就绪」） |
| 运行 | 进程 ✓/✗ · 工作中 · 已连接 · 最后 tick 年龄 |
| 启用 / 凭证 | 开关 + 有/无 |
| 被引用 | 哪些 `td-*` 通过 `td_md_map` 引用我（只读反查，替代当前 expand 里的映射行） |
| 更新时间 | `YYYY-MM-DD HH:mm` |

动作：测试、编辑、删除。映射在 md 侧**只读**（编辑归 td 侧）。

### 2.3 交易接口（td）

| 列 | 内容 |
|---|---|
| code / 名称 / provider / 市场 | 身份与归属 |
| 账号 | `account_key`（脱敏）；virtual 行显示「虚拟/纸面」tag |
| 载体 | 有插件/待接入 |
| 运行 | `td_exec` 心跳：运行/工作/连接/心跳年龄 |
| 配置 | `config_ok` 或缺失项（载体/凭证/映射）——两轴分开，不再混入运行列 |
| 启用 / 凭证 | 开关 + 有/无 |
| 取价映射 | 主备摘要（`md-a p1 / md-b p2`）+ `IconBtn` 编辑入口；无映射显示「缺映射」警告 |
| 更新时间 | `YYYY-MM-DD HH:mm` |

动作：测试、编辑、**编辑映射**、删除。映射弹窗保留 M6b 逻辑（按市场过滤、读失败禁编辑、priority 1..99 唯一、二次确认）。

## 3. 删除/回退项（当前 M6a/M6b 实现里的乱源）

1. 删 `impl` 列（实现细节，不属于运维决策面；需要时放编辑弹窗只读）。
2. 删裸 JSON 凭证/参数输入 → 恢复 manifest 动态字段。
3. 删 expand 里的「映射只读 + 编辑」混排 → md 用「被引用」列；td 用「取价映射」列 + 弹窗。
4. 删手写中文标签/裸 `el-button link` → i18n + IconBtn + RowFilter/ColumnSettings。
5. 不再单独做「状态卡」重复表内状态：状态列即只读卡，避免两处真源。

## 4. 实施顺序（确认后）

1. 抽公共 `InterfacesTable`（kind 参数化，列集按 kind 声明）；
2. 恢复 RowFilter/ColumnSettings/IconBtn/TableShell 与 typed form；
3. 接 `/api/interfaces/status` 两轴 + md 反向引用、td 映射摘要；
4. 三页签验收：列/动作/权限/i18n 三语/D24 三闸/build；staging 彩排后上产。

## 5. 验收口径

- 任一页签不出现裸 JSON 输入、`impl` 列、重复状态卡；
- 每行能回答：是什么（code/name/provider/market）、能不能跑（载体/凭证/启用）、在不在跑（运行轴）、依赖谁（映射/被引用）；
- 读接口 `read`、写接口 `system_config` 与旧 UI 一致。
