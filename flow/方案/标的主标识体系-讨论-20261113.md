# 标的主标识体系 · 归一设计（已实施）

> 定稿 2026-11-13，实施并上产 2026-11-13/14（批 175，175a/b/c/d 四次独立上产）。本篇＝**实施后终态**。
> 关联：A03（映射住代码/偏好住 DB）、D32 §四（InstrumentSpec）、批131（vt 正名）、批173/174（`.SSE` 漏口实证）。

## 一、终态一句话

外部异构后缀（tushare `.SH`、聚宽 `.XSHG`、vnpy `.SSE`）**只活在 adapter 边界**；进入平台即归一为 canonical vt（`.SHSE/.SZSE/.BSE`）；持久层只存 canonical + `mic_code`；`security_master` 的品种/板块/每手数是独立字段，不靠后缀判断。

## 二、分层与真源

| 层 | 形态 | 落点 |
|---|---|---|
| 入站别名（唯一表） | `SH/SZ/BJ/XSHG/XSHE/SSE/SZE` → vt；`BINANCE/OKX` 直通 | `quant_common/symbology.py` `_VENDOR_ALIASES` |
| internal canonical | vt `.SHSE/.SZSE/.BSE` | bar PK / Subscription / pool / DataBus / 委托 / 持仓 |
| venue 标识 | ISO 10383 MIC：`XSHG`/`XSHE`/`BJSE` | `security_master.mic_code`（crypto NULL） |
| 出站映射 | vt → 源格式 | 各 adapter `to_source_symbol`（沿用批131） |
| 品种/规则 | category / board / multiplier(每手数) / tick_size / trade_phase / sellable_rule | `security_master`（0092+0097+0176） |

`symbology` 提供：`canonical()`（任意已知形态→vt，**裸码/未知后缀抛 ValueError，禁猜**）、`to_mic()`（crypto→None）、`split_raw()`、`aliases()`（**双向**：`SHSE↔SSE`，过渡期与历史行查询用；裸码返回原值不抛——调用方在 fail-closed 截断路径上，抛错会变成按原量提交）。

## 四、守门（防退化）

- `canonical` 全表双向 + 裸码/未知抛错 + 幂等；`aliases` 双向集合（深市/加密单值）。
- **基线棘轮**：全仓 `"SSE"→"SHSE"` dict 字面量 `_BASELINE_COUNT = 0`（只降不升，新增即红）。
- `mic_code` 用**字面量期望表**（`600036.SHSE→XSHG` 等；crypto 用 `IS NOT DISTINCT FROM`）——不用 `to_mic(vt)==mic_code` 自证（XSHG/XSHE 互换也会绿）。
- 正向控制：mock XTP 返 `.SSE` Position → `translate.to_position` 断言 `.SHSE`；`_flush_positions` 落库参数断言 `.SHSE`。
- DB 硬闸：`ck_position_snapshot_no_sse`（0182 起）。
- `_flush_positions` 撞 `CheckViolation` 时记 **error**（不与瞬时网络错同列 warning——否则快照静默冻结不可见）。

## 五、迁移与回滚

- 0181（expand）：`upgrade` 加列回填 + 去重归一；`downgrade` 仅 `DROP COLUMN mic_code`，**symbol 数据不回写**（`.SHSE` 无法区分源，回写会误改本来就是 `.SHSE` 的行）。
- 0182（contract）：`upgrade` 首句**前置断言**（存量仍有 `.SSE` 即 abort，不留静默冻结）；`ADD CONSTRAINT ... NOT VALID` 后 `VALIDATE` 走 `autocommit_block`（否则 ACCESS EXCLUSIVE 从 ADD 持到 VALIDATE 结束，非"短锁"）；`downgrade` **DROP CONSTRAINT**（禁 no-op——否则回滚后每次快照写批违约束被吞、永久停更）。
- **回滚 175d 必须手工 `alembic downgrade 0181`**：`rollback-tasks.yml` 只回代码、schema 不回退。

## 六、两条有意为之的取舍

1. **`markets.EXCHANGES` 不补 `SSE` 键**：`market_of_symbol` 对未知后缀缺省 `astock`（`.SSE` 已正确归 astock）；补键会污染 `mgmt` 的"市场可选交易所"枚举与 `_VALID_EXCHANGES` 校验，让 `SSE` 成为合法配置值。默认值已覆盖，故保持手写字面量三键。
2. **`market_of_symbol`/`_market_of`/对账 `split_part` 仍按后缀**：改读 `security_master` 会让 hub 每标的查询成为 N+1，收益不抵成本；SM 化单独立项。

## 七、不做（明确记录）

- surrogate 主键 + 拆 `raw_code`/`venue_suffix`：`vt_symbol` 被 bar PK/订阅/委托全引用，改造面极大；单市场单账户，跨市场串号已由 `account_id`+`category` 隔离。
- 全面以 MIC 做路由/主键：MIC 标识 **venue**（同所全部证券共享），不是证券主键；证券级唯一标识是 **ISIN（ISO 6166）**，当前无跨源对齐需求，按需再立项。
- `order_log` 加 `symbol_canonical` 列：`GENERATED STORED` 会全表重写 + ACCESS EXCLUSIVE 锁，且 `migration_policy` 不识别重写；读侧用 `replace(symbol,'.SSE','.SHSE')` 表达式，历史 symbol 不动（审计史不篡改）。

## 八、外部资料核实（官方 CSV 定案，供后续接入参考）

官方源：`docs/reference/iso/ISO10383_MIC.csv`（2893 条）。

- ✅ `XSHG`=上交所、`XSHE`=深交所、**`BJSE`=北交所**；`CCFX` 中金所、`XSGE` 上期所、`XDCE` 大商所、`XZCE` 郑商所、`GFEX` 广期所、`NEEQ` 新三板、`XCFE` 外汇交易中心、`SGEX` 上海金交所、`XHKG` 港交所、`XJPX`/`XTKS` 东京、`XKRX` 韩国、`XTAI` 台湾、`XLON` 伦敦、`XSWX` 瑞士、`XSTO` 斯德哥尔摩、`XNYS`/`XNAS` 美国。
- ❌ 常见误传：`XNEE`＝**新西兰** NZX 期货期权交易所、`XBSE`＝**罗马尼亚** BVB（都不是北交所）；`.SS` 不是瑞士（Yahoo 的**上交所**后缀，瑞士是 `.SW`）；`.JP` 不成立（Yahoo `.T`、Bloomberg `JT`）。
- 概念澄清：MIC 是 **venue 标识**，不是证券主键；`.SH/.SZ/.BJ` 是国内量化社区约定，非 ISO 标准。
