## 一、结论

项目**已是分层结构**（内部 canonical vt + 供给面 symbology 映射 + `security_master` 品种字段），不是"裸放一个字符串"。真缺口：**① 无 `mic_code`；② vnpy 运行时 `.SSE` 漏进持仓表；③ 仓内已有 4 处后缀映射（收编前不能新增第 5 处）**。

## 七、外部资料核实备注（官方 CSV 一锤定音）

- ✅ 可信：ISO 10383 MIC 真实存在；`XSHG`=上交所、`XSHE`=深交所（venv 聚宽 41 处佐证）；`.SH/.SZ/.BJ` 是国内约定非 ISO；后缀不区分品种；同代码跨市场；每源需独立映射。
- ❌ 错：① `.SS`=瑞士 SIX——`.SS` 是 Yahoo 的**上交所**后缀（`600000.SS`），瑞士是 `XSWX`（`.SW`）、斯德哥尔摩 `XSTO`；② **"MIC=唯一主键"概念错**——MIC 标识 venue，同所全部证券共享；证券主键是 **ISIN（ISO 6166）**/FIGI/surrogate；③ **`XNEE`=新西兰** NZX 期货期权交易所，北交所是 **`BJSE`**（`XBSE`=罗马尼亚 BVB）；④ `.JP` 不稳（`XJPX`/`XTKS`、Yahoo `.T`、Bloomberg `JT`）。
- ⚠️ 拼凑：国际后缀表混 Bloomberg/Yahoo 两套；漏 ISIN。

## 八、边界归一原则（修正版，已吸收双盲审 12 条 P0）

### 8.1 原则：合适，但补两点
✅ 行业标准「防腐层/端口适配器」。补正：① **vnpy 运行时也是外部边界**（`.SSE` 漏口在此）；② **"统一成国标"用词不准**（国内无国标；标准是 ISO MIC[venue]+ISIN[证券]），且**不能只统一后缀**（分层：venue→MIC、证券→ISIN/surrogate、业务键→vt）。

### 8.2 四层落地

**L0 canonical 单点——搬迁并入（不是新增第 5 份，审官 A2/B1）**
- `symbology.py` 收编：`VT_TO_MIC={SHSE:XSHG,SZSE:XSHE,BSE:BJSE}` + `_VENDOR_ALIASES`（含 `SSE`、`SH/SZ/BJ`、`XSHG/XSHE`、**`BINANCE/OKX` 直通**）+ `canonical()/to_mic()/split_raw()`。
- `schema.py`（`TS_EXCHANGE_MAP`/`to_vt_symbol`）、`markets.EXCHANGES`、`strategy._VT_EXCHANGE_ALIASES` 改为**从 symbology re-export/派生**。
- `canonical` 对**裸码（无后缀）抛 ValueError**（禁猜）；`to_mic` crypto→None。
- **AST 守门**：除 `symbology.py` 外全仓禁 `"SSE"→"SHSE"`/`"XSHG"` 字面量映射。

**L1 入站归一（只动交易侧，2 文件，审官 B9）**
- `providers/xtp/translate.py` 三处（`to_order_state/to_trade/to_position`）**先取 `d.vt_symbol`**（`d.symbol` 是裸码，直接 canonical 会抛错并崩 on_order 回调线程）；缺失时 `symbol+"."+exchange.value` 拼。
- adapter 面已有 `to_vt_symbol`，经 L0 re-export，**不叠第二层 `normalize_symbol`**（A10/B9）。
- 守门：喂**无 `vt_symbol` 的真 vnpy Order 形状**断言不抛；喂 `.SSE` Position 断言 `=="600036.SHSE"`。

**L2 出站（已有，保持）**：`to_source_symbol(vt)→源格式`，共享 symbology 别名表。

**L3 持久化只存 canonical + 结构化字段**
- `security_master.mic_code`（expand + 回填；crypto NULL）。
- `position_snapshot` 存量迁移：**先按 `(account_id,direction)` 保大去重 DELETE，再 UPDATE `.SSE→.SHSE`**（否则撞唯一键 `(account_id,symbol,direction)`，迁移 abort——审官 B4）。
- `order_log` 不改历史 symbol；`symbol_canonical` 用 **`GENERATED ALWAYS AS (replace(symbol,'.SSE','.SHSE')) STORED`**（零写侧、不可漂移——审官 A5/B5：普通列会因 3 个 INSERT 点漏写恒 NULL）。
- 显示：`/api/position`、`/api/orders` 读侧输出 canonical（前端字段不变）。

### 8.3 守门（防退化）
- **正向控制**（非"查现表 0 行"——空表必自绿）：mock XTP 返 `.SSE` Position → 跑 `_flush_positions` → 断言落库参数 `.SHSE`。
- **DB 硬闸**：`CHECK (symbol NOT LIKE '%.SSE') NOT VALID` → `VALIDATE`。
- `security_master` 用**字面量期望表** `{"600036.SHSE":"XSHG","000001.SZSE":"XSHE","830799.BSE":"BJSE"}`（**不用 `to_mic(vt)==mic_code` 自证**，XSHG/XSHE 互换也全绿）；crypto 用 `IS NOT DISTINCT FROM`。
- `canonical` 全表双向 + 裸码/未知抛错 + 幂等；新 adapter 校验**入口实际调 canonical**（A6）。

### 8.4 落地顺序（**175b 与 175c 必须同版本上产**）

|---|---|---|---|
