# 标的主标识体系 · 归一设计（已实施，canonical = ISO 10383 MIC）

> 定稿 2026-11-13；**2026-11-14 用户裁定改口径**：内部 canonical 由 vt（`.SHSE`）**全量切 ISO MIC**，
> crypto 每所一个自定义码。批177 实施并上产（0183/0184/0185 三次迁移）。
> 关联：A03、D32 §四、批131、批173/174/175、官方 `docs/reference/iso/ISO10383_MIC.csv`。

## 一、终态

外部异构后缀（tushare `.SH/.SZ/.BJ`、聚宽 `.XSHG/.XSHE`、vnpy `.SSE/.SZSE/.BSE`、旧项目 vt）**只活在边界**；
进入平台统一为 **MIC 形态**；持久层只存 MIC；展示/API/因子/策略/回测/实盘同一口径。

| 市场 | canonical | 依据 |
|---|---|---|
| 上交所 | `600036.XSHG` | ISO 10383 MIC |
| 深交所 | `000001.XSHE` | ISO 10383 MIC |
| 北交所 | `830799.BJSE` | ISO 10383 MIC |
| 币安永续 | `BTCUSDT.XBIN` | **自定义**（已核 ISO 表未占用） |
| OKX 永续 | `BTCUSDT.XOKX` | **自定义**（同上） |

## 二、分层

| 层 | 形态 | 落点 |
|---|---|---|
| 入站别名（唯一表） | `SH/SZ/BJ/XSHG/XSHE/BJSE/SSE/SHSE/SZSE/BSE/BINANCE/OKX` → MIC | `quant_common/symbology.py` |
| 内部 canonical | MIC（crypto 自定义码） | bar PK / 订阅 / 委托 / 持仓 / 风控 / 池 / 回测 / 因子缓存 / 对账 |
| vnpy 边界 | 入站：`translate` 三态 → MIC；出站：`td.send`/`md_gateway`/`EMT` 把 MIC 拆成「裸码 + Exchange 枚举」 | `providers/xtp/*`、`strategy_framework/adapters.py` |
| 出站映射 | MIC → 源格式 | 各 adapter `to_source_symbol` / `schema.to_ts_code` |
| 品种/规则 | category/board/multiplier/tick_size/… | `security_master`（`exchange`/`mic_code` 同为 MIC） |

`symbology` API：`canonical()`（任意已知形态→MIC，裸码/未知抛）、`vt_suffix()`（仅交易所维度）、
`to_mic()`（crypto→None）、`split_raw()`、`aliases()`（多写法候选，兼容历史行）。

## 三、迁移（三次，均为 expand/数据型）

| 版本 | 内容 |

- `test_web_symbol_display`：前端禁剥后缀（含正向探针）；选股**四条**返回路径逐条断言 `vt_symbol`。
