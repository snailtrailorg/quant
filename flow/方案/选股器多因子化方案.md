# 选股器多因子化总体方案（v2 终稿——2026-11-02 用户终裁）

> v1 讨论稿已被本版取代（v1 全文 git 史 fcacf52）。
> 终裁要点：三期实施；筛选器=上双页签（普通条件构建 / 高级 DSL）+下已存方案列表；所有筛选方案（图形化或 DSL）统一保存/加载；编码按三期分批。

## 一、目标形态（用户裁定 UI）

```
选股器（Screener，容器页·品类页签）
 ├─ 品类页签：A股 / 可转债 / 场内基金（现有三屏，§8 形态不变）
 │   每屏左侧筛选器区：
 │     ├─ 上：两个页签
 │     │   ① 普通条件（条件构建器：行式 字段↓+操作符↓+数值+行逻辑，预置 2-3 模板可另存）
 │     │   ② 高级（DSL 表达式：Filter 布尔式 + 可选 Rank 表达式）
 │     └─ 下：已保存筛选方案列表（名称/品类/来源(普通|DSL)/更新时间；点击加载、可删）
 │   右侧：结果表（现有形态）+存池按钮
```

## 二、核心机制（三期共用基建）

### 1. 字段注册表（screen_field_registry）——构建器与 DSL 共同的字段单源
- 按 category 注册（astock/cb/fund）：字段名/中英文标签/数据列或预计算表达式/类型/分组（估值/规模/技术面/质量）
- 预计算字段（动量/分位等）由后端管道生成（选股时算一次落 screen_factor_cache，非每查现算）
- 加品类=加字段集行+测试断言（与 DataKind/SM 注册纪律同构）

### 2. 筛选方案（screen_preset 表）——统一保存面
- 列：id/name/category/source('builder'|'dsl')/definition(json)/created_by/updated_at
- definition：builder 式={rows:[{field,op,value,logic}],match:'all'|'any'}；dsl 式={filter:expression,rank?:expression}
- 出厂预置=种子数据（source='builtin'，只读；用户另存为新方案）
- API：CRUD（require_perm('read')读写面）

### 3. 条件→SQL 编译器（后端）
- 字段注册表驱动：field→列名/表达式+类型校验；op 白名单（= != > >= < <= in percentile_top percentile_bottom）
- **全程参数化查询**（op 与列名白名单映射，值绑定）——注入面封死
- DSL 式走 _safe_eval 同沙箱（AST 白名单+500 字符+横截面函数 rank/zscore/quantile 入白名单）

### 4. 横截面 DSL（期 3）
- CrossSectionContext：每标的一行（快照列+预计算因子列）；复用 _safe_eval/_DT_FUNCS/窗口函数语义
- 前视防护：统一截至 T-1 收盘口径

## 三、三期划分（每期独立可用，编码分三批走八步法）

| 期 | 内容 | 交付 |
|---|---|---|
| **期 1（批 164a）** | 字段注册表+预计算管道+A股屏开闲置字段（pe_ttm/circ_mv/dv_ratio/ps+ST/上市天数过滤）+cb/fund 补 2 项 | 字段集厚起来（构建器弹药）；纯后端+三屏小改 |
| **期 2（批 164b）** | 条件构建器（行式四段+满足全部/任一）+screen_preset CRUD+方案列表 UI+出厂预置种子+左筛选区双页签骨架 | 图形化筛选终态 |
| **期 3（批 164c）** | 高级 DSL 页签（Filter+Rank 表达式+横截面函数+沙箱）+DSL 方案保存/加载+（可选）加密品类第四屏 | 灵活选股终态 |

## 四、范围与非目标

- 不动：DataKind/SM/pools/pool_symbols/三屏右表与存池链/策略绑定
- 非目标（v1 遗留讨论不再做）：L2 拖拽嵌套分组（满足全部/任一已够——歧义零成本方案）；池快照 diff 通知（另立项）
- 前端遵循：§8 v2（页签裸放+内容卡）/§9 组件（RowFilter 风格行控件、ContentCard 方案列表卡）

## 五、验收要点
- 期1：新字段三屏可用+预计算管道有缓存表+注册表测试断言绿
- 期2：构建器方案存/取/删/载全链+出厂预置只读+参数化查询（注入负测试）
- 期3：DSL 与构建器方案同列一表互通加载+_safe_eval 沙箱（越权函数负测试）+T-1 口径断言
