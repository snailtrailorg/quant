## 三、发现（按严重度）

### P0-1 读侧未实现，且文档声称已做（失真）
- 事实：`/api/orders` 走 `web_api/routes/trading.py:637` `SELECT ... FROM order_log`，原样返回 `.SSE`（prod 实测 72/100 行）；`src` 内无任何 `replace(symbol,'.SSE','.SHSE')`。
- 与文档冲突：`flow/方案/标的主标识体系-讨论-20261113.md` §七、`docs/architecture/接口契约.md` 均称"读侧用 replace 表达式"。
- 影响：用户在委托列表/导出仍看到沪市双写，"显示正规"未达成；跨表对不上（持仓 `.SHSE` vs 委托 `.SSE`）。
- 修法（1 行 + 守门）：`trading.py:637` 改为 `replace(symbol,'.SSE','.SHSE') AS symbol`；补一条断言"读侧不含 `.SSE`"的正向测试。

### P0-2 守门有盲区，「唯一别名表」目前只是名义
- 事实：现存 4 处 symbology 之外的 SSE 语义点，且**全部落在棘轮漏检形态**：
  1. `strategy_framework/adapters.py:240` `{"SHSE": Exchange.SSE, "SSE": Exchange.SSE, ...}`（枚举值 dict）
  2. `md_hub/parts.py:36` `f"{sym}.{'SHSE' if ex=='SSE' else ex}"`（内联 if）
  3. `scheduler/tasks.py:2485` SQL `CASE WHEN 'SSE' THEN ... '.SH'`
  4. `data_platform/adapters/base.py:252` 白名单 `{"SHSE","SZSE","BSE","SSE","SH","SZ","BJ"}`
  （另有 `schema.EXCHANGE_TS_MAP["SSE"]="SH"`＝出站，合法；前端 `LiveTask/PaperTrade` 的 `EX` 表＝UI 转换）
- 影响：新增第 5 份映射不会被发现——守门"看起来绿"但不防退化。
- 修法：扩扫描到 ①任意 `ast.Constant=='SSE'` 出现在 dict key/比较字面量（正反例都测）②白名单式集合；或更严：这些点改为调用 `symbology`，棘轮降为纯回归网。

### P1-1 `mic_code` 只写不读
- 事实：`src` 内 `mic_code` 零命中；`InstrumentSpec` 未暴露；无 API 返回。
- 影响：目标"入库与显示正规"只完成入库一半；列暂时是死数据。
- 选项：① `InstrumentSpec` 加 `mic_code`（读表，1 处 + 缓存随 `cfg:version`）② 明确写"仅存储备用，P4 EMT 启用"（改文档）。

### P1-2 legacy 路径未归一（P4 前必须补）
- 事实：`position_snapshot` **唯一写入点** `trading._flush_positions`，入参来自 `adapter.query_position()`。插件路径经 `translate`（已归一）；legacy 路径 `legacy_translate.to_domain_position` 直接透传 `p.symbol`——vnpy `PositionData.symbol` 是**裸码**（`600036`），`adapters.py:897` 则拼 `_ex_suffix`。
- 影响：0182 只挡 `.SSE`，**裸码能静默写进去** → 对账/订阅 join 全部落空；EMT（P4）一旦接入即中。
- 修法：在 `_flush_positions` 入口统一 `canonical()` 兜底（单一咽喉 1 处，失败即 log error 不写坏行），比逐 provider 补更稳。

### P1-3 文档三处与代码不符
1. 方案 §七「读侧 replace 表达式」→ 未实现（见 P0-1）。
2. 归档任务文件 §49「`EXCHANGES` 补 `SSE` 一行」→ 实际有意不补（终态文档已说明，归档件保留计划态属正常，但读者易误解）。
3. `symbology.py:9` docstring「过渡期 `position_symbol_candidates` 仍需要」→ 该函数已删。

## 四、判定

**不彻底**。L0/L3 主体与迁移工程是干净的（C3/C6 数据/C7/C8 PASS），但有 **2 个 P0（读侧未实现且文档失真、守门盲区）+ 2 个 P1（mic_code 无读者、legacy 路径未归一）+ 1 个 P1 文档失真**。

最小补丁集（建议同批）：
1. `trading.py:637` 读侧 replace + 守门（P0-1）
2. 棘轮扩形态 / 或把 4 处 ad-hoc 映射收编进 symbology（P0-2）
3. `_flush_positions` 入口 canonical 兜底（P1-2，收益最高：一次堵住所有 provider）
4. `mic_code` 要么暴露要么明写"备用"（P1-1）
5. 三处文档措辞（P1-3）
