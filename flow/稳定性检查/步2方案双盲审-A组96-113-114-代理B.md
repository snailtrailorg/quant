## 总评

96、113 是纯实施、判据方向正确，无 P0（P1 各有处置）→ 有条件过门。114 有一处**契约不闭合**（P0）→ 不过门，须返工定接口。三批共同问题是「前端组件测试」验收引用了不存在的 harness。

## 致命（P0）

**P0-1｜批114 接口契约不闭合（跨任务数据无接口）。**
「角标数＝F1 未闭合行数」+「点击目标＝冻结任务列表/下拉」是**跨任务**数据，但主案仅暴露 per-task `GET /api/live-task/{tid}/freeze-events`（`server/src/web_api/routes/trading.py:287`）；`list_events(task_id=None)` 支持跨任务但**无 HTTP 暴露**（批76b §2.3 自认）。方案 接口契约 写「复用主案冻结列表读取接口，**不新增**」＝引用不存在的接口，且与产出 1/3 自相矛盾。走 N+1（逐任务拉 freeze-events）又违反 76b §2.1 明令的 N+1 禁令。⇒ **必须返工**：新增跨任务端点（`GET /api/live-task/freeze-events` 或 `GET /live-task` 带 open_freeze 聚合）并重写契约。

## 严重（P1）

**P1-96a｜测试改动识别不全，验收「全绿」自相矛盾。**
`server/tests/test_tier_freshness.py` 有 4 处硬编码 concept_sync/9 表：`:22` `_fresh_tier1_rows`、`:135`、`:157`（`"concept_sync" in ids`）、`:158`（`== 9`）。产出 4 只写「长度断言（若有）9→8」——位置、数量、性质（功能性非长度）全错。不修 `:157/:158` 则 `pytest tests/ -q` 必红，与验收第 1 条冲突。且 `test_disabled_sync_excluded_from_stale` 的 premise 靠 concept_sync 当「停采示例」，移除后测试变**空转**（enabled 集 8=全，无停采项），须换一 sync 当停采示例。
**处置**：逐条列出 4 处测试改动，`_fresh_tier1_rows` 改 import `TIER1_SYNC_IDS`（消第二真源）而非手写。

**P1-96b｜「清理 TRANSITION-0129 分支（:450,463）」歧义且危险。**
`skip_disabled/enabled_ids` 是**通用 guard**（任何停采 sync 都不报断流），非 concept_sync 专属。按字面整段删除：① `test_no_enabled_rows_fail_open`/`test_disabled_sync_excluded_from_stale` 双双失效；② 未来停采任一 TIER1 sync 回归「永久 stale 误报」。
**处置**：保留 enabled 过滤，仅删「TRANSITION-0129」措辞 + 更新列表与注释，明确「过滤是常设守卫，非过渡补丁」。

**P1-114a｜产出 4「铃铛侧冻结告警信号源单向化」机制未定义且语义混淆。**
task_blind（`monitor.py:186-190`）是**盲视观测**，其 `frozen` = `frozen["now"] = 盲视 or sticky`（`hub_worker.py:463`），**含盲视动态态**（盲视不落 F1，`hub_worker.py:452`）。「归一到 F1」按字面执行＝**丢盲视告警（静默漏检）**；heartbeat 字段是单 bool，无法在 task_blind 层拆「盲视 vs sticky」。
**处置**：明确「单向化 ≠ 删 task_blind」；冻结入口由新图标承载，task_blind 保留为盲视观测；若真要拆信号须先在 heartbeat 拆两字段——那是另一批，不进本批。

**P1-113/114b｜验收「组件测试」无 harness（两批共享）。**
`web/package.json` 无 test script、无 vitest、全仓无 `*.spec.js`。mock 方式「前端组件测试 mock 冻结史接口」无可执行载体。对齐八步法 W2/前端交付规约：可执行门= `npm run build` + `scripts/smoke-web.sh`（机器级结构断言）+ 人工视觉验收；若坚持组件测试须先建 harness（超出限定范围）。

**P1-113a｜跳转接线未定义（契约关键点推给编码期）。**
「task 卡片」实为 `ConnectionCards.vue:24-32`（Observe 运行状态页签，admin-only），跳 `LiveTask.vue` 展开行是**跨页导航 + 自动展开指定行 + loadFreeze**，现有代码无深链/自动展开机制。方案写「具体组件与跳转目标在编码期据主案落点定位」= 把契约点后移。**处置**：明确跳转机制（路由参数深链 vs 就地弹窗复用 freeze-events 接口）。
