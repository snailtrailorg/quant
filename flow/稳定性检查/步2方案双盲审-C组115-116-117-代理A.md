## 严重（P1）

**P1-1【批 115】单源切换的真源不一致处置缺失**：产出 2"读侧改读 sync_kind_config，代码常量退役"，但**没写**：若 `sync_kind_config.float_cols` 与 `_TIER1_FLOAT_COLS`（engine.py:3144/3157）历史漂移不一致，以哪边为真源、差异行怎么处置（对齐方向、是否需迁移修正 DB）。已有旁证说明漂移是**真风险**：tushare_adapter.py:771-774 注记明示 `nums` 定义面"**非** sync_kind_config.float_cols"（POOL_DATA_TYPES core 键集含 text 型列）——两套语义**已知不同**，收编时 DB 侧值直接当真源会静默改变 pool_data 族落库语义。这恰是决策 C 要防的事，任务文件却只写了执行顺序没写裁决规则。**修法**：产出 1（数据语义清理）须先产出**差异对账报告**（代码常量 vs DB 逐族 diff）+ 每处差异的裁定方向，作为切换输入。

**P1-2【批 115】真库往返验证无验收命令**：验收写"真库往返验证：清理前后语义一致（不许只加测试）"，但没给可执行命令/判据（对哪张表、比什么、什么算"一致"）。八步法"验收可验性预审"要求每条验收问"按给定方法测得到吗"——当前答案是否。参照系：test_batch107_supply_literals.py:158-165 已有 `sync_kind_config` ↔ 代码内联 dict 对账测试的先例可引。**修法**：验收补具体命令（如：清理前 dump 全族 float_cols/text_cols 快照 → 切换后同一查询比对 + 抽 N 表 row 级类型对账）。
