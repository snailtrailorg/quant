## P0（阻断）

**P0-1 pip-audit rc 语义反转——有漏洞时功能整体失效**（security_collector.py:201）
- 实测：`venv/bin/python -m pip_audit -r <已知漏洞 requirements> --no-deps --format json` ⇒ **rc=1** 且 stdout JSON 完整（requests==2.31.0 出 6 漏洞）；requirements.lock 现状全绿才 rc=0。pip-audit 约定：0=无洞、**1=有洞**、2+=错误。
- :201-202 `rc != 0 ⇒ raise` 把「有漏洞」（唯一需要工作的时刻）当采集失败 ⇒ vulns 分区 degraded ⇒ :429 不 upsert ⇒ **security_finding 永远为空、新漏洞告警永远不触发**。批 120 目标 2（漏洞比对自动化）名存实亡。
- 测试盲区根因：test_vulns_degraded_on_nonzero 恰用 rc=1 当失败样本——把真语义钉反了。
- 修复方向：rc∈(0,1) 均解析 stdout；rc≥2 才 degraded。

**P0-2 snapshot 端点默认路径 500——前端安全 Tab 不可用**（routes/security.py:71-73）
- 参数 `date: str = ""` 遮蔽模块级 `from datetime import date`；无参调用时 `date.today()` 调在 str 上 ⇒ AttributeError ⇒ 500。
- 实测：TestClient `GET /api/security/snapshot`（无参）⇒ **500**。SecurityTab.vue:141 `getSecuritySnapshot()` 无参=前端唯一入口 ⇒ **线③整页只显示警示区**。
- 测试全带 `params={"date":...}` 绕过了默认路径，守门无覆盖。修复：参数改名或显式 `import datetime`。
