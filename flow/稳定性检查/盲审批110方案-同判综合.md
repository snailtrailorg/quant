## 二、收敛项（双方独立同判 ⇒ 高置信，逐条裁断）

- **C1｜产出 D「成本由 scope 数决定」是假陈述**（A:P1-2／B:P1-1，独立同判）。
  **裁断：采纳，且不按「改措辞」收口——按「真批量」收口。** 理由（架构）：若对账的成本契约含 O(标的数) 的 DB 往返，则其时间上界随「宇宙规模」漂移，而任务时限是**常数** ⇒ 契约不闭合；这正是本批要闭的那条。⇒ 产出 D 改为「**读侧探针与状态同步侧一并按 scope 批量**」，并从陈述与验收中**彻底去掉 O(标的数)**。实测支撑见 §四 E1。
- **C2｜产出 A 把 inception 由 adapter 活体改读 SM，引入快照依赖**（A:P1-1「OKX 反向退步」／B:P1-3「scope 级 stale 闸不覆盖 per-symbol 新标的」）。
  **裁断：保留改读 SM（依赖方向正确），但必须补三件**——① **SM 覆盖率进每轮摘要**（`sm_covered/sm_total`）；② 两类缺**分开登记**：「SM 有该 symbol 但 `list_date` 空」＝显式未知（`uncertain(inception_unknown)`）／「SM **无**该 symbol」＝快照不完整（**响亮告警**，不得沉默降级）；③ 互证闸的比对对象＝`sm_inception`（B:G2），不是 adapter。
  不采「回退活体」：① 裁定 G① 已定「inception 可读点＝SM」（活体只是**生产者**）；② 对账是**本地审计动作**，读外部 API ＝ 依赖方向错；③ 活体路径对 tushare/joinquant 恒 `None`（事实 6）⇒ 对 astock 族本不可行。
- **C3｜结论 2「binance 结构性不可做」措辞过强**（A:P1-3／B:G3）。
  **裁断：改措辞、不改实质**——改为「在 §F（真上币日不可得）未解的前提下本批不做；前置＝**Binance 标的级生命周期真值**，或 §5.4 抑制语义细化为『有界盲区登记』」。**同时驳回 A 的核心反驳**（见 §三 D2）。
- **C4｜R2 的 P-2 不成立**（B:P1-2「把主同步补齐的正常 closed 误判为误报」；A 亦指其被 P-1 覆盖）。
  **裁断：删 P-2。** 保留 P-1（同轮振荡）、P-3（抑制失效）；第四类「窗口错配产生的**自洽**假缺口」**不可自动判定** ⇒ 明确记为判据的**诚实边界**，由金标准正负对照兜底（B:G6 同结论）。
- **C5｜R7 时限取值**：双方一致——**本批先落显式声明**（消除「隐式继承全局 300」这一沉默态），具体值挂实测（B:G4 指出与观测互锁会致长期不落，采纳）。

## 三、分歧与仲裁

- **D1｜`_GAP_JUDGE_ROUNDS` 落 DB（A）vs 代码常量（B）** ⇒ **仲裁：代码常量，A 不成立。**
  依据母设计 §三判据逐字：「换一个任务就不同 → 定义层 DB；**同类任务共享 → 代码按 kind 给默认**；连上某源才需要 → 接入层」。N 是**所有对账 scope 共享的同一阈值**（判据性质，非任务个性）⇒ 属「同类共享」。且 §四「定义层 DB」的承载物清单（任务身份/调度/开关/provider/游标/retention/列形状/`sync_gap`）**不含任何判据阈值**；§十 C 的「不设全局值、按族/kind 定义」针对**能力集**，非同族阈值。
  ⇒ 补一条约束：**N 必须显式声明且进可观测摘要**（否则判据不可复核）。
- **D2｜「`unreachable` 盲区登记即可解 Binance」——A 与 B 同向提出，主会话纠回：不成立。**
  盲区登记（§5.3-3）解的是**全族共有的**盲区 `[inception, source_earliest)`——它要求 inception **已知**才能算出该区间的**起点**；而 Binance 的问题恰是 inception **未知**。更关键：即使按「下界＝`source_earliest`」对账，对**晚上币标的**会产生**逐标的假缺口**（标的 2024 上市、期望集自 `2019-12-31` 起算 ⇒ 全段皆「缺」）。而用「本地首日」当 per-symbol 下界恰恰被母设计 §八.2 明令排除（对**整窗 0 行**标的失明——OKX 7/485 的形状）。
  ⇒ **「有界盲区」这个描述本身不成立**：它不是「一段共有盲区」，而是「per-symbol 的假缺口面」。故结论 2 的**实质成立**，仅**措辞**按 C3 软化。

## 四、主会话独立复核（只列新增证据，不引用双方结论）

- **E1｜实测成本（一手，dev 真库）**：复刻 `_local_dates` 的查询形态，`bar_1d`（17.5M 行 / 9088 标的，索引 `bar_1d_symbol_ts_key(symbol, ts)` 在位）：
  - 逐标的：60 次 **0.293s ⇒ 4.88 ms/次**；折算 9088 标的 ≈ **44.3s**（**仅此一步**）。
  - 批量（`GROUP BY symbol` 一次）：9088 标的 **0.470s**（返回 243,805 行）。
  - ⇒ 批量化在该步约 **94×**；且逐标的方案下 `_reconcile_symbols` 有 ≥3 个这样的往返 ⇒ 支撑 C1「真批量」而非改措辞。
- **E2｜新增必修：`hit_rounds` 的递增不足以证明「连续」**（两审均未提）。
  若某轮该 scope **未跑**（skip／error／引擎异常早退），旧行 `hit_rounds` **既不增也不归零** ⇒ 判据会把**中断的观测**当作**连续命中**，「连续 N 轮」退化为「累计 N 轮」。
  ⇒ 必须引入**轮次身份**：每轮生成单调 `round_id`，行上记 `last_hit_round`；判据 ＝ `hit_rounds ≥ N` **且** `last_hit_round == 本轮 round_id`。观测窗的**轮次边界**也须可复核（同一 round_id 写进 journal 摘要）。
- **E3｜新增必修：minute 族的成本/体量上界未评估**（两审均未提）。
  `astock_minute`/`astock_minute_5min` 一旦启用，`bar_1min` 每标的行数远大于日线（E1 的 4.88ms 是日线口径）⇒ 逐标的 DISTINCT 扫描将高若干量级；且 `sync_gap` 落表行数可达「标的 × 缺口段」量级。
  ⇒ 需**按族设体量上界 + 超阈响亮拒绝**，并把「启用 astock_minute 前先评估对账体量」写成前置条件（否则启用当日即触发不可控的长轮＋落表膨胀）。
- **E4｜软时限直抛的语义须明写**（A 提出，主会话确认）：`SoftTimeLimitExceeded` 直抛后**中止整轮**（失去 per-symbol 隔离）⇒ 契约须写「超时＝整轮放弃、幂等、下轮续」，防后人误以为单标的隔离仍在。
