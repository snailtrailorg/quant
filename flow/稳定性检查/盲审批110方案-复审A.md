## 一般 / 陷阱核对
- **round_id 单调性脆弱**：v2:81/87 取「本轮开始 Unix 秒」。beat 重入/手动同秒重跑→同 `round_id` 碰撞→可能双计或判据 `==本轮` 误过；NTP 回拨可非单调。建议 `round_id` 加「(日期,beat 序号)」或 DB 自增防重。
- **「SM 无 symbol」per-symbol 可行性**：对账循环只遍历 `sm_rows`(`engine.py:1828`)，无外部源 universe → per-symbol「SM 缺该 symbol」实际只能 scope 级空检测(v2:1816-1821 已有)；两类型粒度须对齐说明，避免实现时退化为仅 scope 级。
- **N6 漏报取舍**：超阈「不落主张」＝该 scope 当轮漏报，靠 `budget_exceeded=1`+告警非静默；但这本质是「漏报换稳定」，应在判据节显式承认并规定「budget_exceeded 的 scope 其判据不许过门」（与 N2 覆盖率<1 同制）。
- **下游依赖自洽**：后续批（按族删冻结）依赖本批 `hit_rounds/last_hit_round` 列＋2026-10-11 起观测。若 P1-a 带病落地，后续批将基于假连续删冻结→不可逆。故 P1-a 须在定稿前修。
- **四维判据**：单一真源✓（G①收编 `sm_inception`）；依赖方向⚠（互证闸仍依赖 SM 快照新鲜度，§九.1 残留，见 P1-b）；职责层级✓（`_GAP_JUDGE_ROUNDS/_GAP_ROW_BUDGET` 代码常量符 D1 先例，`_RECONCILE_UNKNOWN_INCEPTION` 事实常量＋互证闸可接受）；契约闭合⚠（N3 判定式缺陷削弱）。
- **与既有制度无硬冲突**：迁移 0141 expand-only(`ADD COLUMN IF NOT EXISTS`)✓；`schema_expectations` 列形状门(v2:185)✓；禁读闸（仅 SELECT/quant-journal）✓。
