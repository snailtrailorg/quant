## 三、分歧与仲裁（**本轮核心**）

- **D2-1 争点**：Binance **日包**可达下界是否早于月包 floor `2020-01`？
  - **A2**：实测**日包 floor = `2020-01`**（＝月包 floor），BTCUSDT `2019-09~12` 全 404 ⇒ v2 的 `source_earliest=2019-09-08` **错**，会使 §5.3 unreachable 对早上市标的永不触发 ⇒ **永久 phantom gap**。
  - **B2**：判 P0-2 **闭合**，称 `2019-09-08` **三证吻合**（`_pull` docstring / 迁移 `0132` / DB）。
  - **仲裁（主会话直接实测，不采信任何一方）**：

    | 探测 | 结果 |
    |---|---|
    | 日包 `BTCUSDT-1d-2019-09-08.zip` | **404** |
    | 日包 `BTCUSDT-1d-2019-12-01.zip` | **404** |
    | 日包 `BTCUSDT-1d-2019-12-30.zip` | **404** |
    | 日包 `BTCUSDT-1d-2019-12-31.zip` | **200** |
    | 日包 `BTCUSDT-1d-2020-01-01.zip` | **200** |
    | 月包 `BTCUSDT-1d-2019-09.zip` | **404** |

    ⇒ **A2 正确**：日包真实下界 = **`2019-12-31`**（与月包几乎同期，**不是** `2019-09-08`）。

  - **🔴 方法论要点（本轮最值钱的教训）**：B2 的「三证吻合」是**同源三证**——`_pull` docstring、迁移 `0132` 注释、DB `start_floor` **三者都是从同一个假前提派生的**（0132 的注释与代码 docstring 互相引用，DB 值由 0132 写入）。**同源 ≠ 交叉**。①轮的教训是「两代理一致也不等于对」；②轮补一条：**「多份证据一致」也不等于对——须先问它们是否独立**。
  - **实情更狠**：`_pull` docstring（binance_adapter.py:246-249）「若无条件抬到月包起点会**静默丢掉 2019-09~2019-12 的逐日历史**」——该区间**确实存在**（REST klines 可给），但**批量 S3 拿不到**。⇒ 现状不是「代码丢数据」，而是「批量源本就没有」＋「省流阀分支（:255-263）依据假前提，对 `start_floor=2019-09-08` 的长区间会**静默发起约百次必 404 的日包请求**」——所谓省流阀，实为**费流阀**。

- **D2-2 待裁点 B 的另一面（主会话新增）**：`start_floor` 不是「一列两义」，是**一列三义**（DB 实测）：`binance_perp_daily=2019-09-08`（**上币日/inception**）／`okx_perp_daily=2020-01-01`（**源下限**，0137 明写「实测 K 线边界」）／`hourly=2026-09-29`、`15min`/`1min=2026-10-05`（**retention**）。⇒ v3 新增待裁 **H**。

## 四、主会话独立复核（新增证据）

- **M-1 `start_floor` 一列三义**：见 D2-2。且**无法用规则自动判语义**（同 provider 内部即三种）⇒ 只能逐行判，v3 §2.6 / §十 B / §十 H 三处明写。
- **M-2 `0137` 是被忽略的**「先例富矿」**：它已写明 (a) `listTime` **不是**数据下界（BTC/ATOM `2019-11-12`、FIL `2019-08-10`，而 K 线 2019 全空）；(b) 「`start_floor` 只填**已实证**下界、其余 NULL，**不臆造**」；(c) `0136` **故意**留 NULL 等实测。⇒ **待裁 F 与「源界须实测」不是新规矩，是本仓既有纪律**；v3 已引 0137 为 F 的先例（§2.5 / §十 F）。
- **M-3 本轮 P0 原理的实证反而更强**：可达性 ≠ 上币日，现有**两手独立实证**——OKX 差 **≈2 月**（`2019-11-12` vs `2020-01-01`，prod 实测）、Binance 差 **≈4 月**（`2019-09-08` vs `2019-12-31`，主会话实测）。①轮是靠**假 docstring** 论证，②轮换成**真测量**，结论同向更硬。
- **M-4 `_CRYPTO_TAIL_GRACE` 的替代物已存在**：`_pull` docstring 自己就写了「文件 404（未发布/该日无包）→ 空帧，不是异常（T+1 滞后是常态）」⇒ `publish_lag` 有现成语义落点，v3 §6 收编方向不变。
