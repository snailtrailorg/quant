## 三、分歧与仲裁

### 分歧 1 —— P0-D 的分级与修法 ⇒ **采纳 A4 的 P0；修法采纳主会话版（两人版不闭合）**

- **分级**：B4 的降级理由「非本轮引入、非回归」只对 **P0-C** 成立（相对 `55b5e1e` 确实零缩小，主会话 30k fuzz 亦得 0）；但相对**最初基线 `9fa0e7f`** 实测 **6 例缩小**且全部发生在 `55b5e1e` 就已是 0 ⇒ **由步 3-c 的 P0-B 引入**。按本轮自己立的判据（修复不得缩小检测面）与既有纪律（「当前无实例」「约定」**不得**用于把已可复现的静默绕过降级）⇒ **P0**。
- **修法**（主会话实测三口径对比表，见四 C2）：

  | 修法 | 逗号并列 4 例 | **空格分隔 2 例** | 真排除 5 形态 | 全仓 |
  |---|---|---|---|---|
  | 现状（`[^;\n]*`） | 0 ✗ | 0 ✗ | 0 ✓ | 16/33 |
  | A4 / B4（`[^,;\n]*`） | 1 ✓ | **0 ✗** | 0 ✓ | 16/33 |
  | **主会话（单 action 形态 `ALTER\s+COLUMN\s+\w+\s+SET\s+DEFAULT\b`）** | 1 ✓ | **1 ✓** | 0 ✓ | **16/33** |

  ⇒ **采纳主会话版**：两名复审员的 `[^,;\n]*` 只禁**逗号**，而空格分隔子类（`ALTER COLUMN c DROP COLUMN c set default 1`）仍被整段吃掉——那正是 fuzz 相对最初基线丢失的样本。**单 action 形态**（`ALTER COLUMN <列名> SET DEFAULT`，中间只允许一个标识符）同时闭合两个子类，且 0095 真实形态（`ALTER COLUMN dataset_version SET DEFAULT 2`）仍豁免。

### 分歧 2 —— `DROP DEFAULT` 的措辞（A4「有条件同意」）⇒ **采纳 A4 的修正**

`DROP NOT NULL` 无条件收紧；`DROP DEFAULT` 是否破坏取决于旧代码是否省略该列。⇒ 措辞由「收紧类」改为「**保守归入（方向＝fail-closed），是否真破坏由两步走声明举证**」，避免将来被当错判拆掉。结论不变（不进排除表）。

### 分歧 3 —— 排除项 #3 保留还是移除 ⇒ **保留 + 收窄**

判据：规范 §1.3 明列该豁免 ⇒ 移除会造成**另一处**「声明面 ⊋ 执行面」。收窄后它仍是**形态级**豁免（单 action），符合 §1.3 语义，且不再是漏洞面。
