## 一般 / 陷阱核对

- **`\w+` 列名覆盖**：`ALTER COLUMN "c" SET DEFAULT 1`（引号）与 `… s.c SET DEFAULT 1`（带 schema）⇒ 排除项**不命中**，
  方向 **fail-closed**（与真破坏并列时仍红：`"c" SET DEFAULT 1, DROP COLUMN d` ⇒ 1）⇒ 只假红、**不漏**。
  可选收紧：`\w+` → `[\w".]+`（实测全仓仍 16/33、真排除仍 0）。下划线/大写/`c_1`/数字打头均正常。
- **豁免通道等价路径再穷举**（全部实测，无新洗白路径）：`SET DEFAULT (SELECT …)` ⇒ 0（语义内）；
  `SET DEFAULT 1; DROP TABLE x` ⇒ 1；`SET DEFAULT 1, DROP DEFAULT` / `, DROP NOT NULL` ⇒ 1；
  `SET DEFAULT 1, DROP CONSTRAINT ck` ⇒ 0（正确）；`SET DATA TYPE int` ⇒ 1；
  `alter  column\tc\tset\tdefault 1`（tab/多空格）⇒ 0（豁免正常）；三引号多行逐行扫描 ⇒ `DROP COLUMN d` 命中 1。
- **rc=1 语义唯一性**：非法 UTF-8 ⇒ rc=2（新旧同）、单文件 `chmod 000` ⇒ rc=2、用法错 ⇒ rc=2、prev 不存在 ⇒ rc=3、真命中 ⇒ rc=1。
  本轮仅改一条正则字面量 ⇒ 不可能把内部错落进 rc=1，实测亦无。
- **S7m 判别力**：模块 CLI 复现（`--check-release`）⇒ 三个历史模块 **rc=0**、当前 **rc=1**；`bash -n` 过；S7 行数为 **13**（7a–7m）与注释一致。

  未记本轮步 3-e / 复审轮三裁定；亦未见本周进展条。收工前补齐（CLAUDE.md「收工前必做」）。
