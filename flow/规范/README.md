# flow/规范/ — 规范索引

> 本目录是**规则的单一真相源**。`CLAUDE.md`「详规索引」是面向运行时的精简版，这里是完整版。
>
> **改规范的铁律**：规范属**状态文档**——改就**重写整篇使其自洽**，不在末尾追加变更时间线（见 `工作流程.md` §三「两制式」）。

## A. 流程与规则（本仓现行体系）

| 文件 | 管什么 | 什么时候读 |
|---|---|---|
| `工作流程.md` | **项目主流程**（§一 立项→规划→迭代交付→沉淀→验收/演进）＋ **单任务流程**（§二 取项→设计先行→任务文件→挂行→收口）/ 两制式 / 分层归属 | 规划时 · 接新任务时 |
| `任务模板.md` | **任务文件写法**：8 字段 / 引用 vs 复述判据 / 粒度 / mock 库 | 写 `flow/任务/批xxx.md` 时 |
| `八步法.md` | **单任务流程的强制门禁**：方案双盲审→编码→代码双盲审→单测→提交→部署→集成测试（顺序强制） | 开工前 |
| `文档维护SOP.md` | **真相源文档**（`CLAUDE.md` 体系）写什么 / 不写什么 / 写到哪层 | 动了结构或约定时 |
| `异常处理规范.md` | `except` 块守门（S110/S112）：静默吞异常必须显式声明理由 | 写 `except` 时 |
| `术语表.md` | 压缩词 → 白话释义（**唯一词源**） | 读进展日志遇到生词时 |
