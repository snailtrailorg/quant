# 任务模板（待办写法规范）

> 目标：每个待办**自包含**--仅读「本模块契约 + 接口契约字典 + 本任务节」即可动手，不用读整个项目。
> 配套：`docs/architecture/接口契约.md`（跨模块签名）+ `docs/architecture/模块契约/<module>.md`（本模块 public/内部 API + 依赖 + 被调 + 读写表）
> 适用：新待办（A2 起）按本模板写；旧待办（#1-#42）逐步补。

---

## 一、8 字段模板

每待办一节（`待办.md` 内一节 或 `docs/任务/<id>.md` 独立文件）：

```markdown
### #X 任务名
- **目标**：一句话（做什么，产出什么）
- **依赖（就绪）**：前置条件（哪些待办 ✅ / 哪些接口已实现）。未就绪标"待 #X"
- **产出**：改哪些文件 + 新增什么（接口/表/端点/单测）
- **限定范围**：只改 X/Y/Z，明确不碰 W（防越界）
- **接口契约**：本任务涉及的签名--新加的给全；调用的现有给签名 + 位置（文件:行）；引用接口契约字典 §
- **验收标准**：可执行命令（pytest path + import 检查 + 验证脚本）+ 预期结果
- **mock 方式**：patch 哪个路径 + fake data 样例（见 §二 mock 库）
- **参考文档**：≤ 2 份（接口契约 §X + 本模块契约 / 指定读哪个文件哪段）
```

**字段填写要点**：
- **依赖**：只列就绪的；未就绪标"待 #X"（表明该任务被阻塞，不能立刻做）
- **限定范围**：越严越好（"只改 db.py 的 save_bars 函数"优于"改 db.py"）--降低越界风险
- **接口契约**：新加签名给全（含类型）；现有调用给签名 + 文件:行（让任务作者不用翻代码找签名）
- **验收**：必须可执行（pytest 路径 + python -c import + alembic 命令）；避免"测试通过"这种模糊表述
- **参考文档**：硬上限 2 份--逼任务聚焦本模块，避免"读整个项目"

## 二、mock 模式库（A1 实测验证）

> pytest + `unittest.mock.patch`，不连真实 DB/Tushare/LLM。conftest 提供 gateway fixture。

### mock Tushare（数据源）
```python
from unittest.mock import patch
import pandas as pd

fake_df = pd.DataFrame([{
    "ts_code": "600000.SH", "trade_date": "20260808",
    "open": 10.0, "high": 10.2, "low": 9.9, "close": 10.1,
    "vol": 1000.0, "amount": 10000.0, "adj_factor": None,
}])

with patch("src.data_platform.adapters.tushare_adapter.pull_daily", return_value=fake_df):
    ...
# 分钟线用 pull_minute（trade_time 列，非 trade_date）
```

### mock DB（save_bars / get_conn）
```python
# 不写真实 DB：patch save_bars 返回行数
with patch("src.data_platform.db.save_bars", return_value=1) as m:
    ...
    assert m.call_args.args[0] == "1min"  # 验证 freq

# delete_symbol 等用 get_conn：MagicMock 上下文
mock_conn = MagicMock()
mock_conn.__enter__.return_value = mock_conn
mock_conn.execute.return_value = MagicMock(rowcount=5)
with patch("src.data_sync.engine.get_conn", return_value=mock_conn):
    ...
```

### mock Celery（异步任务）
```python
with patch("src.scheduler.tasks.sync_via_celery.delay") as m:
    m.return_value = MagicMock(id="task-abc")
    response = client.post("/api/sync/trigger/astock_daily")
    assert response.json()["task_id"] == "task-abc"
```

### mock LLM
```python
# conftest 已有 gateway fixture（mock _load_models_from_db）
def test_xxx(gateway):
    with patch.object(gateway, "chat", return_value=LLMResponse(content="OK")):
        ...
```

### mock engine 内部函数（per-symbol 测试）
```python
with patch("src.data_sync.engine._list_static_ts_codes", return_value=["600000.SH"]), \
     patch("src.data_sync.engine._get_pro_api",
           return_value=(MagicMock(), MagicMock(), "astock", "1min", "minute")), \
     patch("src.data_sync.engine._local_bar_range", return_value=(None, None, 0)):
    ...
```

### mock 规则
- patch **调用方导入的路径**（如 `src.data_sync.engine.get_conn`，不是 `src.data_platform.db.get_conn`）--函数内 `from X import Y` 每次重查模块属性，patch 模块属性有效
- fake data **对齐真实接口返回**（列名/类型）--A1 的 `to_save_rows_min` bug 就因 fake df 缺 `trade_date` 列没暴露
- 测试**不连真实服务**（DB/Tushare/LLM/Valkey），全 mock

## 三、任务粒度原则

- **一个任务一个焦点**：能独立验收（一个 pytest 文件 + 一两条命令）
- **限定范围 ≤ 3 文件**：超出说明任务太大，应再拆
- **依赖明确**：前置待办 ✅ 才能做；未就绪标"待 #X"
- **mock 能做**：任务必须能 mock 测试（若必须连真实服务--如 C2 服务器 XTP--标"服务器测前置"）
- **验收可执行**：pytest 路径 + import 命令 + 预期数字

## 四、A2 试写示例（验证自包含）

> 用 A2（数据质量校验，#30）演示模板。这是"只读接口契约字典 + 本节 + db.py save_bars"即可动手的样本。

```markdown
### A2 数据质量校验（#30）
- **目标**：save_bars 入库前校验（剔 ohlc=0 行 + 标 ts 断点 warning，不剔断点）
- **依赖（就绪）**：db.save_bars ✅（db.py:55，写入 bar_<freq> 表）
- **产出**：db.py 加 `validate_bars(rows)` 函数 + save_bars 开头调 `rows = validate_bars(rows)`；tests/test_validate_bars.py
- **限定范围**：只改 db.py（加函数 + save_bars 一行调用）+ 新建 tests/test_validate_bars.py；不碰 schema.py / engine.py / main.py
- **接口契约**：
  - 新加：`validate_bars(rows: list[tuple]) -> list[tuple]`（剔 open/high/low/close=0 的行；ts 断点记 warning 不剔）
  - rows 结构（11 字段元组）：`(vt_symbol, freq, ts, open, high, low, close, volume, amount, adj_factor, source)`（见接口契约 §Bar）
  - 现有调用：`save_bars(freq: str, rows: list[tuple]) -> int`（db.py:55，开头加 `rows = validate_bars(rows)`）
- **验收标准**：
  - `pytest tests/test_validate_bars.py`（剔0 / 断点标记不剔 / 正常行全保留 3 例过）
  - `python -c "from src.data_platform.db import save_bars, validate_bars; print('OK')"`
  - 全套不回归：`pytest tests/ -q`（63+3 过）
- **mock 方式**：
  - `rows = [("600000.SHSE","1D",ts,0,0,0,0,100,1000,None,"tushare")]` -> validate_bars 剔除（ohlc=0）
  - `rows = [("600000.SHSE","1D",ts,10,10,10,10,100,1000,None,"tushare")]` -> 保留
  - 纯函数测，不连 DB
- **参考文档**：接口契约 §Bar §三② validate_bars；模块契约 `data_platform` §一 save_bars（`docs/architecture/模块契约/data_platform.md`）
```

**自包含度验证**：A2 只需读「接口契约 §Bar/§三② + 模块契约 data_platform §save_bars」即可动手，**不读 db.py 代码**。三层配套已齐（接口契约 + 模块契约 + 任务模板），A2 验证通过：做任务时零代码阅读。
