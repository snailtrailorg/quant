# 任务模板（任务文件写法）

> **立论（2026-10-04 重写整篇；起因＝威廉姆方法论断，见 `flow/decisions.md`）**：任务文件是**执行规格**，不是设计文档。它只做两件事——
> ① **实施步骤与验收写全**——这是它的正文，读者照它就能干活；
> ② **设计 / 方案一律引用**——指向 `docs/architecture/`·`docs/design/`·`flow/方案/` 的具体章节，**不复制**。复制＝造第二真源＝改一处忘一处即失准。
>
> **与「自包含」的关系**：旧版立论是「自包含、零代码阅读」。那个目标仍然成立，但它指的是
> **契约层面的自包含**（接口签名 / 表结构 / 读写表写全，读者不必翻代码），**不是**把设计文档复述一遍。
> 二分即：**契约写全 ＋ 方案引用**。
>
> 配套：`docs/architecture/接口契约.md`（跨模块签名）+ `docs/architecture/模块契约/<module>.md`（本模块 public/内部 API + 依赖 + 被调 + 读写表）。流程归属见 `工作流程.md`。

## 一、8 字段模板

每待办一个文件：`flow/任务/批xxx-描述.md`（批号命名，被 `flow/待办.md` 索引；完成后归档 `docs/obsolete/任务归档/`）。

````markdown
# 批 <编号> · <一句话标题>

> 立项 <日期>（谁裁定）。来源＝<哪个勘察 / 哪些实证照出来的>。
> 关联：<关联批次> · <设计文档锚点>

## 目标
一句话：做什么、做完什么样算成功。

## 现状（已实证）
| # | 事实 | 锚点 |
|---|---|---|
| 1 | …（写观测到的事实，不写推测） | `path/file.py:123` ／ 命令输出 |

## 依赖（就绪）
<前置条件：哪些批 ✅、哪些接口 / 通道已具备>；未就绪标「待批 X」。

## 引用（设计 / 方案）
- `docs/architecture/A0x-….md` §N —— 本任务遵循它的哪一条
- `flow/方案/xxx.md` §N —— 同上
（**只给指针，不复述内容**）

## 产出
改哪些文件 + 新增什么（函数 / 表 / 端点 / 单测）。

## 限定范围
只改 A / B / C；**明确不碰** D / E / F（防越界）。

## 接口契约
- 新增：`f(x: T) -> R`（给全签名）
- 调用现有：`g(…)`（`file.py:123`，给签名 + 位置）

## 验收标准
可执行命令 + 预期结果。例：
- `cd server && pytest tests/test_xxx.py -q` → N passed
- `python -c "import …"` → OK
- 全套不回归：`pytest tests/ -q` → 全绿

## mock 方式
patch 哪个路径 + fake data 样例（见 §四）。
````

**字段填写要点**：

- **现状**：只写实证事实 + 锚点。**推测写进"待验"并标明**，不混入事实表（前科：拿推测当现状，整条因果反了）。
- **依赖**：只列就绪的；未就绪标「待批 X」（表明被阻塞，不能立刻做）。
- **引用**：这是本模板与旧版最大的差别。设计取舍**不复述**，给章节号（见 §二）。**硬上限 2 份**——逼任务聚焦。
- **限定范围**：越严越好（「只改 `db.py` 的 `save_bars`」优于「改 `db.py`」）——降低越界风险。
- **接口契约**：新增签名给全（含类型）；调用现有给签名 + `文件:行`（读者不用翻代码找签名）。
- **验收**：必须可执行（pytest 路径 + `python -c import` + alembic 命令），避免「测试通过」这种模糊表述。

## 二、引用 vs 复述：判据

| 内容 | 写法 | 为什么 |
|---|---|---|
| 设计取舍 / 方案论证 / 备选对比 | **引用**（给设计文档章节号） | 设计文档是它的真源；复述＝第二真源 |
| 接口签名 / 表结构 / 读写表 | **写全** | 属「契约自包含」——读者不该去翻代码 |
| 勘察得到的**事实**（现状 + 锚点） | **写全**（带 `文件:行`） | 它是本任务的**输入**，不是别人的结论 |
| 上产记录 / 五证 | **不写** | 属 `flow/进展/<周>.md` |
| 裁定理由 | **不写** | 属 `flow/decisions.md` |
| 踩过的坑 | **不写** | 属 `flow/踩坑记录.md` |

**反面教材**：把设计文档的「方案论证」整段抄进任务文件 → 设计文档一改，任务文件就成了错的说法，而没人会想起来同步它。

---

## 三、任务粒度原则

- **一个任务一个焦点**：能独立验收（一个 pytest 文件 + 一两条命令）
- **限定范围 ≤ 3 文件**：超出说明任务太大，应再拆
- **依赖明确**：前置待办 ✅ 才能做；未就绪标「待批 X」
- **mock 能做**：任务必须能 mock 测试（若必须连真实服务——如服务器 XTP——标「服务器测前置」）
- **验收可执行**：pytest 路径 + import 命令 + 预期数字

## 四、mock 模式库（实测验证）

> pytest + `unittest.mock.patch`，不连真实 DB / Tushare / LLM。conftest 提供 gateway fixture。
> 工作目录 `server/`，包根 `src`。

### mock Tushare（数据源）
```python
from unittest.mock import patch
import pandas as pd

fake_df = pd.DataFrame([{
    "ts_code": "600000.SH", "trade_date": "20260808",
    "open": 10.0, "high": 10.2, "low": 9.9, "close": 10.1,
    "vol": 1000.0, "amount": 10000.0, "adj_factor": None,
}])

with patch("src.data_platform.adapters.tushare_adapter.pull_daily", return_value=fake_df):
    ...
# 分钟线用 pull_minute（trade_time 列，非 trade_date）
```

### mock DB（save_bars / get_conn）
```python
# 不写真实 DB：patch save_bars 返回行数
with patch("src.data_platform.db.save_bars", return_value=1) as m:
    ...
    assert m.call_args.args[0] == "1min"  # 验证 freq

# delete_symbol 等用 get_conn：MagicMock 上下文
mock_conn = MagicMock()
mock_conn.__enter__.return_value = mock_conn
mock_conn.execute.return_value = MagicMock(rowcount=5)
with patch("src.data_sync.engine.get_conn", return_value=mock_conn):
    ...
```

### mock Celery（异步任务）
```python
with patch("src.scheduler.tasks.sync_via_celery.delay") as m:
    m.return_value = MagicMock(id="task-abc")
    response = client.post("/api/sync/trigger/astock_daily")
    assert response.json()["task_id"] == "task-abc"
```

### mock LLM
```python
# conftest 已有 gateway fixture（mock _load_models_from_db）
def test_xxx(gateway):
    with patch.object(gateway, "chat", return_value=LLMResponse(content="OK")):
        ...
```

### mock engine 内部函数（per-symbol 测试）
```python
with patch("src.data_sync.engine._list_static_ts_codes", return_value=["600000.SH"]), \
     patch("src.data_sync.engine._get_pro_api",
           return_value=(MagicMock(), MagicMock(), "astock", "1min", "minute")), \
     patch("src.data_sync.engine._local_bar_range", return_value=(None, None, 0)):
    ...
```

### mock 规则
- patch **调用方导入的路径**（如 `src.data_sync.engine.get_conn`，不是 `src.data_platform.db.get_conn`）——函数内 `from X import Y` 每次重查模块属性，patch 模块属性有效
- fake data **对齐真实接口返回**（列名 / 类型）——A1 的 `to_save_rows_min` bug 就因 fake df 缺 `trade_date` 列没暴露
- 测试**不连真实服务**（DB / Tushare / LLM / Valkey），全 mock
