# 02 · 编写策略

## 两种模式

| | DSL 模式 | Python 模式 |
|---|---|---|
| 适合 | 因子组合+阈值（无状态逻辑） | 自定义状态机/复杂逻辑 |
| 写法 | 选因子+权重+阈值+可选表达式 | Monaco 写 `on_bar(ctx)` |
| 状态 | 无状态（每 bar 独立） | `ctx.set_state(key, val)` 跨 bar |

## DSL 模式步骤

1. 管理 → **策略** → 新建 → 模式选 DSL
2. 因子配置：添加因子行——下拉选因子（显示类别）、权重 0~2、**参数子表单**（因子 params 展开的数值输入，如 n=20）
3. 信号聚合：threshold_buy（如 0.3）/ threshold_sell（如 -0.3）——加权得分越线触发
4. 可选 DSL 表达式行：窗口函数表达式（见 01 册）
5. 执行规则（三下拉，见下节）
6. 保存（自动做品类兼容校验）

## Python 模式步骤

写 `on_bar(ctx)`，返回 `ctx.buy()/ctx.sell()/ctx.hold()` 或 None：

```python
def on_bar(ctx):
    ma5 = sum(ctx.get_history(5)) / 5
    ma20 = sum(ctx.get_history(20)) / 20
    if ma5 > ma20 * 1.001 and ctx.get_state('trend') == 'up':
        return ctx.buy(volume=100)
    if ma5 < ma20 * 0.999:
        return ctx.sell(volume=100)
    return ctx.hold()
```

ctx 接口：`get_history(n)` 近 n 根 close 列表 / `get_full_history(n)` 完整 dict /
`get_param(k)` / `set_state(k,v)`+`get_state(k)` 跨 bar 状态 / `buy(volume, price_type)` / `sell` / `hold`。

**注意**：模块级变量每 bar 重置（沙箱每 bar 重建执行）——跨 bar 状态一律走 `ctx.set_state`。

## 执行规则三档（批次 1 起真实现）

| volume_type | 语义 | 例子 |
|---|---|---|
| SHARES | 固定股数（参数 volume，默认 100） | 每信号买 100 股 |
| PERCENT | 可用资金×百分比（volume_pct 默认 10%） | 100 万×10%÷price，整百股 |
| ALL_IN | **方向感知**：BUY=全部可用资金 / SELL=清仓该标的持仓 | 满仓买入/止损全卖 |

price_type：LIMIT（限价按当前 close）/ MARKET（市价）；order_validity：DAY/GTC。

**SELL 保底语义**：风控哲学 R-AV2——跌了能卖不能买。冻结/盲视期 BUY 拒、SELL 放。

## 品类约束

策略 type+symbol 决定品类（astock/etf/cb），因子有品类归属：
- 通用类（trend/meanrev/fundamental/custom）全品类可用
- 专用（double_low→可转债 / funding_rate→加密）仅本品类
- 保存时校验不兼容直接 400 FACTOR_INCOMPATIBLE
