# 04 · 实盘

## 三级开关（AND，任一关即拒单）

```
① .env ENABLE_LIVE_TRADING 总闸（服务器环境变量）
② Web 实盘分项（Risk 页——品种级）
③ 策略 backtest_verified（回测证据门）
```

Risk 页顶部有总闸状态提示——总闸关闭时分项开关全部无效（红警条）。

## 创建实盘任务

实盘任务 → 新建：
- **策略下拉只列已验证**（backtest_verified）——未验证的先走回测
- **标的**：搜索下拉（输入代码/名称片段，asset_static_info 实时搜索）
- **账户**：下拉（accounts 表绑定项）
- 初始资金 + 策略参数表单（parameter_defs 生成）

start 后 systemd 拉起 `quant-live-task@{id}` 子进程：tick→bar→因子→信号→风控→下单。

**实盘启停唯一入口=LiveTask 页**（Strategy 页旧启停已移除——批次 3 #22）。

## 双模式

| direct（默认） | hub 模式（任务参数 md_mode=hub） |
|---|---|
| 进程自持 XTP 行情+交易连接 | 行情从共享 hub（Valkey Streams），进程 TD-only |
| 内存较高（合约表全量） | 内存低（≤250M worker） |

测试期两模式交替过夜做 bar 双轨 diff（影子期验证）。

## 运行监控

- **管理 → 健康检查**：组件矩阵（unit 状态/依赖/hub/任务心跳）+ 健康事件流（30 天）
- 任务行：md 模式/bars 消费数/lag（距上根 bar 秒数）/frozen
- journal：`journalctl -u quant-live-task@{id} -f`（BAR 每分钟一行）

## 安全机制（自动，无需操作）

| 机制 | 触发 | 行为 |
|---|---|---|
| 下单时刻检查 | bar 停更>300s 或非交易时段 | BUY 拒/SELL 放 |
| sticky 冻结 | untrusted bar（断线失真）/流 gap | BUY 拒直到重启任务 |
| WAL+启动对账 | 崩溃重启 | 残留 submitting 单认领+在场单核对 |
| 持仓真相源 | 每 60s | position_snapshot 全账户券商真值（/api/position） |

## 风控

- Risk 页：熔断（halt/resume）/回撤限制/频次限制/杠杆上限
- 熔断触发 → 撤全部在场单 + 新单全拒（critical 告警到飞书）

## 常见告警对照

| 告警 | 含义 | 处置 |
|---|---|---|
| 任务 N 盲视 | hub 心跳丢失或 bar 停更 | 查 hub 状态；恢复自动解除 |
| 不可信 bar | 断线跨分钟失真 | 重启任务解冻（数据已丢） |
| tick 断流 | 行情源断 | 查 XTP/journalctl；确认后手动重启 |
| 持仓账实分离 | position_snapshot vs trade_log 差异 | 对账页看明细；底仓/场外单属正常差异 |
| schema 漂移 | 列级校验发现缺列 | alembic upgrade head |
