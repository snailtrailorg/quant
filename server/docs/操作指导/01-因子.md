# 01 · 定义因子

## 因子是什么

因子 = 每根 bar 算一个数的函数。策略引用若干因子加权聚合出买卖信号。
两类：**静态因子**（needs_history=0，只看当前 bar——可用于选股）与**动态因子**（needs_history>0，看历史窗口——仅策略）。

## 操作步骤

1. 管理 → **因子** → 新建
2. 填名称（创建后不可改）/类别/描述
3. params：JSON schema 如 `{"n": 20}`（数值型参数会在策略编辑页展开为可编辑输入框）
4. needs_history：函数需要的最大历史窗口长度
5. 写代码（Monaco 编辑器，Python 语法高亮）→ **校验代码** → **试算** → 保存

## compute(ctx) 接口

```python
def compute(ctx, n=20):        # 命名参数=可配置项（与 params 对应）
    # ctx.close/high/low/open_/volume  当前值（float）
    # ctx.history  历史 bar 列表 [{ts,open,high,low,close,volume}, ...]（旧→新，不含当前）
    closes = [h.get("close", 0) for h in ctx.history[-(n-1):]] + [ctx.close]
    return ctx.close / (sum(closes) / n) - 1   # 返回一个 float
```

## AST 沙箱限制（写代码前必读）

- ❌ 禁止 `import` 任何模块
- ❌ 禁用名称：`__import__ / open / exec / eval / getattr / setattr / globals / locals / compile / delattr / vars / input`
- ✅ 可用：算术运算、列表推导、白名单内建（`abs/max/min/sum/round/float/int/len/range/sorted/zip/enumerate`）
- 超限直接校验失败——**不能查数据库**（要外部数据的因子属平台扩展，不是用户因子）

## 试算（写完因子第一件事）

「试算」按钮用真实行情（600000.SHSE 日线近 60 根）逐 bar 喂你的 compute：
- 弹出折线图 + 统计（有效值/失败数/min/max/最新）
- 语法对但逻辑错（如除零后 None）→ 图上断点+errors 计数
- **试算通过≠回测通过**（回测还有品类兼容+参数校验），但试算不过的因子一定不能用

## DSL 表达式（策略里的轻量因子）

策略 DSL 模式可直接写表达式，支持窗口函数：

```
close / mean(close, 20) - 1        # 均线偏离
rsi(close, 14)                      # RSI
slope(close, 10) * 1000             # 斜率放大
```

白名单：`mean/std/max/min/ema/rsi/slope/avevol`（第一参必须是字段名 close/high/low/open/volume）；
标量函数：`abs/max/min/sum/round`。嵌套窗口和表达式入参（`mean(close/2,5)`）会报错——那请写自定义因子。

## 错误对照

| 现象 | 原因 | 处置 |
|---|---|---|
| 校验失败：禁用名称 | 沙箱限制 | 改写逻辑不依赖该名称 |
| 试算 errors>0 | 运行时异常（除零/索引越界） | 看图断点位置检查逻辑 |
| 策略启动"未知因子" | 名字拼错或未保存 | 因子页核对名称 |
| 删除提示 FACTOR_IN_USE | 被策略引用 | 列表"被引用"列查引用数，先从策略移除 |
